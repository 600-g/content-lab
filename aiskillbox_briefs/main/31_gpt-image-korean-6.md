## 따라하기

### 사용법 (공통)

1. ChatGPT 또는 Gemini 에 접속
2. 아래 6종 중 원하는 프롬프트 복사
3. 채팅창에 그대로 붙여넣기 (필요 시 디테일만 변경)
4. 결과 확인 → 미세 조정 요청

### 1️⃣ 운동 셀카 인스타 스토리

```
인스타그램 스토리에 운동하는 사진을 업로드한 한국인 여성 셀카 만들어줘
```

**디테일 추가 권장**:
- 운동 종목: "헬스장에서 덤벨 들고 있는" / "필라테스 매트 위에서"
- 의상: "검정 레깅스 + 크롭탑"
- 분위기: "운동 끝나고 거울 셀카" / "땀 살짝 흘리는"

### 2️⃣ 한강 마라톤 러닝 사진

```
인스타그램 스토리에 한강 마라톤 러닝 대회 나가서 뛰는 사진 올린거로 만들어줘
```

**디테일 추가 권장**:
- "번호표 1234 부착 / 결승선 통과 직전 표정"
- "한강 다리 배경 / 노을 시간대"
- "땀범벅 / 손에 생수통"

### 3️⃣ 이자카야 술자리

```
인스타그램 스토리에 친구랑 이자카야에서 술 한잔 하고 있는 사진 올린거로 만들어줘
```

**디테일 추가 권장**:
- "사케 도쿠리 + 잔 2개 / 안주는 닭꼬치·교자"
- "어두운 조명 / 노렌·일본어 메뉴판 배경"
- "맞은편 친구 표정도"

### 4️⃣ 외계인 청와대 습격 신문 (패러디)

```
외계인이 침공해서 청와대를 습격했다는 내용의 동아일보 신문 만들어줘
```

**디테일 추가 권장**:
- "헤드라인 큰 글씨 / 1면 톱"
- "외계인 UFO + 청와대 배경 일러스트"
- "기사 본문 일부 + 부제 + 발행일 2026.05.27"

### 5️⃣ 남자 단톡방 여행 계획 카톡

```
친구들이랑 단톡방에서 여행 계획짜는 카카오톡 대화 내용 사진 만들어줘.
남자 단톡방이야
```

**디테일 추가 권장**:
- "5-6명 / 닉네임 다양하게"
- "여행지: 강릉 / 일정: 6월 첫째 주말"
- "이모지 자연스럽게 / 농담·디스 섞기"
- "공지방 / 일정 정리 메시지 + 회비 정산"

### 6️⃣ 쿠팡 전용 상세페이지 (이커머스)

```
이거로 쿠팡 전용 세로 2500px 상세페이지 만들어줘.
한국에서 사용하는 뷰티 상세페이지랑 똑같이 만들어주고
모델 사진도 넣어줘
```

**디테일 추가 권장**:
- "타깃: 20-30대 여성 / 카테고리: 스킨케어"
- "후킹 헤드라인 → 사용감 → 성분 → 비교 표 → 후기 → 가격"
- "톤: 미니멀 핑크/베이지 / 한국 폰트"
- "모델 사진: 정면샷 + 사용 장면 2-3 컷"
