💡 이 스킬은 **Claude Chrome Extension 으로 브라우저를 AI 가 직접 조작**하게 만드는 자동화로, **여행 일정·문서 작성·데이터 분석·경쟁사 분석**부터 **Record Workflow + Scheduled Task** 로 매일 반복 작업을 단축키 하나로 처리합니다.

## 이게 뭔가요?

**Claude 가 사용자의 Chrome 탭에서 직접 검색·클릭·페이지 이동·정보 수집을 수행하는 확장 기능**. 다른 도구 없이 Claude 기본 기능만으로:

- 여행 일정 자동 생성 (구글 지도 기반)
- 로컬 맛집 / 쇼핑 / 현지인 장소 추천
- Google Docs / Sheets 자동 작성·분석
- 웹페이지 리서치·쇼핑·경쟁사 분석 자동화

**핵심 작동 원리**: Claude 가 항상 작업 전에 **"이렇게 진행하겠습니다." Plan(실행 계획)** 을 보여주고, 사용자 승인 후 검색·클릭·페이지 이동·정보 수집을 수행.

💰 유료 필요: **Claude Pro 이상** (Free 불가)
✅ 무료 대안: 없음 (브라우저 자동화는 다른 도구로는 별도 설치 필요)

## 따라하기

### STEP 1. 설치 (5단계)

1. **Chrome Web Store** 접속
2. **Claude** 검색
3. **Add to Chrome** 클릭
4. 브라우저 우측 상단 **Claude 아이콘** 클릭
5. **Claude 계정 로그인**

### STEP 2. 자동화 핵심 설정 3가지

- ✅ **현재 탭 접근 허용**
- ✅ **Claude 실행 계획(Plan) 승인**
- ✅ **Google 로그인 유지** (지도 저장 시 필요)

### STEP 3. 기본 여행 일정 생성

**STEP 3-A**. Google Maps 접속 → 도시 검색 (Tokyo, Osaka, Paris, Bangkok 등)
**STEP 3-B**. Claude 실행
**STEP 3-C**. 아래 프롬프트 입력

```
지금 열려 있는 구글지도에서 해당 도시의 주요 관광지와 맛집을 수집해서
3일 여행 일정을 자동으로 만들어줘.
조건
- 이동 동선 최소화
- 점심/저녁은 평점 4.0 이상 음식점
- 일정은 시간대별로 정리
- 각 장소 클릭 후 핵심 정보 요약
- 이동 시간 고려
우선 실행 계획(Plan)만 먼저 보여주고
내 승인 후 진행해줘.
```

Claude 자동 수행: Maps 관광지 검색 → 주요 장소 수집 → 각 장소 상세 페이지 클릭 → 맛집 검색 → 이동 동선 분석 → 최종 일정 생성.

### 여행 스타일별 프롬프트 3종

**📍 로컬 맛집 중심 여행**

```
지금 열려 있는 구글지도에서 관광지보다
현지 사람들이 많이 가는 맛집 중심으로 여행 일정을 만들어줘.
조건
- 평점 4.2 이상 음식점
- 체인점 제외
- 현지 인기 음식 중심
- 관광객 밀집 지역 최소화
- 이동 동선 고려
각 장소에 대해 대표 메뉴 / 평점 / 간단 리뷰 요약 을 정리해줘.
우선 실행 계획만 먼저 보여주고 내 승인 후 진행해줘.
```

**🛍 쇼핑 중심 여행**

```
지금 열려 있는 구글지도에서 쇼핑 중심 여행 일정을 만들어줘.
조건
- 인기 쇼핑 거리 / 편집샵 / 현지 브랜드 매장 / 쇼핑몰
- 휴식 가능한 카페
각 장소에 대해 어떤 쇼핑 / 평균 가격대 / 특징 을 정리해줘.
이동 동선을 고려해 하루 일정으로 구성해줘.
먼저 실행 계획만 보여주고 내 승인 후 진행해줘.
```

**🧭 현지인만 아는 장소**

```
지금 열려 있는 구글지도에서 관광객들이 많이 모르는 현지인 중심 장소를 찾아줘.
조건
- 리뷰 수는 많지 않지만 평점이 높은 장소
- 현지인 리뷰 비율 높은 장소
- 관광지 주변 숨겨진 스팟 / 로컬 카페 / 작은 음식점
각 장소에 대해 왜 현지인들이 많이 가는지 / 분위기 / 대표 메뉴 를 설명해줘.
동선을 고려해서 반나절 코스로 정리해줘.
```

### 🚀 숨은 기능: Workflow + Scheduled Task

**1️⃣ Record Workflow (워크플로우 기록)**

- 내가 브라우저에서 한 번 시범 보이면 → Claude 가 단축키로 저장
- 사용 방법: Claude Extension → `/` 입력 → **Record Workflow** 선택 → 브라우저에서 작업 시연 → 기록 종료
- 예시: 경쟁사 사이트 체크를 **/competitor-check** 로 저장 → 다음부터 단축키 하나로 실행

**2️⃣ Scheduled Task (자동 실행 예약)**

- 저장된 Shortcut 을 정해진 시간에 자동 실행
- Workflow = 작업 저장 / Schedule = 자동 실행

**조합 예시 — 매주 광고 리포트**

```
Shortcut: /weekly-metrics
프롬프트:
광고 대시보드에 접속해서
- ROAS / 클릭수 / 전환수 / CPA
를 확인하고 지난주 대비 변화도 정리해줘.

📅 매주 월요일 자동 실행
```

## 활용 예시

- **출장·여행 잦은 직장인** — 매번 30분 걸리던 일정 짜기를 **5분에 끝**. 같은 도시 재방문 시 단축키 `/tokyo-3day` 같은 형태로 저장
- **마케터·광고 운영자** — 매주 월요일 9시 광고 대시보드 자동 확인 + 슬랙 보고 → 본인이 사무실 도착 전 보고서 완성
- **이커머스 셀러 — 경쟁사 일일 모니터링** — `/competitor-check` 매일 8시 자동 실행 → 경쟁사 신상·할인·블로그 변화 푸시
- **취준생 — 회사 리서치 자동화** — 지원 회사 URL 만 주면 회사 소개·연봉·복지·뉴스 자동 요약
- **콘텐츠 크리에이터 — 트렌드 모니터링** — 매일 아침 9시 본인 분야 키워드 5개 검색 → 상위 결과 요약 → 콘텐츠 아이디어
- **컨설턴트 — 클라이언트 데일리 보고** — Google Sheets 데이터 자동 분석 + 슬랙 채널 보고. 1인이 클라이언트 10-20개 처리 가능

## 💡 아이디어

- **업종별 Workflow 라이브러리** — 카페·헬스장·미용실·블로그 등 직군별 자주 쓰는 워크플로우 10개 패키지 → 가이드 + 동영상 (≈$30/패키지)
- **Scheduled Task 큐레이션 SaaS** — 매주 사용자별 최적 자동화 추천 → "이 작업을 매일 9시에 돌리세요" 알림형 큐레이션 → 월 $10
- **B2B 컨설팅 - AI 자동화 도입** — 회사 1곳당 직무별 워크플로우 50개 + Scheduled Task 30개 세팅 → $3,000-5,000/회 컨설팅
- **여행 가이드 SaaS** — 위 여행 프롬프트 3종을 SaaS 형태로 → 사용자가 도시만 입력하면 자동 일정 생성 → 광고·제휴 수익

## 주의사항

- **Claude Pro 이상 필수** — Free 사용자는 이용 불가. 월 $20 부담
- **승인 단계 건너뛰지 말 것** — 자동 승인 옵션 켜면 의도치 않은 액션(메일 발송·결제 등) 위험. **Plan 확인 후 승인** 패턴 유지
- **Workflow 는 화면 좌표 기반일 수 있음** — 사이트 UI 변경 시 Workflow 깨질 수 있음. 한 달에 한 번 재기록 권장
- **Scheduled Task 로 결제·삭제 작업 금지** — 자동 실행이 결제·중요 삭제 작업 트리거하지 않도록 신중히 설정
- **회사 정책 확인 필수** — 회사 노트북 / 사내망에서 사용 시 정책 위반 여부 확인. 사내 데이터 외부 LLM 전송 제한 조직 많음
