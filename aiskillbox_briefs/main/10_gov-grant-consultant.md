💡 이 스킬은 **Claude 를 정부지원금 전문 컨설턴트로 활용**해 본인 사업 상황 5가지(업종·소재지·규모·창업 연차·목적)만 입력하면 맞춤 지원금·중복 수혜 조합·사업계획서 초안까지 받는 5단계 프롬프트 시스템입니다.

## 이게 뭔가요?

**매년 수십조 원이 집행되지 않고 불용 처리되는 정부 지원금을 Claude 로 찾아내는 컨설팅 자동화 시스템**.

배경:
- **7.6조** — 2024년 중소기업 지원 예산
- **70%** — 신청자 미달로 불용되는 비율
- **380개+** — 부처별 지원 사업 수

왜 모르는가:
- 정보가 부처별(고용노동부·중소벤처기업부·산업통상자원부·지자체) 로 분산. 통합 검색 창구가 없고 공고 기간도 짧음. 전문 컨설턴트조차 전체를 파악하기 어려움

Claude 의 역할:
- 방대한 정부 지원금 구조를 학습하고 있어, **내 상황(업종·직원수·매출·소재지) 입력 → 맞춤 지원금 수십 개 즉시 도출**. **전문 컨설팅 수십만 원짜리 작업을 10분에 해냄**

대표적 착각: "**나 같은 작은 사업엔 해당 없겠지**" — 1인 사업자·프리랜서·소상공인·예비창업자 모두 해당. 직원 0명도, 창업 전도, 폐업 후도 받을 수 있는 지원이 있음

💰 유료 필요: 없음
✅ 무료 대안: Claude 무료 / Gemini 무료 / ChatGPT 무료 모두 동작

## 따라하기

### 지원금 지도 — 카테고리별 최대 금액

| 카테고리 | 최대 금액 | 대표 사업 |
|---|---|---|
| 창업 지원 | 최대 1억 | 예비창업패키지, 초기창업패키지 |
| 소상공인 지원 | 최대 5,000만 | 특화자금, 경영안정자금 |
| 재창업 지원 | 최대 3,000만 | 재도전성공패키지 |
| 디지털 전환 | 최대 2,000만 | 스마트공방, AI바우처 |
| 청년 고용 | 최대 960만 | 청년내일채움공제 |
| 지자체 지원 | 50~500만 | 각 시·도·군별 상이 |

**중복 수혜 전략 — 국가 + 지자체 + 민간 3중 조합**

같은 사업에 국비 지원을 받으면서 동시에 지자체 지원을 신청할 수 있음. 일부 중복은 금지되지만 잘 조합하면 총 수혜액을 크게 늘릴 수 있음. **Claude 로 중복 가능 조합을 물어보는 것이 핵심 전략**.

실제 사례: 인천 1인 디자인 사업자 → 소상공인시장진흥공단 경영안정자금 **2,000만** + 인천시 소상공인 지원금 **300만** + 디지털바우처 **400만** = **총 2,700만원** 수혜. Claude 로 3시간 조사.

### 핵심 원리 — 내 상황을 정확히 줘야 정확히 나옴

| # | 입력 항목 | 권장 입력 |
|---|---|---|
| 01 | 업종 | "교육 콘텐츠 제작" > "서비스업" (구체적으로) |
| 02 | 규모 | 1인 / 직원 수 / 연매출. 소상공인 기준(연매출 10억 이하) 충족 여부 |
| 03 | 소재지 | 시·군·구 단위까지 (지자체별 지원금 완전히 다름) |
| 04 | 창업 연차 | 예비창업자 / 3년 이내 / 7년 이상 등 |
| 05 | 목적 | 운영자금 / 설비투자 / 마케팅 / 고용 / 디지털전환 중 선택 |

**프롬프트 구조 공식**: `[역할 부여] + [내 상황 5가지] + [원하는 출력 형식] + [추가 조건]`

### 5개 실전 프롬프트 (복붙 사용)

**프롬프트 1 — 맞춤 지원금 전체 탐색**

```
너는 지금부터 중소기업·소상공인 정부지원금 전문 컨설턴트야.
내 상황을 알려줄게:
- 업종: [예: 온라인 교육 콘텐츠 제작]
- 소재지: [예: 인천광역시 미추홀구]
- 규모: [예: 1인 사업자, 연매출 3,000만원]
- 창업 연차: [예: 2년차]
- 목적: [예: 운영자금 + 마케팅 예산]
이 조건에 맞는 2025년 현재 신청 가능한 정부·지자체 지원금을
표 형태로 정리해줘.
컬럼: 지원금명 / 지원금액 / 신청기간 / 신청처 / 핵심 자격요건 / 신청URL
```

**프롬프트 2 — 중복 수혜 조합 뽑기**

```
위에서 뽑아준 지원금 중에서
중복으로 신청 가능한 조합을 알려줘.
금액 합산이 가장 큰 조합 TOP 3를 뽑아주고,
각 조합의 예상 수혜 총액과 신청 순서도 알려줘.
```

**프롬프트 3 — 사업계획서 초안 작성**

```
[지원금명] 신청을 위한 사업계획서 초안을 써줘.
내 사업 개요:
- 사업 내용: [간략 설명]
- 차별점: [경쟁 대비 강점]
- 자금 사용 계획: [구체적 항목]
- 기대 효과: [수치 포함]
심사위원이 높이 평가하는 포인트를 중심으로
A4 2페이지 분량으로 작성해줘.
```

**프롬프트 4 — 자격 요건 체크리스트**

```
[지원금명]의 신청 자격 요건을 체크리스트로 정리해줘.
내가 지금 갖춰야 할 서류, 등록 조건,
사전에 확인해야 할 사항을 단계별로 알려주고,
내가 놓치기 쉬운 함정 조건도 따로 표시해줘.
```

**프롬프트 5 — 마감 임박 긴급 탐색**

```
지금 당장 신청 가능한 지원금 중에서
마감이 [이번 달 / 다음 달] 안으로 임박한 것만 골라줘.
내 조건: [업종 / 지역 / 규모]
긴급도 순서대로 정렬하고,
신청 방법과 빠른 접수 팁도 같이 알려줘.
```

### 신청 단계별 실행 가이드

| 단계 | 시간 | 작업 |
|---|---|---|
| 01 탐색 | 30분 | 프롬프트 1 → 맞춤 목록 / 프롬프트 2 → 중복 조합 / TOP 5 선정 |
| 02 자격 검증 | 1시간 | 프롬프트 4 → 체크리스트 / 공식 사이트(기업마당·소상공인포털) 재확인 |
| 03 서류 준비 | 1~3일 | 사업자등록증·매출증빙·통장사본 기본 세트 / Claude 에 "추가 필요 서류?" 재확인 |
| 04 사업계획서 작성 | 2~4시간 | 프롬프트 3 → 초안 / 수치·구체성 강화 / "심사 기준으로 검토해줘" 요청 |
| 05 제출 후 사후 관리 | — | 다음 지원금 탐색 병행 / 탈락 시 "보완점 뭐야?" 피드백 요청 |

## 활용 예시

- **1인 사업자·프리랜서 — 운영자금 확보** — 프롬프트 1·2 조합으로 2-3시간 안에 본인 조건에 맞는 5-10개 지원금 도출. 연 2,000-3,000만원 추가 수혜 가능
- **예비창업자 — 창업 자금 조달** — 프롬프트 1 로 예비창업패키지·초기창업패키지·재도전성공패키지 등 탐색 → 프롬프트 3 으로 사업계획서 초안 자동 생성
- **소상공인 — 디지털 전환 자금** — AI바우처·스마트공방 등 디지털 전환 카테고리에 집중, 본인 사업장 디지털화 비용 정부 부담으로 전환
- **컨설팅 사업자** — 본인 클라이언트 수십 명에게 동일 5개 프롬프트 적용 → 컨설팅 보고서 자동 생산, 1인이 월 20-30 클라이언트 처리 가능
- **창업지원센터·BI 운영자** — 입주 기업 대상 무료 강의 콘텐츠로 활용, 입주 만족도·재계약율 증가

## 💡 아이디어

- **정부지원금 자동 알리미 SaaS** — 사용자 5개 정보 등록 → 매주 새 공고 자동 매칭 → 마감 임박 시 알림. 월 $20-30 구독
- **사업계획서 작성 대행** — 프롬프트 3 + 사람의 다듬기로 1건당 $100-300 받는 1인 대행 사업. 월 10-20건 처리 가능
- **창업 컨설턴트 자격증·교육 콘텐츠** — 5개 프롬프트 + 단계별 가이드를 4시간 강의로 패키징 ($100-200)
- **지자체별 지원금 데이터베이스** — Claude 가 학습한 데이터를 별도 DB 화 → 무료 검색 사이트 운영, 광고·제휴 수익화

## 주의사항

- **"한 번 물어보고 끝낸다" 가 가장 흔한 실수** — Claude 와 대화를 이어가며 "더 있어?", "지자체 거 따로", "중복 신청 가능한 조합 뽑아줘" 식으로 계속 파고들어야 진짜 정보 확보
- **공식 사이트 재확인 필수** — Claude 가 학습한 데이터는 시점 차 있을 수 있음. **기업마당·소상공인포털**에서 최신 공고로 검증
- **자격 요건 함정 조건 주의** — 매출 기준·고용 이력·체납 여부 등 사소한 조건으로 탈락 사례 많음. 프롬프트 4 의 체크리스트로 사전 검증
- **사업계획서는 초안일 뿐** — 프롬프트 3 결과는 80% 초안. 본인 사업의 진짜 차별점·수치는 직접 채워 넣어야 심사 통과
