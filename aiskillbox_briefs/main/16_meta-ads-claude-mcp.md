💡 이 스킬은 **메타(Meta)가 클로드와 공식 출시한 MCP 서버**로, 광고 관리자에 들어가지 않고 **클로드 채팅창에서 자연어로 캠페인 생성·성과 분석·이슈 진단**을 처리하는 광고 운영 자동화 가이드입니다.

## 이게 뭔가요?

**Meta 가 Anthropic 과 공식 협력해 출시한 Marketing API 용 MCP(Model Context Protocol) 서버**. 이전까지의 광고 운영 워크플로우는 **광고 관리자 클릭 → 리포트 다운 → 엑셀 정리 → ChatGPT 복사 → 다시 광고 관리자** 의 탭 5개 왕복이었지만, 이제 클로드 채팅창 한 곳에서 모두 처리.

**MCP 가 뭔가요**:
> MCP = **Model Context Protocol**. **AI 와 외부 서비스를 이어주는 표준 콘센트**.
> 클로드가 광고 계정에 직접 접근해서 작업 처리 → 사용자는 채팅창에 자연어로 명령만.

**클로드 채팅창에서 처리 가능한 작업 4종**:

| 작업 | 명령 예시 | AI 응답 |
|---|---|---|
| **광고 성과 분석** | `지난 30일 광고 성과 요약해줘` | 광고비·노출수·CTR·전환율 표로 정리 |
| **비효율 광고 정리** | `ROAS 2 이하인 광고 다 꺼줘` | 조건 맞는 광고 자동 일시정지 + 절약 예산 안내 |
| **신규 캠페인 생성** | `겨울 신상 캠페인 만들어줘. 예산은 일 5만원` | 캠페인·광고 세트·소재까지 한 번에 세팅 |
| **광고 이슈 진단** | `이 광고 왜 노출이 안 나오는 거야` | 메타 고객센터 데이터 기반 원인 + 해결 방법 |

💰 유료 필요: 메타 광고비만 (클로드는 무료 계정도 가능)
✅ 무료 대안: Claude 무료 / ChatGPT 무료 — MCP 설정만 차이

## 따라하기

### 사전 준비 (3가지)

- **클로드 계정** (무료도 가능)
- **메타 비즈니스 계정** (광고를 운영 중인 계정)
- **메타 개발자 앱** (아래 1단계에서 생성)

### STEP 1. 메타 개발자 앱 만들기

1. **developers.facebook.com** 접속 → 메타 비즈니스 계정으로 로그인
2. **내 앱 메뉴** 이동 → **앱 만들기** 버튼 클릭
3. 사용 사례: **비즈니스** 선택 → 다음
4. 앱 이름 입력 (예: `ClaudeMCP`)
5. 앱 생성 후 좌측 메뉴에서 **마케팅 API** 추가
6. **설정 페이지에서 3가지 정보 메모**:
   - **앱 ID**
   - **앱 시크릿**
   - **액세스 토큰** (마케팅 API 안의 도구 메뉴에서 생성)

### STEP 2. 클로드에 MCP 연결

1. **클로드 앱** 또는 **claude.ai** 접속
2. 좌측 하단 또는 채팅창 옆의 **플러스 버튼** 클릭
3. **커넥터 메뉴** 선택
4. **커스텀 커넥터 추가** 클릭
5. 다음 정보 입력:
   - **이름**: `MetaMCP` (다른 이름 OK)
   - **URL**: 메타 공식 MCP 서버 주소
   - **환경 변수**: 1단계에서 메모한 **액세스 토큰·앱 ID·앱 시크릿**
6. 인증 완료 → **비즈니스 계정 선택**
7. 클로드 **한 번 재시작** → 연결 적용

💡 여기까지 약 **60초** 소요.

### STEP 3. 실제 사용 (작은 작업부터)

**테스트용 캠페인 만들기 (안전한 시작)**

```
트래픽 캠페인 만들어줘.
이름은 Claude Test 2026,
예산은 일 1만원,
상태는 일시정지로
```

💡 **상태를 일시정지로** 만들면 실수로 광고비 나가는 일 차단.

**다른 활용 예시 4종**

| 활용 유형 | 명령 예시 |
|---|---|
| **리포트 요청** | `지난 7일 캠페인별 성과 비교해줘` |
| **소재별 분석** | `가장 클릭률 높은 광고 5개 알려줘` |
| **예산 조정** | `성과 좋은 캠페인 예산 두 배로 올려줘` |
| **오디언스 확인** | `지금 등록된 오디언스 목록 보여줘` |

## 활용 예시

- **1인 셀러 · 소호몰 — 광고 운영 시간 80% 절감** — 매일 아침 1회 "지난 24시간 성과 요약 + ROAS 2 이하 끄기" 정도만 자연어로. 광고 관리자 진입 횟수 주 1회로 감소
- **광고 대행사 — 클라이언트 보고 자동화** — 클라이언트별 주간 리포트 요청 → 표 형식 자동 생성 → 클라이언트 보고서로 바로 활용. 1인 대행사도 클라이언트 10-15개 동시 운영 가능
- **마케팅 팀장 — 빠른 의사결정** — 캠페인 직접 만들지 않더라도 클로드에 "이번 분기 광고 어디에 문제 있어?" 자연어 진단 → 빠른 의사결정
- **이커머스 운영자 — A/B 테스트 자동화** — "현재 잘 되는 소재의 변형 5개 만들고 동일 예산으로 분배해줘" 한 줄로 A/B 테스트 세팅
- **컨설턴트 — 광고 진단 보고서 제작** — 클라이언트 광고 계정 연결 → 클로드에 "이 계정의 가장 큰 문제 5가지" 진단 → 컨설팅 보고서 자동 생성
- **광고 강사 — 실시간 시연 가능** — 강의 중 학생 광고 계정 연결 후 라이브로 진단·세팅 시연 → 강의 가치 큰 폭 상승

## 💡 아이디어

- **메타 광고 MCP + 자동 보고 SaaS** — 사용자 메타 계정 연결 → 매일 9시 자동 리포트 발송 → 이상치 발견 시 텔레그램 알림 → 월 $20-30 구독
- **광고 운영 AI 비서 패키지 (대행사용)** — 메타 MCP + Google Ads MCP + GA4 연동 + 자동 보고서 → 대행사 전용 시트 $50/seat
- **이커머스 ROAS 최적화 봇** — 클로드 + 메타 MCP + 본인 쇼핑몰 데이터 → 매주 자동 캠페인 최적화 → 성과 기반 수수료 모델 (절감 광고비 30%)
- **AI 광고 운영 강의** — 이 가이드 + 실제 데이터 분석 + 자동화 시나리오 → 4시간 강의 패키지 ($100-200)
- **소상공인 정부 사업 연계 컨설팅** — 정부지원 마케팅 바우처 활용 + MCP 도입 컨설팅 → 1인 사업자 $300-500/건

## 주의사항

- **광고 계정 1개만 연결 가능 (출시 초기)** — 광고 계정 여러 개 운영 중이어도 현재는 한 번에 한 계정만. 다계정 운영 시 수동 전환 필요
- **일부 기능은 아직 미지원** — 캠페인 목록 조회 같은 기본 작업도 안 되는 경우 있음. **메타 측에서 점진적 추가 중**
- **메타 전용** — 구글·틱톡·스냅 광고는 별도 도구 필요. 종합 광고 운영은 여전히 여러 도구 병행
- **액세스 토큰 만료 잦음** — 연결 실패 시 1순위 의심. **메타 개발자 페이지에서 토큰 재발급** → 다시 입력
- **소액·일시정지로 첫 테스트 필수** — 첫 명령에서 큰 예산·즉시 활성화 금지. 일 1만원·일시정지로 충분히 익숙해진 후 실전
- **광고 대행사 기존 사용 중이어도 병행 OK** — MCP 연결은 광고 계정 자체에 영향 X. 클로드 접근 방식만 추가
- **데이터 안전** — MCP 는 사용자 토큰으로 메타 API 와 직접 통신. **별도 서버에 데이터 저장 X** → 안전
- **출시 초기 단계** — 안정화 진행 중. 중요한 실전 캠페인은 광고 관리자 백업 확인 권장
