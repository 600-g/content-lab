💡 이 스킬은 **"넌 전문가야" 식 역할 지정 프롬프트를 폐기**하고, **맥락(Context) 중심 8가지 프롬프트 업그레이드 패턴**으로 AI 답변 품질을 즉시 끌어올리는 검증된 프롬프트 엔지니어링 방법론입니다.

## 이게 뭔가요?

**역할 지정 프롬프트("넌 마케팅 전문가야")가 효과 없는 이유와 그 대체 8가지 방법** 정리. 핵심 원리는 한 줄로:

> **AI에게 주는 정보는 역할(Role)보다 맥락(Context)이 10배 강하다.**
> "마케터야" 보다 "팔로워 200명 카페 사장, 예산 없음, 혼자 운영" 이 훨씬 더 정확한 답을 이끈다.

**왜 "전문가야" 가 약한가**:
- AI는 이미 수백만 개 전문 자료로 학습 → "넌 전문가야" 라고 해도 **AI의 실제 지식은 변하지 않음**
- 역할만 주면 AI는 해당 주제에 대해 **'일반적으로'** 알려진 것만 나열 → 구글 검색과 차이 X
- 진짜 문제: AI 가 **어떤 맥락에서 어떤 수준으로 어떤 형식으로** 답해야 하는지 모름

**좋은 프롬프트의 5가지 구성 요소**:

| 구성 요소 | 의미 | 예시 | 없으면 |
|---|---|---|---|
| **상황 (Context)** | 현재 상황·배경 | "월 매출 300만원 스타트업" | 범용 답변 |
| **목적 (Goal)** | 원하는 결과 | "전환율을 2배 높이고 싶어" | 방향 없는 답변 |
| **독자 (Audience)** | 누구를 위한 것인지 | "비전공자 40대 직장인에게" | 수준 안 맞는 답변 |
| **형식 (Format)** | 어떤 형태로 | "3가지 bullet · 각 2줄" | 정리 안 된 답변 |
| **제약 (Constraint)** | 조건·한계 | "무료 도구만 · 1인 운영" | 현실과 동떨어진 답변 |

## 따라하기

### 업그레이드 01. 역할 대신 상황을 줘라

```
❌ BEFORE: "넌 창업 전문가야. 사업 아이디어 평가해줘."

✅ AFTER:
나는 직장을 다니면서 주말에만 작업하는 1인 창업자야.
초기 자본은 500만원이고 제조업은 불가능해.
아래 아이디어가 이 조건에서 현실적인지 평가해줘.
실패 가능성도 솔직하게 말해줘.
[아이디어: ...]
```

효과: AI 가 **"직장 병행 가능 여부", "자본 내 실현 가능성", "1인 운영 가능 여부"** 를 기준으로 평가. 역할만 줬을 때는 일반 사업 평가 프레임만 사용.

### 업그레이드 02. 독자를 명시해라

```
❌ BEFORE: "복리 이자 설명해줘"

✅ AFTER: "수학을 못하는 40대 부모에게 복리 이자를 설명해줘.
숫자보다 실생활 비유 중심으로. 5분 안에 이해되게."
```

같은 내용도 **독자에 따라 어휘 수준·비유·전제 지식·톤이 자동 조정**.

### 업그레이드 03. 원하는 형식을 명시

```
❌ BEFORE: "이커머스 마케팅 팁 알려줘"

✅ AFTER: "이커머스 마케팅 팁 5가지를 표로 만들어줘.
컬럼: 전략 / 예상 효과 / 소요 시간 / 비용 / 난이도(★1-5)"
```

표·번호 리스트·코드블록·JSON 같은 **출력 형식 지정**으로 후속 작업 효율 큰 차이.

### 업그레이드 04. 제약 조건을 명시

```
- 예산: [없음 / 5만원 이하 / 50만원 이하]
- 시간: [주말 2시간만 / 매일 1시간]
- 도구: [무료만 / Mac OS 만 / 코딩 X]
- 인력: [혼자 / 알바 1명 / 팀 3명]
```

제약이 명확하면 **실현 가능한 답변** 만 나옴. 막연한 "최고의 방법"은 결국 실행 안 됨.

### 업그레이드 05. 목적·KPI 를 정확히

```
❌ BEFORE: "인스타 운영 어떻게 해?"

✅ AFTER: "인스타 팔로워 200명 → 6개월 안에 1,000명 만들고 싶어.
주 3회 포스팅 가능. 카테고리는 홈인테리어 1인 셀러.
이 목표 달성 위한 12주 콘텐츠 전략을 짜줘."
```

**숫자·기한·KPI** 가 들어가면 **추상적 조언 → 실행 계획** 으로 변환.

### 업그레이드 06. 이전 시도를 알려라

```
"인스타 마케팅 시도했지만 효과 없었어.
- 했던 것: 음식 사진 위주 (효과 X)
- 안 해본 것: 릴스 / 협업 / 광고
이번엔 음식 사진 빼고 안 해본 것 중에 추천해줘."
```

**이미 실패한 방법** 을 알려주면 AI가 같은 답 반복 안 함. 시간 절약 크고 답변 신선도 ↑

### 업그레이드 07. 솔직한 평가 요청 ("악마의 대변인")

```
"내 아이디어 평가해줘. 동의하는 척 말고,
가장 강한 반론 3개. 어디서 망할지 냉정하게.
내가 과신한다고 가정하고."
```

AI 는 기본적으로 **칭찬하는 톤**. 명시적으로 **비판해달라고** 요청하면 진짜 약점 발견.

### 업그레이드 08. 출처·근거 요구

```
"위 답변의 근거가 되는 데이터·연구·기사를 알려줘.
출처 없는 부분은 명시해줘.
내가 직접 검증할 수 있게."
```

LLM 환각(hallucination) 방지. **출처를 요구하면 추측은 줄어들고 검증 가능한 답** 으로 수렴.

### 상황 지정 마스터 템플릿 (복붙)

```
나는 [직업/역할]이야.
현재 상황: [구체적인 현재 상태]
목표: [원하는 결과 + KPI]
제약: [불가능한 것 / 조건]
이전 시도: [효과 있던 것 / 없던 것]
독자: [답변을 적용할 대상]
형식: [원하는 출력 형태]

위 상황에서 [질문]을 도와줘.
이 조건에 맞지 않는 답변은 필요 없어.
```

## 활용 예시

- **1인 사업자 — 매주 운영 회고** — 매주 금요일 상황 마스터 템플릿에 한 주 데이터 채워 넣으면 AI 가 그 주 가장 큰 임팩트 행동을 1개 추천. 매주 자동화
- **취준생·이직자 — 자기소개서 / 면접** — 본인 상황·지원 회사·강점·약점 다 넣은 후 "예상 질문 10개 + 모범 답안" 요청
- **부모 — 자녀 학습 코칭** — 자녀 학년·성격·약한 과목·이전 시도 다 명시 후 "이번 주 30분짜리 학습 플랜" 요청
- **개발자 — 코드 리뷰 셀프 점검** — 본인 코드 + "PR 리뷰어 입장에서 가장 강한 반론 3개" 요청해 머지 전 검증
- **마케터 — 캠페인 기획** — 브랜드·타깃·예산·KPI·이전 캠페인 결과 다 넣은 후 "이번 분기 캠페인 아이디어 5개" 요청
- **연구자·학생 — 논문 / 리서치** — 주제·기존 연구·본인 가설·연구 방법 명시 후 "내 가설의 약점 3가지" 요청

## 💡 아이디어

- **8개 업그레이드 체크리스트 SaaS** — 사용자가 프롬프트 작성 시 5가지 구성 요소 빠진 항목을 실시간으로 체크해주는 브라우저 익스텐션 → 무료 + Pro $5/월
- **회사 사내 프롬프트 표준화 컨설팅** — 부서별 마스터 템플릿 작성 컨설팅 ($500-1000/회). 모든 직원이 동일 구조로 AI 활용해 결과 일관성 확보
- **프롬프트 학습 카드 게임** — 60개 프롬프트 카드 + 5가지 구성 요소 카드 → 게임 형식으로 프롬프트 작성 연습 → 패키지 $20-30
- **프롬프트 라이브러리 직군별 큐레이션** — 마케터 / 개발자 / 디자이너 / 영업 직군별 마스터 템플릿 50개씩 → 유료 멤버십 $10/월

## 주의사항

- **모든 5요소를 항상 넣을 필요 X** — 간단한 질문엔 1-2개만, 복잡한 작업엔 5개 모두. **상황 / 목적 / 제약 3개는 최소 권장**
- **너무 길면 역효과** — 1000자 넘어가는 프롬프트는 오히려 AI 가 핵심 놓침. 핵심 정보 위주 200-500자 권장
- **민감 정보 주의** — 실명·금액·거래처·내부 데이터 등 외부 LLM 에 넣을 땐 본인 회사 보안 정책 확인. 사내용은 **로컬 Ollama / 자체 호스팅 LLM** 권장
- **악마의 대변인 답변은 감정적으로 받지 말 것** — 솔직한 평가 요청하면 AI 가 다소 강하게 말함. **약점 발견용**이지 자존감 평가가 아님
