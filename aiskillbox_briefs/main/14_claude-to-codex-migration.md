💡 이 스킬은 **OpenAI Codex 의 'Import other agent setup' 기능**으로 Claude Code 의 모든 작업 환경(CLAUDE.md·skills·MCP·hooks·30일 세션)을 **단 5단계 클릭으로 완전 이주**하는 양립 운영 가이드입니다.

## 이게 뭔가요?

**Codex 가 공식 제공하는 Claude Code → Codex 마이그레이션 마법사**. ChatGPT Plus·Pro·Business·Enterprise 구독자면 추가 비용 없이 사용 가능. 8개 항목이 자동 변환되어 양쪽 환경 양립 운영.

**Codex 만의 강점 6가지**:

| 강점 | 의미 |
|---|---|
| 💎 **추가 비용 제로** | ChatGPT 구독자면 별도 결제 없이 사용 (무료 사용자도 넉넉한 사용량) |
| ☁️ **백그라운드 클라우드 작업** | 30분~몇 시간 걸리는 무거운 작업도 노트북 덮어도 클라우드에서 계속 실행 |
| 🚀 **데스크톱 앱 병렬 실행** | 한 번에 여러 작업 동시 지시 → 완료 후 한꺼번에 결과 확인 |
| 📱 **모바일 지시** | ChatGPT 앱에서 음성·텍스트 → 코드 수정·PR 생성까지 자동 |
| 🤖 **AI 코드 리뷰어** | GitHub PR 병합 시 AI 가 직접 리뷰 코멘트 |
| 🧠 **GPT-5 / GPT-5-Codex 탑재** | OpenAI 최신 추론 모델 즉시 활용 |
| 🔒 **샌드박스 격리** | 위험한 명령어·시스템 접근 자동 차단 |

💰 유료 필요: ChatGPT Plus 이상 권장 (무료도 가능)
✅ 무료 대안: Claude Code 와 양립 운영 — 굳이 한 쪽만 고를 필요 X

## 따라하기

### 자동 이주되는 8개 항목

| Claude Code 항목 | Codex 변환 결과 | 역할 |
|---|---|---|
| `CLAUDE.md` 등 instruction files | `AGENTS.md` | AI에게 미리 알려주는 **나만의 작업 규칙과 배경지식** |
| `settings.json` / `config.toml` | 기본 설정 파일 | 테마·언어·기본 동작 등 **전반적 환경 설정** |
| **Skills** | Codex skills | AI 가 수행할 수 있는 구체적 **개인기(기능)** |
| **Slash commands** | Codex skills | `/` 단축 명령어 |
| **Subagents** | Codex agents | 특정 업무 전담 **보조 AI 비서** |
| **MCP server config** | Codex MCP config | 외부 프로그램·DB 연결 설정 |
| **Hooks** | Codex hooks | 특정 상황에서 자동 실행되는 **자동화 규칙** |
| 최근 30일 세션 | Threads / Projects | 한 달간 모든 대화·작업 기록 |

### 5단계 이주 방법

**STEP 1. 설정 열기**

Codex 앱 실행 → 좌측 하단 **Settings(설정)** 메뉴로 이동

**STEP 2. 메뉴 찾기**

**General(일반)** 페이지 → `[Import other agent setup(다른 에이전트 설정 가져오기)]` 찾기

**STEP 3. 가져오기 실행**

**Import** (또는 **Import again**) 버튼 클릭

**STEP 4. 항목 선택**

위 8가지 항목 중 가져올 것만 체크 → 실행

**STEP 5. 결과 확인**

마이그레이션 완료 후 **[View imported files]** 클릭 → 설정이 잘 들어왔는지 확인

💡 **꿀팁**: 자동 변환이 어려운 일부 복잡한 설정은 앱이 알려주며, **'Continue in Codex'** 버튼을 누르면 AI가 대화를 통해 나머지 변환을 직접 도와줍니다.

### 이주 후 필수 점검 체크리스트

자동 이주가 끝나면 다음 항목을 한 번 더 확인하세요:

- [ ] **AI 비서(에이전트)와 스킬들의 파일 접근·수정 권한 범위** 확인
- [ ] **MCP 서버 인증(토큰·환경변수) 보안 설정** 풀리지 않았는지 체크
- [ ] **Hook 규칙**이 Codex 환경에서도 똑같이 작동하는지 테스트
- [ ] Claude 전용 **플러그인·마켓플레이스 항목** 중 따로 재설치 필요한 것 확인
- [ ] **프롬프트 안 파일 경로·변수 템플릿**이 정상적으로 텍스트 불러오는지 확인
- [ ] **슬래시(`/`) 단축 명령어**가 기존과 동일하게 작동하는지 점검

### 나에게 맞는 툴 찾기 (4가지 비교 포인트)

이주를 완료했다고 무조건 Codex 만 쓸 필요 X. 두 환경 모두 갖춰졌으니 비교 운영 권장:

| 비교 포인트 | 체크 항목 |
|---|---|
| **품질·속도** | 똑같은 일을 시켰을 때 어느 쪽이 더 빠르고 정확한가? |
| **작업의 자연스러움** | 내가 자주 쓰는 기능·보조 AI 가 어느 환경에서 더 매끄러운가? |
| **MCP 연동 안정성** | 노션·슬랙 등 외부 툴 연동이 끊김 없이 유지되나? |
| **과거 기록 활용도** | 지난 한 달간의 작업 기록을 검색·불러올 때 어느 쪽이 편한가? |

## 활용 예시

- **개발자 — 양 환경 비교 운영** — 같은 PR 을 두 환경에서 처리해 보고 본인 작업 스타일에 더 맞는 쪽 선정. 2주 비교 후 결정 권장
- **프리랜서 — 장시간 작업 Codex 위임** — 데이터 마이그레이션·테스트 자동 생성 같은 1-3시간 작업은 Codex 백그라운드 클라우드에 위임, 본인은 다른 클라이언트 작업 동시에 진행
- **모바일 활용자 — 외출 중 PR 처리** — ChatGPT 앱에서 음성으로 "이 버그 고쳐줘" → Codex 가 PR 생성. 노트북 없이도 작업 가능
- **팀 리드 — AI 코드 리뷰어 도입** — GitHub PR 자동 AI 리뷰로 코드 품질 1차 검수. 사람 리뷰어 부담 50% 감소
- **AI 강사·블로거 — 양 환경 비교 콘텐츠** — 이주 절차 + 비교 결과를 영상·블로그·뉴스레터로 정리 → 트래픽·구독자 확보
- **사내 표준화 컨설팅** — 회사 내 일부 팀은 Claude Code, 일부는 Codex 운영 → 동일 워크플로우 보장을 위한 마이그레이션 가이드 컨설팅

- **사내 AI 워크플로우 매니지먼트 SaaS** — 회사 내 어느 직원이 어느 환경 사용 중인지 통합 관리 + 사용량 분석 + 비용 최적화 → 월 $20-50/seat

## 주의사항

- **자동 변환이 100% 완벽하진 않음** — 복잡한 Hook·MCP 설정은 'Continue in Codex' 대화로 보완 필요. 이주 직후 반드시 동작 검증
- **MCP 토큰 재발급 필요할 수 있음** — 이주 과정에서 일부 외부 서비스 토큰은 만료 처리될 수 있음. 노션·슬랙·GitHub 토큰 우선 확인
- **무료 사용자는 한도 빠르게 소진** — 무료 티어로도 가능하지만 백그라운드 클라우드 작업은 빠르게 한도 소진. 진지하게 사용하려면 ChatGPT Plus 권장
- **양 환경 동시 사용 시 토큰 중복** — Claude Code · Codex 양쪽에서 같은 MCP 토큰 사용 시 API rate limit 빠르게 도달 가능. 별도 토큰 분리 권장
- **GPT-5 / GPT-5-Codex 의 톤 차이** — Claude 와 답변 스타일이 다름. 코드 스타일·주석 형식 일관성 유지하려면 양쪽 AGENTS.md / CLAUDE.md 에 톤 가이드 명시
