## 이게 뭔가요?

**"지금 사도 될까? 아니면 팔아야 하나? 너무 올랐는데 지금 들어가도 괜찮을까?"** 같은 투자 고민을 Gemini 로 풀어내는 5가지 프롬프트.

원본은 **《제미나이 주식투자》 (율리 추천)** 책의 200개 프롬프트 중 **실전 가장 유용한 5종**. 운영자 율리님이 직접 검증한 셀렉션.

> Gemini 를 활용만 잘해도 투자 고민의 상당 부분이 해결됩니다.

**5가지 모드 전체 요약**:

| # | 모드 | 핵심 질문 |
|---|---|---|
| 1 | **냉철한 분석가** — 뉴스 속뜻 파헤치기 | 호재인가 악재인가? |
| 2 | **가치투자 전문가** — 종목 비교 | A vs B 어느 게 저평가? |
| 3 | **30초 미국 증시 리포트** | 오늘 내 종목에 영향? |
| 4 | **글로벌 수급 분석** — 숨은 의도 | 외국인·기관의 진짜 속내? |
| 5 | **수석 애널리스트** — 미래 섹터 | 향후 6개월 주도 섹터? |

💰 유료 필요: 없음 (Gemini 무료 / Claude·ChatGPT 도 동작)
✅ 무료 대안: Gemini 무료 / Claude 무료 / ChatGPT 무료 모두 사용 가능

## 따라하기

### 1️⃣ 냉철한 분석가 모드 — 뉴스 속뜻 파헤치기

**언제 쓰나**:
- 따끈따끈한 뉴스가 내 주식에 약일지 독일지 궁금할 때
- 호재인지 악재인지 헷갈릴 때 — **주가 영향력 즉시 판별**
- 단순 요약이 아니라 **뉴스 이면의 시장 반응·전문가 시선** 분석 필요할 때

**프롬프트 (복붙)**:

```
너는 냉철한 주식 시장 분석가야.
방금 나온 [종목명]의 뉴스 [제목/내용]을 분석해 줘.
이 뉴스가 단기적으로 주가에 긍정적인지 부정적인지 판단하고,
그 이유를 세 가지로 요약해 줘.
마지막에는 주식 초보자가 주의해야 할 점도 알려줘.
```

### 2️⃣ 가치투자 전문가 모드 — 종목 비교 분석

A 종목을 살까 B 종목을 살까 고민하며 밤잠을 설치는 분들을 위한 마법의 비교 공식.

**언제 쓰나**:
- 두 종목 사이 결정 장애 — 비슷한 업종 중 어느 게 더 저평가?
- 막연한 설명 대신 **PER·PBR·ROE 같은 핵심 지표**를 표로 보고 싶을 때

**프롬프트 (복붙)**:

```
너는 가치투자 전문가야.
[종목 A]와 [종목 B]를 비교하려고 해.
두 회사의 최근 PER, PBR, ROE 수치를 표로 만들어서 비교해 줘.
현재 어떤 종목이 더 저평가되어 있는지,
그리고 수익성은 누가 더 좋은지
초보자도 이해하기 쉽게 설명해 줘.
```

### 3️⃣ 아침을 여는 '30초 미국 증시 리포트'

전 세계 데이터를 실시간으로 훑어 **오늘 내 주식에 줄 영향만 쏙쏙 골라주는 리포트**.

**언제 쓰나**:
- 바쁜 출근길 핵심 요약 필요할 때 — 30초 브리핑
- 글로벌 이슈를 내 종목에 대입 — 해외 대장주 뉴스가 내 한국 보유 종목에 미칠 변화 대비

**프롬프트 (복붙)**:

```
어제 미국 증시에서 [섹터] 지수가 얼마나 올랐어?
특히 엔비디아와 관련된 최신 뉴스 중에서
오늘 한국 [섹터] 주식인 [종목명]에 영향을 줄 만한
핵심 내용만 딱 정리해 줘.
```

### 4️⃣ 글로벌 수급 분석 모드 — 숫자에 숨은 의도

**복잡한 수급 데이터를 전략의 언어로 번역**. '얼마나 샀는지'보다 '왜 샀는지'가 훨씬 중요.

**언제 쓰나**:
- '큰 손'들의 진짜 속내 — 외국인·기관 매수가 단기 트레이딩 vs 장기 매집?
- **단단한 지지선**을 찾고 싶을 때 — 세력 매수 집중 가격대 파악

**프롬프트 (복붙)**:

```
너는 글로벌 헤지펀드의 수석 데이터 분석가야.
최근 10거래일간 [종목명]에 대한 외국인과 기관의 수급 데이터를 분석해 줘.
순매수 강도와 환율과의 관계를 고려해 이 자금의 성격(단기/장기)을 판단하고,
향후 지지선 역할을 할 핵심 가격대를 평가해 줘.
```

### 5️⃣ 수석 애널리스트 모드 — 미래 주도 섹터 분석

20년 경력 전문가의 시선으로 **거시 경제와 산업 변화를 꿰뚫어 보는** 프롬프트.

**언제 쓰나**:
- 다음 시장의 주인공을 미리 선점 — 금리·AI 트렌드 반영 향후 6개월 핵심 업종
- 업종 내 진짜 '대장주' — 기술력·수급 가장 몰리는 1등 기업

**프롬프트 (복붙)**:

```
너는 20년 경력의 글로벌 자산운용사 수석 애널리스트야.
현재 [시점: 2026년] 금리 상황과 AI 산업 변화를 반영해서,
향후 6개월간 시장을 주도할 핵심 업종 3가지를 분석하고
각 업종의 대장주를 추천해 줘.
```

### 5종 조합 활용 — 매일 30분 투자 루틴

```
07:30 — ③ 30초 미국 증시 리포트 (어제 미국 → 오늘 한국 영향)
07:45 — ④ 글로벌 수급 분석 (내 보유 종목 외국인·기관 동향)
08:00 — ① 냉철한 분석가 (밤사이 나온 뉴스 호재/악재 판단)
주말   — ⑤ 수석 애널리스트 (다음 주·다음 분기 섹터 전망)
신규 종목 검토 시 — ② 가치투자 전문가 (A vs B 비교)
```

## 활용 예시

- **개인 투자자 — 출근 전 30분 매매 의사결정** — ③+① 조합으로 매일 출근 전 매수·매도 결정. 데이트레이더 수준의 정보를 무료로
- **장기 투자자 — 가치주 발굴** — ②+④+⑤ 조합으로 매월 본인 종목 평가 + 새 종목 발굴. 외국인·기관 따라가는 추세
- **재무 컨설턴트 — 클라이언트 보고서 자동화** — 클라이언트 N명 보유 종목 각각 ①+②+④ 자동 분석 → 주간 보고서. 1인이 50+ 클라이언트 처리
- **재테크 유튜버 — 매일 콘텐츠 자동 양산** — ③+① 매일 아침 자동 분석 → 영상 스크립트 → 매일 영상 1개 업로드
- **재테크 블로거** — 본인 보유 종목 5개에 매주 ②+④+⑤ 분석 → 블로그 글 → 광고 수익
- **재테크 학습자** — 5개 프롬프트로 매일 30분 학습 + 모의 매매 → 6개월 후 실전 진입
- **부동산·암호화폐 투자자** — 같은 5종 프롬프트를 부동산·암호화폐 용어로 치환 → 다른 자산군 분석
- **사내 투자 동아리** — 회사 동료 5-10명이 각자 종목 분석 후 ⑤ 결과 공유 → 집단 지성

## 💡 아이디어

- **자동 매일 보고서 SaaS** — 사용자 보유 종목 등록 → 매일 5종 자동 실행 → 슬랙·텔레그램 푸시 → 월 $10-20 구독
- **재테크 뉴스레터 자동화** — 5종 프롬프트로 매주 시장 분석 → 뉴스레터 자동 발송 → 광고·제휴 수익
- **종목 분석 자동화 1인 사업** — 클라이언트 1명당 본인 종목 5개 + 5종 분석 = 월간 보고서 → $50-100/월/클라이언트
- **AI 주식 강의 패키지** — 5종 프롬프트 + 활용법 + 책 《제미나이 주식투자》 추천 강의 4시간 ($100-200)
- **종목 코드 자동 입력 봇** — 사용자가 종목명만 말하면 자동으로 5종 프롬프트 실행 + 결과 통합 → 카카오톡 봇
- **백테스트 자동화 도구** — 과거 시점의 ⑤ 결과 vs 실제 시장 결과 비교 → 본인 프롬프트 정확도 검증

## 주의사항

- **AI 분석은 보조 도구 — 투자 결정은 본인 책임** — 5개 프롬프트 결과는 참고용. **AI 판단으로 매매 결정 시 손실 위험 전적으로 본인**
- **실시간 데이터 정확도** — Gemini·Claude·ChatGPT 학습 데이터 시점 차 있음. **최신 시점 데이터는 별도 증권사 앱·HTS 로 검증**
- **PER·PBR·ROE 수치 정확도** — AI 가 환각(hallucination) 일으킬 수 있음. **DART·증권사 리포트로 재검증** 필수
- **거시 경제 예측은 불확실** — ⑤ 수석 애널리스트 결과는 시나리오 중 하나일 뿐. **다른 의견·반대 시나리오** 도 같이 검토
- **프롬프트의 [ ] 안 정보 정확히** — 종목명·섹터·시점 정확하게 입력. 모호하면 답변도 모호
- **개인정보 주의** — 본인 보유 종목·평단·수익률 같은 민감 정보는 외부 LLM 에 신중히 입력
- **법적 책임** — 본 가이드는 투자 권유 X. 본인 투자 손실에 대한 법적 책임 X
