## 따라하기

원본은 와디즈 오픈 예정 콘텐츠로 8종 구체적 프롬프트는 미공개 상태입니다. 아래는 공개된 5종 + 직접 구축 가능한 확장 패턴.

### 1. 광고 효율 분석 AI

```
너는 인스타·페이스북 광고 운영 분석가야.
내 광고 데이터: [노출 / 클릭 / 전환 / 비용 / ROAS]
1주차 vs 2주차 변화 정리하고, 효율 안 좋은 캠페인 3개와
즉시 적용할 개선 포인트 3가지 알려줘.
표 형태로 깔끔하게.
```

### 2. 상품 소싱 아이디어 AI

```
나는 [카테고리] 셀러야 (예: 20-30대 여성 패션 / 홈인테리어 소품).
요즘 인스타·SNS에서 뜨고 있는 신상 트렌드 5가지를 알려줘.
각 트렌드마다:
- 왜 뜨고 있는지 (트리거)
- 도매처에서 찾을 수 있는 키워드
- 마진율 좋은 가격대 추천
- 예상 판매 시즌
```

### 3. 상세페이지 개선 포인트 AI

```
내 상품 상세페이지 텍스트: [붙여넣기]
가격: [원]
타깃: [고객층]
구매 전환율 높이기 위한 개선점 5가지를 알려줘:
- 후킹 카피 보강 위치
- 신뢰 요소 추가 위치 (리뷰·인증·전후 비교)
- 가격 저항 줄이는 표현
- 행동 유도 (CTA) 강화 포인트
- A/B 테스트 권장 영역
```

### 4. CS 답변 초안 AI

```
고객 문의 내용: [붙여넣기]
상품: [상품명 / 가격]
주문일·배송 상태: [정보]

상황에 맞는 CS 답변 초안 3가지 톤으로 작성:
- 차분한 톤 (단순 안내)
- 진심 사과 톤 (배송 지연·불량)
- 친근한 톤 (단골·재구매)
각각 100자 이내.
```

### 5. 경쟁사·리뷰 키워드 정리 AI

```
경쟁사 [상품명 / URL] 의 최근 리뷰 100개에서
- 긍정 키워드 TOP 10 (빈도 순)
- 부정 키워드 TOP 10 (빈도 순)
- 우리 상품이 보완할 수 있는 차별점 5가지
표 형태로 정리해줘.
(리뷰 텍스트는 내가 붙여넣기 할게)
```

### 추가 구축 가능한 3종 (확장)

**상품명 SEO 최적화 AI**: 카테고리·키워드·금지어 입력 → 스마트스토어 상위 노출용 상품명 5개

**가격 전략 AI**: 경쟁사 가격 + 원가 + 마진 입력 → 가격대별 예상 매출 + 손익분기점

**시즌 캘린더 AI**: 카테고리 → 연간 시즌 마케팅 캘린더 자동 작성 (광고 집중 시기·재고 준비 시기)

## 활용 예시

- **스마트스토어 1인 셀러 — 주간 운영 자동화** — 월요일 아침 광고 효율 분석 / 화요일 신상 소싱 / 수요일 상세페이지 점검 / 목요일 경쟁사 리뷰 / 금요일 CS 일괄 답변 — 주 5일 운영 시간 50% 단축
- **소호 패션몰 — 트렌드 추적 자동화** — 매일 아침 30분, 상품 소싱 AI 로 그날의 트렌드 5개 받아 도매처 확인 → 발주 결정 1시간 안에
- **신규 1인 셀러 — 학습 곡선 단축** — 광고 운영 / 상세페이지 카피 / CS 응대 — 모두 처음이라도 AI 비서로 매뉴얼 없이 일주일 만에 가동
- **부업 셀러 — 본업 병행 운영** — 본업 중에도 CS 답변 AI 로 1차 응대 자동화 → 퇴근 후 1-2시간만 최종 검토하면 운영 가능
- **컨설팅 강사** — 8종 비서 세팅법을 4시간 강의로 패키징, 수강생 30-50명 단위 모집

- **AI 답변은 시장 데이터 시점 차** — 트렌드·가격은 시간 차 있을 수 있어 실제 도매처·시장 가격 재확인 필수
