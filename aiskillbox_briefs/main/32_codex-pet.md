💡 이 스킬은 **OpenAI Codex 데스크톱 앱 내장 Codex Pet — 플로팅 AI 동반자 UI** 활용 가이드로, 작은 동물의 행동 상태로 **Codex 가 지금 무엇을 하는지 한눈에 파악**하는 멀티태스킹 인지 부담 해결 시스템입니다.

## 이게 뭔가요?

**Codex Pet = OpenAI Codex 데스크톱 앱 내장 플로팅 AI 동반자 UI**. 단순히 귀여운 장식이 아니라 **Codex 가 지금 무엇을 하고 있는지 직관적으로 알려주는 실용적 기능**.

**해결하는 문제**:
> Codex 에게 코딩을 시키면 몇 분씩 기다리며 이런 고민:
> - "지금 생각 중인가?"
> - "내 답변을 기다리며 멈춰 있는 건가?"
> - "이미 완료하고 리뷰를 기다리는 중인가?"

**작은 동물의 행동 상태**로 이 문제 해결.

### 펫의 3가지 핵심 상태

**상태 / 표시 의미 / 실무 활용 팁**:

- 🏃 **Running** (달리는 중) / Codex 가 현재 작업 진행 중 / **다른 업무로 전환해도 OK**
- ⏳ **Waiting** (대기 중) / 사용자 입력·응답 기다리는 중 / **빠르게 확인하고 입력 필요**
- ✅ **Review** (검토 대기) / 작업 완료, 리뷰 요청 상태 / **결과물 확인 타이밍**


🎯 **멀티태스킹 환경에서 특히 효과적**. 창을 일일이 전환하지 않아도 **펫 상태만 보면 작업 흐름 파악**.

💰 유료 필요: **ChatGPT 유료 구독 필수** (Plus·Pro·Business·Enterprise·Edu)
✅ 무료 대안: 현재 임시로 Free·Go 플랜도 사용 가능 — 정식은 유료

**플랜별 Codex 사용 가능 여부**:

**플랜 / Codex 사용**:

- Free / Go / 한시적 무료 제공 중
- **Plus** / ✅ 사용 가능
- **Pro $100** / ✅ 2x 활용 (2026.05.31 까지 프로모)
- **Pro $200** / ✅ 최대 활용
- Business / Enterprise / Edu / ✅ 사용 가능


## 따라하기

### ⚠️ 시작 전 사전 준비

**1. Codex Desktop 앱 설치 필수** (CLI 버전 X):

```bash
# 방법 1: npm 설치 후 데스크톱 앱 실행
npm i -g @openai/codex
codex app

# 방법 2: Homebrew (macOS)
brew install --cask codex
```

혹은 **Codex App 페이지에서 직접 다운로드**.

### Step 1 — Codex Pet 활성화하기

**기본 설정 (3단계)**:

```
1단계: 최신 버전 Codex로 업데이트 (Pets 기능 포함 버전 필요)
2단계: 입력창에 /pet 입력
   또는 Settings → Appearance → Pets 이동
3단계: 원하는 내장 펫 선택 또는 커스텀 펫 설치
```

**내장 펫 빠르게 켜기/끄기**:

```
/pet
```

입력창에 `/pet` 입력 → 펫 토글.

### Step 2 — 커스텀 펫 만들기 (hatch-pet)

기본 제공 펫 외에 **나만의 캐릭터 직접 제작 가능**.

**hatch-pet 스킬 설치** (신규 시):

```
# 1. Codex 입력창에서 스킬 설치
$skill-installer hatch-pet

# 2. 스킬 리로드: Cmd+K (macOS) / Ctrl+K (Windows)
→ "Force Reload Skills" 선택

# 3. 펫 생성 시작
$hatch-pet create a new pet inspired by my recent projects
```

`hatch-pet` 은 [openai/skills](https://github.com/openai/skills) 리포지토리의 공식 스킬.

**hatch-pet 명령어 사용법**:

```
# 기본 형식
$hatch-pet [원하는 캐릭터 설명]

# 예시 1: 코드 스타일 기반
$hatch-pet 내 최근 코드 스타일(주로 Rust)을 기반으로 펫을 부화시켜줘
→ 게(Crab) 캐릭터가 생성될 가능성이 높습니다

# 예시 2: 구체적인 캐릭터 지정
$hatch-pet 실험실 가운을 입은 카피바라를 만들어줘

# 예시 3: 사진 기반 생성
$hatch-pet 이 사진 속 고양이를 Codex 펫으로 만들어줘
(사진 첨부)

# 예시 4: 상태 반응 지정
$hatch-pet 작은 픽셀 스타일의 검은 고양이, 노란 눈,
코딩할 때 졸다가 완료되면 반짝이는 느낌의 Codex pet 만들어줘
```

### Step 3 — 커스텀 펫 제작 전체 흐름

**① 콘셉트 정하기**

펫은 작은 크기로 표시 → 단순하고 알아보기 쉬운 디자인:
- 픽셀 스타일 추천
- 외곽선 두껍게
- 디테일 최소화

**② hatch-pet 명령어로 생성 요청** (위 예시 참고)

**③ 기준 이미지(Base Image) 확인** — 생성된 기준 이미지가 모든 애니메이션의 원본

**④ 애니메이션 상태 설정** *(hatch-pet 스킬이 다 해줌)*:

**상태 이름 / 동작 의미**:

- idle / 평소 대기
- running-right / running-left / 좌우 이동
- waving / 완료 반응
- jumping / 강조
- failed / 오류 발생
- waiting / 입력 대기
- running / 작업 진행 중
- review / 검토 요청


**⑤ 스프라이트시트 생성** *(Codex가 다 해줌)*:

**항목 / 조건**:

- 전체 크기 / 1536 × 1872
- 셀 크기 / 192 × 208
- 구조 / 8 × 9
- 형식 / WebP
- 배경 / 투명


**⑥ 파일 구성** *(Codex가 다 해줌)*:

```
~/.codex/pets/[펫이름]/spritesheet.webp
~/.codex/pets/[펫이름]/pet.json
```

**⑦ pet.json 작성** *(Codex가 다 해줌)*:

```json
{
  "id": "your-pet-name",
  "displayName": "펫 표시 이름",
  "description": "상태 반응 설명",
  "spritesheetPath": "spritesheet.webp"
}
```

**⑧ Codex에 적용**:
- 설치 경로: `~/.codex/pets/[펫이름]`
- 설정값: `custom:[펫이름]`
- 앱 재실행 후 `/pet` 명령어로 확인

### 적용 확인 체크리스트

- [ ] 앱을 재실행했나요?
- [ ] `~/.codex/pets/[이름]/` 폴더가 존재하나요?
- [ ] `pet.json` 파일이 있나요?
- [ ] 파일명이 정확히 `spritesheet.webp` 인가요?
- [ ] 설정값이 `custom:[이름]` 형식인가요?

### 성향별 추천 전략

**나의 상황 / 추천 방법**:

- 기본부터 시작하고 싶다 / `/pet` 으로 **내장 펫 먼저 활성화**
- 개성 있는 펫을 원한다 / `$hatch-pet` 으로 **커스텀 생성**
- 집중력 방해될 것 같다 / **일단 끄고 사용**, 핵심 기능에 영향 없음
- Claude Code 도 함께 쓴다 / **Codex 에는 Pets, Claude Code 에는 MCP Buddy** 설치


### 실사용자 평가 (5점 만점)

**평가 항목 / 평균 점수 / 핵심 피드백**:

- 상태 인지 효율성 / ⭐ 4.6 / "진행률 표시줄보다 직관적"
- 멀티태스킹 도움 / ⭐ 4.4 / "어떤 작업이 대기 중인지 바로 파악"
- 커스터마이징 만족도 / ⭐ 4.7 / "나만의 캐릭터를 키우는 소속감"
- 장기 사용 의향 / ⭐ 4.1 / "없으면 허전할 것 같다"

## 활용 예시

- **시니어 개발자 — 멀티태스킹 효율** — 3-5개 Codex 세션 동시 운영 시 펫 상태로 어디 봐야 할지 즉시 인지. 생산성 30%+
- **개인 개발자 — 코딩 동기 부여** — 본인 캐릭터 만들어 정 붙이고 매일 코딩. **"내 펫 보고 싶어서 출근"** 같은 정성적 효과
- **백엔드 자동 작업 모니터링** — 마이그레이션·테스트·빌드 같은 긴 작업 시 펫 행동으로 진행 상황 추적. 화면 안 봐도 됨
- **팀 협업 — 공통 펫 캐릭터** — 회사 마스코트로 팀원 모두 같은 펫. 사내 문화 형성
- **AI 강사 — 학생 동기 부여** — 학생들에게 본인 hatch-pet 만들기 과제 → 코딩 학습 진입 장벽 ↓
- **콘텐츠 크리에이터** — 본인 hatch-pet 만들기 과정을 영상화 → 유튜브 콘텐츠 + Codex 광고 효과
- **사내 표준화 — 팀별 펫 캐릭터** — 부서별 다른 펫으로 정체성 형성 (백엔드 = 게, 프론트 = 새, QA = 펭귄)
- **부캐 운영 — 본인 hatch-pet IP** — 본인 펫을 인스타·트위터 캐릭터로 → 본인 브랜딩 + 굿즈 사업

## 💡 아이디어

- **hatch-pet 캐릭터 마켓플레이스** — 디자이너가 만든 고품질 펫 100+ 종 → 카테고리별 $5-20/펫
- **펫 IP → 굿즈 사업** — 본인 hatch-pet 으로 스티커·인형·티셔츠 → Etsy 판매 / 한국 굿즈 마켓
- **사내 Codex 도입 컨설팅** — 회사별 마스코트 펫 제작 + Codex 도입 가이드 → 컨설팅 패키지 $5,000-15,000
- **MCP Buddy 통합 (Claude Code 용)** — Codex Pets 와 Claude Code MCP Buddy 양립 운영 강의 → 4시간 패키지 ($100-200)
- **AI 동반자 UX 연구** — 펫 상태 인지 효율성 학술 연구 → 논문 발표 → AI 도구 UX 표준화 기여
- **펫 행동 데이터 분석 SaaS** — 본인의 펫 상태 시간대별 통계 → 본인 작업 패턴 분석 → 월 $5
- **펫 캐릭터 자동 생성 봇** — 사용자 정보(직업·취향·MBTI) → 펫 자동 생성 + 설치 자동화

## 주의사항

- **CLI 버전 X — Desktop 앱만** — 터미널 Codex CLI 사용자는 펫 못 봄. Desktop 앱 별도 설치 필요
- **ChatGPT 유료 구독 필수 (정식 사용)** — Free 는 한시적. 본격 사용은 Plus($20)+ 권장
- **집중력 방해 가능성** — 펫 너무 자주 보면 오히려 산만. **익숙해질 때까지는 끄고 사용**해도 OK
- **커스텀 펫 — 외부 IP 표절 주의** — 디즈니·포켓몬 같은 기존 IP 그대로 따라 만들기 X. 라이선스 이슈
- **스프라이트시트 192×208 셀 크기 — hatch-pet 이 자동** — 본인이 수동 제작 시 정확한 크기 안 맞으면 깨짐
- **pet.json 형식 변경 가능성** — Codex 버전 업데이트 시 형식 변경 가능. 변경 시 본인 펫 재설치 필요
- **상태 매핑 비표준** — `running`, `waiting`, `review` 외 새 상태 OpenAI 가 추가하면 본인 펫 못 표현 → 정기 업데이트
- **공식 vs 커뮤니티 스킬** — `hatch-pet` 은 OpenAI 공식 (`openai/skills` 리포). 다른 커뮤니티 스킬은 보안 검토 필요
