💡 이 스킬은 **Claude Code 카운슬(Council)** — 한 질문에 **5명의 AI 전문가**가 각기 다른 관점으로 분석하고 피어 리뷰·트레이드오프 분석을 거쳐 최적의 결론을 도출하는 다중 에이전트 의사결정 시스템입니다.

## 이게 뭔가요?

**Claude Code 에서 작동하는 다중 에이전트 의사결정 지원 스킬**입니다. `Ask the Council:` 트리거 한 줄로 5명의 전문가 에이전트(반대론자·원칙주의자·확장론자·외부인·실행가)가 각자의 렌즈로 문제를 해부합니다.

핵심 가치 — **단일 AI 의 태생적 편향과 환각을 시스템적으로 차단**:
- **다중 에이전트 합의**: 1명의 똑똑한 AI 가 아닌, 5명의 전문가가 논쟁하고 합의
- **타 AI 모델 교차 검증**: 필요 시 Gemini · GPT 등 경쟁 AI 모델을 호출해 **세컨드 오피니언(Second Opinion)** 확보
- **완벽한 커스텀**: 비즈니스·프로젝트 성격에 맞춰 위원회 멤버(에이전트 역할) 자유롭게 재구성

💰 유료 필요: Claude Max (Claude Code CLI 사용)
✅ 무료 대안: 동일 패턴을 Gemini 무료 API + 수동 프롬프트 체이닝으로 흉내 가능

## 따라하기

1. **카운슬 스킬 설치** — Claude Code CLI 환경에 다운로드 (원본 노션 페이지 안내 따름)

2. **에이전트 역할 커스터마이즈** — 5명의 멤버를 본인 비즈니스에 맞게 프롬프트 수정

3. **호출 — 입력창에 `Ask the Council:` 트리거 후 질문**

   ```
   Ask the Council:
   우리가 새로 출시하는 AI 교육 B2B 서비스의 과금 모델을
   '월 구독' 으로 할지, '건별 결제' 로 할지 결정해야 해.
   각 방식의 리스크와 기회를 다각도로 분석하고,
   최종적으로 어떤 모델을 선택해야 할지 명확한 근거와 함께 제시해 줘.
   ```

4. **결과 받기** — 5명의 독립 분석 → 피어 리뷰 → 트레이드오프 분석 → 의장 에이전트의 최종 결론·다음 스텝

## 활용 예시

- **신사업 Go/No-Go 결정** — 신규 SaaS 출시 전, "이 시장에 진입할까?" 카운슬에 던지면 반대론자가 시장 리스크를, 확장론자가 기회를, 실행가가 90일 액션 플랜을 한 번에 정리
- **방향성 피봇 판단** — 6개월간 PMF 못 잡은 스타트업이 "사업 모델 피봇할까, 시장 바꿀까?" 질문 → 외부인 시점에서 편견 없는 답
- **투자·자금 운용 결정** — "이번 분기에 부동산 매각하고 주식 늘릴까?" 같은 개인 재무 결정에서 반대론자가 다운사이드 시나리오 강제 점검
- **이력 결정 / 진로 선택** — "이 회사로 이직할까?" 5인 각도(리스크·원칙·성장·객관·즉시 행동)로 분석 받기
- **콘텐츠·마케팅 전략** — "다음 캠페인 톤을 보수적으로 갈지 도발적으로 갈지" → 트레이드오프 정리

## 💡 아이디어

- **컨설팅 도구로 패키징** — 1인 컨설턴트가 카운슬을 자체 도구화 → 클라이언트에게 "5인 위원회 보고서" 형태로 제공, 기존 컨설팅 단가의 1/3 가격에 더 풍부한 분석
- **팀 의사결정 표준화** — 사내에 "결정 전 카운슬 통과" 룰 도입, 회의 시간 감소 + 의사결정 품질 일관성 확보
- **교육용 콘텐츠** — 5인 시점이 매번 다르게 답하는 흐름이 비판적 사고 교재로 좋음 → MBA·코칭 클래스에서 활용

## 주의사항

- **5명 에이전트 호출은 토큰 5배** — Claude Max 외에는 비용 부담 큼. 무료 모델로 흉내 낼 때는 호출 횟수 관리 필요
- 에이전트 역할 정의가 부실하면 5명이 비슷한 답만 줘 의미 없음 — 초기 커스터마이즈가 핵심
- **즉답형 단순 질문에는 과잉** — 정답이 있는 사실 확인에는 일반 Claude 한 번이 효율적
