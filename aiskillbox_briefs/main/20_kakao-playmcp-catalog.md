## 활용 예시

- **데이트·나들이 코스 설계** — *"이번 주말 신촌 데이트 코스 짜줘"* → ArtBridge 공연 + 여기어때 카페·숙소 + 팝업스토어 + 다이소(소품 쇼핑) 통합 추천
- **주식 투자자 — 정량 분석 자동화** — *"매출 5,000억 이상 코스피 200 중 부채비율 100% 이하 + 배당수익률 5% 이상"* → OpenDART + 미국 주식 정보 → 종목 스크리닝 자동화
- **부동산 매수자** — *"신혼집 강서구 25평 매물 + 가격 추이 + 근처 학군"* → 아파트 정보 + 네이버 검색(학군 정보) 통합 분석
- **1인 사업자 — 시장 조사** — *"이번 분기 뷰티 카테고리 검색 트렌드 + 인기 매장 분포"* → 네이버 데이터랩 + 다이소·올리브영 매장 분포 분석
- **콘텐츠 크리에이터** — *"이번 주 화제 팝업 + Apple 신규 공지 + 검색 트렌드"* → 매주 자동 트렌드 리포트 생성 → 콘텐츠 아이디어
- **택배 자영업자** — *"오늘 도착 예정 택배 전체 목록 + 사기 의심 URL 체크"* → 띵동 + 자동 알림으로 사무실 운영 자동화
- **일정 관리 자동화** — *"내일 미팅 + 동선 + 점심 추천"* → 투두메이트 + 여기어때 통합
