작업 단계에 맞춰 습관화하세요.

| 명령어 | 사용 시점 | 기대 효과 |
|---|---|---|

### 2. CLAUDE.md 룰북 템플릿

프로젝트 루트 또는 `~/.claude/CLAUDE.md` 에 아래 내용을 저장하세요. 클로드가 매번 이 규칙을 먼저 읽어 **불필요한 출력 토큰을 획기적으로 감소**:

```markdown
# Response Style
- 응답은 간결하게 작성하며, 불필요한 서문이나 요약은 금지합니다.
- 한 줄로 끝날 수 있는 답변은 한 줄로만 출력하세요.
- 코드만 요청한 경우, 코드에 대한 부연 설명은 생략하세요.

# Output Limits
- Bash output이 길 경우 `head`, `tail`, `jq` 등을 활용해 잘라서 보여주세요.
- 테스트 로그는 마지막 20줄만 분석하세요.

# Workflow
- 대규모 조사 및 분석 작업은 서브에이전트(Sub-agent)에 위임하세요.
- 메인 컨텍스트는 작업의 지휘 및 검토 역할만 수행하세요.
```

⚠️ 토큰 절감 효과는 진행 중인 프로젝트 규모와 작업 패턴에 따라 달라집니다.

### 3. 서브에이전트 패턴

메인 컨텍스트 오염을 막고 병렬 처리를 극대화하는 방법.

**기본 원칙**:
- **격리 작업**: 서브에이전트는 격리된 컨텍스트에서 작업
- **결과만 반환**: 진행 과정은 숨기고 최종 결과만 메인으로 반환
- **병렬 저장**: 3개 이상 병렬 작업 시, 각 결과를 **파일로 개별 저장**하고 메인은 '파일 경로 + 한 줄 요약'만 전달받도록 구성

**🚨 Opus 비용 함정**:
- **문제**: 서브에이전트는 부모 모델 설정을 상속. Opus 모델에서 서브에이전트 5개 병렬로 돌리면 Opus 토큰 비용이 **5배 폭증**
- **해결**: 단순 정보 조사·크롤링은 명시적으로 **Sonnet 모델** 을 지정해 위임

**서브에이전트 위임 기준**:
- ✅ 위임 추천: 다중 모듈 조사, 병렬 코드 리뷰
- ❌ 위임 비추천: 단일 검색, 짧은 Lookup, 순차 의존성 작업

### 4. autocompact 임계값 설정

기본 임계값(약 95%)을 낮춰 컨텍스트가 꽉 차기 전에 미리 압축. `~/.claude/settings.json`:

```json
{
  "env": {
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "75"
  }
}
```

권장 설정:
- 일반 작업: **60~75%**
- 매우 큰 컨텍스트 유지 필요: **85%**
