💡 이 스킬은 **HyperFrames + Claude 로 웹사이트 URL 하나만 던지면 광고 영상까지 자동 제작**하는 HTML→MP4 변환 프레임워크로, **인스타 릴스·틱톡·제품 소개·브랜드 광고** 다양한 포맷을 Claude Code 명령 한 줄로 만듭니다.

## 이게 뭔가요?

**HyperFrames — HTML → MP4 자동 변환 프레임워크**. Claude 에게 **웹사이트 주소 던지면 디자인 분석부터 영상 완성까지 자동**.

**만들 수 있는 영상 종류**:

| 종류 | 길이 | 포맷 |
|---|---|---|
| **인스타 릴스 / 스토리** | 10~15초 | 1080 × 1920 세로 |
| **틱톡 광고** | 10~15초 | 1080 × 1920 세로 |
| **제품 소개 영상** | 30~60초 | 1920 × 1080 가로 |
| **브랜드 광고** | 15~30초 | 원하는 포맷 |

💰 유료 필요: Claude Pro 이상 권장 (Claude Code 동작 필요)
✅ 무료 대안: 일부 클립은 Suno 무료 티어 (하루 5곡) + 본인 영상 편집 도구로 대체 가능

## 따라하기

### STEP 1. HyperFrames 셋업

Claude 에게 깃헙 링크 주며 **"적용하게 셋팅해달라"** 고 한 줄 명령:

```
HyperFrames 깃헙 레포 [URL] 를 내 프로젝트에 설치하고 셋업해줘.
Claude Code 슬래시 명령으로 /website-to-hyperframes 가 동작하도록.
```

### STEP 2. Claude Code 에서 한 줄 명령

```
/website-to-hyperframes https://원하는사이트.com 15초짜리 인스타 광고 만들어줘
```

Claude 가 프리뷰 URL 주면 브라우저에서 열기.

### STEP 3. 상세 프롬프트 (제품 정보 포함)

```
/hyperframes 사용해서 영상 만들어줘.

제품 : claudeasy
설명 : 클로드가 어려운 분들이 요즘 유행하는 것들을 사용하고,
      개발을 몰라도 알아서 척척 자동화 혹은 개발을 만들어주는 웹앱.
핵심 기능 : 200개 넘는 하네스 임베드, 추가로 없는 하네스는 알아서 만들어줌.
          내가 대답할 필요 없이 오케스트레이션이 알아서 대답해줌.
          나는 개발요청만 하면됨. 깃헙 트렌드를 실시간으로 볼 수 있고,
          내 프로젝트에 어떻게 적용하면 좋을지 바로 인사이트 줌.
타겟 : 비전공자 / 클로드가 어려운 초보.
길이 : 15초.
프로젝트 path: [본인 프로젝트 경로]
```

### STEP 4. MP4로 저장

Claude 가 만들어준 **웹페이지에서 Export → 다운받기**.

### STEP 5. Suno AI 로 배경음악 추가 (선택)

**사이트**: [https://suno.com](https://suno.com)
**무료 한도**: 하루 5곡

| 항목 | 입력 |
|---|---|
| **Lyrics** | 가사 (또는 Instrumental 체크 시 가사 없음) |
| **Style of Music** | 분위기 (예: `cinematic, ambient, minimal, emotional`) |
| **Title** | 곡 제목 |

**영상용 배경음악 추천 프롬프트**:

```
cinematic ambient, minimal piano, no vocals, soft, premium feel, 30 seconds
```

```
upbeat electronic, corporate, motivational, no lyrics, clean
```

```
J-pop rock, anime opening, energetic, female vocal, refreshing, 1 minute
```

**활용 팁**: 1막 (도입)·2막 (전개)·3막 (CTA) 별로 다른 BGM 으로 분위기 전환.

## 활용 예시

- **신제품 런칭 광고** — 본인 웹사이트 만들고 → URL 한 줄로 15초 인스타 광고 5종 생성 → A/B 테스트. 영상 외주 비용 0
- **에이전시·마케터 — 클라이언트 광고 양산** — 클라이언트 N개에게 매주 다른 광고 영상 제공 → 1인이 5-10 클라이언트 처리 가능
- **이커머스 셀러 — 상품별 영상 자동 생성** — 새 상품 등록할 때마다 상품 페이지 URL → 10초 영상. 모든 상품에 영상 부착
- **YouTube 광고 자동화** — 본인 영상 인트로·아웃트로 자동 생성 → 매번 별도 편집 X. 콘텐츠 양산 속도 ↑
- **B2B 영업 — 제품 소개 영상 즉시 제작** — 미팅 직전 본인 제품 페이지 URL → 1분 제품 소개 영상 → 미팅 처음 30초에 임팩트
- **개인 브랜딩** — 본인 포트폴리오·블로그·LinkedIn 페이지 → 15초 자기 소개 영상 → 인스타·LinkedIn 게시
- **부동산·매물 영상** — 매물 페이지 URL → 30초 영상 → 인스타·당근·번개장터 동시 활용

- **유튜브 자동 콘텐츠 채널** — Suno 자동 음악 + HyperFrames 자동 영상 → AI 콘텐츠 채널 운영. 광고 수익화

## 주의사항

- **저작권 — 본인 웹사이트만** — 타사 웹사이트 URL 로 광고 영상 만들어 본인 광고로 사용 X (라이선스·도용 이슈)
- **HyperFrames 셋업은 Claude Code 권한 필요** — 깃헙 레포 클론·로컬 빌드 가능한 환경 필수
- **Suno 무료 5곡 한도** — 광고 캠페인 대량 운영 시 빠르게 한도 도달. Suno Pro ($10/월) 권장
- **자동 생성 영상의 톤 검수 필수** — AI 가 본인 브랜드 톤에 안 맞는 영상 생성 가능. 첫 5개는 사람 검수
- **모바일 표시 검수** — 1080×1920 세로 영상은 인스타·틱톡 등에서 다르게 잘릴 수 있음. 실제 앱에서 미리 보기 필수
- **Suno 가사 한국어 발음 아쉬움** — 한국어 보컬은 발음 어색할 수 있음. 영어 가사 또는 Instrumental 권장
- **상업 사용 라이선스** — Suno 무료 플랜은 상업 사용 제한. 광고용은 Pro 플랜으로 라이선스 확인
