## 이게 뭔가요?

**디자이너 없이도 퀄리티 미친 이미지를 뽑아내는 사람들이 쓰는 16가지 검증된 영어 프롬프트 모음**. 단순 프롬프트 리스트가 아니라 각 프롬프트마다 **언제 쓰면 좋은지 / 어떤 결과물이 나오는지 / 어떤 콘텐츠에 활용할 수 있는지** 까지 같이 정리되어 있어 복붙해서 바로 쓰거나 본인 스타일로 변형 가능.

핵심 가치:
- **6단계 공식** — 키워드 나열 X, 구조화된 설명문이 결과물 퀄리티를 결정
- **3가지 치트키** — 렌즈/장비 명시 / 빛의 성질 정의 / 질감 디테일 극대화
- **한글 텍스트 렌더링** — 큰따옴표 + `verbatim` 으로 깨짐 없이

💰 유료 필요: 없음 — Bing Image Creator(DALL-E 3) / Gemini 이미지 / GPT2 이미지 등 무료 도구로 다 동작
✅ 추천 조합: Bing Image Creator 무료 / Leonardo AI 무료 / Gemini 무료

## 따라하기

### 3가지 핵심 치트키

**1. 구체적인 렌즈와 장비 명시** — 단순히 "사진" 이라고 쓰지 말고 `85mm f/1.8`, `Phase One XF`, `Arri Alexa` 같은 전문 장비를 언급하면 질감이 확 달라짐

**2. 빛의 성질 정의** — `Bright` 보다는 `Volumetric fog`, `Rim lighting`, `Golden hour backlight` 같이 빛의 방향과 질감 지정

**3. 질감과 디테일 극대화** — `Micro-pores`, `Subsurface scattering`, `Ray-traced reflections` 같은 용어로 결과물 디테일 강화

### 6단계 프롬프트 공식

**단계 / 항목 / 예시**:

- 1 / **Artifact** (결과물 유형) / Poster, UI Mockup, Product Shot
- 2 / **Subject** (주제) / Jazz musician, Wireless earbuds
- 3 / **Scene** (장면/상황) / Rainy rooftop at dusk
- 4 / **Details** (디테일) / Warm light from left
- 5 / **Constraints** (제약 조건) / No extra text, Sharp focus
- 6 / **Style** (스타일) / Kodak film style, 35mm

### 프롬프트 활용 꿀팁

**한글 텍스트 깨짐 없이 넣는 법** — 큰따옴표 `" "` 로 감싸고 `verbatim` (글자 그대로) 키워드 추가. 예: `Text: "역대급 성능!" verbatim`

**부정 프롬프트 활용** — 원치 않는 요소는 `No [요소]` 형식. 예: `No watermarks`, `No distorted hands`, `No extra text`

**인물 일관성 유지** — 연속으로 같은 인물 만들 때: `Keep the character's facial features identical to the previous image`

**결과물 수정 요청** — 사진작가에게 말하듯 구체적으로: `Make the lighting more dramatic`, `Change the camera angle to low-angle`, `Add more contrast to the shadows`

**이미지 참조 활용** — 기존 이미지 업로드 후: `이 이미지의 스타일을 유지하면서 [새로운 주제]를 그려줘`
