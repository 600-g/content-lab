## 따라하기

### 01 — 학습 로드맵 만들기

**언제 쓰나**: 새로운 분야를 처음 시작할 때, 어디서부터 공부해야 할지 막막할 때

복붙 프롬프트:

```
나는 [목표]를 위해 [스킬]을 배우고 싶어.
주당 [시간] 투자 가능.
무료 자료만 써서 주차별 학습 계획 짜줘.
각 주마다 무엇을 공부하고, 무엇을 만들고,
이해했는지 확인하는 법까지.
```

사용 예시 — [목표]: 유튜브 채널 운영 / [스킬]: 영상 편집 / [시간]: 주 5시간

### 02 — 12살도 이해하게 설명해줘

**언제 쓰나**: 어려운 개념을 처음 접할 때, 쉽게 이해하고 싶을 때

복붙 프롬프트:

```
[복잡한 개념]을 비유로 설명해줘.
기초→중급→심화 3단계로.
마지막에 내가 이해했는지 확인할 질문 3개도.
```

사용 예시 — [복잡한 개념]: 양자컴퓨터 / 블록체인 / SEO 알고리즘

### 03 — 이해도 테스트

**언제 쓰나**: 배운 내용을 제대로 이해했는지 확인하고 싶을 때

복붙 프롬프트:

```
방금 배운 [개념] 관련 퀴즈 5개 내줘.
틀리면 틀린 이유와 원리를 설명해줘.
단순 정답 말고.
```

**팁**: 퀴즈를 풀고 나서 틀린 문제만 다시 모아서 복습 세션 만들어달라고 하면 효과 극대화

### 04 — 책 한 권을 10분에 요약

**언제 쓰나**: 책·강의 내용을 빠르게 흡수하고 오늘 바로 적용하고 싶을 때

복붙 프롬프트:

```
[책/강의]의 핵심 인사이트 10가지를 3~4문장으로 요약해줘.
각 인사이트마다 오늘 바로 실천할 수 있는
한 가지 행동도.
```

사용 예시 — [책/강의]: 아토믹 해빗 / 부의 추월차선 / 마케팅 불변의 법칙

### 05 — 내 실수에서 배우기

**언제 쓰나**: 틀린 문제나 잘못 작성한 내용에서 원리를 파악하고 싶을 때

복붙 프롬프트:

```
내가 [문제를 해결/작성]한 내용이야: [붙여넣기].
무엇을 틀렸고 왜 틀렸는지 분석해줘.
정답보다 원리를 알고 싶어.
연습 문제 3개도.
```

**팁**: 에세이·코드·수학 문제·영어 작문 등 뭐든 붙여넣으면 동작

### 06 — 무료 자료 큐레이션

**언제 쓰나**: 돈 없이 제대로 배우고 싶을 때

복붙 프롬프트:

```
[주제]를 배우고 싶어.
돈 없이 배울 수 있는 최고의 무료 자료를 순위별로 알려줘.
유튜브, 플랫폼 강의, 커뮤니티 포함.
```

사용 예시 — [주제]: 파이썬 / 포토샵 / 영어회화 / AI 활용

### 07 — 소크라테스식 AI 튜터

**언제 쓰나**: 단순히 정답을 받는 게 아니라, 스스로 생각하는 힘을 키우고 싶을 때

복붙 프롬프트:

```
[과목] 전문 튜터 역할을 해줘.
소크라테스식으로 질문하며 내가 스스로 깨닫게 도와줘.
2번 막히면 직접 설명하고 다시 테스트해줘.
```

사용 예시 — [과목]: 철학 / 경제학 / 마케팅 전략 / 글쓰기

### 만능 시작 프롬프트 — 오늘 당장 복붙

```
나는 [목표]를 이루고 싶어.
[스킬]을 처음부터 가르쳐줘.
비유와 예시를 사용하고,
내가 이해했는지 확인해줘.
틀리면 원리부터 설명해줘.
```
