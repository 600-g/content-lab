💡 이 스킬은 **월 2~4만원 링크인바이오 서비스를 Claude 로 직접 만들어 평생 무료**로 쓰는 방법으로, 디자인 커스텀·방문자 분석·슬랙 알림 연동까지 포함된 1인 사업자용 완전 자체 솔루션입니다.

## 이게 뭔가요?

**Linktree·LiketoKnow·Hago 같은 링크인바이오 SaaS 를 Claude 로 자체 구축**하는 패턴. 인스타·유튜브·트위터 등 **단일 URL 만 표시 가능한 곳에서 여러 링크를 모아 보여주는 랜딩 페이지**를 본인 도메인에 무료로 호스팅.

**SaaS 대비 핵심 장점**:
- **월 0원** — 한 번 만들면 평생 무료 (vs Linktree Pro 월 $9, Hago 월 ₩39,000)
- **디자인 100% 커스텀** — SaaS 의 템플릿 제약 X, 본인 브랜드 톤에 맞춤 가능
- **이름·전화번호 캡처 → 슬랙 알림** — 리드 수집 워크플로우 직접 통합
- **방문자 분석** — Google Analytics / Vercel Analytics 자체 연동
- **백엔드 코드 0줄** — Claude 가 HTML/CSS/JS 통합 페이지 한 번에 출력

💰 유료 필요: 없음 (호스팅도 Vercel/Cloudflare Pages 무료 티어 충분)
✅ 무료 대안: Claude 무료 / ChatGPT 무료 어떤 것이든 동작

## 따라하기

### STEP 1. Claude 에 요구사항 전달

**프롬프트 예시 (복붙용)**

```
나는 [사업/직업] 운영자야. 인스타·유튜브에서 쓸 링크인바이오 페이지를
정적 HTML 한 파일로 만들어줘.

요구사항:
- 단일 index.html 파일 (외부 의존성 최소)
- 디자인: [예: 미니멀 / 핑크 그라데이션 / 다크 모드]
- 상단: 프로필 사진 + 이름 + 한 줄 소개
- 중앙: 링크 버튼 6개 (각각 아이콘+이름+URL 변경 가능하게)
- 하단: 이름·전화번호 입력 → Slack Webhook 으로 전송
- 모바일 우선 디자인 (Tailwind CSS CDN 사용)
- Vercel Analytics 스니펫 자리 표시
```

### STEP 2. Slack Webhook 받기

1. Slack → 워크스페이스 → **Apps** → "Incoming Webhooks" 추가
2. 알림 받을 채널 선택 → Webhook URL 복사 (`https://hooks.slack.com/services/...`)
3. Claude 가 만들어준 `fetch()` 코드의 URL 부분에 붙여넣기

### STEP 3. 호스팅 (3가지 무료 옵션)

| 플랫폼 | 장점 | 권장 |
|---|---|---|
| **GitHub Pages** | 단순, GitHub 계정만 있으면 OK | ⭐ 초보자 |
| **Vercel** | Analytics 무료 / 빌드 자동화 | ⭐⭐ 일반 |
| **Cloudflare Pages** | CDN 빠름 / 트래픽 무제한 | ⭐⭐ 트래픽 많을 때 |

배포 명령 예시 (Vercel):

```bash
npm i -g vercel
vercel --prod
```

### STEP 4. 커스텀 도메인 (선택)

- **Vercel/CF Pages 대시보드 → Domains → Add** → 본인 도메인 (`bio.example.com`) DNS A 레코드 / CNAME 추가
- SSL 인증서 자동 발급
- 이후 인스타 바이오에 `bio.example.com` 으로 노출

### STEP 5. 방문자 분석 추가

- **Google Analytics 4**: gtag 스니펫 1줄을 `<head>` 에 추가
- **Vercel Analytics**: Vercel 프로젝트 설정에서 **Analytics 활성화** → 자동 적용

## 활용 예시

- **1인 콘텐츠 크리에이터 — 콜라보·DM 캡처** — 인스타 바이오 링크 → 자체 링크인바이오 → 협업 문의 폼 → Slack 즉시 알림. **SaaS 월 $9 절약** + 모든 리드를 슬랙에서 즉시 응대
- **소상공인 — 카페·헬스장·미용실 메뉴 페이지** — 인스타 바이오에 메뉴·예약·후기 버튼을 모아 표시. 디자인은 본인 매장 톤에 맞춤
- **부동산 중개사 — 매물 목록 + 카톡 연결** — 링크인바이오 안에 진행 중인 매물 6개 → 각각 카카오톡 채널 자동 연결
- **인플루언서 — 어필리에이트 캠페인 분리** — 캠페인별로 다른 페이지 URL 운영 → 클릭률 비교 → 어떤 캠페인이 효과 좋은지 데이터 기반 의사결정
- **취준생·포트폴리오 — 깃허브·블로그·이력서 한 곳에** — 채용 담당자가 1클릭으로 모든 자료 접근. 본인 브랜딩 강화
- **B2B 영업 담당자 — QR 명함** — 명함에 QR → 링크인바이오 → 회사 소개·미팅 예약·자료 다운로드 즉시 안내

## 주의사항

- **Slack Webhook URL 노출 위험** — 클라이언트 JS 에 직접 박으면 누군가 도용해서 스팸 발송 가능. **Vercel Edge Function** 같은 서버리스 함수로 한 단계 감싸는 것 권장
- **GDPR·개인정보보호 동의** — 이름·전화번호 받기 전 **체크박스 (동의 받기)** + 개인정보처리방침 링크 필수. 한국은 KISA 가이드 준수
- **모바일 표시 검수** — 인스타·유튜브 바이오에서 진입 시 **인앱 브라우저** 라서 일부 CSS 가 다르게 보일 수 있음. 실제 인스타 앱에서 테스트
- **백엔드 없이는 데이터 영속화 X** — 입력받은 이름·전화번호는 슬랙으로 전송될 뿐 DB 에 저장 X. DB 필요하면 **Supabase 무료 티어** 추가 권장
