💡 이 스킬은 **6가지 인스타그램 카드뉴스 디자인 템플릿 프롬프트 팩**으로, 주제·계정명만 입력하면 컬러 추출·레이아웃·Gemini 이미지 프롬프트까지 한 번에 생성되는 **AI 티 안 나는 카드뉴스 자동 생성기**입니다.

## 이게 뭔가요?

**Claude AI 에 프롬프트 한 번만 붙여넣으면 카드뉴스 한 시리즈 전체를 만들어주는 템플릿 팩**. 디자인 1~6 각각에 풀 프롬프트가 정의되어 있어, 사용자는 `[주제]` 와 `@[계정명]` 만 채우면 됩니다.

핵심 구조:
- **컬러 추출 규칙** — 첨부 이미지 또는 컬러 조합에서 주조색·보조색·배경색 자동 추출
- **카드 구성** — 표지 / 본문 / 마무리(CTA) 자동 분배, 카드 수는 주제 분량에 맞춰 자동
- **Gemini 이미지 프롬프트** — 영어로 정확히 박혀 이미지 생성 AI 에 바로 사용 가능
- **HTML 토글 출력** — 클릭하면 다음 카드로 넘어가는 형태로 최종 출력

💰 유료 필요: 없음 (Claude 무료 + Gemini 무료 조합 가능)
✅ 무료 대안: Claude 무료 / Gemini 1.5 Flash 무료 / Bing Image Creator 무료 — 어느 조합도 동작

## 따라하기

1. **Claude AI 접속** — claude.com 또는 앱

2. **원하는 디자인 번호(1~6) 의 프롬프트를 복사** — 아래 6가지 중 선택

3. **프롬프트 맨 위 `[주제]` 와 `@[계정명]` 채우기** — 컬러 조합 또는 레퍼런스 이미지를 같이 첨부하면 이미지에서 색상 추출

4. **Claude 가 출력한 Gemini 영어 프롬프트를 복사** → Gemini / Bing / ChatGPT 이미지 생성기에 붙여넣어 카드별 이미지 생성

5. **결과는 HTML 토글 형태** — 클릭으로 카드 넘기며 미리보기, 인스타에 업로드

### 디자인 1 — 이미지·텍스트 반반

```
[주제]에 대한 인스타그램 카드뉴스를 만들어줘.
계정명: @[계정명]
사이즈는 1080×1350px 기준이야.

── 컬러 추출 ──
첨부한 이미지(또는 아래 컬러 조합)에서
주조색 1개, 보조색 1개, 배경색 1개를 추출해줘.
추출한 컬러를 아래 역할에 적용해:
- 배경색 → 텍스트 블록 배경
- 주조색 → 포인트 강조 문구 컬러
- 보조색 → 본문 텍스트 컬러
모든 카드에 동일한 컬러 팔레트를 일관되게 유지해줘.

── 절대 금지 요소 (예외 없음) ──
① 카테고리 태그 / 필 뱃지 / 라벨
② 서브텍스트 / 소제목 / 부제
③ 모든 종류의 선(line) 요소
④ 페이지 번호
⑤ 이미지와 텍스트 블록 사이의 추가 장식 요소

── 카드 구성 ──
카드 수는 주제 분량에 맞게 자동으로 정해줘.

[ 1. 표지 카드 ]
상단 이미지 영역이 카드의 3/5, 하단 텍스트 블록이 2/5.
텍스트 블록 배경: 추출한 배경색. 메인 제목(상단) + @계정명(하단 고정).
제목: 주제에 맞는 후킹 멘트 자동 생성 (질문형/숫자형/반전형/공감형 중 가장 강한 스타일).

[GEMINI PROMPT]
"A [구체적 장면 묘사 — 주제와 직접 연관],
[감정/분위기], [구도/시점],
keep the lower area clear, main subject centered,
no text, no logos, 4:3 ratio, cinematic photo"

[ 2. 본문 카드 ]
레이아웃 자동 선택:
- 본문 텍스트 2줄 이하 → A/B/C 중 선택
- 본문 텍스트 3줄 이상 → A 또는 B만 선택
A: 이미지 위(3/5) + 텍스트 아래(2/5)
B: 텍스트 위(2/5) + 이미지 아래(3/5)
C: 이미지 좌(1/2) + 텍스트 우(1/2)
포인트 강조 문구: 추출한 주조색. 본문 텍스트: 추출한 보조색.

[GEMINI PROMPT]
"A [카드 내용과 직접 연관된 구체적 장면],
[감정/분위기 묘사], [구도 — close-up/wide/bird's eye 등],
[스타일 — cinematic photo/flat illustration/3D render 중 내용에 맞게],
no text, no logos, square format"

[ 3. 마무리 카드 ]
이미지 위(3/5) + 텍스트 블록 아래(2/5).
CTA 문구: 주제에 맞게 자동 생성 (저장 유도/행동 유도/공유 유도 중 선택).
CTA 컬러: 추출한 주조색.

[GEMINI PROMPT]
"A [주제의 마무리/결론을 상징하는 구체적 장면],
[따뜻하거나 희망적인 분위기 묘사],
[구도], [스타일],
no text, no logos, square format"

── 공통 규칙 ──
- 모든 Gemini 프롬프트는 영어로 작성
- 언어: 한국어
- 이미지와 텍스트 블록 사이 선/구분선 절대 없음
- 스타일: 클린, 모던, 에디토리얼
- 완성된 카드뉴스는 클릭하면 다음 카드로 넘어가는 토글 방식 HTML 로 출력
```

A: 포인트 문구 상단 + 본문 하단 → 상단/하단 각각 그라디언트 (중앙 투명)

C: 포인트 문구 + 본문 정중앙 → 중앙 기준 그라디언트
포인트 문구 컬러: 추출한 주조색.

[GEMINI PROMPT]
"A [카드 내용과 직접 연관된 구체적 장면], [감정/분위기 묘사],

CTA 컬러: 주조색. 폰트 컬러: 흰색 기본.

[GEMINI PROMPT]
"A [주제의 마무리를 상징하는 구체적 장면],
[따뜻하거나 희망적인 분위기], [구도],

── 공통 규칙 ──

## 활용 예시

- **1인 인스타그램 운영** — 매일 한 시리즈 카드뉴스 만들기. 주제(예: "AI 도구 추천 5선") + 계정명만 넣으면 5분 안에 표지·본문·마무리 + 영어 Gemini 프롬프트까지 완성
- **소상공인 SNS 마케팅 대행** — 클라이언트별 브랜드 컬러를 레퍼런스 이미지로 첨부 → 일관된 톤의 카드뉴스 시리즈 대량 생산 (인당 월 5-10 브랜드 관리 가능)
- **교육 콘텐츠 제작자** — "오늘의 단어 5개", "수학 공식 7선" 같은 학습 콘텐츠를 디자인 4(번호 강조) 로 시리즈화
- **스타트업 IR·블로그 콘텐츠** — 디자인 5/6 (좌우 분할) 로 회사 소개·서비스 기능·고객 후기를 카드뉴스 시리즈로 (블로그 글 → 인스타 캐러셀 전환)
- **유튜브·블로그 운영자의 인스타 보조 채널** — 본인 콘텐츠 핵심 인사이트를 매번 카드뉴스로 변환해 SNS 트래픽 확보

## 💡 아이디어

- **브랜드별 디자인 7번·8번 추가** — 6 디자인이 베이스, 본인 브랜드만의 7번째 디자인을 직접 만들어 차별화

## 주의사항

- **Gemini 프롬프트는 반드시 영어로** — 한국어 프롬프트는 결과 품질 하락. 영어 그대로 복붙 권장
- **이미지 영역의 한글 텍스트는 깨질 수 있음** — 텍스트는 항상 별도 레이어로 작성 (이미지 안에 한글을 넣지 말 것)
- **컬러 일관성** — 시리즈 내 카드들이 다른 컬러 팔레트로 생성되지 않도록 "모든 카드에 동일한 컬러 팔레트" 지시 반드시 유지
