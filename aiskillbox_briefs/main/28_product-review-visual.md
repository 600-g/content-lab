💡 이 스킬은 **매출이 달라지는 브랜드 사진 4가지 프롬프트**로, ChatGPT(GPT-4o)에 사진 1장 업로드 + 카테고리별 프롬프트 복붙만으로 **룩북·메뉴·카페·제품 후기** 4종 비주얼 콘텐츠를 10초컷에 만드는 자영업자·셀러용 완전 가이드입니다.

## 이게 뭔가요?

**브랜드 콘텐츠는 1편(일상편) 과 결이 달라요**:

**1편 (일상편) / 2편 (브랜드편)**:

- "감정과 맥락을 얹는 거" / "**이유와 설명을 얹는 거**"
- "오늘 기분 좋은 코디 ♡" / "여름 데일리 추천 / 사이즈 FREE / 신상 ♡"


요즘 인스타에서 **매출로 이어지는 콘텐츠들의 공통점**:
> 사진 위에 손글씨 한 줄, 작은 화살표, 체크리스트, 사용 후기 한 줄. **이게 다예요. 진짜로.**

**그냥 사진은 좋아요까지, 이유가 보이는 사진은 매출까지.**

### ⚠️ 브랜드 사진에 메모 넣을 때 — 이 3가지는 꼭 지키세요

**1️⃣ 메인 제품은 가리지 않기** — 손글씨가 아무리 좋아도 상품이 안 보이면 의미 X. **제품·메뉴·룩이 항상 주인공**, 손글씨는 보조.

**2️⃣ 문장은 짧게, 포인트는 선명하게** — 긴 설명 안 읽힘. **5~14자 안에서 핵심만**.

**3️⃣ 예쁜 말보다 추천하는 이유를 적기** — "오늘 기분 좋은 코디" (X 감성) → "여름 데일리 추천 / 사이즈 FREE / 신상" (✅ 이유)

### 📌 사용법 (4종 공통)

1. ChatGPT 에 사진 1장 업로드
2. 만들고 싶은 카테고리 프롬프트 복사
3. ChatGPT 에 그대로 붙여넣기
4. 대기 → 완성!

💰 유료 필요: ChatGPT Plus (GPT-4o 한글 텍스트 렌더링 안정)
✅ 무료 대안: Gemini 무료 + Canva 후처리 / Bing Image Creator

## 활용 예시

- **1인 패션 셀러 — 매주 룩북 양산** — 매주 신상 입고 시 룩북 프롬프트로 5-10개 콘텐츠 생성 → 인스타·블로그·스마트스토어 동시 배포. 콘텐츠 외주 비용 0
- **카페·식당 사장님** — 매월 시즌 메뉴 출시 시 메뉴 홍보 + 카페 홍보 콘텐츠 1주일 분량 미리 제작 → 매일 자동 업로드 봇으로 운영
- **화장품 1인 브랜드** — 신제품 출시 = 솔직 후기 프롬프트로 인스타·블로그·쿠팡 상세페이지용 콘텐츠 생성 → 매출 전환 측정
- **광고 대행사 — 클라이언트별 콘텐츠 양산** — 4가지 프롬프트 + 클라이언트 사진으로 매주 클라이언트당 10-20개 콘텐츠 제공 → 1인이 10+ 클라이언트 처리
- **부동산·자동차 매물** — 솔직 후기 프롬프트 응용 → 매물 사진 + 장점·평점 → 인스타 매물 콘텐츠 자동화
- **소상공인 컨설팅** — 카페·식당·미용실 사장님 대상 4가지 프롬프트 활용법 강의 + 본인 매장 콘텐츠 제작 패키지 → $300-500/회 컨설팅
- **인스타 마케팅 강의** — 4가지 프롬프트를 4시간 강의 패키지 → 수강생 50명 모집 ($100-200/회)
- **유튜브 / 블로그 콘텐츠 운영자** — 본인 콘텐츠 썸네일을 4가지 결로 양산 → A/B 테스트 → CTR 가장 높은 결 발견

## 💡 아이디어

- **사진→비주얼 콘텐츠 SaaS** — 사용자가 사진 업로드 + 카테고리 선택 → 4종 프롬프트 자동 적용 → 결과 1초 미리보기. 월 $10-20 구독
- **카페·식당 콘텐츠 대행** — 매주 카페·식당 5-10곳에서 사진 받기 → 4종 프롬프트로 매주 10-20개 콘텐츠 제공 → 매장당 $50-100/월
- **사진 + 손글씨 결 마켓플레이스** — 직군별·결별(빈티지·미니멀·키치·러브리) 100+ 변형 프롬프트 → $5-20/팩
- **인스타 운영 자동화 봇** — 사진 폴더 모니터링 → 자동 비주얼 콘텐츠 생성 → 자동 업로드. 매장 사장님 운영 시간 90% 절감
- **결혼식·돌잔치 추억 콘텐츠** — 가족 사진을 4종 결로 손글씨·메모지 추가 → 캘리그래피 효과 가족 앨범 → $20-50/패키지
- **셀러 컨설팅 1인 사업** — 1인 셀러 1명당 본인 제품 사진 분석 + 4종 프롬프트 커스터마이즈 + 1개월 콘텐츠 제작 가이드 → $200-500/건

- **상업 사용 라이선스 — ChatGPT 약관 확인** — 본인 비즈니스 콘텐츠 사용 가능하지만, 타사 IP·인물 사진은 X
- **광고처럼 보이지 않게 — 핵심 원칙** — 4가지 프롬프트 모두 "soft-sell" 강조. **🔥💰 이모지·빨강·과도한 SALE 문구 절대 X**

- **결과물 검수 필수** — AI 생성 텍스트가 의도와 다를 수 있음. 매장 운영 정보(영업시간·연락처) 등은 사람이 최종 확인
