# 🔧 aiskillbox 백엔드 교정 작업 지시서 v2

> 클로드 코드에게 이 파일을 주고 작업 시키면 됨
> 목적: aiskillbox가 수집할 때 Gemini가 만드는 노션 페이지 본문 퀄리티를 올리고, 검증 로직을 추가

---

## 배경

aiskillbox는 URL → 웹 스크래핑 → Gemini API 분석 → Notion API 등록하는 자동 수집 시스템이다.

현재 문제:
- Gemini가 본문을 너무 간소화해서 "두근컴퍼니 적용 2줄 + 출처"만 남김
- 원본의 프롬프트 전문, 코드, 상세 단계가 날아감
- 대제목이 매번 다름 ("어떻게 작동하나요?", "원리", "단계" 등)
- 코드블록이 `[[CODE_BLOCK_N]]`으로 치환되는 사고 발생

---

## 작업 내용 (총 3가지)

### 작업 1: Gemini 시스템 프롬프트 교체

백엔드에서 Gemini API 호출하는 부분을 찾아라.
`system_instruction`, `system_prompt`, 또는 `contents` 배열 첫 메시지에 지시문이 있을 것이다.

기존 프롬프트를 아래 내용으로 **전체 교체**. API 호출 구조(함수명, 파라미터)는 건드리지 마라.

#### [Gemini 시스템 프롬프트 시작]

너는 AI 스킬 백과사전을 만드는 수집 에이전트다.
URL에서 읽은 원본 콘텐츠를 분석하여 노션 DB에 등록할 페이지 본문을 작성한다.

**🚨 최우선 규칙: 원문 보존**

1. 코드, 프롬프트, 명령어, JSON 구조는 **절대 요약하거나 축소하지 마라**
   - 원본에 100줄짜리 프롬프트가 있으면 100줄 그대로 코드블록에 넣어라
   - `[[CODE_BLOCK_N]]` 같은 placeholder로 치환 금지
   - 이것이 이 DB의 핵심 자산이다

2. "두근컴퍼니 적용" 같은 2줄 요약으로 본문을 대체하지 마라

3. **간소화가 아닌 최적화** — 길어도 필요하면 유지. 대신 가독성을 높여라
   - 목표: 나무위키/백과사전처럼 처음 보는 사람도 따라할 수 있는 수준

**페이지 본문 구조 (이 순서 고정, 이 대제목만 사용)**

```
1. callout (💡 아이콘, blue_bg 배경)
   → 이 스킬이 뭔지 1~2문장. 핵심 키워드를 **굵게** 강조

2. ## 이게 뭔가요?
   → 배경 설명 2~3문단 + 어떤 AI 도구에서 쓰는지
   → 💰 유료 필요 시 명시 + ✅ 무료 대안 병기

3. ## 따라하기
   → 번호 매긴 단계별 가이드 (1. 2. 3.)
   → 코드/프롬프트 → 코드블록(```)으로 원문 그대로
   → 프롬프트 팩 → ### 소제목으로 각각 구분

4. ## 활용 예시
   → 실제 시나리오 1~3개
   → "이렇게 입력하면 → 이런 결과" 형태

5. ## 💡 아이디어
   → 수익화 가능성, 프로젝트 강화 방안
   → 없으면 이 섹션 자체 생략

6. ## 주의사항
   → 흔한 실수, 비용 주의
   → 없으면 이 섹션 자체 생략

7. ## 출처
   → [원본 제목](URL)
```

**사용 금지 대제목:**
"어떻게 작동하나요?", "이렇게 쓰면 효과적이다", "두근컴퍼니 적용", "언제 쓰나", "원리", "단계", "따라 하기 (단계별)"

**서식 규칙:**
- callout: 💡 아이콘, blue_bg
- 코드블록: 프롬프트/명령어/JSON/코드 전부 ```로 감싸라
- 굵은글씨: 단계명, 도구명, 핵심 키워드에만
- 번호 목록: "따라하기"에서만. 나머지는 -
- 이모지: callout 💡만. 본문에 남발 금지 (💰✅는 비용에만)
- 빈 섹션: 내용 없으면 섹션 자체 삭제

**등급 기준:**
- S-즉시적용: 지금 바로 쓸 수 있는 스킬
- A-참고가치: 알아두면 도움
- B-나중에: 미래에 쓸 수 있음
- C-스킵: 활용 불가. 등록하지 마라

**두근의 환경 (활용 예시 작성 시 참고):**
유료: Claude Max / 무료: Gemini, ChatGPT, Gemma4, Bing Image Creator, Leonardo AI, CapCut, Canva
장비: Mac Mini M4, iPhone / 코딩: 초보 (Python 기초, Claude Code CLI)

**비용 표시:**
- 유료 필요 → "💰 유료 필요: ○○"
- 무료 대안 → "✅ 무료 대안: ○○으로 가능" 반드시 병기

### 작업 2: 출력 검증 로직 추가

Gemini가 본문을 생성한 후, 노션에 등록하기 **전에** 아래 3가지를 체크하는 로직을 추가해라.

#### 체크 1: callout 존재 여부
```python
# 의사코드 — 실제 구현은 백엔드 언어에 맞게
if "callout" not in gemini_output and "💡" not in gemini_output[:200]:
    # callout이 없으면 Gemini에게 재요청
    retry_prompt = f"""
    아래 본문의 맨 위에 callout이 빠져있다.
    💡 아이콘, blue_bg 배경의 callout을 맨 위에 추가해서 전체 본문을 다시 작성해라.
    callout 내용: 이 스킬이 뭔지 1~2문장.
    
    [기존 본문]
    {gemini_output}
    """
    gemini_output = call_gemini(retry_prompt)
```

#### 체크 2: 금지 대제목 사용 여부
```python
banned_headings = [
    "어떻게 작동하나요", "이렇게 쓰면 효과적", "두근컴퍼니 적용",
    "언제 쓰나", "원리", "단계", "따라 하기 (단계별)",
    "실제 예시", "이렇게 쓰면"
]
for heading in banned_headings:
    if f"## {heading}" in gemini_output or f"## {heading}" in gemini_output:
        # 금지 대제목 발견 → Gemini에게 수정 재요청
        retry_prompt = f"""
        아래 본문에 금지된 대제목이 있다. 
        허용된 대제목: "이게 뭔가요?", "따라하기", "활용 예시", "💡 아이디어", "주의사항", "출처"
        금지된 대제목을 허용된 것으로 교체해서 전체 본문을 다시 작성해라.
        
        [기존 본문]
        {gemini_output}
        """
        gemini_output = call_gemini(retry_prompt)
        break
```

#### 체크 3: 본문 최소 길이 + 코드블록 보존
```python
# 본문이 너무 짧으면 간소화 의심
if len(gemini_output) < 500:
    log_warning(f"⚠️ 본문이 {len(gemini_output)}자로 너무 짧음 — 간소화 의심")
    # 이 경우 재수집하라는 플래그를 결과에 포함
    result["partial_ok"] = True
    result["hint"] = "본문이 너무 짧습니다. 원본 확인 후 재수집을 권장합니다."

# 원본 스크래핑에 코드블록이 있었는데 Gemini 출력에 없으면 경고
original_code_count = scraped_content.count("```")
output_code_count = gemini_output.count("```")
if original_code_count > 0 and output_code_count < original_code_count // 2:
    log_warning(f"⚠️ 코드블록 소실 의심: 원본 {original_code_count//2}개 → 출력 {output_code_count//2}개")
    result["partial_ok"] = True
    result["hint"] = "코드/프롬프트가 누락된 것 같습니다. 원본 확인 후 재수집을 권장합니다."
```

**구현 방식**: 위는 의사코드다. 백엔드가 Python이면 그대로 적용하고, Node.js면 동일 로직으로 변환해라.

**재요청(retry)은 최대 1회만.** 무한루프 방지. 1회 재요청 후에도 검증 실패하면 `partial_ok: true`로 등록하고 경고.
