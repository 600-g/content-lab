이 가이드는 Claude Chrome Extension 기능만 사용해서

AI가 브라우저에서 직접 작업을 수행하도록 만드는 방법입니다.

이 문서를 통해 아래 작업을 할 수 있습니다.

• 여행 일정 자동 생성

• 로컬 맛집 여행 루트 찾기

• 쇼핑 중심 여행 계획 만들기

• 현지인만 아는 장소 찾기

• Google Docs 문서 자동 작성

• Google Sheets 데이터 분석

• 웹페이지 리서치 자동화

• 쇼핑 리서치

• 경쟁사 분석

추가 프로그램 없이 Claude 기본 기능만으로 실행 가능합니다.

## ⚙️ 1️⃣ Claude Chrome Extension 설치

1️⃣ Chrome Web Store 접속

2️⃣ Claude 검색

3️⃣ Add to Chrome 클릭

4️⃣ 브라우저 우측 상단 Claude 아이콘 클릭

5️⃣ Claude 계정 로그인

⚠️ 참고

Claude Chrome Extension은 Claude Pro 이상 플랜에서 사용 가능합니다.

## ⚙️ 2️⃣ 자동화가 작동하는 핵심 설정

Claude가 브라우저를 사용할 때 필요한 설정입니다.

✔ 현재 탭 접근 허용

✔ Claude 실행 계획(Plan) 승인

✔ Google 로그인 유지 (지도 저장 시 필요)

Claude는 작업 실행 전에 항상

“이렇게 진행하겠습니다.” 라는 Plan(실행 계획) 을 보여줍니다.

사용자가 승인하면 Claude가 실제로

• 검색

• 클릭

• 페이지 이동

• 정보 수집

• 데이터 정리

같은 작업을 수행합니다.

## 🗺 3️⃣ 기본 여행 일정 생성 방법

📍 STEP 1

Google Maps 접속 → 예시 검색 → (Tokyo, Osaka, Paris, Bangkok)

📍 STEP 2

Claude 실행

📍 STEP 3

아래 프롬프트 입력

지금 열려 있는 구글지도에서 해당 도시의 주요 관광지와 맛집을 수집해서
3일 여행 일정을 자동으로 만들어줘.
조건
- 이동 동선 최소화
- 점심/저녁은 평점 4.0 이상 음식점
- 일정은 시간대별로 정리
- 각 장소 클릭 후 핵심 정보 요약
- 이동 시간 고려
우선 실행 계획(Plan)만 먼저 보여주고
내 승인 후 진행해줘.

## 🚀 꿀팁: Claude Chrome Extension 숨은 기능 (Workflow & Scheduled Task)

Claude Chrome Extension에는 많은 사람들이 잘 모르는

강력한 자동화 기능 2가지가 있습니다.

✔ 워크플로우 기록 (Record Workflow)

✔ Scheduled Task

이 두 가지를 같이 사용하면

브라우저 작업을 자동화할 수 있습니다.

예를 들어

매일 뉴스 체크

• 경쟁사 사이트 확인

• 이메일 정리

• 대시보드 데이터 확인

같은 작업을 Claude가 대신 실행하도록 만들 수 있습니다.

## 🧠 1️⃣ 워크플로우 기록 (Record Workflow)

워크플로우 기록은

👉 내가 브라우저에서 한 번 시범을 보이면
Claude가 그 작업을 단축키로 저장하는 기능입니다.

즉

말로 설명하기 어려운 작업을

직접 보여줘서 학습시키는 방식입니다.

📍 사용 방법

1️⃣ Claude Chrome Extension 열기

2️⃣

/

입력3️⃣ Record Workflow 선택

4️⃣ 브라우저에서 작업 시연

예시

사이트 검색

• 버튼 클릭

• 페이지 이동

• 텍스트 입력

5️⃣ 기록 종료

그러면 Claude가 해당 작업을

Shortcut(단축키) 로 저장합니다.

📍 예시 — 경쟁사 사이트 체크

예를 들어 매주 경쟁사 사이트를 확인한다고 가정하면

1️⃣ 경쟁사 홈페이지 접속

2️⃣ 가격 페이지 확인

3️⃣ 블로그 확인

4️⃣ 채용 페이지 확인

5️⃣ 변경된 내용 요약

이 작업을 워크플로우로 기록하면

다음부터는

/competitor-check

단축키 하나로 실행할 수 있습니다.

📍 예시 — Gmail 자동 정리

/inbox-cleanup

Claude에게

프로모션 메일 archive

• 중요한 메일 star 표시

• 답장 필요한 메일 정리

같은 작업을 시킬 수 있습니다.

## ⏰ 2️⃣ Scheduled Task (자동 실행)

Scheduled Task는

👉 저장된 Shortcut을 정해진 시간에 자동 실행하는 기능입니다.

즉

Workflow = 작업 저장

Schedule = 자동 실행

이라고 보면 됩니다.

📍 예시

매일 아침 9시

Claude가

뉴스 사이트 확인

• 경쟁사 업데이트 체크

• 새 블로그 글 확인

을 자동으로 실행

📍 예시 Shortcut

/market-check

프롬프트

A사, B사, C사 사이트에 방문해서
- 새 업데이트
- 가격 변경
- 새 공지
- 새 블로그 글
이 있는지 확인하고
핵심 내용만 요약해줘.

이 Shortcut을

⏰ 매일 09:00

으로 설정하면

Claude가 자동 실행합니다.

📍 예시 — 매주 업무 리포트

/weekly-metrics

프롬프트

광고 대시보드에 접속해서
- ROAS
- 클릭수
- 전환수
- CPA
를 확인하고
지난주 대비 변화도 정리해줘.

이 작업을

📅 매주 월요일

자동 실행하도록 설정할 수 있습니다.
