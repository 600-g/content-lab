**여기어때**여기어때

여기어때 MCP는 실시간 숙소 정보 제공을 위해 두 가지 핵심 도구를 지원합니다. 첫째, search 도구는 사용자가 입력한 지역이나 숙소명을 바탕으로 실시간 검색을 수행합니다. 체크인·체크아웃 날짜와 인원에 맞춰 현재 예약 가능한 숙소 리스트, 가격, 위치 정보를 즉시 제공하여 탐색 과정을 간소화합니다. 둘째, fetch 도구는 선택한 숙소에 대한 심층 정보를 조회합니다. 객실별 상세 요금, 시설 정보, 이용 정책 및 이미지를 파싱하여 제공함으로써 사용자가 외부 사이트를 일일이 방문하지 않고도 AI 대화창 안에서 정확한 비교와 의사결정을 내릴 수 있게 돕습니다. 이 도구들은 서로 유기적으로 작동하여, AI가 단순한 추천을 넘어 실제 데이터에 기반한 맞춤형 여행 계획과 상세 가이드를 제공할 수 있도록 설계되었습니다.

핵심 기능:

- 박스오피스 기반 인기 공연 추천 (실시간 순위 반영)

- 지역별 실시간 공연 검색 (구/군 -> 시/도 -> 전국 순 자동 확장)

- 무료 공연 자동 필터링 (API 체이닝)

- 마감임박(종료 14일 이내) 공연 가중치 점수로 추천

- 출연진·시놉시스·예매 링크 등 상세 정보 통합 조회

실사용 예시:

카카오톡에서 "이번 주에 연극이나 볼래?"라는 대화가 나오면, AI가 자동으로 `기간`, `장르` 파라미터를 추출해 실시간 공연 정보를 즉시 제공합니다.

이를 통해 사용자는 끊김 없는 문화생활 경험을, 서비스 제공자는 예매 전환율 향상과 비즈니스 가치 창출 기회를 얻게 됩니다.
