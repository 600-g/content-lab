고용노동부, 중소벤처기업부, 산업통상자원부, 지자체... 각 부처가 따로따로 공고를 올린다. 통합 검색 창구가 없고, 공고 기간도 짧다. 전문 컨설턴트조차 전체를 파악하기 어렵다.

클로드의 역할

클로드는 방대한 정부 지원금 구조를 학습하고 있다. 내 상황(업종, 직원 수, 매출, 소재지)을 입력하면 맞춤 지원금을 수십 개 뽑아낼 수 있다. 전문 컨설팅 수십만 원짜리 작업을 10분에 해낼 수 있는 것이다.

대표적인 착각

"나 같은 작은 사업엔 해당 없겠지"

1인 사업자, 프리랜서, 소상공인, 예비창업자 모두 해당되는 지원금이 수두룩하다. 오히려 대기업보다 혜택이 훨씬 크다. 직원 0명도, 창업 전도, 폐업 후도 받을 수 있는 지원이 있다.

중복 수혜 전략

국가 + 지자체 + 민간 3중 조합

같은 사업에 국비 지원을 받으면서 동시에 지자체 지원을 신청할 수 있다. 일부 중복은 금지되지만, 잘 조합하면 총 수혜액을 크게 늘릴 수 있다. 클로드로 중복 가능 조합을 물어보는 것이 핵심 전략이다.

실제 사례

인천 소재 1인 디자인 사업자 → 소상공인시장진흥공단 경영안정자금 2,000만 + 인천시 소상공인 지원금 300만 + 디지털바우처 400만 = 총 2,700만원 수혜. 클로드로 3시간 조사.

클로드를 지원금 컨설턴트로 만드는 법

프롬프트 구조 하나만 알면 전문 컨설턴트 수준의 분석이 가능하다.

핵심 원리

내 상황을 정확히 줘야 정확히 나온다

클로드는 넓게 알고 있다. 하지만 "지원금 알려줘" 같은 막연한 질문은 막연한 답을 낳는다. 아래 5가지 정보를 같이 넣으면 맞춤 결과가 나온다.

01

업종

제조, 서비스, 온라인, 농업 등 구체적으로 입력. "교육 콘텐츠 제작" > "서비스업"

02

규모

1인 / 직원 수 / 연매출 범위. 소상공인 기준(연매출 10억 이하) 충족 여부 중요

03

소재지

시·군·구 단위까지. 지자체별 지원금이 완전히 다르므로 반드시 포함

04

창업 연차

예비창업자 / 3년 이내 / 7년 이상 등. 연차에 따라 신청 가능 사업이 달라짐

05

목적

운영자금 / 설비투자 / 마케팅 / 고용 / 디지털전환 중 선택

프롬프트 구조 공식

[역할 부여] + [내 상황 5가지] + [원하는 출력 형식] + [추가 조건]

이 구조를 지키면 클로드가 표 형태로 지원금명 / 지원금액 / 신청기간 / 신청처 / 자격요건을 정리해준다.

자주 하는 실수

한 번 물어보고 끝낸다

클로드와 대화를 이어가면 처음엔 몰랐던 지원금이 계속 나온다. "더 있어?", "지자체 거 따로 알려줘", "중복 신청 가능한 조합 뽑아줘" 같이 계속 파고드는 것이 핵심이다.

Chapter 05

신청 단계별 실행 가이드

발견 → 확인 → 준비 → 제출 → 사후 관리. 각 단계마다 클로드를 쓰는 법이 다르다.

01

탐색 단계 (30분)

프롬프트 1번으로 맞춤 지원금 목록 추출 → 프롬프트 2번으로 중복 수혜 조합 확인 → 우선순위 TOP 5 선정

02

자격 검증 단계 (1시간)

프롬프트 4번으로 체크리스트 생성 → 공식 사이트(기업마당, 소상공인포털)에서 실시간 공고 재확인 → 미달 요건 파악

03

서류 준비 단계 (1~3일)

사업자등록증, 최근 3개월 매출증빙, 통장사본 기본 세트 준비 → 클로드에게 "추가로 필요한 서류 뭐야?" 재확인

04

사업계획서 작성 (2~4시간)

프롬프트 3번으로 초안 생성 → 수치와 구체성 강화 → 클로드에게 "심사 기준으로 검토해줘" 요청 후 보완

05

제출 후 사후 관리

결과 통보 대기 중에도 다음 지원금 탐색 병행 → 탈락 시 클로드에게 "보완점 뭐야?" 피드백 요청
