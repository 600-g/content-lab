이 문서는 앱을 출시하는 과정에서 활용한 AI 도구들의 정의와 활용법을 정리한 교육자료입니다.

## 🔭 시장조사 — Claude in Chrome

### 정의

Claude in Chrome은 Chrome 브라우저 확장 프로그램으로, 웹 페이지를 탐색하면서 Claude AI가 실시간으로 콘텐츠를 분석·요약·추출하는 도구입니다. 별도의 탭 전환 없이 브라우저 사이드패널에서 AI와 대화하며 시장 데이터를 수집할 수 있습니다.

### 활용법

Step 1
Chrome 웹 스토어에서 Claude for Chrome 확장 프로그램을 설치하고 Anthropic 계정으로 로그인합니다.

Step 2
경쟁사 웹사이트, 앱스토어 리뷰 페이지, 산업 리포트 등 조사할 페이지를 열고 사이드패널의 Claude를 실행합니다.

Step 3
"이 페이지에서 사용자 불만 키워드를 추출해줘" 또는 "경쟁 앱의 핵심 기능을 표로 정리해줘" 와 같이 프롬프트를 입력합니다.

Step 4
여러 페이지를 순회하며 Claude에게 누적 데이터를 비교·분석하도록 요청합니다.

Step 5
수집된 인사이트를 Claude에게 마크다운 보고서 형식으로 정리하도록 요청하여 클립보드로 복사합니다.

## 🗂️ 데이터 정리 — Claude Co-work

### 정의

Claude Co-work(Cowork)는 Anthropic이 제공하는 데스크탑 기반 자동화 도구로, 파일·폴더·문서 등 로컬 리소스를 Claude가 직접 접근하여 처리할 수 있게 해줍니다. 수집된 원자료를 체계적인 구조로 자동 분류·정제하는 데 최적화되어 있습니다.

### 활용법

Step 1
Claude Cowork 데스크탑 앱을 설치하고, 시장조사에서 수집한 원자료 파일(CSV, 텍스트, 스크린샷 등)을 지정 폴더에 모아둡니다.

Step 2
Cowork에서 해당 폴더를 작업 컨텍스트로 연결합니다.

Step 3
"중복된 항목을 제거하고 카테고리별로 분류해줘" 등 정제 지시를 내립니다.

Step 4
Claude가 생성한 정리 결과물(표, 요약 문서 등)을 검토하고 필요한 경우 추가 수정을 요청합니다.

Step 5
최종 정제된 데이터를 다음 단계(아이디어 회의)의 입력 자료로 저장합니다.

## 💡 아이디어 회의 — Gemini Pro

### 정의

Gemini Pro는 Google DeepMind가 개발한 대형 멀티모달 언어 모델로, 긴 컨텍스트 창(최대 100만 토큰)과 강력한 추론 능력을 갖추고 있습니다. 대용량 문서를 한 번에 업로드하여 아이디어 브레인스토밍 및 전략 회의에 활용할 수 있습니다.

### 활용법

Step 1
Google AI Studio 또는 Gemini 앱에 접속하고, 앞서 정리된 시장조사 데이터를 파일로 업로드합니다.

Step 2
"이 데이터를 기반으로 해결할 수 있는 사용자 문제 10가지를 제안해줘" 와 같이 브레인스토밍 프롬프트를 입력합니다.

Step 3
생성된 아이디어 목록에서 팀과 함께 투표 또는 점수 부여 방식으로 우선순위를 결정합니다.

Step 4
선정된 아이디어에 대해 Gemini에게 "이 아이디어의 장단점과 MVP 기능을 정의해줘" 를 요청합니다.

Step 5
최종 아이디어 명세서를 문서화하여 구현 단계로 전달합니다.

## ⚙️ 아이디어 구현 — Claude Artifacts

### 정의

Claude Artifacts는 Claude.ai 내에서 코드·UI·문서 등을 독립적인 렌더링 패널(아티팩트)로 즉시 생성·미리보기하는 기능입니다. HTML, React, SVG, 마크다운 등 다양한 형식을 지원하며, 대화형으로 반복 수정하면서 프로토타입을 빠르게 구현할 수 있습니다.

Claude Artifacts 구현 흐름

### 활용법

Step 1
Claude.ai에서 새 대화를 시작하고 아이디어 명세서를 붙여넣습니다.

Step 2
"이 기능 명세를 바탕으로 React 컴포넌트를 만들어줘" 또는 "랜딩 페이지 HTML을 작성해줘" 와 같이 요청합니다.

Step 3
아티팩트 패널에서 결과물을 실시간으로 확인하고, "버튼 색상을 파란색으로 바꾸고 애니메이션을 추가해줘" 처럼 반복 수정합니다.

Step 4
완성된 컴포넌트 코드를 복사하여 실제 프로젝트 파일에 통합합니다.

Step 5
기능별로 여러 아티팩트를 만들어 조합하며 전체 앱 구조를 완성합니다.

## 🎨 디자인 — Claude Design

### 정의

Claude Design은 Claude의 디자인 특화 기능으로, 텍스트 설명만으로 UI/UX 목업, 디자인 시스템, 아이콘, 일러스트레이션 등 시각적 결과물을 생성합니다. Figma 연동 및 코드 익스포트를 통해 개발-디자인 사이클을 단축시킵니다.

### 활용법

Step 1
Claude에게 앱의 브랜드 키워드(예: "미니멀, 따뜻한 톤, 20-30대 여성 타겟")와 디자인 요구사항을 설명합니다.

Step 2
"온보딩 화면 3개 세트를 목업으로 만들어줘" 또는 "색상 팔레트와 타이포그래피 가이드를 생성해줘" 를 요청합니다.

Step 3
생성된 디자인 코드(HTML/CSS 또는 SVG)를 아티팩트에서 미리보기하고 수정합니다.

Step 4
확정된 디자인의 CSS 변수와 컴포넌트 스타일을 코드로 추출하여 개발팀에 전달합니다.

Step 5
필요 시 Figma MCP 연동으로 디자인 파일을 자동 생성합니다.

## 🚀 배포 — Replit × Expo

### 정의

Replit은 브라우저 기반 클라우드 IDE로 백엔드 서버를 코드 없이 즉시 배포할 수 있고, Expo는 React Native 앱을 iOS·Android·웹 멀티플랫폼으로 동시에 배포하는 프레임워크입니다. 두 도구를 결합하면 서버와 앱을 모두 빠르게 라이브로 출시할 수 있습니다.

### 활용법

Step 1
Replit에서 새 프로젝트를 생성하고 Claude Artifacts에서 완성한 백엔드 코드를 붙여넣어 서버를 실행합니다.

Step 2
Replit의 "Deploy" 버튼으로 서버를 공개 URL에 배포하고 API 엔드포인트를 확인합니다.

Step 3
로컬 환경에서

npx create-expo-app

으로 Expo 프로젝트를 생성하고 Replit API URL을 환경 변수로 설정합니다.Step 4

npx expo start

로 개발 서버를 실행하고 Expo Go 앱으로 실제 디바이스에서 테스트합니다.Step 5

eas build

및 eas submit

명령으로 App Store / Google Play에 최종 앱을 제출합니다.💡 Tip — 각 단계의 결과물을 다음 단계의 입력으로 연결하는 것이 핵심입니다. 시장조사 → 데이터 정리 → 아이디어 회의 → 구현 → 디자인 → 배포의 흐름을 유지하세요.
