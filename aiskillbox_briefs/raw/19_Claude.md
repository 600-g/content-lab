### 2. memory.md 파일 10배 더 잘 활용하는 꿀팁

MEMORY.md

는 Claude Code 메모리 시스템의 핵심으로, 셰프가 주방에서 일하며 개인적으로 적어두는 '자동 메모리(Auto Memory)' 파일입니다.이 파일이 어떻게 작동하고 관리되는지 핵심 내용을 상세히 설명해 드립니다.

1. 저장 위치 및 성격

MEMORY.md

는 프로젝트 폴더에 겉으로 드러나지 않고 ~/.claude/projects/<프로젝트해시>/memory/

경로에 저장됩니다.팀원들과 공유(Git 체크인)하는

CLAUDE.md

와 달리, 철저히 사용자 개인의 작업 환경과 취향에 맞춰진 **개인 전용 파일(Git 공유 불가)**입니다.2. 똑똑한 자동 기록 방식

AI의 자체 판단: 사용자가 일일이 적어주지 않아도, Claude가 작업하면서 발견한 유용한 패턴, 반복해서 쓰는 명령어, 사용자의 선호도 등을 스스로 파악하여 스냅샷처럼 백그라운드에서 자동 저장합니다.

자연스러운 지시: 대화 중에 "우리는 npm 대신 pnpm을 쓴다고 기억해"라고 말하거나,

/memory

명령어를 입력하면 AI가 알아서 이 파일에 요약해 기록합니다.3. 가장 중요한 원칙: "첫 200줄의 법칙"

매 세션이 시작될 때, Claude는

MEMORY.md

의 첫 200줄까지만 자동으로 읽어 들입니다.이는 AI의 작업대(컨텍스트 윈도우) 공간을 낭비하지 않기 위함입니다.

관리 팁: 만약 내용이 길어진다면 모든 것을

MEMORY.md

에 담지 말고, 같은 폴더 안에 debugging.md

와 같은 '토픽 파일'로 분리해야 합니다. 이렇게 하면 기본 200줄만 항상 기억하고, 디버깅 등 특정 작업이 필요할 때만 해당 토픽 파일을 추가로 꺼내 읽게 됩니다.4. 한눈에 보는 요약 (

CLAUDE.md

와의 차이)
두 파일을 헷갈리지 않게 완벽히 구분 지으면 다음과 같습니다:구분 | CLAUDE.md (주방 운영 매뉴얼) | MEMORY.md (셰프의 개인 노트) |
|---|---|---|
작성 주체 | 사용자가 직접 작성 | Claude가 자동 작성 (또는 사용자 지시) |
로드 시점 | 매 세션 시작 시 전체 로드 | 매 세션 시작 시 첫 200줄만 로드 |
주요 용도 | 프로젝트 전반의 아키텍처, 코딩 컨벤션, 핵심 규칙 | 작업 중 학습된 패턴, 유용한 명령어, 사용자 선호도 |
팀 공유 | Git 체크인 가능 (팀원 공유) | Git 체크인 불가 (개인 맞춤형) |

결론적으로

MEMORY.md

는 사용자가 직접 텍스트 편집기로 열어서 장문의 지시를 내리는 용도가 아니라, 에이전트와 대화하며 자연스럽게 나만의 작업 비서를 똑똑하게 훈련시키는(Fine-tuning) 숨겨진 노트로 이해하시면 됩니다.이 글을 보는 분들께.
