### 이미지·영상 생성 방식 비교

방식 | 이미지 | 영상 | 비고 |
|---|---|---|---|
RunningHub (원본 기본) | ✅ | ✅ | 유료 크레딧 필요 |
Gemini API (우리 패치) | ✅ | ❌ | 무료 티어 있음, 영상은 RunningHub 필요
→ 저는 이미지 (Gemini), 영상도 (Veo3)로 했습니다. RunningHub 연결하면 기본적으로 되어있는게 많아서,,, 한번 시도해보실 분들은 해보는 거 추천! (한달 9달러정도) |
ComfyUI 로컬 | ✅ | ✅ | GPU 필요 |

- A. Claude Code에게 시키기 — 프롬프트 복붙하면 끝 (추천)

### 📋 프롬프트 2 — config.yaml 설정 (RunningHub 방식 — 기본)

이미지 + 영상 모두 생성하고 싶을 때 사용하세요.

JavaScript

[내_작업폴더]/Pixelle-Video/config.yaml 파일을 아래 내용으로 설정해줘.
llm:
api_key: "여기에_API키" # Ollama는 아무 값이나
base_url: "https://api.anthropic.com/v1/" # Claude
# base_url: "https://api.openai.com/v1" # ChatGPT
# base_url: "https://api.deepseek.com" # DeepSeek
# base_url: "http://localhost:11434/v1" # Ollama (무료, 로컬)
model: "claude-sonnet-4-6" # Claude
# model: "gpt-4o" # ChatGPT
# model: "deepseek-chat" # DeepSeek
# model: "llama3.2" # Ollama
comfyui:
runninghub_api_key: "여기에_RunningHub_API키"
runninghub_concurrent_limit: 1
tts:
default_workflow: selfhost/tts_edge.json
inference_mode: local
local:
voice: "ko-KR-SunHiNeural"
speed: 1.0
image:
default_workflow: runninghub/image_flux.json
video:
default_workflow: runninghub/video_wan2.1_fusionx.json
template:
default_template: "1080x1920/image_default.html"
