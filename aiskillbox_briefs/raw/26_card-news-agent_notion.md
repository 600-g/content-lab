> 💡 Claude Code 환경에서 에이전트를 구축하여, 구조화된 데이터(엑셀/PDF)를 카드뉴스 형식으로 자동 변환하는 워크플로우입니다. 데이터 입력 → 내용 추출 → 시각적 레이아웃 구성까지 자동화합니다.

## 이게 뭔가요?

대량의 콘텐츠(카드뉴스, 보고서 등)를 주기적으로 제작해야 할 때, 반복적인 수작업을 줄이기 위한 자동화 에이전트입니다. 구조화된 데이터(엑셀 시트, 표, 목록 등)를 입력하면 에이전트가 내용을 추출·가공하고, 카드뉴스에 적합한 텍스트와 레이아웃을 자동으로 구성합니다.

Claude Code 환경에서 개발하며, 기존의 자동화 도구(Zapier/Make)가 필요했던 과정을 Claude Code + GitHub Actions 조합으로 대체 구현할 수 있습니다.

- ✅ 무료 구현 가능: Claude Code(Claude Max 포함) + GitHub Actions

## 따라하기

1. 데이터 준비: 카드뉴스에 들어갈 원본 데이터를 엑셀 시트나 구조화된 PDF 형태로 정리합니다. 구조화 수준이 높을수록 결과물 품질이 올라갑니다.

1. 에이전트 설계: Claude Code 환경에서 에이전트의 역할을 정의합니다.

1. 자동화 구현: 데이터가 입력되면 에이전트가 자동으로 내용을 추출하고, 카드뉴스에 적합한 텍스트와 레이아웃을 구성하도록 코드를 작성하고 테스트합니다.

## 활용 예시

입력: 클로드 코드 마스터 시트 자료.xlsx (주제별 핵심 키워드 및 내용)

출력: 시각적 레이아웃이 적용된 카드뉴스 PDF 또는 이미지 시퀀스

첼시인스타 프로젝트에 적용하는 경우:

- 인스타그램 캐러셀 콘텐츠를 주 3회 올려야 할 때 → 엑셀에 주제·키워드만 정리하면 카드뉴스 자동 생성

- Claude Code가 Canva API 또는 HTML→이미지 변환으로 최종 이미지까지 출력

## 💡 아이디어

- 소상공인 콘텐츠 대행 자동화: 이 에이전트 + 제품 후기 프롬프트를 조합하면, 고객사별 SNS 콘텐츠를 반자동으로 대량 생산하는 시스템 구축 가능

- 뉴스레터 자동화: 매주 수집된 AI 뉴스 → 카드뉴스 자동 변환 → 인스타 배포

## 주의사항

- 원본 데이터의 구조화 수준이 낮으면 에이전트가 정확한 내용을 추출하기 어려움. 엑셀 컬럼을 명확히 정의해야 함

- 에이전트가 생성하는 시각적 결과물의 최종 디자인 검토는 사람이 반드시 거쳐야 함

- AI가 만든 레이아웃은 폰트·색상 조합이 일관되지 않을 수 있어서 Canva에서 후처리 권장
