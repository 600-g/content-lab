# 화면 시안을 코드로 만드는 Claude

💡 AI 모델 **Claude Code**에 탑재된 **`/design` 스킬**을 사용하여, 텍스트 설명만으로 **편집 가능한 화면 시안**을 생성하고 이를 **실제 코드로 구현**하는 기능입니다.

## 이게 뭔가요?

앤트로픽(Anthropic)이 2026년 8월 18일, AI 코딩 도구인 **Claude Code**에 `/design` 스킬을 추가했습니다. 이 기능은 사용자가 만들고 싶은 화면을 텍스트로 설명하면, 여러 개의 **편집 가능한 시안**을 생성해주고, 그중 하나를 선택하여 수정한 뒤 **실제 코드로 구현**까지 이어주는 혁신적인 워크플로우를 제공합니다. 

기존에는 시안 디자인과 코드 구현이 별도의 도구에서 이루어져야 했으나, 이제 Claude Code 안에서 이 모든 과정이 통합되어 더욱 효율적인 개발이 가능해졌습니다. 이 기능은 현재 **연구 미리보기 단계**이며, Claude Code의 **Pro, Max, Team, Enterprise 요금제**에서 사용할 수 있습니다.

## 따라하기

**핵심 워크플로: 세 단계면 끝**

1.  **`/design` 뒤에 만들고 싶은 화면을 적는다**
    채팅 입력창에 `/design`을 입력하고, 뒤이어 만들고 싶은 화면에 대한 설명을 텍스트로 작성합니다.
    예시: `/design 클로드 코드를 위한 새로운 채팅 입력창`

2.  **시안을 고르고, 그 자리에서 고친다**
    입력한 설명을 바탕으로 여러 개의 편집 가능한 시안이 생성됩니다. 이 시안들을 직접 보면서 버튼 위치나 문구 등을 수정할 수 있습니다. 공식 문서에서는 이를 "editable artboards"라고 지칭하며, 화면 요소들을 직접 조작하여 원하는 디자인을 만들 수 있습니다.

3.  **"이 안으로 만들어 줘" 한마디로 구현을 맡긴다**
    마음에 드는 시안을 확정한 후, "이 안으로 만들어 줘"와 같은 명령어를 통해 Claude Code가 해당 디자인을 바탕으로 실제 코드를 생성하도록 요청합니다.

**시작 준비: Claude Code를 최신으로**

이 기능을 사용하려면 Claude Code를 최신 버전으로 업데이트해야 합니다. 설치 방식에 따라 업데이트 방법이 다를 수 있습니다.

*   **기본 설치판**: Claude Code를 직접 설치한 경우, 설치된 버전을 업데이트합니다.
*   **Homebrew 또는 WinGet**: 해당 패키지 관리자를 통해 설치한 경우, 관리자 도구를 사용하여 업데이트합니다.

업데이트 후에도 `/design` 명령이 보이지 않으면, 관련 도움말을 참고해야 할 수 있습니다.

## 활용 예시

*   **채팅 입력창 재설계**: `/design 클로드 코드를 위한 새로운 채팅 입력창, 사용자 경험을 개선하여 버튼 위치를 조정하고 텍스트 입력 영역을 넓힌다.` 입력 시, 여러 디자인 시안이 제시되며 사용자는 이를 수정하여 최종 코드를 얻을 수 있습니다.
*   **대시보드 UI 생성**: `/design 월간 판매 실적을 보여주는 심플한 웹 대시보드. 좌측에는 필터링 옵션을, 우측에는 차트와 주요 지표를 배치한다.` 와 같이 구체적인 요구사항을 전달하여 맞춤형 UI를 생성할 수 있습니다.

## 💡 아이디어

*   **스타트업 MVP 제작 가속화**: 초기 단계 스타트업에서 아이디어를 빠르게 시각화하고 프로토타입 코드를 생성하여 개발 속도를 높일 수 있습니다.
*   **개인 프로젝트 디자인 시스템 구축**: 자신만의 디자인 규칙을 Claude Code에 학습시켜 일관된 디자인 시스템을 적용한 코드를 지속적으로 생성하는 데 활용할 수 있습니다.

## 주의사항

*   **연구 미리보기 단계**: 이 기능은 아직 개발 초기 단계이므로, 예상치 못한 오류가 발생하거나 기능이 불안정할 수 있습니다.
*   **요금제 제한**: `/design` 스킬은 Claude Code의 유료 요금제(Pro, Max, Team, Enterprise)에서만 사용할 수 있습니다. 무료 요금제에서는 지원되지 않습니다.
*   **공식 문서 부재**: 연구 미리보기 단계이므로, Claude Code 공식 문서에 이 기능에 대한 전용 페이지가 아직 없을 수 있습니다. 따라서 상세한 기능이나 사용량 계산 등에 대한 정보는 제한적일 수 있습니다.
