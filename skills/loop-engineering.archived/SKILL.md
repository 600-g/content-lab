# AI 루프 시스템 구축 및 자동화 (합병됨)

## 이게 뭔가요?

'루프 엔지니어링(Loop Engineering)'은 AI에게 매번 일회성 명령(프롬프트)을 내리는 방식에서 벗어나, AI가 스스로 작업을 반복하고 검증하며 목표에 도달할 때까지 알아서 돌아가는 '자동화 시스템(루프)'을 설계하는 방법론입니다. 이는 AI를 단순한 '비서'가 아닌, '작동하는 시스템'으로 취급하는 패러다임의 전환을 의미합니다.

Claude AI의 Cowork 기능은 사용자가 AI에게 자신의 정보, 작업 방식, 선호하는 소통 스타일 등을 미리 설정하여 AI가 마치 개인 비서처럼 작동하도록 만드는 기능입니다. 이를 통해 반복적인 정보 제공 없이 일관되고 효율적인 AI 활용이 가능해집니다. 주로 Claude Desktop 버전에서 사용됩니다.

이 개념은 개발자 커뮤니티에서 큰 화제가 되었으며, AI 활용의 수준을 '명령어 입력' 단계에서 '시스템 설계' 단계로 끌어올렸습니다. 단순히 프롬프트를 길게 쓰는 것을 넘어, 시스템의 흐름(Flow)과 안전장치(Safety Mechanism)를 설계하는 것이 핵심입니다.

루프의 가장 기본적인 뼈대는 ①트리거(언제 시작할지), ②액션(무엇을 할지), ③정지조건(언제 멈출지) 세 가지입니다. 하지만 이 뼈대만으로는 AI가 무한히 반복하며 '쓰레기'를 생산하는 '쓰레기 무한생산기'가 될 위험이 있습니다. 따라서 실제로는 ④검증자(Self-Correction), ⑤기억(Memory), ⑥관찰·되돌리기(Observation/Rollback)라는 3가지 운영 요소가 반드시 추가되어야 비로소 '믿고 맡길 수 있는 자동화'가 완성됩니다.

Claude AI의 Cowork 기능을 활용하여 이러한 루프 설계 원리를 개인에게 최적화된 AI 비서 시스템으로 구현할 수 있습니다. Claude Desktop의 `Settings > Cowork`에서 전역 지침(Global Instructions)과 `about-me` 폴더를 설정함으로써, AI가 사용자의 맥락을 깊이 이해하고 일관성 있는 결과물을 생성하도록 만들 수 있습니다.

이 가이드는 코드를 전혀 모르는 비개발자도 이 복잡한 원리를 이해하고, 자신의 업무에 적용할 수 있도록 '시스템 설계 관점'으로 풀어낸 것이 특징입니다. AI 활용의 목표가 '결과물'이 아닌 '안정적으로 돌아가는 프로세스'로 바뀌는 지점을 이해하는 것이 중요합니다.

또한, 이 스킬은 힉스필드(Hicksfield)의 MCP(Multi-modal Content Platform)와 클로드(Claude)를 연동하여 복잡한 설명 없이도 **캐러셀 카드뉴스**나 **이미지**를 자동으로 제작하는 방법도 포함합니다. 별도의 복잡한 프롬프트 엔지니어링 없이도 사용자의 간단한 명령만으로 원하는 결과물을 얻을 수 있도록 합니다. 기존에는 디자인 툴을 사용하거나 AI 이미지 생성 모델에 복잡한 프롬프트 입력해야 했지만, 이 스킬을 활용하면 텍스트 기반의 간단한 지시만으로도 AI가 이를 해석하여 힉스필드의 강력한 MCP 기능을 통해 결과물을 생성해 줍니다. 프로필 사진이나 카드뉴스 주제와 같은 콘텐츠를 빠르고 효율적으로 만들 수 있습니다.

이 과정은 힉스필드의 MCP 링크와 클로드의 커스텀 커넥터 기능을 활용합니다. 힉스필드에서 MCP 링크를 복사하여 클로드에 추가한 뒤, 원하는 결과에 대한 간단한 지시사항(예: 프로필 사진에 사용할 내 사진 첨부 및 간단한 설명, 만들고 싶은 카드뉴스의 주제)을 클로드 모델(sonnet5)에 입력하면 자동으로 결과물이 생성됩니다.

Anthropic에서 개발한 Claude Fable 5 모델의 내부 지시서 38,000 단어가 GitHub을 통해 유출되었습니다. 이 지시서에는 Claude 모델이 따라야 할 12가지 주요 가드레일(보호 장치)이 포함되어 있으며, 이 가이드라인은 현재 Claude Sonnet, Opus 등 일상적으로 사용하는 모델에도 동일하게 적용됩니다. 이 자료는 Claude Fable 5 내부 작동 방식을 이해하고, 이를 통해 현재 사용 중인 Claude 모델의 응답 품질과 안전성을 개선하는 데 도움을 줍니다.

Claude Fable 5는 2026년 7월 12일까지 Pro / Max / Team 유료 플랜 사용자에게 주간 사용량 한도의 50% 내에서 무료로 제공됩니다. Claude Pro 구독자는 추가 크레딧 없이 사용할 수 있으며, claude.ai 웹, 앱, Claude Code, Claude Cowork 모두 지원됩니다. 7월 12일 이후에는 사용량 크레딧을 별도로 결제해야 합니다. 유료 창구의 시한은 정해져 있지만, 여기서 정리된 내부 지시서 가이드라인은 계속 유효합니다.

또한, 이 프로젝트는 AI 에이전트가 특정 마케팅 업무를 수행할 수 있도록 설계된 '마케팅 스킬' 모음집입니다. 각 마케팅 스킬은 `.md` 파일 하나하나로 구성되어 있으며, 해당 업무에 대한 전문 지식과 구체적인 작업 절차를 담고 있습니다. 이 스킬들을 프로젝트에 통합하면, 사용자는 "랜딩페이지 전환율을 높여줘"와 같은 자연어 요청만으로 AI 에이전트가 적절한 스킬을 선택하여 검증된 프레임워크에 따라 작업을 수행하도록 할 수 있습니다. 이 라이브러리는 기술에 익숙한 마케터나 창업자가 전환 최적화, 카피라이팅, SEO, 광고, 그로스 해킹 등 다양한 마케팅 활동을 자동화하기 위해 구축되었습니다. Claude Max와 같은 상위 AI 모델 사용 시 더 높은 성능을 기대할 수 있으며, Gemini, ChatGPT 등 다른 AI 도구를 활용하여 유사한 스킬을 구현하거나 적용할 수 있습니다.

이 스킬은 macOS 메뉴바에 표시되는 위젯으로, **Claude Code**와 **Codex**의 사용량 제한 상태를 배터리 아이콘 형태로 시각화합니다. 이를 통해 사용자는 `/usage` 페이지를 열어보지 않고도 남은 사용량을 직관적으로 확인할 수 있습니다.

주요 기능은 다음과 같습니다:

*   **Claude Code 사용량**: 5시간 세션, 주간 사용량, Fable 모델의 주간 상한선 등을 표시합니다. Anthropic의 공식 OAuth 사용량 API를 통해 실시간으로 데이터를 가져옵니다. 계정 전체의 사용량이 합산되어 표시되므로, 여러 기기에서 사용해도 정확한 정보를 얻을 수 있습니다.
*   **Codex 사용량**: 5시간 세션 제한 또는 신용 잔액을 표시합니다. `~/.codex/sessions/**/*.jsonl` 파일에서 `rate_limits` 정보를 읽어옵니다.
*   **시각적 피드백**: 배터리 아이콘의 색상(초록 ≥ 50%, 주황 < 50%, 빨강 < 20%)으로 사용량 임계치를 즉시 파악할 수 있습니다.
*   **상세 정보**: 위젯을 클릭하면 각 사용량 제한에 대한 상세 정보와 리셋 시간까지 확인할 수 있습니다.

이 위젯은 **SwiftBar** 플러그인으로 제작되어, 단일 스크립트로 별도의 라이브러리 설치 없이 작동합니다. 런타임으로는 **bun**을 사용합니다. Claude Code 사용량 정보는 macOS Keychain에 저장된 로그인 정보를 활용하며, Codex 사용량은 로컬 세션 로그를 기반으로 합니다.

💰 **유료 필요**: Claude Code는 유료 플랜 사용 시 정확한 사용량 추적이 가능하며, Codex 역시 별도의 CLI 설치가 필요할 수 있습니다.
✅ **무료 대안**: Claude Code 또는 Codex를 사용하지 않는 경우, 해당 부분의 정보는 표시되지 않거나 비어있게 됩니다. 완전 무료 대안은 명확히 없으나, 유사한 사용량 추적 위젯을 직접 개발할 수 있습니다.

### Claude Code 및 Codex 사용량 모니터링 (macOS 메뉴바 위젯)

**사전 요구사항:**

*   **macOS**: 운영체제
*   **SwiftBar**: 메뉴바 위젯 관리 도구 (`brew install swiftbar`로 설치 가능)
*   **bun**: JavaScript 런타임 (`curl -fsSL https://bun.sh/install | bash`로 설치 가능)
*   **Claude Code**: `C` 배터리 표시를 위해 필요 (macOS에 로그인되어 있어야 함)
*   **Codex CLI**: `X` 배터리 표시를 위해 선택적으로 필요
*   **ccusage (선택)**: 비용/토큰/모델별 상세 정보 표시를 위해 사용

**설치 단계:**

1.  **GitHub 저장소 복제**:
    ```bash
    git clone https://github.com/dennykim123/claude-codex-battery.git
    cd claude-codex-battery
    ```

2.  **설치 스크립트 실행**:
    ```bash
    ./install.sh
    ```
    `install.sh` 스크립트는 다음을 수행합니다:
    *   `bun`과 `SwiftBar` 설치 여부 확인 및 안내
    *   플러그인을 `~/.swiftbar-plugins/` 경로로 복사하고, 시스템의 `bun` 경로를 사용하도록 shebang 수정
    *   SwiftBar가 플러그인을 인식하도록 설정하고 실행
    *   SwiftBar를 로그인 항목으로 등록하여 재부팅 시 자동 실행

설치 후 몇 초 안에 메뉴바에 배터리 위젯이 나타납니다. 기본 새로고침 주기는 2분입니다.

**수동 설치 (스크립트 실행이 꺼려질 경우):**

```bash
mkdir -p ~/.swiftbar-plugins
# 자신의 bun 경로로 shebang을 수정한 후 복사
sed "1s|.*|#!$(command -v bun)|" claude-codex-usage.2m.js > ~/.swiftbar-plugins/claude-codex-usage.2m.js
chmod +x ~/.swiftbar-plugins/claude-codex-usage.2m.js
defaults write com.ameba.SwiftBar PluginDirectory -string ~/.swiftbar-plugins
open -a SwiftBar
```

## 활용 예시

1.  **실시간 사용량 모니터링**:
    *   **입력**: 메뉴바의 `C`와 `X` 배터리 아이콘을 확인합니다.
    *   **결과**: 배터리가 녹색이면 사용량이 충분함을, 주황색이나 빨간색이면 곧 한도에 도달하거나 초과될 수 있음을 직관적으로 파악합니다. 아이콘 클릭 시 상세 잔여량과 리셋 시간을 볼 수 있어, API 사용 계획을 세우는 데 도움이 됩니다.

2.  **비용 관리**:
    *   **입력**: 메뉴바 위젯을 클릭하여 상세 정보를 확인합니다. (선택적으로 `ccusage` 설치 시)
    *   **결과**: Claude Code의 모델별(Fable, Opus, Sonnet 등) 사용 비용을 달러($) 단위로 표시하여, 불필요한 지출을 방지하고 예산을 관리하는 데 도움을 줍니다.

3.  **오류 발생 시 디버깅**:
    *   **입력**: 위젯이 예상대로 작동하지 않거나 오래된 정보를 표시할 때 (예: Claude API 연결 실패 시 앰버 색상 표시).
    *   **결과**: 위젯의 상태 표시(예: 'used 30%', 'resets 3h 18m')와 색상 코드를 통해 현재 상태를 진단하고, 필요시 Claude Code 로그인 상태 확인, Codex CLI 실행 여부 점검, 네트워크 연결 상태 등을 확인할 수 있습니다.

## 💡 아이디어

*   **프로젝트 관리**: 여러 AI 모델(Claude, Codex 외)의 동시 사용량을 추적하는 통합 대시보드 위젯으로 확장하여, 개인 개발 또는 팀 프로젝트의 AI 리소스 사용 현황을 한눈에 파악할 수 있습니다.
*   **자동 알림**: 사용량이 특정 임계치(예: 20% 미만)에 도달하면 macOS 알림을 보내도록 기능을 추가하여, 사용자가 미처 인지하지 못하는 사이에 API 사용 한도를 초과하는 것을 방지할 수 있습니다.
*   **비용 최적화 추천**: 사용량 패턴 분석을 통해 특정 시간대에 더 저렴한 모델 사용을 권장하거나, 비활성 상태일 때 API 호출을 최소화하는 등의 최적화 방안을 제시할 수 있습니다.

## 주의사항

*   **개인 계정 정보**: 이 위젯은 사용자의 **개인 계정** 정보를 활용합니다. Claude Code의 경우 macOS Keychain에 저장된 OAuth 토큰을 사용하며, Codex는 로컬 세션 로그를 읽습니다. 민감한 정보가 외부에 유출되지는 않으나, 보안에 유의해야 합니다.
*   **Codex 데이터 최신성**: Codex 사용량 데이터는 마지막 세션 기록에 기반하므로, 오랫동안 Codex를 사용하지 않았다면 정보가 최신이 아닐 수 있습니다. 위젯은 이를 표시하지만, 실시간 반영에는 한계가 있습니다.
*   **네트워크 호출**: Claude 사용량 API 호출 및 업데이트 확인을 위한 네트워크 요청이 발생합니다. 인터넷 연결이 불안정하거나 차단된 경우 정보가 최신이 아닐 수 있습니다.
*   **SwiftBar 및 bun 설치**: 위젯 작동을 위해서는 macOS에 SwiftBar와 bun이 설치되어 있어야 합니다. 설치 과정에서 PATH 설정 등에 주의가 필요합니다.
