# 주식 분석 대시보드 무료로 사용하기

💡 유료 주식 분석 사이트 구독료 없이, **Finnhub 무료 API 키**와 **Claude Code**로 직접 만든 주식 분석 대시보드를 활용하는 스킬입니다.

## 이게 뭔가요?
유료로 구독하던 주식 분석 사이트의 비싼 구독료를 절약할 수 있는 방법입니다. 이 스킬은 Claude Code를 활용하여 직접 만든 주식 분석 대시보드를 무료로 사용할 수 있도록 안내합니다. Finnhub에서 제공하는 무료 API 키를 발급받아 연동하면, SEC 공시 기반의 정확한 실시간 데이터를 이용해 관심 종목을 편리하게 비교 분석할 수 있습니다. 한번 설정해두면 영구적으로 사용 가능하며, PC와 모바일 모두 지원합니다.

대시보드는 설치나 서버가 필요 없는 단일 HTML 파일 구조로, 브라우저에서 바로 실행됩니다. 입력한 Finnhub API 키와 마지막으로 조회한 종목 정보는 브라우저에 자동으로 저장되어 사용자 본인에게만 안전하게 유지됩니다.

💰 유료 필요: Finnhub 무료 API 키는 무료 제공됩니다. (개인 사용 기준 분당 60회 조회 가능)
✅ 무료 대안: 직접 개발하지 않는 이상, 유료 주식 분석 툴 구독료 절약

## 따라하기
1.  **대시보드 접속 및 Finnhub 무료 API 키 발급**
    *   대시보드 링크를 통해 접속합니다. (별도 다운로드나 설치 불필요)
    *   Finnhub 웹사이트에서 무료 회원가입 후 로그인합니다.
    *   로그인 후, 대시보드 상단에 표시된 **API Key**를 복사합니다.
    *   대시보드 상단의 API 키 입력란에 복사한 키를 붙여넣고 **[저장]** 버튼을 클릭합니다.

2.  **주식 티커 입력 및 데이터 조회**
    *   대시보드 상단 검색창에 분석하고자 하는 주식의 티커(예: GOOGL, AAPL, NVDA, MSFT, TSLA)를 입력하고 Enter 키를 누르거나 자동 완성 제안을 클릭합니다.
    *   이전에 조회했던 티커는 자동으로 복원되어 다음 접속 시 편리하게 사용할 수 있습니다.
    *   새로운 티커를 입력하면 즉시 데이터가 새로고침됩니다.

3.  **5개 탭 구성 상세 확인**
    *   **개요:** 시가총액, 52주 고가/저가, 베타, 최근 분기 실적 (매출, 영업이익, 순이익), EPS, 분기 추이 차트 등 기본 정보를 제공합니다.
    *   **손익:** 분기 손익계산서, 이익률 추이, EPS 실제 vs 예상치 비교 정보를 보여줍니다.
    *   **현금흐름:** 영업활동 현금흐름(OCF), 자본적 지출(CapEx), 잉여현금흐름(FCF) 등 핵심 KPI와 분기 추이 차트를 제공합니다.
    *   **밸류에이션:** 주가수익비율(P/E), 주가매출비율(P/S), 주가순자산비율(P/B), 기업가치 대비 영업이익(EV/EBITDA) 등 주요 멀티플과 수익성, 재무 건전성 지표를 표시합니다.
    *   **대차대조표:** 분기별 현금, 자산, 부채, 자본 현황을 표 형태로 제공합니다.

## 활용 예시
*   **관심 종목 집중 비교:** 5~10개 관심 종목 리스트를 만들어 순회하며 각 종목의 분기 실적, P/E vs P/B 비율, FCF Yield 등을 한눈에 비교 분석할 수 있습니다.
*   **실적 시즌 동향 파악:** 특정 기업의 실적 발표 당일, 해당 기업의 경쟁사들의 재무 지표를 함께 조회하여 시장 전반의 흐름이나 경쟁 구도를 파악하는 데 활용할 수 있습니다. (예: NVDA 실적 발표일에 AMD, TSMC 데이터 함께 조회)
*   **개인화된 대시보드 제작:** Claude Code에 익숙하다면, 이 대시보드 구조를 기반으로 한국 주식 종목이나 암호화폐 등 분석 대상에 맞춰 커스터마이징하여 사용할 수 있습니다.

## 주의사항
*   **미국 종목 전용:** SEC 공시 데이터를 기반으로 하므로 한국 주식 종목은 지원하지 않습니다.
*   **데이터 지연 및 누락 가능성:** Finnhub 무료 플랜 이용 시 시세 및 멀티플 데이터에 약간의 지연이 발생할 수 있습니다. 또한, SEC 공시 데이터 구조의 한계로 인해 회사별 세부 사업 부문 매출 정보가 누락될 수 있습니다.
*   **투자 책임:** 본 대시보드는 투자 참고용 자료이며, 실제 투자 결정은 반드시 해당 기업의 공식 IR 페이지와 공시 원문을 직접 확인한 후에 신중하게 내려야 합니다.
