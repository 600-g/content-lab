# AI 비서·직원·회사로 업무 자동화

💡 사무 업무 자동화는 **AI 비서 한 명**(Claude Cowork)에서 시작해 **AI 직원팀**(지휘자+실무자 에이전트), **AI 가상회사**(12부서→32명·대시보드)로 규모를 키워 가는 일입니다. 맨 앞의 **선택 가이드**에서 내 규모·목적에 맞는 단계를 골라, 그 절만 따라 하면 됩니다.

## 이게 뭔가요?

혼자서 조사·기획·검수·제작·메일·일정·정산을 다 처리하는 대신, 반복적이고 시간이 많이 드는 일은 AI에게 맡기고 사람은 **핵심 의사결정(승인·선택)** 에만 집중하도록 만드는 방법을 한곳에 모은 가이드입니다. 접근 방식은 규모에 따라 다섯 층으로 나뉩니다.

1. **혼자 쓰는 AI 비서** — Claude 데스크톱 앱의 **Cowork** 는 단순한 챗봇이 아니라 내 로컬 폴더에 접근해 파일을 읽고 쓰는 '일해주는 AI'입니다. **전역 지침(Global Instructions)** 과 **나를 아는 파일 3개**(about-me·voice-style·my-company)를 주면 업무 맥락을 이해하는 '나를 아는 직원'이 되고, **Record a Skill** 로 내가 하던 일을 화면 녹화로 보여주면 재실행 가능한 자동화 스킬이 됩니다.
2. **도구 조합 자동화** — **"도구 + 도구 = 자동화"** 공식으로 Gmail·Notion·캘린더·텔레그램·Playwright 같은 도구를 Claude 에 연결(MCP)하고, 복붙 프롬프트 하나로 메일 분류·회의록 정리·일정 관리를 맡깁니다.
3. **AI 직원팀** — 역할별 에이전트를 여러 명 두고 **지휘자 한 명에게 목표 한 줄**만 말하면 나머지를 자동으로 부르게 합니다. 오픈소스 **agency-agents** 의 264명 중 7명만 골라 Claude Code 에 설치하는 방법과, 무료 오픈소스 앱 **머더디핀(Munder Difflin)** 으로 사무실 화면에서 직원들을 굴리는 방법이 있습니다.
4. **AI 가상회사** — 업무 흐름을 12개 부서로 나눠 텍스트로 위임하는 **기본편**, 직원을 32명으로 늘리고 Claude Code 로 직원들이 출근·회의·승인 요청을 하는 가상 오피스 화면을 만드는 **심화편**, 업무 전체를 하나의 대시보드로 묶는 **확장편(AI Office)** 이 있습니다. 하루에 내가 개입하는 건 **승인 결정 1번**뿐인 구조가 목표입니다.
5. **업종 적용** — 이커머스처럼 소싱·광고 분석·CS 가 반복되는 업종에서는 위 방법 중 하나를 골라 가장 시간이 많이 걸리는 업무 하나부터 자연어 명령으로 위임합니다.

## 따라하기

### 0. 모든 단계에 공통으로 적용할 원칙

#### 프롬프트는 세 요소로

어떤 도구 조합이든 프롬프트는 **"무엇을 / 어떤 기준으로 / 결과를 어떻게"** 세 가지가 분명해야 합니다. 하나라도 모호하면 결과도 모호해집니다. 지휘자에게 주는 목표도 **한 줄, 결과물 하나**로 씁니다.

#### 안전 규칙 6가지 (문서·지침 최상단에)

AI 에게 자율권을 줄수록 사고 방지 규칙이 중요합니다. 전역 지침이든 `AI_COMPANY.md` 든 맨 위에 다음을 적어 둡니다.

① 메일 실제 발송 금지 — 초안까지만
② SNS 실제 게시 금지 — 예약·업로드는 사람이
③ 결제·구독 금지
④ 원본 파일 삭제·덮어쓰기 금지 — 복제본에만 작업
⑤ 연결 안 된 서비스를 '완료'라고 보고 금지
⑥ 확인 안 된 정보를 사실처럼 쓰기 금지 — 출처 없으면 '미확인'이라고 표시

🚨 특히 ⑤번은 AI 가 존재하지 않는 완료 보고를 하는 것을 막는 데 중요합니다. Cowork 전역 지침 템플릿의 **"실행 전 꼭 확인할 것"** 칸(1-3)이 같은 역할을 하므로, 둘 중 어디에 쓰든 내용은 맞춰 둡니다.

#### 작게 시작해 반복으로 굳히기

30개, 264명, 32명을 처음부터 다 세팅하지 않습니다. 지금 가장 **귀찮은 일 하나**를 골라 한 번 성공시키고, 잘 되면 "매일 아침 9시에 자동으로" 같은 반복 지시를 붙이거나 직원·부서를 한 명씩 늘립니다.

### 1단계. 혼자 쓰는 AI 비서 — Claude Cowork

#### 1-1. 코워크 시작하기

Cowork 는 Claude 데스크톱 앱에서 Claude 가 내 컴퓨터의 파일·폴더에 접근해 작업하도록 권한을 주는 방식입니다. 반복적인 파일 관리, 정보 요약, 코드 작성, 이메일 초안 같은 일을 위임할 수 있습니다.

1. **앱 설치**: claude.com/download 에 접속해 운영체제(맥/윈도우)에 맞는 Claude 데스크톱 앱을 설치합니다.
2. **로그인**: Pro 플랜 이상 계정으로 로그인합니다. (무료 플랜으로는 Cowork·Record a Skill 을 쓸 수 없습니다.)
3. **코워크 선택**: 채팅 입력창 왼쪽 아래에서 "Cowork"를 선택합니다. 일반 채팅과 코워크는 같은 화면에서 전환됩니다. 메뉴·버튼 위치는 앱 버전에 따라 다를 수 있으니 앱 내 안내를 참고하세요.
4. **폴더 연결**: 코워크가 접근할 폴더를 지정합니다(1-2 에서 만드는 폴더).
5. **작업 지시**: 일반 채팅처럼 자연어로 지시합니다. 예: "내 문서 폴더에 있는 모든 TXT 파일 내용을 요약해줘"

로컬 파일 읽기/쓰기는 **데스크톱 앱에서만** 됩니다. 웹/모바일 코워크는 베타이며 로컬 폴더 연결은 데스크톱 전용입니다. 운영체제 수준의 파일 접근 권한을 앱에 허용해야 할 수도 있습니다.

#### 1-2. 작업 폴더 만들기

1. 바탕화면에 `코워크` 폴더를 만듭니다.
2. 안에 하위 폴더 세 개를 만듭니다.
   - `회사정보/`: 나에 대한 파일 3개가 저장되는 곳 (읽기 전용)
   - `결과물/`: 코워크가 생성한 결과물이 저장되는 곳
   - `템플릿/`: 잘 나온 결과물을 재사용하기 위해 모아두는 곳
3. 코워크를 이 `코워크` 폴더에 연결합니다.

바탕화면 전체나 문서 전체를 연결하지 마세요. 연결된 폴더는 읽기/쓰기가 모두 열리므로 범위를 좁게, 민감한 폴더는 빼고 필요한 최소 범위만 줍니다.

#### 1-3. 전역 지침(Global Instructions) 넣기

전역 지침은 이름·역할·사업 목표·대화 스타일을 미리 정의해, 매번 긴 프롬프트를 쓰지 않아도 일관된 답이 나오게 하는 설정입니다.

1. Claude Desktop 을 실행합니다.
2. 좌측 하단의 **내 이름**을 클릭해 설정을 엽니다.
3. `Settings` > `Cowork` 메뉴로 이동합니다.
4. `Global Instructions` 섹션에서 `Edit` 를 클릭합니다.
5. 아래 템플릿을 복사해 붙여넣습니다.
6. **[대괄호]** 안을 내 상황에 맞게 고칩니다. 쓰지 않는 줄은 지워도 됩니다. 1-2 에서 만든 폴더를 쓴다면 파일 저장 위치를 그 `결과물/` 폴더로, 승인 전 금지 항목은 0번의 안전 규칙과 맞춰 적습니다.
7. `Save` 를 누르고, 대화해 보며 설정이 적용되는지 확인합니다.

#### 1-5. Record a Skill — 화면 녹화로 자동화 스킬 만들기

**Record a Skill(스킬 녹화)** 은 복잡한 프롬프트나 코딩 없이, 평소 하던 작업을 **화면 녹화로 시연하면서 그 이유와 과정을 음성으로 설명**하면 Claude 가 화면 움직임·클릭·타이핑·음성을 종합 분석해 재실행 가능한 '스킬'로 저장하는 Cowork 기능입니다. 이후 비슷한 요청이 오면 저장된 스킬을 불러와 자동 실행합니다.

- 화면을 그대로 재생하던 예전 매크로와 달리 **작업 의도를 추출·일반화**하므로 화면이 조금 바뀌어도 유연하게 대처합니다.
- 시연이 완벽하지 않거나 실수가 있어도 말과 행동에서 핵심 의도를 파악합니다.
- 해당 서비스에 API 연동이 가능하면 화면 조작 대신 **API 연동을 먼저 제안**합니다.
- 순서·예외 처리·판단이 섞여 글로 설명하기 어려운 작업에 특히 유용합니다.
- 2026년 7월 21일 Anthropic 발표. **Pro, Max, Team 플랜**만 사용 가능(Free 불가), **데스크톱 앱(Mac/Windows) 전용**이며 모바일·웹에서는 녹화·실행이 안 됩니다. 순차 롤아웃 중이라 계정마다 활성화 시점이 다를 수 있습니다.

**사전 설정** (빠지면 녹화는 되는데 클릭이 안 먹히는 문제가 생깁니다)

1. **computer-use 커넥터 켜기**: 데스크톱 앱 설정에서 "computer-use" 커넥터를 활성화합니다. 켜지면 대화창의 "Context" → "Connectors" 탭에 "computer-use"가 보이고, Claude 가 직접 클릭·타이핑할 수 있습니다. (Pro·Max 리서치 프리뷰 기능)
2. **macOS 권한 설정**
   - 화면을 보기 위한 권한: 시스템 설정 → 개인정보 보호 및 보안 → "Screen & System Audio Recording" 에서 Claude 토글 ON
   - 컴퓨터 조작 권한: 같은 경로의 "Accessibility" 에서 Claude 토글 ON ("Allow the applications below to control your computer")
   - 윈도우도 '컴퓨터 사용'을 지원하지만 권한 설정 경로는 운영체제에 맞게 다릅니다.
3. **앱 최신 버전 확인**: 메뉴바 "Claude" → "Check for Updates".
4. **앱 실행 유지**: Record a Skill 과 컴퓨터 사용 기능은 Claude 앱이 실행 중(백그라운드 포함)일 때만 작동합니다.

**녹화 흐름**

1. Cowork 에서 "Record a skill" 녹화를 시작합니다. 녹화 전에 비밀번호·결제 정보·개인 메시지가 화면에 없는지 확인합니다.
2. 평소처럼 작업을 시연하면서, **무엇을 왜 고르고 무엇을 왜 빼는지 판단 기준을 말로** 설명합니다.
3. 녹화를 끝내면 Claude 가 스킬로 저장합니다.
4. 이후 짧은 명령 한 줄로 스킬을 호출합니다. (구체 사례는 '활용 예시'의 인스타 릴스 오디오 참고)

조건 분기가 너무 많은 작업은 녹화만으로 한계가 있으니 **작은 스킬 여러 개로 나눠** 녹화합니다.

### 2단계. 도구 조합 자동화 — 복붙 프롬프트 카드

**"도구 + 도구 = 자동화"** 공식으로 비개발자도 Claude 와 노코드 도구를 조합해 잡무를 줄이는 방법입니다. 원래 30개 조합 카드로 구성된 가이드이며, 아래는 '메일 · 일정 · 기록 (01–10)' 섹션의 카드 01~05 입니다. 30개를 다 할 필요는 없고, 지금 가장 귀찮은 일 하나의 카드부터 씁니다.

1. **도구 연결**: 카드에 필요한 도구(Gmail, 슬랙, Google Sheets 등)를 Claude 에 연결(MCP)합니다. "Claude 가 해당 앱을 직접 만질 수 있게 권한을 주는 것"이며, 필요한 권한만 줍니다.
2. **프롬프트 붙여넣기**: 복붙 프롬프트를 그대로 붙여넣고 **[대괄호]** 안만 고칩니다.
3. **반복으로 굳히기**: 한 번 성공하면 끝에 **"이걸 매일 아침 9시에 자동으로 해줘"** 같은 명령을 붙여 24시간 비서로 만듭니다.

**01 메일 자동 분류 (Gmail + Claude)** — 받은 메일을 종류별로 자동 정리

```
Gmail에서 오늘 받은 메일을 읽고 [업무 / 광고 / 뉴스레터 / 개인]으로 분류해서 각각 라벨을 붙여줘. 애매한 건 내가 정할게,
목록만 먼저 보여줘.
```

세팅 팁: **Gmail MCP** 연결 후 성공하면 **"매일 아침 8시에 자동으로"** 를 추가합니다.

**02 회의록 자동 정리 (Claude + Notion)** — 회의·자료 내용을 문서로 자동 정리

```
아래 회의 내용을 [결정사항 / 담당자별 할일 / 다음 안건] 세 가지로 정리해서 Notion [회의록] 페이지에 오늘 날짜로 저장해
줘.
```

세팅 팁: 녹취 텍스트를 그대로 붙여넣어도 됩니다.

**03 일정 자동 관리 (Claude + 캘린더)** — 일정 등록과 리마인드까지

```
"[날짜] [시간] [내용]" 일정을 Google Calendar에 등록하고 하루 전·1시간 전 알림을 설정해줘. 겹치는 일정이 있으면 먼저
알려줘.
```

세팅 팁: **"이번 주 빈 시간 2시간 찾아줘"** 같은 명령으로 스케줄 관리에도 씁니다.

**04 어디서나 지시 (텔레그램 + Claude)** — 메시지 한 줄로 외부에서 업무 지시

```
앞으로 내가 텔레그램으로 보내는 메시지를 업무 지시로 받아 처리하고, 완료되면 결과를 텔레그램으로 다시 보내줘.
```

세팅 팁: 컴퓨터를 켜 둔 채 외출하면 스마트폰으로 모든 업무 지시가 가능합니다.

**05 웹 정보 자동 수집 (Playwright + Claude)** — 특정 사이트 정보를 긁어와 요약

```
[사이트 URL]에 접속해서 [제목 / 가격 / 내용 등]을 수집해서 정리해줘. 여러 페이지면 [N]페이지까지 순서대로.
```

세팅 팁: **Playwright MCP** 를 설정하면 API 없이 어떤 사이트든 정보를 수집할 수 있습니다.

### 3단계. AI 직원팀 — 지휘자 1명 + 실무자 6명 (agency-agents)

GitHub 의 **agency-agents** 저장소(별 15만 개, MIT 라이선스, 회사 일에 써도 되는 오픈소스)에는 AI 직원 264명이 들어 있습니다. 직원 한 명 = 마크다운 파일 하나이고, 파일에 이름·성격·일하는 순서가 적혀 있어 Claude Code 같은 AI 코딩 도구에 붙이면 그 역할대로 일하는 '에이전트'가 됩니다.

264명을 다 깔면 매번 "이번엔 누굴 부르지"를 직접 골라야 해서 느려집니다. 그래서 **일곱 명만** 고르고, 그중 지휘자(agents-orchestrator)에게 나머지 여섯을 맡깁니다. 그러면 지휘자 한 명에게 목표만 말하면 됩니다.

```
flowchart TD
ME["나<br/>목표 한 줄만 적는다"] --> O["agents-orchestrator<br/>«비서실장» · 7번째"]
O --> A["Frontend Developer<br/>화면을 만든다"]
```

### 4단계. AI 직원팀 사무실 앱 — 머더디핀(Munder Difflin)

머더디핀은 미드 '오피스(The Office)'를 패러디한 이름의 무료 오픈소스 데스크톱 앱(맥·윈도우·리눅스)으로, **클로드 코드를 엔진**으로 여러 AI 에이전트를 '직원'처럼 배치하고 사무실 화면에서 일을 나눠 처리하게 합니다. 원본: github.com/chaitanyagiri/munder-difflin (MIT 라이선스). NBC 드라마 '오피스'와 공식 관계는 없습니다.

- 💰 앱은 무료지만 실제 작업은 내 **클로드 구독 사용량**을 그대로 씁니다. 클로드 코드는 무료 플랜에서 쓸 수 없으므로 **Pro 이상** 구독이 필수입니다.
- ✅ 앱 설치·사무실 화면·직원 메모리·작업 보드는 무료판으로 그대로 쓰고, 받아쓰기·회의 기록 같은 부가 기능만 Pro 기능입니다.

#### STEP 1. 클로드 코드 설치

터미널을 엽니다(맥: 응용 프로그램 → 유틸리티 → 터미널 / 윈도우: 시작 메뉴에서 PowerShell). 내 컴퓨터에 맞는 한 줄을 붙여넣고 Enter.

맥·리눅스:
```
curl -fsSL https://claude.ai/install.sh | bash
```

윈도우(PowerShell):
```
irm https://claude.ai/install.ps1 | iex
```

설치가 끝나면 창을 닫고 새 창을 엽니다. (3단계·5~6단계에서 Claude Code 가 필요할 때도 이 설치 방법을 그대로 씁니다.)

#### STEP 2. 클로드 코드 로그인

새 창에 입력하고 Enter.
```
claude
```
브라우저가 열리면 평소 쓰는 클로드 계정으로 로그인하고 허용을 누릅니다. 창에 입력칸이 뜨면 끝이고, 창은 닫아도 됩니다. 이미 로그인돼 있으면 바로 입력칸이 뜨니 그대로 넘어갑니다.

#### STEP 3. 머더디핀 내려받기

harnessmd.com/download 에서 내 컴퓨터에 맞는 버튼을 누릅니다.

- **맥**: macOS · Apple silicon and Intel (dmg 파일, 인텔·애플 칩 모두 이 파일 하나)
- **윈도우**: Windows · x64 (win-x64-setup.exe). 설치 없이 쓰려면 깃허브 Releases 에서 win-x64-portable.exe 를 받습니다.
- **리눅스**: Linux · x86_64 (AppImage 파일)

#### STEP 4. 설치하고 처음 열기

- 맥: dmg 를 더블클릭하고, 뜬 창에서 앱 아이콘을 Applications 폴더로 끌어다 놓습니다.
- 윈도우: setup.exe 를 더블클릭해 설치합니다.
- 머더디핀을 실행합니다. 경고가 뜨면 맥은 시스템 설정 → 개인정보 보호 및 보안 맨 아래 "그래도 열기", 윈도우는 "Windows의 PC 보호" 창에서 추가 정보 → 실행.

#### STEP 5. 로그인하고 첫 설정

1. "How are you using Munder Difflin?" 에서 **On my own** 을 고릅니다.
2. Sign in to continue 화면에서 브라우저가 열리면 이메일로 로그인하거나 가입합니다.
3. 작업공간 이름을 정하고 일할 폴더를 고릅니다. 개발자가 아니면 **non technical** 을 고르면 어려운 용어가 줄어듭니다.
4. 총괄 직원 이름칸에 **Michael** 을 적습니다.
5. 엔진은 **Claude Code**. 옆에 Installed 가 보이면 STEP 1~2 가 제대로 된 것입니다.
6. **Open the workspace** 를 누릅니다.
7. "Go PRO on this machine" 창이 뜨면 **Continue with the free version**.

#### STEP 6. 마이클에게 첫 일 시키기

오른쪽 아래 Message Michael 칸을 누르고 붙여넣은 뒤 send.
```
마이클, 이번 주 인스타 캐러셀 기획해줘
```
왼쪽 사무실에서 직원 캐릭터들이 움직이며 일을 나눠 받는 걸 지켜봅니다.

#### STEP 7. 직원 늘리고 역할 나누기

1. Agents 화면에서 **Add an agent**.
2. 엔진은 **Claude Code**.
3. 이름에 역할을 적습니다. 예: 기획, 글쓰기, 검토
4. 오른쪽 tasks 탭에서 누가 어떤 일을 하는지(TODO, DOING) 보드로 봅니다.

#### STEP 8. 사용량 한도 걸어 두기

기본값은 직원들이 묻지 않고 알아서 일하는 Autonomous 입니다. 사용량이 한꺼번에 빠지지 않게 한도를 겁니다.

1. 오른쪽 위 톱니바퀴(설정) → **Autonomy & Budgets**.
2. **CIRCUIT BREAKER** 가 on 인지 확인합니다.
3. **FLOOR TOKEN BUDGET** 칸에 전체 한도 숫자를 적고 save. 한도를 넘는 직원은 먼저 말리고, 그래도 안 되면 멈춥니다.

맥에서 마이크·손쉬운 사용 권한을 물을 수 있습니다(마이크는 말로 지시하는 voice 버튼용). 시스템 설정 → 개인정보 보호 및 보안에서 머더디핀을 켜 줍니다.

### 5단계. AI 가상회사 기본편 — 12부서 텍스트 위임

콘텐츠가 세상에 나오기까지 거치는 단계를 부서로 나눠, 회사처럼 순서대로 일을 넘기게 합니다. 코딩 지식 없이 Claude 대화창만으로도 충분히 됩니다.

#### 5-1. 12개 부서 정의

필요에 따라 조정하거나 5개 부서로 시작해도 됩니다.

| 부서 | 하는 일 | 없으면 생기는 일 |
|---|---|---|
| 시장조사팀 | AI 뉴스·트렌드 수집, 출처 확인 | 남들 다 아는 소재만 반복 |
| 브랜드 분석팀 | 계정 흐름·저장률·페르소나 점검 | 감으로 만들고 망함 |
| 기획 1팀 | 아이디어 10개 생산, TOP 3 선정 | 소재 고갈, 백지에서 시작 |
| 브랜드 검수팀(QA) | 톤·금칙어·중복·근거 검사 | AI 말투 그대로 나감 |
| 기획 2팀 | 승인된 아이디어만 대본으로 작성 | 안 쓸 대본까지 쓰느라 시간 낭비 |
| 영상 제작팀 | 릴스 대본→컷 구성, 자막 초안 | 편집에서 멈춤 |
| 이미지 제작팀 | 캐러셀·썸네일 문구 및 장수 구성 | 디자인에 하루 다 씀 |
| 협업 소통팀 | 협찬·제휴 메일 검토, 답장 초안 | 기회가 메일함에 묻힘 |
| 정산팀 | 광고비·입금·미수금 정리 | 돈 새는 것을 3개월 뒤에 앎 |
| 성과리뷰팀 | 게시 후 저장·댓글·도달 기록, 잘된 이유 정리 | 터진 이유 모름 |
| 자동화 운영팀 | 연동 상태·실패·재시도 관리 | 어디서 멈췄는지 모름 |
| 비서실 | 전 부서 보고 취합 및 대표에게 요약 | 직접 12군데 확인 필요 |

💡 초보자를 위한 시작 부서: 1번(조사) · 3번(기획) · 4번(검수) · 5번(대본) · 12번(비서실)

#### 5-2. 부서 카드 작성

부서마다 다섯 항목을 채웁니다.

- **부서 이름:**
- **오늘 할 일:**
- **지켜야 할 기준:** (3개)
- **결과물 형태:**
- **넘겨줄 다음 부서:**

예시 (브랜드 검수팀):
- 부서 이름: 브랜드 검수팀(QA)
- 오늘 할 일: 기획팀이 낸 아이디어 10개를 내 브랜드 기준으로 검사
- 지켜야 할 기준: ① 금칙어 포함 시 탈락 (예: "여정", "마법 같은"), ② 근거 링크 없으면 탈락, ③ 최근 7일 콘텐츠와 40% 이상 겹치면 각도 변경
- 결과물 형태: 통과 O / 반려 X + 반려 사유 한 줄
- 넘겨줄 다음 부서: 기획 2팀(대본)

1단계에서 만든 `voice-style.md` 의 금지 표현을 검수팀 금칙어로 그대로 가져오면 기준이 한 번에 맞춰집니다.

#### 5-3. 회사 규칙 적용 (Claude Code 또는 Claude 앱)

1. **`AI_COMPANY.md` 파일 생성**: 0번의 안전 규칙 6가지를 맨 위에, 그 아래 부서 카드를 넣어 `.md` 로 저장합니다.
2. **첫 지시**:
```
AI_COMPANY.md를 읽어줘.
지금부터 너는 이 회사의 직원들이야.
읽고 나서, 내가 채워야 할 빈칸이 어디인지 먼저 알려줘.
```
3. **부서 채우기 (AI 활용)**:
```
AI_COMPANY.md의 부서 12개를 내 채널 기준으로 채워줘.
내 채널은 [주제]를 다루고, 주 시청자는 [타깃]이야.
부서마다 '지켜야 할 기준' 3줄은 반드시 반려 기준으로 써줘.
```
4. **일일 업무 지시**:
```
오늘 업무 시작. 시장조사팀 → 기획 1팀 → 검수팀 순서로 진행하고,
TOP 3만 뽑아서 나한테 보고해줘. 내가 고르면 그때 대본 써.
```
5. **개별 부서 호출**:
```
브랜드 검수팀으로만 일해줘. 이 원고 검사하고 반려 사유만 말해줘.
[원고 붙여넣기]
```

💡 Claude 앱 사용자: Claude Code 없이 대화창에 `AI_COMPANY.md` 내용을 붙여넣고 "지금부터 이 회사 규칙대로 일해줘"라고 지시해도 똑같이 작동합니다. Cowork 를 쓴다면 `AI_COMPANY.md` 를 연결 폴더에 두고 읽게 하면 됩니다.

#### 5-4. 하루 업무 흐름

- **07:00**: 시장조사팀 → 기획 1팀 → 검수팀 순서로 진행
- **내가 하는 일**: 검수팀의 반려 결과를 보고 최종 TOP 3 중 1개 선정
- **이후**: 기획 2팀(대본 작성) → 제작팀(영상/이미지) → 성과리뷰팀(결과 기록) → 비서실(일일 보고 요약)

하루에 내가 직접 개입하는 건 **1번의 결정**뿐입니다.

### 6단계. AI 가상회사 심화편 — 32명 가상 오피스

기본편을 바탕으로 직원을 32명으로 늘리고, Claude Code 로 직원들이 출근하고 회의실에 모이고 승인을 요청하며 상태를 색으로 표시하는 '살아있는 회사' 화면을 구현합니다. 유료 플랜이 필요할 가능성이 있습니다.

#### 6-1. 12명 → 32명 편성

팀장 12명 체제에 팀원을 붙이고, 역할이 겹치지 않게 세분화해 결과물을 구체화합니다(예: '릴스팀' → '릴스팀 편집 담당').

**갓생맘 실제 편성표 (예시)**

| # | 부서 | 인원 | 팀장이 맡는 것 | 팀원이 맡는 것 |
|---|---|---|---|---|

#### 6-4. 대표 지시창

화면 옆에 대표 지시창을 두어 직원들에게 직접 묻고 답을 받습니다.

| 내가 묻는 말 | 누가 답하나 | 답 내용 |
|---|---|---|
| "현황 보고" | 비서실장 | 현재 시각·단계·진행률·다음 순서 |
| "왜 늦어져?" | 비서실장 | 진짜 병목 1개 + 원인 |
| "재무팀 뭐해?" | 재무 팀장 | 자기 팀 상황 + 팀원 현황 |
| "회의 소집" | 팀장 전원 | 회의실에 모여 한 줄씩 보고 |
| "집중 모드" | 전원 | 커피·잡담 중단하고 자리 복귀 |

"왜 늦어져?" 답변 규칙:
1. 내 결정을 기다리는 중이면 → 그것부터 말하기
2. 작업 중이면 → 부서명 + 진행률 + "정상 속도예요"
3. 외부 연동 때문이면 → 무엇이 없어서 못 하는지 정확히
4. 아무 문제 없으면 → "지연 없습니다" 한 줄로 끝

### 7단계. 확장편 — AI Office 통합 대시보드

가상 오피스 구조가 갖춰지면 업무 흐름 전체를 하나의 시스템 대시보드로 묶어 트렌드 분석·콘텐츠 추천·이메일 관리·카드뉴스 제작·콘텐츠 계획 같은 마케팅·기획·운영 실무를 한 화면에서 관리할 수 있습니다. 다음 8가지 기능 중 필요한 것부터 고릅니다.

1. **시스템 대시보드**: 업무 전반의 현황을 한눈에 보는 통합 대시보드
2. **트렌드 뷰어**: 시장의 주요 트렌드를 시각적으로 분석해 보여줌
3. **콘텐츠 추천**: 어떤 주제·형식의 콘텐츠가 효과적일지 AI 가 추천
4. **인스타 대시보드**: 인스타그램 채널 성과 분석·관리
5. **이메일 대시보드**: 이메일 관리 자동화·효율화
6. **카드뉴스 만들기**: 텍스트와 이미지를 조합한 카드뉴스 제작
7. **콘텐츠 계획표**: 발행 계획을 세우고 관리하는 캘린더형 계획표
8. **저장건 대시보드**: 저장하거나 모은 정보를 한곳에서 관리·분석

**실행 단계**
1. **필요 기능 정의**: 가장 부족하거나 개선하고 싶은 업무 영역(예: '콘텐츠 기획', '인스타 성과 분석')을 정합니다.
2. **기능 매칭**: 8가지 중 그 영역에 가장 가까운 기능을 고릅니다.
3. **구현 방법 탐색**: 어떤 AI 도구(Gemini, ChatGPT 등)의 어떤 기능을 조합할지 조사합니다. (예: '콘텐츠 계획표' → Gemini 에게 '다음 달 주제 10개와 각 주제별 예상 포스팅 횟수'를 요청) 이메일 대시보드처럼 메일을 다루는 기능은 2단계의 01번 카드(메일 분류)부터 시작하면 됩니다.
4. **피드백 및 개선**: 만들어 본 결과를 바탕으로 '가장 만들어보고 싶은 것'을 구체적인 개선점으로 남겨 다음 프롬프트에 반영합니다.

### 8단계. 업종 적용 — 이커머스 업무 비서
