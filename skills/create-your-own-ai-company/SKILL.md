# AI 직원 12명으로 콘텐츠 회사 만들기

💡 콘텐츠 제작 업무를 **12개의 AI 부서**로 나누어 효율적으로 관리하고, **복붙 가능한 프롬프트**를 활용하여 나만의 AI 회사를 만드는 방법을 안내합니다.

## 이게 뭔가요?
이 가이드는 혼자서 모든 콘텐츠 제작 과정을 담당하는 대신, AI를 12개의 전문 부서로 나누어 업무를 위임하는 방법을 알려줍니다. 이를 통해 콘텐츠 제작의 효율성과 품질을 높이고, 마치 실제 회사를 운영하듯 AI 직원들을 관리할 수 있습니다. 특히 코딩 지식이 없는 초보자도 따라 할 수 있도록 Claude 또는 Claude Code를 활용하는 구체적인 방법과 복사하여 바로 사용할 수 있는 프롬프트를 제공합니다.

## 따라하기
### 1단계: AI 회사의 12개 부서 정의
콘텐츠가 세상에 나오기까지 거치는 단계를 기준으로 12개의 부서를 정의합니다. 각 부서는 특정 역할을 수행하며, 필요에 따라 부서를 조정하거나 처음에는 5개 부서로 시작해도 좋습니다.

**주요 부서:**

| 부서 | 하는 일 | 없으면 생기는 일 |
|---|---|---|
| 시장조사팀 | AI 뉴스·트렌드 수집, 출처 확인 | 남들 다 아는 소재만 반복 |
| 브랜드 분석팀 | 계정 흐름·저장률·페르소나 점검 | 감으로 만들고 망함 |
| 기획 1팀 | 아이디어 10개 생산, TOP 3 선정 | 소재 고갈, 백지에서 시작 |
| 브랜드 검수팀(QA) | 톤·금칙어·중복·근거 검사 | AI 말투 그대로 나감 |
| 기획 2팀 | 승인된 아이디어만 대본으로 작성 | 안 쓸 대본까지 쓰느라 시간 낭비 |
| 영상 제작팀 | 릴스 대본→컷 구성, 자막 초안 | 편집에서 멈춤 |
| 이미지 제작팀 | 캐러셀·썸네일 문구 및 장수 구성 | 디자인에 하루 다 씀 |
| 협업 소통팀 | 협찬·제휴 메일 검토, 답장 초안 | 기회가 메일함에 묻힘 |
| 정산팀 | 광고비·입금·미수금 정리 | 돈 새는 것을 3개월 뒤에 앎 |
| 성과리뷰팀 | 게시 후 저장·댓글·도달 기록, 잘된 이유 정리 | 터진 이유 모름 |
| 자동화 운영팀 | 연동 상태·실패·재시도 관리 | 어디서 멈췄는지 모름 |
| 비서실 | 전 부서 보고 취합 및 대표에게 요약 | 직접 12군데 확인 필요 |

**💡 초보자를 위한 시작 부서:** 1번(조사) · 3번(기획) · 4번(검수) · 5번(대본) · 12번(비서실)

### 2단계: 부서 카드 작성
각 부서별로 다음 5가지 항목을 포함한 카드를 작성합니다.

- **부서 이름:**
- **오늘 할 일:**
- **지켜야 할 기준:** (3개)
- **결과물 형태:**
- **넘겨줄 다음 부서:**

**예시 (브랜드 검수팀):**
- 부서 이름: 브랜드 검수팀(QA)
- 오늘 할 일: 기획팀이 낸 아이디어 10개를 내 브랜드 기준으로 검사
- 지켜야 할 기준: ① 금칙어 포함 시 탈락 (예: "여정", "마법 같은"), ② 근거 링크 없으면 탈락, ③ 최근 7일 콘텐츠와 40% 이상 겹치면 각도 변경
- 결과물 형태: 통과 O / 반려 X + 반려 사유 한 줄
- 넘겨줄 다음 부서: 기획 2팀(대본)

### 3단계: Claude Code에 회사 규칙 적용
1. **`AI_COMPANY.md` 파일 생성:** 위에서 작성한 부서 카드 내용을 포함하여 `.md` 파일로 저장합니다.
2. **Claude Code 첫 지시:**
```
AI_COMPANY.md를 읽어줘.
지금부터 너는 이 회사의 직원들이야.
읽고 나서, 내가 채워야 할 빈칸이 어디인지 먼저 알려줘.
```
3. **부서 채우기 (AI 활용):**
```
AI_COMPANY.md의 부서 12개를 내 채널 기준으로 채워줘.
내 채널은 [주제]를 다루고, 주 시청자는 [타깃]이야.
부서마다 '지켜야 할 기준' 3줄은 반드시 반려 기준으로 써줘.
```
4. **일일 업무 지시:**
```
오늘 업무 시작. 시장조사팀 → 기획 1팀 → 검수팀 순서로 진행하고,
TOP 3만 뽑아서 나한테 보고해줘. 내가 고르면 그때 대본 써.
```
5. **개별 부서 호출:**
```
브랜드 검수팀으로만 일해줘. 이 원고 검사하고 반려 사유만 말해줘.
[원고 붙여넣기]
```

**💡 Claude 앱 사용자:** Claude Code 없이 대화창에 `AI_COMPANY.md` 내용을 붙여넣고 "지금부터 이 회사 규칙대로 일해줘"라고 지시해도 동일하게 작동합니다.

### 4단계: 안전 규칙 설정
AI에게 자율권을 부여하더라도 사고를 방지하기 위해 문서 최상단에 다음 6가지 안전 규칙을 명시합니다.

① 메일 실제 발송 금지 — 초안까지만
② SNS 실제 게시 금지 — 예약·업로드는 사람이
③ 결제·구독 금지
④ 원본 파일 삭제·덮어쓰기 금지 — 복제본에만 작업
⑤ 연결 안 된 서비스를 '완료'라고 보고 금지
⑥ 확인 안 된 정보를 사실처럼 쓰기 금지 — 출처 없으면 '미확인'이라고 표시

**🚨 특히 ⑤번 (연결 안 된 서비스 완료 보고 금지)은 AI가 존재하지 않는 완료 보고를 하는 것을 막는 데 중요합니다.**

### 5단계: 일일 업무 흐름
- **07:00:** 시장조사팀 → 기획 1팀 → 검수팀 순서로 업무 진행
- **내가 하는 일:** 검수팀의 반려 결과를 보고, 최종 TOP 3 중 1개 선정
- **이후:** 기획 2팀(대본 작성) → 제작팀(영상/이미지) → 성과리뷰팀(결과 기록) → 비서실(일일 보고 요약)

하루에 내가 직접 개입하는 시간은 단 1번의 결정뿐입니다.

## 활용 예시
**콘텐츠 아이디어 발굴 및 발행 자동화:**
- **입력:** `AI_COMPANY.md` 내용과 함께 "오늘 업무 시작. 시장조사팀 → 기획 1팀 → 검수팀 순서로 진행하고, TOP 3만 뽑아서 나한테 보고해줘. 내가 고르면 그때 대본 써." 라는 지시
- **결과:** AI가 시장 조사, 아이디어 기획, 자체 검수를 거쳐 검토할 만한 TOP 3 아이디어를 제시하고, 선택된 아이디어에 대해 대본 초안까지 작성해 줍니다. 이후 영상/이미지 제작 및 결과 기록까지 AI 부서들이 순차적으로 처리합니다.

**특정 콘텐츠 검토:**
- **입력:** `AI_COMPANY.md` 내용과 함께 "브랜드 검수팀으로만 일해줘. 이 원고 검사하고 반려 사유만 말해줘. [원고 내용]"
- **결과:** 해당 원고가 브랜드 검수팀의 기준(금칙어, 근거, 중복 여부 등)에 따라 반려될 경우, 반려 사유와 함께 명확하게 피드백을 제공합니다.

## 💡 아이디어
이 시스템을 활용하여 개인 블로그, 유튜브 채널, SNS 등 다양한 플랫폼의 콘텐츠 제작 워크플로우를 구축할 수 있습니다. 각 부서의 기준을 명확히 정의함으로써 AI가 일관된 톤앤매너와 품질을 유지하도록 제어할 수 있으며, 이를 통해 콘텐츠 생산성을 극대화할 수 있습니다. 예를 들어, '시장조사팀'의 기준을 특정 산업 트렌드로, '브랜드 검수팀'의 기준을 특정 브랜드 가이드라인으로 설정하여 전문적인 콘텐츠 제작이 가능합니다.

## 주의사항
- **AI의 자율권 남용 방지:** 메일 발송, SNS 게시, 결제/구독, 원본 파일 삭제, 확인되지 않은 정보 사실화 등의 행위를 금지하는 안전 규칙을 반드시 문서 상단에 명시해야 합니다.
- **무료 vs 유료:** Claude 무료 버전으로도 충분히 활용 가능하나, Claude Code를 사용하거나 더 높은 성능을 원할 경우 유료 결제를 고려할 수 있습니다. 무료 대안으로는 Gemini, ChatGPT 등을 활용하여 유사한 방식으로 적용해볼 수 있습니다.
