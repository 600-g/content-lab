# 자율 코딩 에이전트 구축

💡 **초기화 에이전트**가 기능 목록을 만들고 **코딩 에이전트**가 그 목록을 하나씩 구현해 **Git**에 진행 상황을 남기는 구조로, 한 세션에 끝나지 않는 앱도 여러 세션에 걸쳐 완성합니다. 같은 저장소의 **computer-use 모범 사례**를 더하면 실제 macOS 데스크톱을 다루는 에이전트까지 비용 효율적으로 만들 수 있습니다.

## 이게 뭔가요?

Anthropic 공식 저장소 `anthropics/anthropic-quickstarts` 에 들어 있는 두 개의 레퍼런스 프로젝트를 바탕으로, 스스로 일하는 에이전트를 만드는 방법입니다.

| 디렉토리 | 무엇을 하나 | 언제 쓰나 |
|---|---|---|
| `autonomous-coding` | Claude Agent SDK 기반 자율 코딩 에이전트. 두 에이전트 패턴 + Git 진행 관리 | 특정 기능이나 작은 애플리케이션을 에이전트가 스스로 개발하고 진행 상황을 관리해야 할 때 |
| `computer-use-best-practices` | macOS 데스크톱에서 동작하는 컴퓨터 사용 에이전트의 모범 사례 레퍼런스 | 에이전트가 앱을 열고, 문서를 쓰고, 웹에서 정보를 뽑고, 파일을 관리하는 등 실제 컴퓨터 작업을 해야 할 때 |

### 두 에이전트 패턴

- **초기화 에이전트**: 만들 애플리케이션에 필요한 작업(기능) 목록을 생성합니다.
- **코딩 에이전트**: Claude Agent SDK 위에서 작동하며, 기능 목록을 점진적으로 처리합니다. 코드를 수정하고 테스트한 뒤 변경 사항을 Git 에 커밋해 진행 상황을 영구적으로 저장합니다.
- 진행 상황이 Git 에 남기 때문에 세션이 끊겨도 다음 세션이 이어서 작업할 수 있고, 그 결과 여러 개발 세션에 걸쳐 완전한 애플리케이션을 구축할 수 있습니다.

### 신뢰성·비용 효율을 높이는 7가지 패턴

`computer-use-best-practices` 가 시연하는 패턴입니다. 데스크톱 에이전트뿐 아니라 코딩 에이전트의 안정성과 비용에도 그대로 도움이 됩니다.

| 패턴 | 효과 |
|---|---|
| **명시적 도구 정의** (Explicit Tool Definitions) | 에이전트가 쓸 수 있는 도구를 명확히 정의해 행동을 예측 가능하게 만듭니다 |
| **정확한 이미지 크기 조정 및 정리** (Correct Image Sizing and Pruning) | 화면 이미지 크기를 적절히 조정하고 불필요한 부분을 제거해 시각 정보를 효율적으로 처리합니다 |
| **프롬프트 캐싱** (Prompt Caching) | 반복되는 프롬프트를 캐싱해 API 호출 비용을 줄이고 응답 속도를 높입니다 |
| **서버 측 압축** (Server-Side Compaction) | 에이전트의 컨텍스트 길이를 관리해 효율을 높입니다 |
| **일괄 도구 호출** (Batched Tool Calls) | 여러 도구 호출을 묶어 한 번에 처리해 오버헤드를 줄입니다 |
| **샌드박스 셸** (Sandboxed Shell) | 명령 실행 환경을 격리해 시스템에 미치는 영향을 최소화합니다 |
| **궤적 기록** (Trajectory Recording) | 에이전트의 행동과 의사결정 과정을 기록해 디버깅·분석에 활용합니다 |

## 따라하기

### 1단계: 저장소 준비

1. `anthropics/anthropic-quickstarts` GitHub 저장소를 로컬에 클론합니다.
2. 목적에 맞는 디렉토리로 이동합니다.
   - 자율 코딩 에이전트 → `autonomous-coding`
   - 컴퓨터 사용 모범 사례 → `computer-use-best-practices`
3. 각 디렉토리의 `README` 를 참고해 의존성을 설치합니다. 일반적으로 `pip install -r requirements.txt` 입니다. 두 프로젝트는 독립적이라 의존성이 다를 수 있으니 디렉토리마다 따로 설치합니다.
4. Claude API 키를 환경 변수 `ANTHROPIC_API_KEY` 로 설정합니다.

### 2단계: 자율 코딩 에이전트 돌려 보기

1. `autonomous-coding` 의 README 에 있는 스크립트·명령으로 실행합니다.
2. 초기화 에이전트가 만든 기능 목록을 확인합니다. 목록이 곧 에이전트의 작업 범위이므로, 너무 크거나 모호한 항목이 없는지 먼저 봅니다.
3. 코딩 에이전트가 목록을 하나씩 처리하며 커밋을 쌓는 과정을 Git 로그로 따라갑니다.
4. 세션을 끊었다가 다시 실행해, Git 에 남은 진행 상황에서 이어지는지 확인합니다.

### 3단계: 컴퓨터 사용 모범 사례 적용

1. `computer-use-best-practices` 를 **가상 머신(VM) 안의 macOS** 에서 실행합니다. 실제 데스크톱을 직접 조작하므로 VM 이 강력히 권장됩니다.
2. `computer_use_20251124` 같은 최신 도구 버전을 지원하므로, 사용하는 SDK·API 환경을 그 버전에 맞춥니다.
3. 7가지 패턴이 코드 어디에 구현돼 있는지 하나씩 찾아 읽습니다. 특히 프롬프트 캐싱·이미지 프루닝·서버 측 압축은 비용에, 명시적 도구 정의·샌드박스 셸은 신뢰성과 안전에 직결됩니다.
4. 함께 읽을 공식 가이드: Anthropic 의 [computer-use best-practices guide](https://claude.com/blog/best-practices-for-computer-and-browser-use-with-claude)

### 4단계: 내 프로젝트로 확장

1. 두 레퍼런스의 코드 구조를 분석하고, 만들려는 서비스의 기능 목록·도구 목록으로 바꿔 끼웁니다.
2. 자율 코딩 에이전트에도 7가지 패턴을 이식합니다. 예: 도구를 명시적으로 정의하고, 셸 명령은 샌드박스에서 실행하고, 궤적을 기록해 실패한 세션을 사후 분석합니다.
3. 에이전트가 만든 커밋은 사람이 리뷰한 뒤 병합합니다.

### 점검 체크리스트

- [ ] `ANTHROPIC_API_KEY` 가 환경 변수로 설정돼 있고 코드에 하드코딩돼 있지 않다
- [ ] 디렉토리별 `README` 기준으로 의존성을 설치했다
- [ ] 컴퓨터 사용 에이전트는 VM 에서 돌린다
- [ ] 진행 상황이 Git 커밋으로 남고, 재시작 시 이어진다
- [ ] 프롬프트 캐싱·이미지 프루닝 등 비용 패턴을 켰다
- [ ] API 사용량을 모니터링하고 있다

## 활용 예시

- **기능 단위 자율 개발**: 웹사이트의 '고객 문의 게시판'에 특정 필드를 추가하는 일. 초기화 에이전트가 필요한 작업 목록을 만들고, 코딩 에이전트가 실제 코드를 수정·테스트한 뒤 Git 에 커밋합니다.
- **작은 앱을 여러 세션에 걸쳐 완성**: 기능 목록이 길어 한 번에 끝나지 않는 앱도, 세션마다 목록의 다음 항목부터 이어서 구현합니다.
- **데스크톱 작업 자동화**: 에이전트가 데스크톱 애플리케이션을 열어 문서를 작성하거나, 특정 웹사이트에서 정보를 추출하거나, 파일을 관리하는 작업을 macOS 네이티브 기능을 활용해 실제 사용자처럼 수행합니다.
- **반복 작업·정교한 시스템 상호작용**: 반복적인 개발 작업, 기능 추가, 시스템과의 세밀한 상호작용이 필요한 경우에 효과적입니다.

## 주의사항

- **요금**: Claude API 사용량에 따라 요금이 발생합니다. 특히 화면 이미지를 반복 전송하는 컴퓨터 사용 에이전트는 사용량을 면밀히 모니터링해야 합니다.
- **격리 실행**: 컴퓨터 사용 에이전트는 macOS 데스크톱에 직접 접근해 동작하므로 **가상 머신(VM) 환경에서 실행**하는 것을 강력히 권장합니다.
- **도구 버전**: `computer_use_20251124` 와 같은 최신 도구 버전 기준으로 작성돼 있으므로, 최신 환경에 맞춰 구성해야 합니다.
- **사전 지식**: Claude Agent SDK 와 다중 에이전트 간 상호작용 아키텍처에 대한 이해, Git 버전 관리와 코드 충돌 해결에 대한 기본 지식이 필요합니다.
- **코드 검토 필수**: AI 가 생성한 코드의 품질, 보안 취약점, 성능은 개발자가 반드시 검토해야 합니다.
