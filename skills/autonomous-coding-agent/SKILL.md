## When to use

AI 에이전트가 특정 기능이나 작은 애플리케이션을 자율적으로 개발하고 진행 상황을 관리해야 할 때, 또는 macOS 데스크톱 환경에서 실제 컴퓨터 작업을 신뢰성 높고 비용 효율적으로 수행해야 할 때 사용합니다. 특히 반복적인 개발 작업, 기능 추가, 그리고 시스템과의 정교한 상호작용이 필요한 경우에 효과적으로 활용할 수 있습니다.

## 두근컴퍼니 적용 메모

company-hq 플랫폼에서 다른 에이전트의 지시를 받아 코드를 생성하거나, 내부 도구를 개발하는 등 자율 개발 에이전트를 구축할 때 이 스킬의 핵심 패턴을 적용합니다. 또한, AI 에이전트들이 가상 사무실 내에서 데스크톱 애플리케이션(문서 작성, 이메일, 데이터 분석 등)을 조작하는 기능을 구현하거나, 두근펫 Electron 앱이 Mac에서 구동될 때 펫 에이전트가 시스템과 상호작용하는 고급 기능을 구현하는 데 핵심 참고 자료가 됩니다. 특히 Mac Mini M4 환경에 최적화되어 있어 성능 테스트 및 즉각적인 적용이 용이하며, CX 운영 경험을 바탕으로 에이전트의 사용자 경험 시나리오를 구체화하고 신뢰성 높고 비용 효율적인 에이전트 시스템을 구축하는 데 필수적인 학습이 선행되어야 합니다. > Claude Agent SDK 기반의 자율 코딩 에이전트 스킬은 초기화 에이전트와 코딩 에이전트의 두 가지 에이전트 패턴을 사용하여 애플리케이션을 구축합니다. Git을 통해 진행 상황을 유지하고, 기능 목록을 점진적으로 처리하며 여러 세션에 걸쳐 완전한 애플리케이션을 개발할 수 있습니다. 이제 이 스킬은 macOS 데스크톱 환경에서 신뢰성 높고 비용 효율적인 컴퓨터 사용 에이전트를 구축하기 위한 최신 모범 사례를 포함하여 더욱 강력해졌습니다.

## 핵심 패턴
이 스킬은 `초기화 에이전트`와 `코딩 에이전트`로 구성된 **'두 에이전트 패턴'**을 활용하여 자율적인 애플리케이션 개발을 수행합니다. 코딩 에이전트는 Claude Agent SDK를 기반으로 작동하며, Git을 통해 개발 진행 상황을 영구적으로 저장하고 관리합니다. 에이전트는 주어진 기능 목록을 점진적으로 처리하여 여러 개발 세션에 걸쳐 완전한 애플리케이션을 구축할 수 있습니다.
여기에 더해, 신뢰성 높고 비용 효율적인 컴퓨터 사용 에이전트를 구축하기 위한 다음과 같은 **핵심 모범 사례 패턴**들을 제시합니다:
*   **명시적 도구 정의 (Explicit Tool Definitions)**: 에이전트가 사용할 수 있는 도구를 명확하게 정의하여 에이전트의 행동을 예측 가능하게 만듭니다.
*   **정확한 이미지 크기 조정 및 정리 (Correct Image Sizing and Pruning)**: 에이전트가 시각 정보를 효율적으로 처리할 수 있도록 화면 이미지의 크기를 적절히 조정하고 불필요한 부분을 제거합니다.
*   **프롬프트 캐싱 (Prompt Caching)**: 반복적인 프롬프트에 대한 응답을 캐싱하여 API 호출 비용을 절감하고 응답 속도를 향상시킵니다.
*   **서버 측 압축 (Server-Side Compaction)**: 에이전트의 컨텍스트 길이를 관리하여 효율성을 높입니다.
*   **일괄 도구 호출 (Batched Tool Calls)**: 여러 도구 호출을 묶어서 한 번에 처리하여 오버헤드를 줄입니다.
*   **샌드박스 셸 (Sandboxed Shell)**: 에이전트의 명령 실행 환경을 안전하게 격리하여 시스템에 미치는 영향을 최소화합니다.
*   **궤적 기록 (Trajectory Recording)**: 에이전트의 행동과 의사결정 과정을 기록하여 디버깅 및 분석에 활용합니다.

## 적용 단계
1.  `anthropics/anthropic-quickstarts` GitHub 저장소를 로컬 환경에 클론합니다.
2.  자율 코딩 에이전트 구현을 위해서는 클론된 저장소 내의 `autonomous-coding` 디렉토리로 이동하고, 컴퓨터 사용 모범 사례 적용을 위해서는 `computer-use-best-practices` 디렉토리로 이동합니다.
3.  각 디렉토리의 `README` 파일을 참조하여 필요한 의존성을 설치합니다 (일반적으로 `pip install -r requirements.txt`).
4.  Claude API 키를 환경 변수(예: `ANTHROPIC_API_KEY`)로 설정합니다.
5.  제공된 스크립트나 명령어를 사용하여 각 Quickstart 애플리케이션을 실행하고 핵심 패턴을 학습합니다.
6.  두근컴퍼니의 company-hq 환경 및 두근펫 프로젝트에 맞게 코드 구조를 분석하고 기능을 확장하며, 두 스킬의 패턴을 통합하여 적용합니다.

## 예시
이 스킬은 두 가지 유형의 시나리오에서 활용될 수 있습니다. 첫째, 회사 웹사이트의 '고객 문의 게시판'에 특정 필드를 추가하는 것과 같이 AI 에이전트가 특정 기능 개발을 자율적으로 수행해야 할 때 사용합니다. 초기화 에이전트가 필요한 작업 목록을 생성하고, 코딩 에이전트가 이 목록을 바탕으로 실제 웹사이트 코드를 수정, 테스트, 변경사항을 Git에 커밋하는 과정을 자율적으로 수행할 수 있습니다.
둘째, Claude를 활용하여 macOS 데스크톱 환경에서 특정 작업을 수행하는 AI 에이전트를 구축할 때 모범 사례를 제공합니다. 예를 들어, 에이전트가 데스크톱 애플리케이션을 열어 문서를 작성하거나, 특정 웹사이트에서 정보를 추출하거나, 파일을 관리하는 등의 작업을 신뢰성 높고 효율적으로 수행하도록 구성할 수 있습니다. 이는 macOS의 네이티브 기능을 활용하여 실제 데스크톱 사용 경험과 유사하게 에이전트가 작동하도록 설계됩니다.

## 주의사항
*   Claude API 사용에 따라 요금이 발생할 수 있으므로, 사용량을 면밀히 모니터링해야 합니다.
*   Claude Agent SDK 및 다중 에이전트 간의 상호작용 아키텍처에 대한 심도 깊은 이해가 필요합니다.
*   Git을 통한 버전 관리 및 잠재적인 코드 충돌 해결에 대한 기본적인 지식이 요구될 수 있습니다.
*   AI가 생성한 코드의 품질, 보안 취약점 및 성능에 대한 개발자의 검토가 필수적입니다.
*   이 프로젝트는 macOS 데스크톱 환경에 직접적으로 접근하여 동작하므로, **가상 머신(VM) 환경에서 실행**하는 것을 강력히 권장합니다.
*   `computer_use_20251124`와 같은 최신 도구 버전에 대한 지원을 포함하므로, 최신 환경에 맞춰 구성하는 것이 중요합니다.
