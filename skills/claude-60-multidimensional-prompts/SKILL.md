# 목적별 복붙 프롬프트 라이브러리

💡 목적에 맞는 프롬프트를 골라 **`[ ]` 안만 내 상황으로 바꿔** 붙여넣으면 됩니다. 결과가 아쉬우면 **"더 구체적으로", "표로", "더 짧게"** 같은 후속 요청 한 줄로 다듬습니다.

## 이게 뭔가요?

AI에게 매번 처음부터 지시문을 쓰지 않도록, 목적별로 미리 다듬어 둔 프롬프트 모음입니다. 좋은 프롬프트는 **무엇을, 어떤 형식으로, 무엇을 하지 말라**까지 정해 둡니다. 예를 들어 "할 일 정리해줘" 대신 "긴급함 말고 실제 임팩트 순으로, 오늘 2개만"처럼 기준·분량·금지 사항을 함께 적는 식입니다. 아래 프롬프트는 모두 이 원칙으로 짧게 압축돼 있습니다.

- 입문자용 60종(@kirin.cookie 제작)은 학습부터 관계까지 8개 카테고리로 나뉘어 있습니다.
- 회의록·메모 요약 프롬프트는 임원 비서처럼 핵심 결정사항, 담당자별 액션 아이템(할 일·기한), 다음 회의까지의 미결 안건을 나눠 정리하고, 원문에 없는 내용은 추측하지 않으며 모호한 것은 '확인 필요'로 표시합니다.
- 업무·글쓰기·투자·학습 등 10가지 주제, 70개 완성형 프롬프트를 [복사] 버튼으로 가져다 쓰는 웹 모음집도 있습니다(출처 두 번째 링크, 투자 카테고리는 `#cat-invest`). 이 문서에는 그중 회의록 요약 프롬프트가 실려 있고, 나머지는 해당 페이지에서 복사합니다.

💰 유료 필요: 프롬프트 자체는 무료입니다. 다만 최적의 성능을 원하면 Claude Max 같은 고성능 모델 사용이 권장됩니다.
✅ 무료 대안: Gemini나 ChatGPT 등 최신 모델의 무료 버전에서도 충분히 높은 성능을 경험할 수 있습니다.

## 따라하기

### 기본 사용 절차

1. 아래 카테고리 목차에서 목적에 맞는 프롬프트를 고릅니다.
2. 번호를 뺀 문장을 복사해 Claude(또는 사용 중인 AI) 채팅창에 붙여넣습니다.
3. `[ ]` 자리(또는 `[회의 내용] 여기에 붙여넣기` 자리)에 내 내용을 넣고 실행합니다.
4. 결과가 아쉬우면 후속 요청을 붙입니다. 예: "더 구체적으로", "다른 방식으로", "예시 추가", "더 짧게", "표로 정리해줘".

`[ ]` 안은 구체적일수록 결과가 좋아집니다. "이커머스"보다 "스마트스토어 1인 셀러, 월매출 500만원"처럼 씁니다.

| ⚡ 업무 생산성 | 07–12, 회의록 요약 | 우선순위·회의·보고를 빠르게 끝낼 때 |
| ✍️ 글쓰기·소통 | 13–18 | 이메일·문자·교정 |
| 🔍 리서치·의사결정 | 19–24 | 비교·팩트체크·결정 |
| 💰 콘텐츠·수익화 | 25–30 | 카드뉴스·쇼츠·사이드잡·가격 |
| 🌱 일상·퍼스널 브랜딩 | 31–36 | 여행·소개글·일정·큰 일 쪼개기 |

### 📚 학습·이해 (01–06)

```
01. [주제]를 비유로 설명해줘. 기초→중급→심화 3단계로. 마지막엔 이해했는지 확인할 질문 3개도.
02. [스킬] 배우고 싶어. 주당 [시간] 투자 가능. 7일 학습 플랜 짜줘. 무료 자료만.
03. 방금 배운 [개념] 관련 퀴즈 5개. 틀리면 원리부터 설명해줘.
04. [목표] 위해 [스킬] 배워. 처음부터 가르쳐줘. 비유와 예시 써줘.
05. [주제] 가르쳐줘. 이론 먼저 아니고 사례 3개로 시작해. 패턴 보이게.
06. 12살한테 설명하듯 [주제] 알려줘. 그다음 초보, 그다음 전문가 버전 비교해줘.
```

### ⚡ 업무 생산성 (07–12)

```
07. 할 일: [리스트]. 긴급함 말고 실제 임팩트 순으로 줄 세워줘. 오늘 2개만.
08. [미팅] 회의 안건 써줘. 최대 4개. 마지막엔 결정할 것 하나로 끝내줘.
09. 회의록: [붙여넣기]. 결정된 것, 담당자, 미결 사항 정리해줘.
10. [업무]에 2시간째 막혔어. 뭐가 진짜 막히는지 찾게 질문 5개만 해줘.
11. 주간 보고 써줘. 한 일: [리스트]. 3줄. 활동 아닌 성과 중심으로.
12. [이벤트] 45분 전. 지금 할 수 있는 최고 임팩트 한 가지만.
```

#### 회의록·메모 요약 (완성형)

09번의 짧은 버전으로 부족할 때 쓰는 정밀판입니다. 역할(임원 비서), 출력 구조 3단, 담당자·할 일·기한 표, 추측 금지와 '확인 필요' 표시까지 지정돼 있어 회의 직후 후속 조치를 바로 시작할 수 있습니다.

```
너는 임원 비서다. 아래 회의 내용을 세 부분으로 정리해라. (1)핵심 결정사항 3~5개 (2)담당자별 액션 아이템(이름·할 일·기한 표) (3)다음 회의까지 미결 안건. 추측하지 말고 원문에 있는 것만 써라. 애매하면 '확인 필요'로 표시해라. [회의 내용] 여기에 붙여넣기
```

입력·결과 예시는 아래 활용 예시에 있습니다.

## 활용 예시

### 회의록 요약 예시 1: 신규 프로젝트 회의

입력:
```
[회의 내용]
오늘 신규 프로젝트 A에 대한 논의가 있었습니다. 주요 안건은 다음과 같습니다. 첫째, 프로젝트 목표를 시장 점유율 5% 달성으로 설정하기로 했습니다. 둘째, 개발팀은 UX 개선에 집중하고, 마케팅팀은 사전 홍보 활동을 시작합니다. 각 팀별로 구체적인 실행 계획은 다음 주까지 제출하기로 했습니다. QA팀에서는 베타 테스트 일정을 다음 달 말로 확정했습니다. 다만, 예산 증액 건은 추가 검토가 필요합니다.
```

결과:
```
(1) 핵심 결정사항:
- 신규 프로젝트 A 목표: 시장 점유율 5% 달성
- 개발팀: UX 개선 집중
- 마케팅팀: 사전 홍보 활동 시작
- QA팀: 베타 테스트 일정 확정 (다음 달 말)

(2) 담당자별 액션 아이템:
| 이름 | 할 일 | 기한 |
|---|---|---|
| 개발팀 | 구체적인 실행 계획 제출 | 다음 주까지 |
| 마케팅팀 | 구체적인 실행 계획 제출 | 다음 주까지 |

(3) 다음 회의까지 미결 안건:
- 프로젝트 A 예산 증액 건 검토
```

### 회의록 요약 예시 2: 주간 팀 회의 메모

입력:
