# Claude 프롬프트 60선 — 입문자용 복붙 라이브러리

## 이게 뭔가요?

@kirin.cookie가 제공하는 입문자용 60개 복붙 프롬프트 라이브러리. 6개 카테고리별 10개씩 정리. **`[ ]` 안 내용을 본인 상황에 맞게 바꿔서 사용**하면 됨. 답이 모호하면 "더 구체적으로" / "다른 방식으로" 추가 요청.
