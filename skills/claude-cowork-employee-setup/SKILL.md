# AI 직원을 만들어 업무 자동화하기 (합병됨)

## 이게 뭔가요?

Claude Cowork는 단순한 AI 챗봇을 넘어, 사용자의 로컬 폴더에 접근하여 파일을 읽고 쓰는 '일해주는 AI'입니다. 이 기능을 활용하면 Claude를 단순한 질문 답변 기계를 넘어, 사용자의 업무 맥락을 이해하고 맞춤형 결과물을 생성하는 '나를 아는 직원'처럼 만들 수 있습니다. 반복적인 업무를 위임하거나, 흩어진 자료를 효율적으로 정리하고, "이게 Claude로 될까?" 싶은 복잡한 업무까지 직접 시켜볼 수 있게 됩니다. 특히 비개발자도 코딩 지식 없이 1:1 과외처럼 Claude 활용법을 익히고 즉시 업무에 적용할 수 있도록 돕는 것을 목표로 합니다.

**Record a Skill(스킬 녹화)**은 AI에게 업무를 지시할 때, 복잡한 프롬프트 작성이나 코딩 능력 없이 내가 하던 일을 **화면 녹화**로 보여주기만 하면 Claude가 이를 **재실행 가능한 자동화 스킬**로 만들어주는 혁신적인 기능입니다. 기존에는 AI에게 원하는 것을 글로 명확하게 설명해야 했지만, 이 기능은 정반대의 접근 방식을 취합니다. 사용자는 화면 녹화 버튼을 누르고 평소 하던 작업을 시연하면서 그 이유와 과정을 음성으로 설명하기만 하면 됩니다. 녹화가 끝나면 Claude는 사용자의 화면 움직임, 클릭, 타이핑, 음성을 종합적으로 분석하여 하나의 '스킬'로 저장합니다. 이후 유사한 요청이 들어오면 저장된 스킬을 불러와 자동으로 실행합니다. 이 기능은 자동화의 진입 장벽을 획기적으로 낮추며, 단순히 화면 녹화를 재생하는 과거의 매크로 방식과 달리 작업의 **의도를 추출하고 일반화**하여 화면 변화에도 더 유연하게 대처할 수 있다는 장점이 있습니다. 또한, 해당 서비스에 API 연동이 가능한 경우, 화면 조작 대신 API 연동을 우선적으로 제안하여 더 효율적인 자동화를 지원합니다. 완벽하지 않은 시연이나 실수하더라도 Claude는 사용자의 말과 행동에서 핵심 의도를 파악하여 스킬을 생성합니다.

Record a Skill은 사용자의 화면 기록을 통해 AI가 특정 작업을 학습하고, 이후에는 해당 작업을 자동으로 실행하도록 하는 클로드 코워크(Co-work)의 혁신적인 기능입니다. 복잡한 프롬프트 작성만으로는 설명하기 어려운 순서, 예외 처리, 판단 등이 섞인 작업에 특히 유용하며, 사용자의 반복적인 업무 부담을 획기적으로 줄여줄 수 있습니다.

이 기능은 2026년 7월 21일에 Anthropic에서 발표했으며, Pro, Max, Team 플랜 사용자만 이용 가능합니다. Free 플랜은 지원되지 않습니다. 사용을 위해서는 클로드 데스크톱 앱(Mac/Windows)이 필요하며, 모바일이나 웹에서는 녹화 및 실행이 불가능합니다.

프롬프트와 달리, 글로 표현하기 어려운 미묘한 작업이나 순차적인 절차를 AI에게 효과적으로 전달할 수 있다는 장점이 있습니다.

이 스킬은 Claude 데스크톱 앱의 유료 플랜(Pro, Max, Team 월 $20 이상)을 필요로 합니다. 무료 플랜으로는 Cowork 기능 및 Record a Skill 기능을 사용할 수 없습니다. 음성 받아쓰기 도구는 선택 사항이지만, 더 솔직하고 구체적인 답변을 얻는 데 도움이 됩니다.

## 따라하기

Record a Skill 기능을 사용하기 전에 몇 가지 필수 설정이 필요합니다. 이 설정이 제대로 되지 않으면 기능이 제대로 작동하지 않거나 클릭이 먹히지 않는 문제가 발생할 수 있습니다.

### 1. 코워크 들어가기 (처음이라면 여기부터)

1.  **앱 설치**: claude.com/download에 접속하여 자신의 운영체제(맥/윈도우)에 맞는 Claude 데스크톱 앱을 다운로드하고 설치합니다.
2.  **로그인**: Pro 플랜 이상 계정으로 로그인합니다.
3.  **코워크 선택**: 채팅 입력창 왼쪽 아래에서 "Cowork"를 선택합니다. (일반 채팅과 코워크는 같은 화면에서 전환됩니다.)
4.  **폴더 연결**: 코워크가 접근할 폴더를 지정합니다. (아래 STEP 1에서 생성할 폴더)
5.  **작업 지시**: 입력창에 자연어로 원하는 작업을 지시합니다.
    *주의*: 로컬 파일 읽기/쓰기 작업은 데스크톱 앱에서만 가능합니다. 웹/모바일 코워크는 베타 버전이며 로컬 폴더 연결은 데스크톱 전용입니다.

### 2. 폴더 만들기

1.  바탕화면에 `코워크`라는 폴더를 생성합니다.
2.  `코워크` 폴더 안에 다음과 같이 세 개의 하위 폴더를 만듭니다:
    *   `회사정보/`: 나에 대한 파일 3개가 저장되는 곳 (읽기 전용)
    *   `결과물/`: 코워크가 생성한 결과물이 저장되는 곳
    *   `템플릿/`: 잘 나온 결과물을 재사용하기 위해 모아두는 곳
3.  코워크를 이 `코워크` 폴더에 연결합니다.
    *주의*: 바탕화면 전체나 문서 전체를 연결하지 마세요. 연결된 폴더는 읽기/쓰기 권한이 모두 열리므로, 범위를 좁게 지정하여 안전하게 사용합니다.

### 3. 파일 3개 만들기 (`회사정보` 폴더 안에)

이 세 개의 파일은 Claude를 '나를 아는 직원'으로 만드는 핵심 요소입니다.

#### ① `about-me.md` — 내가 누구고 무슨 일을 하는지

1.  Claude 채팅창에 다음 프롬프트를 그대로 입력하여 자신을 인터뷰하도록 합니다:
    ```
    나에 대한 about-me.md 파일을 만들고 싶어.
    너가 나를 인터뷰해서 채워줘. AskUserQuestion 기능을 써서, 
    객관식 선택지가 있는 질문 형태로 하나씩 물어봐. 총 15개 정도.
    다음 내용을 다뤄줘:
    - 내가 무슨 일을 하는지, 누구랑 일하는지
    - 어떤 결과물을 자주 만드는지
    - 일할 때 뭘 중요하게 여기는지
    - 나한테 잘된 결과물은 뭐고, 별로인 결과물은 뭔지
    - 어떻게 소통하는 걸 좋아하는지
    - 지금 뭐에 집중하고 있는지
    객관식으로 만들되, 보기에 없는 답을 위해 직접 입력도 가능하게 해줘.
    내 답을 받고 다음 질문으로 넘어가.
    질문이 다 끝나면 정리해서 about-me.md로 만들어서 회사정보 폴더에 저장해줘.
    ```
2.  음성 받아쓰기 도구를 사용하면 타이핑보다 더 솔직하고 상세한 답변을 할 수 있습니다.

#### ② `voice-style.md` — 내 말투로 글 쓰게 만들기

1.  자신이 실제로 작성한 글 3개 이상을 준비합니다 (인스타 캡션, 블로그 글, 카톡/메일, 뉴스레터 등). 계약서처럼 딱딱하거나 AI가 작성/수정한 글은 제외합니다.
2.  준비한 글을 채팅창에 붙여넣거나 `회사정보` 폴더에 파일로 넣습니다.
3.  Claude 채팅창에 다음 프롬프트를 입력합니다:
    ```
    voice-style.md 파일을 만들고 싶어. 내 실제 말투를 분석해서 만들어줘.
    먼저, 내가 쓴 글 샘플이 있으면 그걸 분석해줘.
    (내가 지금 붙여넣거나, 회사정보 폴더에 넣어둔 파일을 읽어줘.)
    샘플을 보고 이런 걸 뽑아줘:
    - 자주 쓰는 단어·표현·말버릇
    - 문장 길이 (짧게 끊는지 / 길게 잇는지)
    - 톤 (친근 / 단호 / 편안 등)과 높임말·반말·이모지 습관
    - 글의 구조 습관 (결론부터? 예시를 드는 방식? 문단 길이?)
    - 내가 잘 안 쓰는 표현 (= 피해야 할 것)
    만약 내가 준 샘플이 없으면, 샘플부터 달라고 요청해줘. 
    샘플을 정말 구하기 어려우면, 그때는 질문으로 대체해줘 —
    내가 어떤 표현을 싫어하는지, 뭘 믿는지, 어떻게 말하는지 물어봐줘.
    분석이 끝나면 voice-style.md로 정리해줘.
    "이렇게 써줘(선호)"와 "이건 하지 마(금지 단어·표현)"를 나눠서 쓰고, 
    회사정보 폴더에 저장해줘.
    ```
    *핵심*: "뭘 하지 마라" 규칙을 명확히 하는 것이 중요합니다. "직설적으로 써줘"보다 "이런 단어는 절대 쓰지 마"가 효과적입니다.

#### ③ `my-company.md` — 회사 정보와 지금 상황

1.  관련 자료(사업계획서, 노션 페이지, 메모 등)가 있다면 Claude에게 제공합니다.
2.  Claude 채팅창에 다음 프롬프트를 입력하여 정보를 채워나갑니다:
    ```
    my-company.md 파일을 만들고 싶어. 내 사업 정보를 파악해서 만들어줘.
    내가 준 자료가 있으면 먼저 읽고 참고해줘.
    (지금 붙여넣은 내용이나, 회사정보 폴더에 넣어둔 파일)
    그다음 빠진 부분은 AskUserQuestion으로 하나씩 물어봐줘.
    객관식 선택지를 주되, 보기에 없으면 직접 입력도 가능하게. 다음을 채워줘:
    - 회사·브랜드가 뭐 하는 곳인지, 주요 고객이 누구인지
    - 어떻게 돈을 버는지 (수익 모델)
    - 혼자 하는지, 팀이면 규모가 어떤지
    - 이번 주에 가장 중요한 일 3가지
    - 지금 진행 중인 프로젝트와 각각의 다음 할 일
    - 자주 함께 일하는 핵심 인물
    - 이번 분기 목표
    - 코워크가 알아둘 회사 맥락 (업계 용어, 내부 규칙, 민감한 것)
    다 채워지면 my-company.md로 정
    ```

### 4. 컴퓨터 사용(computer-use) 커넥터 켜기

*   클로드 데스크톱 앱의 설정에서 "computer-use" 커넥터를 활성화해야 합니다.
*   이 커넥터가 켜지면 클로드 대화창의 "Context" → "Connectors" 탭에 "computer-use"가 표시됩니다.
*   활성화 후 클로드는 직접 클릭과 타이핑을 수행할 수 있습니다. (Pro·Max 리서치 프리뷰 기능)

### 5. macOS 권한 설정 (필수)

**화면을 보기 위한 권한:**

*   시스템 설정 → 개인정보 보호 및 보안 → "Screen & System Audio Recording" 항목에서 Claude 토글을 ON으로 설정합니다.

**컴퓨터 조작을 위한 권한:**

*   같은 경로에서 "Accessibility" 항목을 찾고, Claude 토글을 ON으로 설정합니다. ( "Allow the applications below to control your computer" 권한)

### 6. 앱 최신 버전 확인

*   클로드 데스크톱 앱 메뉴바에서 "Claude" → "Check for Updates"를 선택하여 앱을 최신 버전으로 유지합니다.

**윈도우 사용자 참고:**

*   "컴퓨터 사용" 기능은 macOS와 Windows 모두 지원되지만, 시스템 권한 설정 경로는 각 운영체제에 맞게 다릅니다.

### 7. 클로드 데스크톱 앱 실행

*   Record a Skill 기능 및 컴퓨터 사용 기능은 클로드 앱이 백그라운드 또는 실행 중일 때만 작동합니다.

## 활용 예시 (인스타 릴스 오디오 자동화)

인스타그램 릴스에서 인기 오디오를 자동으로 선택하고 저장하는 작업은 모바일 앱에만 존재하여 PC 웹에서는 자동화가 어려웠습니다. Record a Skill을 활용하면 이 작업을 자동화할 수 있습니다.

**시연 흐름:**

1.  맥에서 아이폰 미러링을 실행하여 폰 화면을 맥 창으로 띄웁니다.
2.  클로드 코워크에서 "Record a skill" 녹화를 시작합니다.
3.  인스타그램 릴스 만들기 화면으로 이동합니다.
4.  "음악" 아이콘을 클릭하여 "인기 탭"으로 이동합니다.
5.  화면을 훑어보며 어떤 오디오를 선택할지에 대한 **말**을 녹음합니다 (예: "이건 사용 가능한 오디오이고, 저건 내 계정에 뜨지 않으니 제외할 거야" 와 같은 판단 기준 포함).
6.  오디오를 선택하고 저장합니다.

**결과:**

이후에는 "인스타 릴스 인기 오디오 찾아줘"와 같은 간단한 명령만으로 조건에 맞는 오디오를 자동으로 찾아주는 스킬을 사용할 수 있습니다.

## 💡 아이디어

*   **반복 사무 작업:** 엑셀 데이터를 정리하여 노션에 붙여넣거나, 주간 리포트 양식을 자동으로 채우는 등 반복적인 사무 작업을 자동화할 수 있습니다.
*   **사내 도구 조작:** API 연동이 없는 사내 관리 페이지의 반복적인 입력 작업을 스킬로 만들어 효율성을 높일 수 있습니다.
