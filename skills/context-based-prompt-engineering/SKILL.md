# 상황 기반 맥락 주입 프롬프트 엔지니어링 (합병됨)

## 두근컴퍼니 적용

AI에게 '무엇을' 할지(Role)보다 '어떤 상황에서', '누구를 위해', '어떤 제약 하에' 해야 하는지(Context)를 명시하는 것이 핵심입니다. 특히 비즈니스 문제 해결이나 마케팅 전략 수립 시 필수적으로 적용해야 할 고도화된 스킬입니다.
