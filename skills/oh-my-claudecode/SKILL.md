# AI 에이전트 협업 코딩 플러그인

💡 OMC는 **Claude Code**에 여러 역할의 AI 에이전트를 붙여, **계획부터 수정까지** 이어가는 플러그인입니다.

## 이게 뭔가요?

**오 마이 클로드 코드(OMC)**는 **Claude Code** 환경에서 여러 전문 역할을 가진 AI 에이전트들을 연결하여 마치 하나의 팀처럼 협업하게 만드는 플러그인입니다. 이 플러그인을 사용하면 단순한 코드 생성 요청을 넘어, 실제 소프트웨어 개발 사이클 전체를 AI가 주도적으로 관리할 수 있게 됩니다.

작업의 범위가 작은 코드 수정부터 여러 파일에 걸친 대규모 기능 개발이나 리팩토링에 이르기까지 다양합니다. 기존에는 개발자가 각 단계(기획, 코딩, 테스트, 디버깅)를 수동으로 나누어 지시해야 했지만, OMC는 이러한 **역할 분담**을 시스템적으로 관리해 주어 작업의 효율성과 완성도를 극대화합니다.

이 기능은 특히 복잡한 프로젝트를 진행하거나, 여러 이해관계자의 검토가 필요한 대규모 개발 작업에서 빛을 발합니다. 현재는 **Claude Code** 환경에 최적화되어 있으며, 사용자가 직접 에이전트 간의 상호작용을 설계하고 관리하는 것이 핵심입니다. 

💰 **유료 필요**: 해당 플러그인 사용을 위해서는 **Claude Code** 환경이 필수적입니다. (별도의 구독료는 명시되지 않았으나, 특정 플랫폼 사용이 전제됨)
✅ **무료 대안**: 현재는 OMC가 제공하는 '역할 분담 및 워크플로우 자동화' 수준을 무료 도구만으로 완벽히 대체하기는 어려우나, **Gemini**나 **GPT**의 고급 프롬프팅을 통해 '역할극(Role-Playing)'을 시뮬레이션하여 유사한 구조를 흉내 낼 수는 있습니다.

## 따라하기

OMC를 사용하기 위한 가장 기본적인 설치 과정은 **Claude Code** 환경에서 아래 명령어를 순서대로 정확하게 입력하는 것입니다. 이 과정은 플러그인 마켓플레이스에 접근하여 필요한 모듈을 추가하고 설치하는 과정입니다.

**1. 플러그인 마켓플레이스에 모듈 추가하기**
먼저, 플러그인 마켓플레이스에 해당 모듈의 저장소 주소를 추가해야 합니다. 아래 코드를 복사하여 붙여넣고 실행하세요.

```
/plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode
```

**2. 플러그인 설치하기**
모듈 추가가 완료되었다면, 이제 실제로 플러그인을 설치합니다. 이 명령어는 시스템에 **oh-my-claudecode**를 등록합니다.

```
/plugin install oh-my-claudecode
```

설치가 완료되면, 이제 OMC의 다양한 기능과 규칙을 숙지하고 활용할 준비가 된 것입니다. 이 외에도 플러그인 사용에 필요한 추가적인 설정이나, 다른 AI 모델과의 연동 방법(예: 코덱스, 제미나이 연동)에 대한 가이드가 제공되므로, 해당 가이드를 참고하여 시스템을 최적화하는 것이 중요합니다.

### O-M-C를 잘 쓰는 3가지 규칙

OMC의 성능을 100% 끌어내기 위해서는 단순히 명령어를 입력하는 것 이상의 '규칙' 준수가 필요합니다. 이 규칙들은 마치 팀 프로젝트의 컨벤션과 같습니다. 이 세 가지 규칙을 숙지하는 것이 핵심입니다.

### 자주 쓰는 명령어 한눈에 보기

플러그인이 제공하는 다양한 명령어들은 복잡한 워크플로우를 한 번에 실행할 수 있는 '단축키'와 같습니다. 이 섹션에서는 자주 사용되는 핵심 명령어들을 한눈에 파악하고, 필요할 때마다 참고하여 작업 흐름을 끊김 없이 유지하는 것이 중요합니다.

### 코덱스·제미나이도 같이 쓰고 싶다면

OMC의 확장성이 큰 장점 중 하나는 다른 강력한 AI 모델과의 연동을 지원한다는 점입니다. 만약 **Codex**나 **Gemini** 등 다른 모델의 강점을 활용하고 싶다면, 이 섹션의 가이드를 따라 모델을 연결하고, 각 모델의 특성에 맞는 역할을 부여하여 시너지를 낼 수 있습니다.
