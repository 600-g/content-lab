# AI로 8단계 웹사이트 만들기 (합병됨)

## 이게 뭔가요?

코딩 지식 없이 **Claude AI**의 프롬프트 입력만으로 **나만의 사업 웹사이트**를 8단계 안에 완성하는 방법과, Claude를 활용하여 비개발자도 코딩 없이 자신만의 숫자 데이터를 기반으로 웹 대시보드를 만들 수 있도록 안내하는 가이드입니다. 복잡한 코딩이나 디자인 툴, 복잡한 설정이나 프로그램 설치 없이, 준비된 프롬프트를 순서대로 입력하고 필요한 정보만 채워 넣으면 한 페이지 분량의 웹사이트 또는 인터넷 주소로 공유 가능한 대시보드를 완성할 수 있습니다.

이 방식은 웹사이트 제작 또는 대시보드 구축 순서를 프롬프트로 명확히 정의하여, 마치 사람이 웹사이트를 기획하고 작성하거나 대시보드를 설계하는 과정을 AI에게 안내하는 것과 같습니다. 방향 설정부터 시작하여 첫 화면 문구, 신뢰도 향상 문구, 상품/서비스 소개, 망설임 해소, 최종 행동 유도까지 체계적으로 진행되며, 마지막 단계에서는 Claude가 이 모든 내용을 바탕으로 실제 작동하는 HTML 웹사이트 코드를 생성해 줍니다. 대시보드의 경우, Supabase에 데이터를 저장하고 HTML/CSS/SVG로 직접 그려내며 GitHub, Vercel을 통해 배포 및 공유까지 가능합니다.

Claude AI는 이러한 콘텐츠 생성 및 코드 생성 작업에 매우 효과적이며, 특히 복잡한 지시사항을 이해하고 구조화된 결과물을 만들어내는 능력이 뛰어납니다. 프롬프트 기반으로 작동하기 때문에, 사용자는 자신의 사업 내용에 맞게 정보를 입력하기만 하면 됩니다.

디자이너나 개발자가 없어도, 채팅창에 프롬프트를 순서대로 입력하기만 하면 나만의 사업 웹사이트 한 페이지를 만들 수 있습니다. 이 가이드라인은 처음 웹사이트를 만드는 사람들을 기준으로 8단계로 나누어 설명합니다.

웹사이트 제작 실패의 주된 이유는 실력 부족이 아니라 **순서**를 지키지 않기 때문입니다. 예를 들어, Claude에게 "내 사업 웹사이트 만들어줘"라고 한 번에 요청하면 만족스럽지 못한 결과가 나올 가능성이 높습니다. 실제 웹사이트 제작 과정처럼, 먼저 전체적인 방향을 설정하고, 첫 화면 구성을 하고, 신뢰를 구축하고, 상품/서비스를 소개하며, 고객의 망설임을 해소하고, 마지막으로 행동을 유도하는 이러한 단계별 접근 방식이 필요합니다. 이 과정을 순서대로 문구를 쌓아 올린 후, 최종적으로 전체 내용을 웹사이트 페이지로 변환하는 것입니다.

아래 8가지 프롬프트는 이러한 제작 순서를 그대로 반영하여 만들어졌습니다. 각 단계를 위에서부터 순서대로 복사하여 Claude에 입력하고, 대괄호 `[ ]` 안의 내용만 자신의 사업에 맞게 수정하면 됩니다.

각 단계마다 프롬프트를 입력하고 Claude의 답변을 받은 후, 마음에 들지 않는 부분을 구체적으로 수정 요청하고 다음 단계로 진행하는 것이 좋습니다. 이 과정을 통해 웹사이트의 완성도를 높일 수 있으며, 잘 진행된다면 문구를 다듬는 시간이 실제 제작 시간보다 더 길어질 수도 있습니다.

### 주요 도구 (대시보드 구축 시)
*   **Claude**: 집을 지어주는 목수 역할
*   **GitHub**: 집 설계도(코드)를 보관하는 택배함 역할
*   **Supabase**: 숫자를 보관하는 창고 역할
*   **Vercel**: 남들이 찾아올 수 있게 하는 집 주소 역할

### 비용 및 소요 시간 (대시보드 구축 시)
*   **비용**: 무료 (신용카드 불필요)
*   **소요 시간**: 첫 대시보드 1~2시간, 이후 20분

## 따라하기

### 웹사이트 만들기 (8단계)

다음은 Claude AI를 활용하여 웹사이트를 만드는 8단계 프롬프트입니다. 각 단계를 순서대로 Claude에 입력하고, 대괄호 `[ ]` 안의 내용을 자신의 사업에 맞게 수정하여 사용합니다. 각 단계별로 Claude의 답변을 받은 후, 마음에 안 드는 부분을 고쳐달라고 요청하고 다음 단계로 넘어가세요. 같은 대화창에서 순서대로 진행해야 앞 단계의 맥락을 이어받아 더 나은 결과물을 얻을 수 있습니다.

1.  **웹사이트 전체 방향 설정**
    ```
    너는 브랜드 웹사이트를 오래 만들어온 전략가야. 나는 [내 사업 한 줄 설명]을 하는 사람이고, [어떤 고객]을 대상으로 웹사이트를 하나 만들려고 해. 이 사이트에서 방문자가 하길 바라는 딱 한 가지 행동은 [예: 상담 신청 / 구매 / 문의]야. 먼저 이 웹사이트의 전체 방향을 잡아줘. 어떤 톤이 맞는지, 섹션을 어떤 순서로 두면 좋은지, 첫 화면에 와야 할 핵심 한 문장은 뭔지. 화려한 말 말고, 이 고객이 실제로 반응할 방향으로.
    ```

2.  **홈 첫 화면 문구 작성**
    ```
    방금 잡은 방향을 기준으로, 홈 첫 화면 문구를 써줘. 방문자가 3초 안에 "내 얘기다" 싶게. 큰 제목 한 줄, 그 아래 설명 한 줄, 버튼에 들어갈 문구 하나. 내 사업이 남들과 다른 점 한 가지가 그 제목에 꼭 들어가야 해.
    ```

3.  **신뢰 섹션 문구 작성**
    ```
    이 웹사이트에 넣을 신뢰 섹션을 써줘. [경력 / 해온 횟수 / 실제 후기 중 내가 내세울 수 있는 것]을 근거로, 짧은 신뢰 문구 3개. 없는 숫자는 절대 지어내지 말고 내가 실제로 가진 것만으로. 처음 온 사람이 안심할 정도면 충분해.
    ```

4.  **상품/서비스 소개 섹션 작성**
    ```
    내 [상품 / 서비스]를 소개하는 섹션을 써줘. 항목마다 이게 뭔지 한 줄, 이걸로 고객에게 뭐가 좋아지는지 한 줄. 기능 자랑 말고 고객이 얻는 결과 중심으로. 항목은 [개수]개로.
    ```

5.  **망설임 해소 및 사전 답변 섹션 작성**
    ```
    내 고객이 결제나 신청 직전에 망설이는 이유 5개를 뽑아줘. "비싸다" "나한테 맞을까" "지금 꼭 해야 하나" 같은 속마음. 그리고 각각을 웹사이트에서 미리 풀어주는 문장을 써줘. 방문자가 묻기 전에 페이지가 먼저 대답하게.
    ```

6.  **최종 행동 유도 섹션 작성**
    ```
    페이지 맨 아래 마지막 행동 유도 섹션을 써줘. 여기까지 읽은 사람이 [원하는 행동]을 지금 하게. 짧은 제목 한 줄, 미루면 아쉬운 이유 한 줄, 버튼 문구 하나. 압박하지 말고, 지금 하는 게 낫다는 느낌만.
    ```

7.  **HTML 웹사이트 코드 생성**
    ```
    지금까지 나온 문구 전부야: [①~⑥에서 받은 문구를 여기에 다 붙여넣기] 이걸 실제로 열리는 웹사이트 한 페이지로 만들어줘. HTML 한 파일로, 스타일까지 넣어서. 색 분위기는 [예: 차분한 남색 / 따뜻한 베이지 / 깔끔한 흰색], 폰트는 읽기 편한 걸로. 휴대폰에서도 안 깨지게.
    ```

8.  **웹사이트 검토 및 수정**
    ```
    이 웹사이트를 처음 보는, 의심 많은 방문자라고 생각하고 전체를 봐줘. 무슨 사이트인지 5초 안에 이해돼? 안 믿기는 문장, 어색한 부분, 빼도 되는 군더더기를 짚어줘. 그리고 딱 3가지만 고치라면 뭐야? 그 3가지는 바로 반영해줘.
    ```

**중요:** 위 프롬프트들을 같은 대화창에서 순서대로 입력해야 앞 단계에서 설정한 방향과 문구가 다음 단계로 자연스럽게 이어집니다. 중간 단계를 건너뛰면 결과가 일관되지 않을 수 있습니다.

**추가 팁:**
*   결과가 마음에 들지 않으면 "더 자연스럽게 다시 써줘" 와 같이 구체적인 피드백을 제공하세요.
*   7단계에서 생성된 `index.html` 파일을 무료 호스팅 서비스에 업로드하면 실제 웹사이트 주소를 얻을 수 있습니다.
*   제작 과정에서 막히는 부분이 있다면, 같은 스킬을 만드는 다른 사람들과 오픈채팅방에서 정보를 공유하고 도움을 받을 수 있습니다.

### 자동화 대시보드 만들기 (5단계)

집 짓기에 비유하여 대시보드 구축의 각 요소를 설명합니다.

| 부품 | 역할 | 우리가 쓸 것 |
|---|---|---|
| 창고 | 숫자를 보관하는 곳 | Supabase |
| 집 | 숫자를 보기 좋게 그리는 것 | HTML 파일 하나 |
| 택배함 | 집 설계도를 보관 | GitHub |
| 주소 | 남들이 찾아올 수 있게 | Vercel |
| 목수 | 집을 지어주는 사람 | Claude |

구축 순서는 창고 → 집 → 택배함 → 주소 순으로 진행됩니다.

#### 0단계 · 뭘 만드는지 그림부터 (위 테이블 참고)

#### 1단계 · 계정 3개 만들기 (15분)
모든 계정은 무료이며 신용카드가 필요 없습니다. 반드시 GitHub 계정으로 나머지 두 개를 가입해야 자동 배포가 원활하게 이루어집니다.
1.  **GitHub**: 이메일로 가입
2.  **Supabase**: Continue with GitHub 선택
3.  **Vercel**: Continue with GitHub 선택

#### 2단계 · 창고 만들기 (20분)
1.  **프로젝트 만들기**: Supabase에 로그인 후 'New project'를 클릭하고, 'Name'은 `my-dashboard`, 'Region'은 'Northeast Asia (Seoul)'로 설정합니다. 데이터베이스 비밀번호는 반드시 메모장에 저장합니다.
2.  **첫 번째 표 만들기 — 영업**: Supabase의 SQL Editor에 아래 SQL 코드를 붙여넣고 실행합니다. `[ ]` 안의 숫자는 실제 회사 데이터로 변경할 수 있습니다.
    ```sql
    -- ① 월별 매출
    create table sales_monthly (
      id bigint primary key generated always as identity,
      sort_order int not null,
      month text not null,
      revenue bigint not null,
      target bigint not null
    );
    insert into sales_monthly (sort_order, month, revenue, target) values
    (1, '[2월]', [6200], [9200]),
    (2, '[3월]', [6900], [9200]),
    (3, '[4월]', [71
    ```

## 활용 예시

*   **코칭·컨설팅·과외 소개 페이지:** 전문성을 강조하고 상담 신청을 유도하는 웹사이트
*   **카페·공방·스튜디오 안내:** 감성적인 분위기와 함께 방문 예약을 유도하는 페이지
*   **단일 상품 랜딩 페이지:** 특정 상품의 장점을 부각하고 구매 전환을 높이는 페이지
*   **포트폴리오/작업물 소개 페이지:** 자신의 작업물을 효과적으로 보여주고 문의를 유도하는 페이지
*   **클래스/모집 안내 페이지:** 교육 과정의 매력을 어필하고 신청을 받기 위한 페이지
*   **상담 신청 중심 소개 페이지:** 서비스의 가치를 설명하고 상담 신청을 받기 위한 페이지
