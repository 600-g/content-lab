# 맥락으로 답변 품질 높이기 (합병됨)

## 이게 뭔가요?

AI에게 "넌 전문가야"라는 식으로 일반적인 역할을 부여하는 대신, "나는 지금 이런 상황이고, 이 독자를 위해, 이런 제약 안에서 답변해줘"라고 구체적인 맥락을 제공하는 프롬프트 작성 원리입니다.

AI는 이미 방대한 데이터로 학습되어 있어서 역할을 지정한다고 지식 수준 자체가 바뀌지는 않습니다. 대신 '상황(Context)', '목적(Goal)', '독자(Audience)', '형식(Format)', '제약(Constraint)'의 5가지 구성 요소를 프롬프트에 구체적으로 명시하면, AI가 답변의 맥락·수준·방향을 정확히 파악해서 최적화된 결과물을 생성합니다. 핵심 법칙은 **역할보다 맥락이 10배 강하다**는 것입니다.

역할 지정 프롬프트("넌 마케팅 전문가야")는 AI의 지식을 바꾸지 못하고 범용적·비현실적인 답변을 초래하기 쉽습니다. 반면 맥락 지정 프롬프트는 AI가 사용자의 특정 요구에 맞춰 지식을 재구성하도록 유도합니다. 즉, '무엇을(Role)' 할지보다 '어떤 상황에서', '누구를 위해', '어떤 제약 하에' 해야 하는지(Context)를 명시하는 것이 핵심이며, 특히 비즈니스 문제 해결이나 마케팅 전략 수립처럼 현실적 제약이 강하게 작용하는 질문에서 효과가 극대화됩니다.

## 따라하기

1. AI에게 '넌 전문가야' 대신 '나는 지금 이런 상황이야'라고 구체적으로 설명합니다.

2. 아래 템플릿을 사용해 현재 상황, 목표, 제약, 독자를 명시합니다.

```
나는 [직업/역할]이야.
현재 상황: [구체적인 현재 상태]
목표: [원하는 결과]
제약: [불가능한 것 / 조건]
위 상황에서 [질문]을 도와줘.
이 조건에 맞지 않는 답변은 필요 없어.
```

3. **상황(Context) 지정**: 내가 처한 구체적인 상황, 현재 상태, 목표, 불가능한 조건 등을 명확히 설명합니다.

4. **독자(Audience) 명시**: 답변을 받아볼 대상이 누구인지, 그들의 특징·배경·경험 수준을 알려줘서 AI가 언어 수준, 비유, 전제 지식, 톤을 조정하도록 유도합니다.

5. **제약 조건(Constraint) 추가**: 예산, 시간, 인원, 도구, 경험 등 현실적인 한계를 먼저 제시해서 AI가 실행 가능한 답변을 하도록 유도합니다.

## 활용 예시

**약한 프롬프트 (역할 지정만):**
```
넌 마케팅 전문가야. 인스타 마케팅 방법 알려줘.
```

**강한 프롬프트 (상황/맥락 기반):**
```
나는 월 예산 50만원의 로컬 카페 사장이야. 인스타 팔로워 200명. 이전에 일반 음식 사진만 올렸고 효과가 없었어. 지금 당장 할 수 있는 무료 전략 3가지를 각각 구체적인 행동 단계로 알려줘.
```

**약한 프롬프트 (역할 지정만):**
```
넌 창업 전문가야. 사업 아이디어 평가해줘.
```

**강한 프롬프트 (상황/맥락 기반):**
```
나는 직장을 다니면서 주말에만 작업하는 1인 창업자야. 초기 자본은 500만원이고 제조업은 불가능해. 아래 아이디어가 이 조건에서 현실적인지 평가해줘. 실패 가능성도 솔직하게 말해줘.
```

## 💡 아이디어

- Claude Max, Gemini API, Gemma 등 모든 AI 도구 활용 시 프롬프트 작성의 기본 원칙으로 적용해서 답변 품질을 극대화할 수 있습니다.
- company-hq의 AI 에이전트 프롬프트에 이 원리를 적용하면 더 정확하고 상황에 맞는 답변을 유도할 수 있습니다.
- 두근펫, 매매봇, 검은별, 클로드코드, AI900 등 여러 프로젝트의 프롬프트 및 MCP(Multi-agent Collaboration Protocol) 설계에 활용해서 각 프로젝트의 특수성에 맞는 AI 행동을 정의할 수 있습니다.
- 초보 코딩 실력을 가진 사용자를 위해서는, AI가 초보자 수준에 맞춰 친절하고 구체적인 단계를 제공하도록 독자(Audience) 명시를 적극 활용하는 것이 효과적입니다.

## 주의사항

- 단순히 '넌 전문가야' 같은 역할 지정 프롬프트는 AI의 지식을 변화시키지 못하며, 범용적이고 비현실적인 답변을 초래할 수 있습니다.
- 맥락 정보가 부족하면 AI는 이상적인 조건을 가정해서 현실과 동떨어진 답변을 줄 수 있습니다. 상황, 목표, 제약, 독자를 최대한 구체적으로 채워 넣는 것이 품질 차이를 만듭니다.
