# AI 네이티브 워크플로우 5단계 프레임워크 (OpenAI × 무신사)

## 이게 뭔가요?

핵심 메시지: **"AI 도입 ≠ 툴 구매 ≠ 업무 방식 전환"**. 조직의 업무 흐름 자체가 AI와 함께 돌아가도록 재설계되어야 한다.

## AI 도입 4대 필수 조건

1. **권한과 접근성** — 팀원 전체가 AI 사용 가능 (사용량 아끼는 문화면 실패)
2. **실제 업무 데이터 연결** — 슬랙·노션·정책·과거 케이스 → 조직 기억을 활용하는 파트너
3. **업무별 워크플로우 자동화** — 범용 툴 교육보다 직무별 반복 업무 자동화
4. **리더십 푸시** — "AI 써도 돼"가 아니라 "AI 안 쓰면 안 돼"

## 5단계 확산 구조

### 1단계 — 전사 AI 접근권 부여
- 실무자·리더·기획자·마케터·디자이너·개발자 동일 수준 접근권
- **"업무에 써도 된다"는 명확한 시그널**

### 2단계 — 챔피언 선발
- 부서별 AI 챔피언
- 선발 기준: "AI 잘 아는 사람" 보다 **"업무 병목 잘 아는 사람"**
- 역할: 자기 업무 비효율 정의 / 작동하는 사례 만들기 / 팀 안에서 전파

### 3단계 — 업무별 비효율 수집

| 직무 | 반복 비효율 | AI 적용 방향 |
|---|---|---|
| 마케팅 | 캠페인 기획안·광고 카피·리포트 | 브리프 자동 생성·리포트 요약 |
| 콘텐츠 | 영상 기획·썸네일·숏폼 재가공 | 원본 기반 멀티 포맷 재생산 |
| 디자인 | 상세페이지 구조·반복 배너 | 디자인 초안·컴포넌트화·프론트 보조 |
| 개발 | 기능 구현·버그·리팩터링 | Codex 개발 에이전트 |
| CS/운영 | 반복 문의·정책 확인 | 슬랙·노션·FAQ 응답 자동화 |
| PM | 요구사항·정책 문서·실험 설계 | PRD 초안·우선순위 보조 |

### 4단계 — 워크플로우 템플릿화
"블로그 글 써줘" → 못 씀. **반복 가능한 워크플로우** 필요.
예: 키워드 → 타깃 정의 → 검색 의도 분류 → 제목 10개 → 상위 노출 분석 → 톤앤매너 → SEO 본문 → CTA → 검수 → 최종 포맷

### 5단계 — 성공 사례 공유
- 기존: 사람 2시간 수동 정리
- AI: 노션·슬랙 히스토리 연결해 초안 자동 생성
- 결과: **작업 시간 70% 감소**
- 사람 역할: 최종 판단·맥락 보정·품질 검수

## 직무별 영향

- **평균 실행자** — 가치 ↓ (반복 업무 대체)
- **PM** — 가치 ↑↑ (우선순위 판단 중요성 증가)
- **디자이너** — 수 ↓, 역할 ↗ (UX·브랜드·프론트 구현 연결자)
- **기획자·디자이너** — 개발 진입 장벽 ↓ (Codex로 프로토타입 직접 제작)

## 4대 리스크 관리

1. **툴만 도입, 업무 방식은 그대로** — 성공 사례 + 워크플로우 강제 적용
2. **품질 관리 실패** — 병원·금융·법률·채용·개인정보는 사람 검수 필수 (금지 표현/사실 검증/개인정보 제거/브랜드 톤/법적 리스크/최종 승인자)
3. **보안·권한** — 4단계 권한 분할 (공개 문서 → 프로젝트 자료 → 고객사 민감 → 액션 가능 시스템)
4. **조직 저항** — "AI가 아니라 AI 쓰는 사람으로 대체" 메시지 + 평가·교육·챔피언 연동

## 주의사항

- 무신사 사례 그대로 따라하지 X — 본인 조직 디지털 성숙도 조정
- 챔피언은 "현장 업무 잘 아는 사람" 우선
- 5단계 동시 진행 X — 1-2-3 순서대로
- 리더십 푸시 없이는 실패
- 보안 사고 1건 = 전체 도입 중단 위험
