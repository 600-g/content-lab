복잡한 개념을 기초-중급-심화 단계별 비유로 설명하고 이해도 확인 질문을 생성하여 학습 효율을 높일 때 사용합니다.

## 언제 쓰나

- 새로운 AI 기술이나 프레임워크를 학습할 때
- 복잡한 시스템이나 아이디어를 팀원에게 설명해야 할 때
- 초보 코더가 AI 관련 지식을 빠르게 습득하도록 도울 때

## 원리

사용자가 지정한 주제를 Claude가 비유를 활용하여 설명합니다. 설명은 기초, 중급, 심화의 세 단계로 나뉘어 점진적으로 깊이를 더하며, 최종적으로 사용자의 이해도를 점검하는 질문 3개를 제공하여 능동적인 학습을 유도합니다.
```
[주제]를 비유로 설명해줘. 기초→중급→심화 3단계로. 마지막엔 내가 이해했는지 확인할 질문 3개도.
```

## 단계

1) 설명받고 싶은 **[주제]**를 명확히 정의합니다. (예: "RAG", "Function Calling", "Phaser 엔진")
2) 위 프롬프트 템플릿에 **[주제]**를 채워 Claude Max에 입력합니다.
3) Claude의 단계별 설명을 확인하며 학습하고, 마지막 3개의 질문에 답하며 이해도를 점검합니다.
4) 필요시 "더 구체적으로", "다른 비유로 설명해줘" 등의 추가 지시를 사용하여 설명을 심화할 수 있습니다.

## 예시

**입력:**
```
[주제]를 비유로 설명해줘. 기초→중급→심화 3단계로. 마지막엔 내가 이해했는지 확인할 질문 3개도.

주제: RAG (Retrieval Augmented Generation)
```
**출력 (예상):**
```json
{
  "기초 (초등학생 눈높이):": "RAG는 도서관에서 책을 찾아보고 답을 쓰는 것과 같아요. 똑똑한 AI 친구에게 질문하면, 친구는 바로 답하지 않고 도서관(외부 지식)에 가서 필요한 정보를 찾아와요. 그리고 그 정보들을 바탕으로 훨씬 더 정확하고 자세한 답을 말해주는 거죠.",
  "중급 (고등학생 눈높이):": "RAG는 AI가 답변을 생성하기 전에 관련 정보를 검색하여 활용하는 방식입니다. 일반적인 생성형 AI가 학습 데이터 내에서만 답을 찾는 것과 달리, RAG는 외부 문서나 데이터베이스에서 실시간으로 최신 정보를 '검색(Retrieval)'한 후, 이를 기반으로 답변을 '생성(Generation)'하여 환각(Hallucination)을 줄이고 정확성을 높입니다. 마치 검색 엔진과 글쓰기 능력을 합쳐놓은 것과 같습니다.",
  "심화 (대학생/전문가 눈높이):": "RAG 아키텍처는 주로 두 가지 핵심 단계로 구성됩니다: Retrieval(검색)과 Generation(생성). Retrieval 단계에서는 사용자 쿼리와 관련성 높은 문서 스니펫이나 정보 조각을 외부 지식 저장소(예: 벡터 데이터베이스)에서 검색합니다. 이는 임베딩 모델을 사용하여 쿼리와 문서 간의 의미론적 유사성을 계산함으로써 이루어집니다. Generation 단계에서는 검색된 정보와 원본 쿼리를 대규모 언어 모델(LLM)에 입력하여 맥락에 맞는 고품질 답변을 생성합니다. 이 과정을 통해 LLM은 학습 시점 이후의 최신 정보나 특정 도메인 지식에 접근하여 답변의 신뢰성과 관련성을 크게 향상시킬 수 있습니다.",

    "RAG 시스템을 구축할 때 필요한 외부 지식 저장소의 한 가지 예시를 들어보세요."
```

## 두근컴퍼니 적용

- Claude Max를 활용하여 회사 내부 AI 교육 자료 (예: RAG, Function Calling, 프롬프트 엔지니어링 개념)를 제작하는 데 사용.
- 초보 파이썬 코더가 AI 기술 (Claude Code, Gemma, Ollama 등)을 빠르게 이해하도록 돕는 학습 가이드 생성.
- AI900 자격증 준비 시 복잡한 Azure AI 개념을 단계별로 학습하고 이해도를 점검하는 데 활용.

## ️ 주의

- 비유의 적절성은 AI 모델의 이해도에 따라 달라질 수 있으며, 필요시 추가 프롬프트로 보완해야 합니다.
- 복잡성이 매우 높은 주제의 경우, 더 세분화된 단계나 특정 비유를 직접 지정해 줄 필요가 있습니다.
