# 클로드에 인터넷 읽기 기능 달기

💡 이 스킬은 **Agent Reach**라는 오픈소스 CLI를 한 줄 명령으로 설치해, 클로드 같은 AI 에이전트가 유튜브 자막·깃허브·레딧·X·링크드인·팟캐스트를 **API 비용 없이** 직접 읽게 만드는 스킬입니다.

## 이게 뭔가요?

클로드에게 리서치를 맡기면 금방 벽에 부딪힙니다. "이 유튜브 영상 요약해줘"라고 하면 자막을 못 가져오고, "트위터 반응 좀 찾아줘"라고 하면 검색이 유료 API 뒤에 막혀 있고, "레딧에 같은 버그 겪은 사람 있나"라고 하면 익명 접근이 막혀 403이 뜹니다. 일반 웹페이지는 읽지만, 정작 사람들이 이야기를 나누는 공간은 전부 플랫폼 안에 있고 그 안을 보려면 플랫폼마다 구독료를 내고 API 키를 따로 발급받아야 합니다.

**Agent Reach**는 이 과정을 도구 하나로 대신 처리하는 오픈소스 CLI입니다. 플랫폼마다 지금 가장 잘 도는 접근 방식을 대신 골라 설치하고, 상태 점검까지 해줍니다. 핵심은 "접근 방식은 계속 바뀌지만 당신은 신경 쓰지 않아도 된다"는 것 — 플랫폼이 차단 방식을 바꾸면 도구 쪽이 따라가고, 사용자는 같은 명령을 계속 쓰면 됩니다.

- 저장소: `github.com/Panniantong/Agent-Reach`
- 라이선스: MIT (상업적 이용·수정·재배포 가능)
- 언어: Python 3.10 이상 필요
- 지원 플랫폼: 15개 (조회 시점 기준, 2026-09-01)
- ✅ 무료: 공식 API를 우회하므로 사용량 과금이 없습니다. 로컬 PC에서는 프록시도 필요 없고, 서버에 올려 돌릴 때만 프록시가 필요합니다.

## 따라하기

1. **준비물 확인** — Python 3.10 이상, 클로드 같은 에이전트. 로그인이 필요한 채널을 쓸 때만 데스크톱 크롬이 추가로 필요합니다.

2. **설치** — 아래 문장을 에이전트(클로드 등)에게 그대로 붙여넣으면, 에이전트가 문서를 읽고 필요한 것을 알아서 설치하고 상태 점검까지 돌립니다.

```
Agent Reach 설치해줘:
https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
```

3. **설치 직후 바로 되는 채널 확인** — 공식 문서 기준 제로 컨피그 채널은 6개입니다. 설정 파일도 키도 필요 없습니다.
   - 웹페이지 — 아무 페이지나 정리된 텍스트로 읽어옵니다
   - YouTube — 자막 추출 + 영상 검색
   - RSS — 아무 RSS/Atom 피드나 구독
   - 전체 검색 — 자동 설정 (키 필요 없음)
   - GitHub — 공개 저장소 읽기 + 검색
   - V2EX — 인기 글·노드 글·댓글

4. **로그인이 필요한 채널 열기** — 아래처럼 에이전트에게 말만 하면, 무엇이 필요한지 알려주고 단계별로 안내합니다.

```
Reddit 설정해줘
```

   이 방식으로 열리는 채널: Twitter/X(검색·타임라인·긴 글), Reddit(검색·글과 댓글), LinkedIn(프로필·회사 페이지·채용 검색), Facebook·Instagram(검색·프로필·최근 게시물), 小红书/RedNote(검색·읽기·댓글), B站/Bilibili(자막), 팟캐스트(음성 전사), 雪球(주식 시세·인기 글)

5. **상태 점검** — 어느 플랫폼이 지금 어떤 방식으로 서비스되는지 한 번에 확인합니다. 뭔가 안 될 때 가장 먼저 볼 곳입니다.

```
agent-reach doctor --json
```

6. **업데이트 확인** — 저장소가 활발히 업데이트되므로 주기적으로 확인합니다.

```
agent-reach check-update
```

## 활용 예시

- **유튜브 튜토리얼 요약** — "이 링크 자막 가져와서 요약해줘"라고 링크를 주면 → 설정 없이 바로 자막 추출 후 요약이 나옵니다.
- **깃허브 저장소 조사** — "이 저장소가 뭐 하는 건지, 이슈에서 사람들이 뭘 불평하는지 알려줘" → 공개 저장소 읽기·검색이 제로 컨피그라 바로 조사됩니다.
- **RSS 브리핑** — 관심 있는 블로그 몇 개를 등록하고 "새 글 있으면 정리해줘" → 추가 설정 없이 구독 피드 요약이 돌아갑니다.

셋 다 추가 설정 없이 10분 안에 바로 됩니다.

## 주의사항

| 증상 | 짚어볼 것 |
|---|---|
| 레딧이 안 됩니다 | 제로 컨피그 경로가 없습니다. 익명 접근이 막혀 있어 로그인 상태가 꼭 필요합니다 |
| 트위터가 검색이 안 됩니다 | 단일 트윗 읽기는 되지만 검색은 설정이 필요합니다 |
| 링크드인이 프로필까지 안 열립니다 | 공개 페이지 읽기는 되고, 프로필 상세·채용 검색은 설정 후입니다 |
| 파이썬 버전 오류 | 3.10 미만이면 설치가 막힙니다. 버전부터 확인하세요 |
| 서버에서만 막힙니다 | 서버 배포 시에만 프록시가 필요합니다. 로컬은 필요 없습니다 |
