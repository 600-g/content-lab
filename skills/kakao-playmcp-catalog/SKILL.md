# 카카오 PlayMCP — AI에서 카톡·맵·멜론 연동

## 이게 뭔가요?

카카오가 운영하는 PlayMCP 마켓플레이스 — 한국 시장 특화 MCP 서버 12종 큐레이션. 기존 글로벌 MCP로 접근 불가한 한국 데이터(공연·아파트·금감원 공시 등)를 AI 채팅창에서 자연어로 즉시 사용.

## 사용 시작 (3단계)

### STEP 1. 마켓플레이스 접속
`https://playmcp.kakao.com/` → 원하는 MCP 선택

### STEP 2. MCP 클라이언트에 연결
- **Claude Desktop**: 설정 → MCP 서버 추가 → URL 붙여넣기
- **카카오 i 오픈빌더**: 자연어로 활성화

### STEP 3. 자연어 사용
```
"관악구 25평 아파트 시세 알려줘" (아파트 정보)
"지난주 코스피 시총 상위 10개 공시 요약" (OpenDART)
"신촌 근처 다이소에 텀블러 있어?" (다이소 MCP)
"내일 명동 갈 거야, 4성급 호텔 추천" (여기어때)
"이번 주말 연극 추천" (ArtBridge)
"내 택배 어디까지 왔어?" (띵동)
```

## 조합 활용 예

- **데이트 코스** — ArtBridge(공연) + 여기어때(카페·숙소) + 팝업스토어 통합 추천
- **주식 스크리닝** — OpenDART(재무) + 미국 주식 정보(뉴스) → 조건별 종목 자동 선별
- **부동산 매수** — 아파트 정보 + 네이버 검색(학군) 통합 분석
- **콘텐츠 트렌드 리포트** — 네이버 데이터랩 + 팝업스토어 + Apple → 매주 자동

## 주의사항

- **사용량 한도** — 일부 MCP 공공데이터 기반, 일시 미조회 가능
- **데이터 시점 차** — 실시간 아닌 것 확인 필요
- **공식 인증 X** — Apple 탐색기 등 일부 개인 운영
- **개인정보** — 띵동 사기 이력 조회 시 본인 명의 외 조회 법적 이슈
- **카카오톡 나챗방 자동 메시지** — 스팸 주의
- **DART 데이터** — 자동 추출 데이터 투자 결정은 사람 최종 검증
