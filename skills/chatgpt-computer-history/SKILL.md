# ChatGPT에 작업 맥락 넘기기

💡 ChatGPT 데스크톱 앱은 **지금 이 창**을 넘기는 **Appshots**(양쪽 Command/Alt 동시 누르기)와, **지나간 작업 흐름**을 기억하는 **Computer History** 로 내 작업 맥락을 AI 에 전달합니다. 둘 다 맥에서는 **손쉬운 사용·화면 기록 권한**과 **민감 정보 관리**가 핵심입니다.

## 이게 뭔가요?

AI 에게 "내가 지금 뭘 하고 있는지"를 알려주려면 보통 스크린샷을 찍거나 내용을 복사해 붙여넣습니다. ChatGPT 데스크톱 앱에는 이 과정을 줄여주는 기능이 두 가지 있습니다.

| | **Appshots** | **Computer History** |
|---|---|---|
| 한 줄 요약 | 맨 앞 창 하나를 **이미지 + 창 안의 텍스트**로 대화에 바로 붙임 | 허용한 앱·웹사이트의 **상호작용 이벤트**를 기록해 나중에 맥락을 이어감 |
| 시점 | 지금 이 순간 (내가 누를 때만) | 계속 (켜 두는 동안) |
| 넘어가는 것 | 창 이미지 + 창 안 텍스트 (스크롤 밖 텍스트까지 가능) | 클릭, 타이핑, 키보드 단축키, 앱 전환 이벤트 → 요약된 메모리 |
| 넘어가지 않는 것 | 맨 앞 창 외의 다른 창·화면 전체 | 스크린샷, 화면 녹화, 마이크, 시스템 오디오, 시크릿 모드 검색 기록 |
| 플랫폼 | 맥(2026년 5월 21일부터), 윈도우(9월 11일부터) | macOS 데스크톱 앱만 |
| 요금제 | 데스크톱 앱 자체 기능 (Free/Plus 모두 사용 가능) | 유료 요금제 (아래 "사용 조건" 참고) |
| 맥 권한 | 화면 및 시스템 오디오 기록, 손쉬운 사용 | 앱·웹사이트 범위(Permissions) 설정 |

### 어떤 기능을 언제 쓰나

| 이런 상황이면 | 이 기능 |
|---|---|
| 에러 화면·편집 화면·문서를 지금 바로 보여주고 질문하고 싶다 | Appshots |
| 긴 웹페이지·문서를 스크린샷 여러 장 대신 한 번에 넘기고 싶다 | Appshots |
| 두 화면(전/후)을 비교시키고 싶다 | Appshots 를 60초 안에 연달아 두 번 |
| 여러 사이트·문서를 오가던 작업을 나중에 이어서 할 때, 어디까지 했는지 AI 가 기억해 주길 원한다 | Computer History |
| 매번 상황 설명을 반복하는 게 번거롭다 | Computer History |
| 구글 독스·지메일·시트·슬라이드 전체 내용을 넘겨야 한다 | 둘 다 아님 — 파일로 받거나 링크로 공유 (또는 Work·Codex 의 해당 앱 플러그인) |

## 따라하기

### 기능 1. Appshots — 지금 이 창을 통째로 넘기기

일반 스크린샷과 다른 점은 그림만 보내는 게 아니라 창 안의 **텍스트까지 같이 읽어서** 넘긴다는 것입니다. 아래 내용은 공식 문서(learn.chatgpt.com/docs/appshots)와 직접 눌러본 결과를 함께 정리한 것이며, 문서에 없는 동작은 "직접 확인한 동작"으로 구분했습니다.

#### 1단계. 단축키 이해하기

한 키를 두 번 누르는 게 아니라 **양쪽 키를 같이** 누릅니다.

| 환경 | 단축키 | 원문 |
|---|---|---|
| macOS | 양쪽 Command 키 동시 | Press both Command keys on macOS |
| Windows | 양쪽 Alt 키 동시 | or both Alt keys on Windows |
| 공통 | 설정에서 원하는 단축키로 변경 가능 | or use the custom hotkey you configured |

#### 2단계. 맥 권한 두 개 켜기

맥에서는 처음 찍을 때 권한을 따로 물어봅니다. **시스템 설정 › 개인정보 보호 및 보안**에서 `Codex Computer Use` 항목을 켭니다.

| 권한 | 없으면 안 되는 것 |
|---|---|
| 화면 및 시스템 오디오 기록 | 창 이미지를 못 찍습니다 |
| 손쉬운 사용(Accessibility) | 창 안의 글자를 못 읽습니다 |

**손쉬운 사용** 권한이 핵심입니다. 이걸 안 켜면 앱샷이 그냥 스크린샷이 됩니다. 텍스트가 같이 넘어가는 것이 이 기능의 알맹이인데 그 부분이 빠집니다.

#### 3단계. 찍기

1. 넘기고 싶은 앱 창을 맨 앞으로 가져옵니다.
2. 양쪽 **Command**(맥) 또는 양쪽 **Alt**(윈도우)를 같이 누릅니다.
3. 권한을 물으면 2단계대로 설정을 마칩니다.
4. 넘어간 창을 두고 시킬 일을 적습니다.

찍히는 건 맨 앞 창 **하나**입니다. 화면 전체나 여러 창이 아니라 그 순간 활성화된 창만 갑니다.

#### 4단계. 어디에 붙는지 정하기 (Appshot destination)

설정의 **Appshot destination** 으로 목적지를 고릅니다.

| 설정값 | 동작 |
|---|---|
| Automatic | 직전 60초 안에 만진 채팅이 있으면 거기에 붙고, 없으면 새 채팅 |
| Current chat | 항상 쓰던 채팅에 붙임 |
| New chat | 항상 새 채팅을 엶 |

맥에서는 플로팅 펫 컨트롤이 떠 있고 메인 창이 뒤에 있으면, Automatic 일 때 그 컨트롤에서 새 채팅이 시작됩니다. 펫을 Mini 로 두었을 때도 같습니다. 윈도우는 메인 앱에서 열립니다.

**직접 확인한 동작**: 일반 대화창을 보다가 크롬으로 넘어가 양쪽 Command 를 눌렀더니, 보던 대화창이 아니라 **Work** 로 넘어가 거기에 담겼습니다. Codex 에서는 그대로 들어갔습니다. 문서에는 직전 60초 안에 만진 채팅에 붙인다고 돼 있지만, 방금까지 보던 일반 대화창인데도 붙지 않았습니다. 즉 앱샷이 붙을 수 있는 "채팅"에 일반 대화창은 포함되지 않는 것으로 보입니다. 맥 권한 항목 이름이 `Codex Computer Use` 인 것을 보면 이 기능 자체가 Work·Codex 쪽에 묶여 있는 것으로 추정됩니다 (한 계정에서 한 번 확인한 결과이며, 추측이 섞여 있습니다).

그래서 실무에서는 **찍기 전에 어디서 이어서 일할지 먼저 정하는 것**이 편합니다. 일반 대화창에서 이어가던 중이라면 앱샷이 그 자리에 붙지 않아 흐름이 한 번 끊깁니다.

#### 안 될 때 확인 순서

1. 데스크톱 앱을 최신으로 업데이트합니다.
2. 설정된 단축키가 무엇인지 확인합니다 (바꿔 놓고 잊은 경우).
3. 회사 계정이면 조직이 Appshots 를 허용하는지 확인합니다.
4. 맥이면 **시스템 설정 › 개인정보 보호 및 보안**을 엽니다.
5. **화면 및 시스템 오디오 기록**과 **손쉬운 사용**에서 `Codex Computer Use` 항목을 확인합니다.
6. 앱을 재시작하고 다시 시도합니다.

앱샷이 들어 있는 대화를 CLI 에서 이어받으면 첨부는 기록에 남지만, CLI 에서 새 앱샷을 만들지는 못합니다. 터미널로 넘어간 뒤 화면을 더 보여주려면 데스크톱 앱으로 돌아와야 합니다.

### 기능 2. Computer History — 지나간 작업 맥락 기억시키기

OpenAI 가 **ChatGPT 맥 앱**에 도입한 기능으로(원문 기준 도입일 2024년 8월 13일), 사용자가 허용한 앱과 웹사이트에서 일어난 **상호작용 이벤트**를 기록합니다. 목적은 작업을 하다 중단했을 때, 나중에 다시 시작하면 AI 가 그 **맥락(Context)** 을 기억해 대화를 자연스럽게 이어가게 하는 것입니다.

이전 기록 방식(Chronicle)이 스크린샷 기반이었다면, Computer History 는 **클릭, 타이핑, 키보드 단축키, 앱 전환** 같은 **이벤트 기반**으로 바뀌었습니다. 그래서 스크린샷, 화면 녹화, 마이크, 시스템 오디오는 수집되지 않고, 시크릿 모드 검색 기록도 포함되지 않습니다.

구조적으로 OpenAI 가 실시간으로 화면을 '들여다보는' 방식이 아닙니다. 기록은 먼저 사용자의 **맥 로컬**에 쌓이고, 이 로컬 데이터를 요약해 **메모리** 형태로 만든 뒤 ChatGPT 나 Codex 가 참조합니다. '실시간 감시'라는 오해와 실제 구조는 다릅니다.

#### 사용 조건

- **요금제**: **Pro, Business, Enterprise** 구독 사용자 (원문 일부에는 Plus, Business, Enterprise 로도 적혀 있어, Plus 지원 여부는 앱 설정 화면에서 확인하는 것이 정확합니다).
- **환경**: 반드시 **macOS 데스크톱 앱**. **Memories** 기능이 켜져 있어야 합니다. API 키나 Amazon Bedrock 환경에서는 쓸 수 없습니다.
- **지역**: **EEA, 스위스, 영국**은 미지원, **한국**은 지원됩니다.
- 💰 유료 필요 / ✅ 무료 대안: 로컬 이벤트 기록과 맥락 유지를 완전히 대체하는 무료 도구는 확인되지 않았습니다.

설정은 `Settings > Computer history > Permissions` 에서 합니다. 설정 단계가 많으므로 **켜기 전에** 아래를 순서대로 확인합니다.

#### 1단계. 기록 범위 방식 고르기

범위를 좁히는 방식이 상반된 두 가지라, 목적에 맞는 하나를 먼저 정합니다. 섞어 쓰면 나중에 무엇을 허용했는지 헷갈립니다.

| 방식 | 동작 | 맞는 경우 |
|---|---|---|
| ✅ 빼는 방식 (Exclusion) | 기본적으로 모두 켜 두고 특정 앱·웹사이트만 제외 | 사용 범위가 넓고 민감한 앱이 적을 때 |
| ✅ 넣는 방식 (Inclusion) | 지정한 앱·웹사이트만 허용하고 나머지는 모두 차단 | 특정 작업 흐름에만 AI 기억력을 쓰고 싶을 때 |

#### 2단계. 민감한 앱·통신 앱 정리 (필수)

- **민감 앱 제외**: **건강, 재무, 개인정보**를 다루는 앱은 켜기 전에 **미리 제외(Exclude)** 하도록 문서에서 직접 권고합니다. 보안상 가장 중요한 단계입니다.
- **통신 앱 동의**: 다른 사람과 대화하는 **통신 앱**의 상호작용 기록이 들어갈 수 있으므로, 켜 두려면 **사전에 상대방의 명시적 동의**를 받아야 합니다.

#### 3단계. 저장 파일 두 종류 이해하기 (가장 중요)

데이터는 보호 수준과 보관 기간이 다른 두 파일로 나뉩니다.

| | 이벤트 파일 (Event File) | 메모리 파일 (Memory File) |
|---|---|---|
| 내용 | 원본에 가까운 이벤트 기록 | 이벤트를 요약한 기억 |
| 위치 | ChatGPT App Group 안에 **격리** 저장 | 보통 `~/.codex/memories/extensions/skysight/` 같은 경로에 **마크다운 파일** |
| 접근 | 명시적 권한 없이는 다른 앱 접근 불가 | 일반 파일 — **암호화되지 않음** |
| 보관 | **최대 48시간** | 사용자가 **직접 지울 때까지** |

가장 큰 위험 요소는 **메모리 파일이 암호화되지 않고 계속 남는다**는 점입니다. Mac 잠금 상태 유지와 계정 공유 여부를 반드시 점검합니다.

#### 4단계. 일시정지·삭제 방법 익히기

- **일시정지/재개**: 메뉴 바의 **ChatGPT 아이콘**에서 **Pause** 또는 **Resume** 을 눌러 수집을 즉시 제어합니다. 같은 메뉴에서 지금 무엇이 수집 중인지도 볼 수 있습니다.
- **삭제**: **최근 10분, 1시간, 1일, 전체** 중에서 고릅니다. 기록을 지우면 그 기록으로 만들어진 **기억(Memory)까지 함께 사라집니다.**

#### 켜기 전 체크리스트

- [ ] 요금제·macOS 앱·Memories 활성화 조건을 충족한다
- [ ] Exclusion / Inclusion 중 하나로 방식을 정했다
- [ ] 건강·재무·개인정보 앱을 제외했다
- [ ] 통신 앱을 포함한다면 상대방 동의를 받았다
- [ ] 메모리 파일 경로(`~/.codex/memories/extensions/skysight/`)가 암호화되지 않는다는 점을 알고, Mac 잠금·계정 공유를 점검했다
- [ ] 메뉴 바 Pause 위치와 삭제 범위(10분/1시간/1일/전체)를 확인했다

## 활용 예시

- **에러 해결 (Appshots)**: 코드 에러가 떠 있는 터미널이나 에디터 창을 맨 앞에 두고 양쪽 Command/Alt 를 누르면 에러 메시지 텍스트까지 그대로 읽혀 채팅에 붙습니다. 그림만 보고 추측하는 것과 문구를 그대로 받아 답하는 것은 정확도가 다릅니다.
- **긴 문서 한 번에 (Appshots)**: 앱이 스크롤 밖 텍스트까지 내주는 경우, 화면에 안 보이는 부분까지 같이 넘어갑니다. 스크린샷 여러 장 대신 앱샷 한 번으로 대체할 수 있습니다.
- **전후 비교 (Appshots)**: 앱샷 두 장을 60초 안에 연달아 찍으면 같은 채팅에 쌓이므로 "이전 화면과 지금 화면을 비교해줘" 같은 요청에 편합니다.
- **구글 문서류 (Appshots 한계)**: 구글 독스·지메일·구글 시트·구글 슬라이드에서는 보이는 화면만 갈 수 있고, 문서 전체나 화면 밖 텍스트는 안 넘어갈 수 있다고 문서에 명시돼 있습니다. ChatGPT Work 나 Codex 에서는 해당 앱 플러그인이 설치돼 있으면 그쪽으로 내용을 가져올 수 있습니다. 그 외에는 파일로 받거나 링크를 넘기는 방식이 더 안전합니다.
- **복잡한 리서치·문서 작성 (Computer History)**: 여러 웹사이트(A 사이트 → B 사이트 → 로컬 문서)를 오가며 기술 문서를 조사하고 핵심 개념을 ChatGPT 에 물어가며 정리하는 경우, Computer History 를 켜 두면 작업을 멈췄다가 나중에 돌아왔을 때 어떤 자료를 오갔는지 처음부터 다시 설명하지 않아도 AI 가 기록된 맥락을 바탕으로 이어서 도울 수 있습니다. 이때 Inclusion 방식으로 리서치에 쓰는 브라우저·문서 앱만 허용해 두면 범위가 깔끔합니다.

## 💡 아이디어

- **두 기능 조합**: 평소 작업 흐름은 Computer History 로 기억시키고, 특정 순간의 정확한 화면·문구가 필요할 때만 Appshots 로 보강하면 설명 시간을 크게 줄일 수 있습니다.
- **프로젝트별 Inclusion**: 특정 프로젝트 기간에만 그 프로젝트에 쓰는 앱만 넣는 방식으로 켜고, 끝나면 "전체" 삭제로 정리하는 루틴을 만들 수 있습니다.

## 주의사항

**Appshots**
- 맥은 양쪽 Command, 윈도우는 양쪽 Alt 입니다. 한 키를 두 번 누르는 게 아니라 **양쪽을 같이** 눌러야 합니다.
- 이미지만이 아니라 창 안의 글자, 스크롤 밖 부분까지 넘어갑니다. 그래서 손쉬운 사용 권한을 안 켜면 반쪽짜리 기능이 됩니다.
- 구글 독스·지메일·시트·슬라이드는 보이는 화면까지만 넘어갑니다.
- 일반 대화창을 보다가 다른 앱에서 찍으면 그 대화창이 아니라 Work 로 넘어가 담깁니다. Codex 는 그대로 들어갑니다 (직접 확인한 동작이며, 공식 문서에는 명시돼 있지 않음). 일반 대화창은 60초 규칙의 대상이 아닌 것으로 보입니다.
- 찍은 이미지와 읽어낸 글자가 함께 전송됩니다. 민감한 내용이 떠 있는 창은 필요할 때가 아니면 찍지 말고, 스크린샷이나 문서를 공유할 때와 같은 기준으로 판단합니다.
- CLI 에서 앱샷이 포함된 대화를 이어받아도 CLI 자체에서 새 앱샷을 만들 수는 없습니다.

**Computer History**
- 메모리 파일은 **암호화되지 않고** 직접 지울 때까지 남습니다. Mac 잠금과 계정 공유 여부를 점검합니다.
- 건강·재무·개인정보 앱은 켜기 전에 제외하고, 통신 앱은 상대방 동의 없이 포함하지 않습니다.
- 기록을 삭제하면 그 기록으로 만든 기억도 함께 사라집니다.
- EEA, 스위스, 영국에서는 지원되지 않으며, API 키·Amazon Bedrock 환경에서는 쓸 수 없습니다.
- 요금제 표기(Pro 와 Plus)가 원문 안에서 엇갈리므로, 실제 사용 가능 여부는 앱 설정에서 확인합니다.
