# 클로드 코드 무제한 활용법 (합병됨)

## 이게 뭔가요?
클로드 코드 사용 한도가 걸렸을 때 작업을 이어가거나, 요청을 압축하여 더 오래 사용하고, 세션이 바뀌어도 지난 작업을 기억하게 도와주는 세 가지 무료 도구를 소개합니다. 이 도구들을 설치하면 클로드 코드의 제약을 극복하고 더욱 효율적으로 AI를 활용할 수 있습니다.

이 가이드는 특히 **클로드 코드 CLI(Command Line Interface)** 버전을 기준으로 하며, 데스크톱 앱은 일부 기능(Headroom)이 지원되지 않을 수 있습니다. 클로드 코드를 처음 사용한다면 claude.ai/code 에서 시작할 수 있습니다.

**주요 도구:**
*   **OmniRoute**: 클로드 한도 도달 시, 요청을 다른 회사의 무료 모델로 자동 환승시켜 줍니다. (환승 중계소 역할)
*   **Headroom**: 클로드에게 보내는 요청 내용을 미리 압축하여 토큰 사용량을 절약해 줍니다. (요청 압축)
*   **Claude-mem**: 이전 세션의 작업 내용을 기억하여, 새로운 세션에서도 맥락을 유지하게 해 줍니다. (세션 기억)

이 세 가지 도구는 필수로 모두 설치할 필요는 없으며, 목적에 따라 선택적으로 사용할 수 있습니다. OmniRoute와 Headroom은 클로드 앞단에서 동일한 역할을 수행하므로 하나만 선택하는 것이 좋습니다. Claude-mem은 이들과 함께 사용해도 무방합니다.

**주의:** 무료 모델로 환승 시, 민감한 정보는 해당 무료 제공사(제3자)의 서버로 전송될 수 있으므로 주의해야 합니다.

## 따라하기

### 준비물 확인

설치는 모두 터미널(맥: 터미널, 윈도우: PowerShell)에서 진행됩니다. 코딩 지식은 필요 없으며, 안내된 명령어를 복사하여 붙여넣고 엔터만 누르면 됩니다.

설치 전, Node.js와 Python이 설치되어 있는지 확인합니다:

```bash
node --version
python3 --version
```

만일을 대비하여 설정 파일을 백업합니다. 파일이 없다는 메시지가 나와도 무시하고 진행하면 됩니다:

```bash
cp ~/.claude/settings.json ~/.claude/settings.backup.json
cp ~/.claude.json ~/.claude.backup.json
```

### STEP 1. OmniRoute: 무료 모델 환승

클로드 한도 초과 시 다른 무료 모델로 자동 전환해주는 OmniRoute를 설치합니다.

1.  **설치**: 터미널에 다음 명령어를 입력합니다.
    ```bash
    npm install -g omniroute
    ```
    맥에서 `permission denied` 또는 `EACCES` 오류 발생 시, 관리자 권한으로 실행합니다 (`sudo npm install -g omniroute` 후 맥 로그인 비밀번호 입력).

2.  **서버 켜기**: 설치 후 다음 명령어로 서버를 실행합니다.
    ```bash
    omniroute
    ```
    `localhost:20128`와 같은 주소가 표시되면, 이 창은 켜둔 채로 유지합니다. 이후 작업은 새 터미널 창에서 진행합니다.

3.  **무료 제공사 연결**: 브라우저에서 `http://localhost:20128`로 접속하여 OmniRoute 대시보드에 접속합니다. Providers 메뉴에서 사용할 무료 제공사를 선택하고 연결합니다. 처음 접속 시 관리자 비밀번호 설정이 필요할 수 있습니다.

4.  **상태 확인**: 새 터미널에서 다음 명령어로 연결 상태를 확인합니다.
    ```bash
    omniroute status
    ```
    연결된 제공사가 표시되면 성공입니다.

5.  **환승 모드로 클로드 실행**: 한도 도달 시, 일반 `claude` 대신 다음 명령어로 클로드 코드를 실행합니다.
    ```bash
    omniroute launch
    ```
    평소에는 `claude`를 사용하고, 한도에 도달했을 때만 `omniroute launch`를 사용합니다. 서버 창은 계속 켜두어야 합니다.

### STEP 2. Headroom: 토큰 아끼기

클로드에 보내는 요청을 압축하여 토큰을 절약하는 Headroom을 설치합니다.

1.  **설치**: Headroom은 `pip3`를 사용하여 설치합니다.
    ```bash
    pip3 install "headroom-ai[all]"
    ```
    `pip` 명령어가 작동하지 않으면 `pip3`를 사용합니다. `npm install headroom-ai`는 실행 명령어가 생성되지 않으므로 사용하지 않습니다.

2.  **압축 모드로 켜기**: 이제부터 `claude` 대신 다음 명령어로 클로드 코드를 실행하여 압축 기능을 활성화합니다.
    ```bash
    headroom wrap claude
    ```
    이 명령으로 실행된 창에서만 압축이 작동합니다. 처음 실행 시 Serena라는 코드 탐색 보조 도구가 함께 설치 및 등록됩니다.

3.  **상태 확인**: 다음 명령어로 Headroom 설치 및 설정을 확인합니다.
    ```bash
    headroom doctor
    ```
    모든 항목에 체크 표시가 나오면 정상입니다.

**활용:** `headroom dashboard` 명령어로 절약된 토큰량을 실시간으로 확인할 수 있습니다. 원래대로 돌리려면 `headroom unwrap claude`를 사용합니다.

### STEP 3. Claude-mem: 세션 기억 유지

세션이 끝나도 작업 내용을 기억하게 하는 Claude-mem을 설치합니다.

1.  **설치**: 터미널에서 다음 명령어를 실행합니다.
    ```bash
    npx claude-mem install
    ```
    중간에 질문이 나오면 엔터로 기본값을 선택합니다. 클로드 코드 화면 내에서 `/plugin marketplace add thedotmack/claude-mem` 후 `/plugin install claude-mem` 명령으로도 설치 가능합니다.

2.  **재시작**: 설치 후 클로드 코드를 완전히 종료했다가 다시 시작해야 기억 기능이 활성화됩니다.

**활용:** 재시작 후 새 세션을 열면 이전 작업 요약이 자동으로 나타나며, 맥락을 유지한 채 작업을 이어갈 수 있습니다. OmniRoute 환승 모드에서도 동일하게 작동합니다.

### 전체 설치 확인

모든 도구의 설치 및 작동 여부를 확인합니다.

```bash

omniroute status
headroom doctor
```

OmniRoute는 서버 상태 표시, Headroom은 체크 표시를 확인합니다. Claude-mem은 클로드 코드 내에서 `/plugin`을 입력했을 때 `claude-mem`이 목록에 보이면 정상입니다.

## 활용 예시

*   **코드 생성:** 특정 기능 구현을 위한 Python 코드를 Claude Code에 요청하여 빠르게 생성할 수 있습니다. OmniRoute를 함께 사용하면 한도에 도달해도 작업을 중단하지 않고 코드를 계속 생성할 수 있습니다.
*   **코드 분석:** 작성된 코드의 작동 방식을 이해하기 위해 Claude Code에 설명을 요청할 수 있습니다. Headroom을 사용하면 긴 코드 파일도 효율적으로 압축하여 분석 요청을 보낼 수 있습니다.
*   **오류 디버깅:** 코드에서 발생하는 오류의 원인을 파악하고 해결 방법을 제안받는 데 활용할 수 있습니다. Claude-mem을 사용하면 이전 디버깅 세션의 맥락을 기억하여 더 정확하고 빠른 해결책을 얻을 수 있습니다.
*   **시나리오 1: 클로드 한도 도달 시 작업 이어가기**
    평소에는 `claude` 명령어로 작업하다가, "한도에 도달했습니다" 메시지가 뜨면 새 터미널에서 `omniroute` 서버를 켜고 `omniroute launch`로 클로드 코드를 실행합니다. 연결된 무료 모델로 중요한 작업을 이어가고, 클로드 한도가 풀리면 다시 `claude`로 돌아옵니다.
*   **시나리오 2: 긴 파일 내용 요약 및 분석**
    매우 긴 코드 파일이나 로그 데이터를 클로드에 전달하기 전에 `headroom wrap claude` 명령으로 클로드 코드를 실행합니다. Headroom이 내용을 압축하여 토큰을 절약하고, 요약 및 분석 작업을 수행합니다. `headroom dashboard`로 얼마나 토큰을 절약했는지 확인합니다.
*   **시나리오 3: 장시간 작업 맥락 유지**
    며칠에 걸쳐 진행하는 복잡한 프로젝트의 경우, Claude-mem이 설치되어 있으면 세션을 다시 열 때마다 이전 작업 내용을 요약하여 보여줍니다. "어제 하던 카드뉴스 작업 이어서 해줘"와 같은 요청에도 AI가 맥락을 이해하고 빠르게 대응합니다.

## 💡 아이디어

*   Claude Code를 활용하여 개인 프로젝트의 개발 속도를 높이고, 프로토타이핑 시간을 단축할 수 있습니다. OmniRoute, Headroom, Claude-mem을 함께 사용하면 개발 과정 전반의 효율성을 극대화할 수 있습니다.
*   정기적인 코드 리뷰나 새로운 기술 학습에 Claude Code를 보조 도구로 사용하여 효율성을 극대화할 수 있습니다. 특히 대규모 프로젝트의 경우, 세 가지 도구를 활용하여 지속적인 학습과 개발을 지원받을 수 있습니다.

## 주의사항

*   **OmniRoute와 Headroom**: 이 두 도구는 클로드 앞단에서 동일한 역할을 수행하므로 하나만 선택하여 사용하는 것이 좋습니다.
*   **무료 모델 전환 시**: OmniRoute를 통해 무료 모델로 환승할 경우, 해당 무료 제공사(제3자)의 서버로 민감한 정보가 전송될 수 있으므로 주의해야 합니다. 중요한 정보는 공유하지 않도록 합니다.
*   **CLI 환경**: 본 가이드의 설치 및 활용법은 클로드 코드 CLI 버전을 기준으로 합니다. 데스크톱 앱의 경우 일부 기능(특히 Headroom)이 제한될 수 있습니다.
