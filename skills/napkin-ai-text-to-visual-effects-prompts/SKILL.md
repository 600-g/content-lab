# 글을 비주얼로 즉시 변환하기

💡 이 스킬은 **Napkin AI**로 복잡한 텍스트·메모를 몇 초 만에 다이어그램·차트로 바꾸고, **Effects 프롬프트**로 젤리·클레이·글래스 등 12가지 질감을 입히는 스킬입니다.

## 이게 뭔가요?

**Napkin AI**는 회의 메모나 기획안처럼 막 쏟아낸 텍스트를 그대로 붙여넣으면, 다이어그램·차트·구조도 같은 깔끔한 비주얼을 몇 초 만에 만들어주는 툴입니다. 파워포인트에서 도형을 하나하나 그리던 작업이 사라진다고 보면 됩니다. 영문 툴이지만 **한국어로 입력해도 자연스럽게 결과가 나온다**는 점이 직장인 입장에서 가장 큰 장점입니다.

가입은 구글 계정으로 1분이면 끝나고 신용카드가 필요 없습니다. 무료 플랜도 크레딧이 매주 갱신되기 때문에 부담 없이 계속 사용할 수 있습니다.

| 항목 | 내용 |
|---|---|
| 가입 | 구글 계정으로 1분, 신용카드 불필요 |
| 무료 플랜 | 크레딧이 매주 갱신돼서 부담 없이 사용 |
| 언어 | 한국어 입력 OK |
| 내보내기 | PPT · PNG · SVG · PDF |

✅ 무료 대안: 별도 유료 결제 없이 무료 플랜(주간 크레딧)만으로 아래 전체 워크플로가 가능합니다.

## 따라하기

1. 구글 계정으로 Napkin AI 에 가입합니다 (신용카드 불필요).
2. 회의록·기획안·메모 등 정리되지 않은 텍스트를 그대로 붙여넣습니다.
3. 몇 초 안에 생성된 다이어그램/차트/구조도를 확인합니다.
4. 비주얼이 마음에 들면, **Effects** 기능을 열고 아래 원하는 톤의 영어 프롬프트를 그대로 붙여넣어 질감을 바꿉니다.
5. 완성된 결과물을 PPT · PNG · SVG · PDF 중 원하는 포맷으로 내보냅니다.

아래는 Effects 에 넣을 수 있는 스타일별 프롬프트 전문입니다. 원문 그대로 복사해서 사용하면 됩니다.

### 젤리 (말랑+반투명+속광)

```
Transform all filled areas into soft translucent jelly fills, like gummy candy with a faint inner glow. Add only soft diffused shadows from an overhead light box — no hard shadow lines, no glossy highlights, no contour lines. Standalone lines become thin rounded matte wires matching the original tint. Keep everything slightly plump but clean.
```

### 클레이 (매트하고 도톰한 따뜻한 느낌)

```
Turn this diagram into a soft matte clay style — rounded, slightly chubby fills with a gentle dough-like surface. Add minimal soft shadows only, no hard shadows, no highlights, no contour lines. Standalone lines become thin matte clay ropes matching the original tint. Keep it tactile but smooth, no fingerprints.
```

### 페이퍼컷 (레이어 컷 + 층간 그림자)

```
Transform all surfaces into thin, cleanly cut paper layers resting on the background, with very soft drop shadows between the layers. Standalone lines become thin matte paper strips matching the original tint. Ignore all contour lines, no highlights. Keep each layer flat and crisp.
```

### 프로스티드 글래스 (반투명+블러, 세련된 톤)

```
Transform all filled areas into frosted translucent glass fills with a soft blur behind them. Add only gentle diffused shadows from an overhead light box — no hard shadows, no sharp highlights, no contour lines. Standalone lines become thin matte wires matching the original tint. Keep surfaces smooth, clean, and slightly see-through.
```

### 플랫 모던 (제일 무난, 처음 쓰기 좋음)

```
Transform all filled areas into flat, modern fills. Add soft, diffused shadows only, lit by a big overhanging light box — no hard shadow lines, no highlights, no contour lines. For volumetric objects, use physically accurate but very subtle soft shadows.
```

### 풍선 (가볍고 통통한 느낌)

```
Turn this diagram into a soft inflated balloon style — gently puffed, air-filled fills with rounded edges. Add subtle soft shadows only; a faint sheen is okay but no hard highlights, no contour lines. Standalone lines become thin rounded matte wires matching the original tint. Keep it light and bouncy, not glossy.
```

### 펠트 (얇은 매트 울 질감)

```
Turn this diagram into a flat soft felt style — matte fuzzy fills kept thin, like fine wool felt with no thick pile. Don't add stitches. Add minimal soft shadows only, no hard shadows, no highlights, no contour lines. Standalone lines become thin matte felt cords matching the original tint.
```

### 니트 울 (포근하고 감성적인 톤)

```
Transform all filled areas into chunky knitted wool fills with soft looping stitch texture, kept fairly flat. Add minimal soft shadows only, no hard shadows, no highlights, no contour lines. Standalone lines become thin matte yarn cords matching the original tint. Keep it cozy with a gentle fuzzy edge.
```

### 블론 글라스 (시선 강탈용)

```
Transform all filled areas into glossy translucent blown-glass fills with faint swirling color inside. Add only soft diffused shadows; very subtle edge light is okay but no hard highlights, no contour lines. Standalone lines become thin rounded glass wires matching the original tint. Keep it smooth and clear, slightly rounded.
```

### 아이스 (시원하고 크리스탈한 톤)

```
Transform all filled areas into clear carved-ice fills with a subtle frosted edge. Add only soft diffused shadows, a faint cool glow is okay but no hard highlights, no contour lines. Standalone lines become thin matte icy wires matching the original tint. Keep surfaces crisp, cool-toned, and slightly translucent.
```

### 리퀴드 크롬 (모던·고급 톤)

```
Transform all filled areas into smooth liquid-chrome fills with soft mirrored reflections. Add only gentle diffused shadows; keep reflections muted with no hard highlights, no contour lines. Standalone lines become thin matte metal wires matching the original tint. Keep surfaces rounded, sleek, and clean.
```

### 종이접기 (포근하고 친근한 톤)

```
Transform all filled areas into folded pastel origami paper with soft rounded creases. Add only gentle diffused shadows, no hard shadow lines, no glossy highlights, no contour lines. Standalone lines become thin matte folded-paper strips matching the original tint. Keep folds clean and slightly chubby, friendly not sharp.
```

원하는 톤에 따라 아래 표를 참고해 고르면 됩니다.

| 톤 | 추천 스타일 |
|---|---|
| 귀여움 최대 | 젤리 · 풍선 · 클레이 |
| 정보 슬라이드 | 페이퍼컷 · 플랫 모던 · 펠트 |
| 모던·고급 | 프로스티드 글래스 · 리퀴드 크롬 |
| 포근·감성 | 니트 울 · 종이접기 |
| 시선강탈 | 블론 글라스 · 아이스 |

## 활용 예시

- 회의 끝나고 받아적은 두서없는 메모를 그대로 붙여넣기 → 몇 초 만에 구조도가 나오고, 발표 슬라이드에 넣을 때는 **플랫 모던** Effects 를 적용해 톤을 통일한다.
- 기획안 초안 텍스트를 붙여넣어 차트를 생성 → SNS 콘텐츠용으로는 **젤리** 또는 **풍선** Effects 를 적용해 시선을 끄는 카드뉴스 이미지로 활용한다.
- 프로젝트 프로세스를 줄글로 정리한 뒤 다이어그램화 → 사내 문서용으로는 **페이퍼컷** 이나 **프로스티드 글래스** 로 가독성과 세련된 느낌을 동시에 잡는다.

## 주의사항

- Effects 프롬프트는 영어 문구를 정확히 그대로 입력해야 의도한 질감이 재현됩니다. 임의로 줄이거나 번역하면 결과가 달라질 수 있습니다.
- 무료 플랜 크레딧은 매주 갱신되지만, 한 주 안에 다량으로 생성하면 소진될 수 있어 사용량을 확인하는 것이 좋습니다.
- Effects 는 비주얼을 먼저 생성한 뒤 적용하는 후처리 기능이므로, 반드시 다이어그램 생성 → Effects 적용 순서를 지켜야 합니다.
