# 클로드에서 GPT 이미지 만들기

💡 **`gpt-image` 스킬**을 설치하면 클로드 작업 흐름 안에서 `/gpt-image` 한 줄로 **챗GPT 이미지 생성**을 부를 수 있습니다. **API 키 없이** 기존 챗GPT 유료 구독 사용량으로 돌아갑니다.

## 이게 뭔가요?

클로드(Claude)는 텍스트 중심 AI라 직접 이미지를 생성하지 못합니다. 이 방법은 깃허브(GitHub)에 공개된 서드파티 **`gpt-image` 스킬**을 클로드의 코드 기능(Claude Code)에 설치해, 클로드가 **챗GPT(Codex)의 이미지 생성 기능**을 대신 호출하게 만드는 방식입니다.

| 항목 | 내용 |
|---|---|
| 작동 방식 | 클로드에서 `/gpt-image` 호출 → 연동된 챗GPT(Codex)가 이미지 생성 |
| 필요한 것 | 클로드의 코드 기능 + 💰 **ChatGPT 유료 구독(Codex 포함)** |
| API 키 | 필요 없음 — 추가 결제 없이 기존 구독 사용량 안에서 생성 |
| 성격 | 공식 클로드 기능이 아닌 서드파티 스킬 |
| 무료 대안 | 직접 대체는 없음. 이미지 자체가 목적이면 Bing Image Creator, Leonardo AI 등 다른 이미지 생성 도구 |

글을 쓰던 클로드 작업 안에서 바로 썸네일·삽화를 뽑을 수 있어, 도구를 오가는 시간이 줄어드는 것이 장점입니다. 블로그·SNS 콘텐츠를 만드는 크리에이터나 소규모 비즈니스 운영자에게 특히 유용합니다.

## 따라하기

### 1. `gpt-image` 스킬 설치

1. 깃허브에서 `gpt-image` 스킬 저장소를 찾습니다.
2. 저장소의 README에 있는 설치용 프롬프트를 복사해 클로드(코드 기능) 환경에 **한 번** 붙여넣습니다. 이 프롬프트가 스킬의 초기 설정을 해 줍니다.
3. 챗GPT 유료 계정(Codex 포함)이 연동돼 있어야 이후 생성이 됩니다.

### 2. 클로드에서 스킬 호출

클로드 입력창에 `/gpt-image` 명령을 입력해 스킬을 활성화한 뒤, 만들고 싶은 이미지를 텍스트로 상세히 설명합니다.

```
/gpt-image
```

프롬프트의 명확성과 구체성이 결과를 크게 좌우합니다. 다음 요소를 같이 적으면 좋습니다.

- **주제·장면**: 무엇이 무엇을 하고 있는가
- **스타일**: 사이버펑크, 동화풍, 실사풍, 유화풍 등
- **용도**: 블로그 썸네일, 발표 자료, SNS 삽화 등

### 3. 이미지 생성과 사용량 관리

명령과 프롬프트가 들어가면 클로드와 연동된 챗GPT(Codex)가 이미지를 생성합니다. 별도의 API 키 설정이나 추가 결제는 없지만, **요청할 때마다 챗GPT 유료 구독 사용량이 차감될 수 있으므로** 본인 구독 사용량을 주기적으로 확인합니다.

### 체크리스트

- [ ] ChatGPT 유료 구독(Codex 포함)이 있다
- [ ] README의 설치 프롬프트를 클로드에 한 번 붙여넣었다
- [ ] `/gpt-image` 뒤에 주제·스타일·용도를 구체적으로 적었다
- [ ] 생성 후 챗GPT 사용량을 확인했다

## 활용 예시

| 용도 | 요청 예시 | 효과 |
|---|---|---|
| 블로그 썸네일 | "AI가 인간처럼 그림을 그리는 미래 지향적인 모습" | 독자의 흥미를 끌고 게시물 전달력을 높입니다 |
| 콘텐츠 삽화 | "귀여운 고양이 캐릭터가 코딩하는 모습" | 블로그·SNS·뉴스레터용 독창적 삽화 |
| 개인 프로젝트 디자인 | "사이버펑크 스타일의 로봇이 고서점에서 책을 읽고 있는 모습" | 웹사이트·발표 자료·포트폴리오용 시각 자료 |
| 프레젠테이션 자료 | "데이터 시각화 차트의 추상적인 예술적 표현" | 딱딱한 데이터 슬라이드에 창의적 이미지를 더해 집중도를 높입니다 |

## 💡 아이디어

- **스타일·테마 특화 이미지 봇**: 동화풍·실사풍·유화풍 같은 스타일이나 로고·캐릭터·배경 아트 같은 테마를 고정한 프롬프트 틀을 만들어 두면, 짧은 요청만으로 일관된 결과를 얻는 맞춤형 이미지 생성 흐름이 됩니다.
- **이미지 기반 2차 창작**: 생성한 이미지로 스토리텔링 중심 SNS 시리즈를 기획하거나 짧은 애니메이션 클립의 소재로 씁니다.
- **대화형 AI 아트 서비스**: 클로드의 대화로 요구를 구체화하고 `gpt-image`로 그리는 흐름을 묶어, 사용자 니즈에 맞춘 AI 아트 생성 서비스로 확장할 수 있습니다.

## 주의사항

- **서드파티 스킬**: 공식 클로드 기능이 아니라 외부 개발자가 만든 도구입니다. 예상치 못한 오류, 기능 변경, 서비스 중단 가능성이 있습니다.
- **ChatGPT 유료 구독 필수**: 무료 ChatGPT 사용자나 미구독자는 이 스킬로 이미지를 만들 수 없습니다.
- **사용량 차감**: 생성할 때마다 챗GPT 구독 사용량이 차감될 수 있으니 요청 전에 남은 사용량을 확인합니다.
- **업데이트 확인**: 깃허브 `gpt-image` 스킬은 기능 개선·버그 수정·보안 강화가 반영될 수 있으므로 주기적으로 최신 버전을 확인하고 필요하면 업데이트합니다.
