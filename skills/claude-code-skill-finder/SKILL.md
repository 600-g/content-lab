# Claude 스킬 탐색 및 검증 가이드

💡 내 작업에 딱 맞는 **Claude 스킬**을 효율적으로 찾고, 설치 전 **신뢰도를 검증**하여 안전하게 활용하는 가이드입니다.

## 이게 뭔가요?
스킬이 많아질수록 내게 진짜 필요한 '좋은 스킬'을 찾는 것은 더 어려워집니다. 이 페이지는 Vercel Labs의 /find-skills를 기준으로, 내 작업에 맞는 Claude/Agent 스킬을 찾고 설치하기 전 신뢰도를 확인하는 완벽한 흐름을 정리한 가이드입니다.

Claude Code는 단순한 채팅창을 넘어, 사용자가 필요한 능력을 장착하는 무기처럼 활용될 수 있습니다. 'find-skills'는 이러한 스킬 생태계에서 길을 잃지 않도록 돕는 핵심 도구로, 70만 개가 넘는 사전 검증된 스킬 중에서 사용자의 작업에 가장 적합한 것을 찾아주고, 설치 시 안전성을 검증할 수 있도록 지원합니다.

## 따라하기

### Step 1. find-skills 링크 전달 및 장착 요구

```
아래 Vercel Labs의 find-skills 깃허브 링크 내용을 참고해서, 내가 앞으로 요청하는 작업에 맞는 Claude 스킬을 찾고 추가할 수 있도록 준비해줘.
```

### Step 2. 내 맞춤형 스킬 찾아달라고 하기

#### 방법 A : 나의 작업 환경을 분석하여 추천받기 (강력 추천)

```
이 프로젝트 폴더 구조와 최근 작업 내용(git 로그 및 주요 코드) 등 그동안 나의 워크플로우를 파악해서, 지금 나한테 가장 필요한 스킬을 find-skills에서 찾아서 제안해줘.
```

#### 방법 B : 특정 목적에 맞는 스킬 타겟팅하기

```
내가 지금 이 프로젝트에서 [예: 모바일 앱 화면 디자인 / 리액트 컴포넌트 성능 개선 / 대형 코드 리뷰] 작업을 하고 싶은데, 여기에 딱 맞는 스킬을 find-skills에서 찾아서 리스트업해줘.
```

### 🚨 설치 전 필수! 신뢰도 체크리스트

무작정 설치하기 전, 아래 4가지를 반드시 확인하세요.

1.  **설치 수 (Downloads)**: 가급적 1K 이상 설치된 스킬을 우선순위로 둡니다. (100 미만은 코드를 더 신중하게 확인하세요)
2.  **출처 (Owner)**: vercel-labs, anthropics, microsoft 등 공식적이거나 널리 알려진 출처를 우선합니다.
3.  **GitHub 평판 (Reputation)**: Repo Stars ⭐️ 수, 최근 업데이트 날짜, Issue 및 PR 해결 상태를 점검합니다.
4.  **SKILL.md 검증**: 실제로 AI에게 어떤 작업을 지시하는 프롬프트인지, 불필요한 권한 요구나 위험한 명령(ex: 무단 파일 삭제)이 없는지 읽어봅니다.

## 💡 아이디어
Claude Code를 잘 쓰는 사람은 모든 기능을 외우는 사람이 아니라, 필요한 작업에 맞춰 능력을 찾고 장착하는 사람이 될 가능성이 큽니다. 스킬은 무조건 많이 까는 것이 중요한 게 아니라, 지금 내 업무에 딱 맞는 것을 고르고, 그것이 믿을 만한지 검증해 내는 안목이 핵심입니다. 이를 통해 개인의 생산성을 극대화하고, 복잡한 작업을 자동화하는 데 집중할 수 있습니다.
