# 클로드코드 상태바 세팅 가이드

💡 클로드코드 사용 시 현재 작업 환경과 사용량을 한눈에 파악할 수 있도록 **상태바를 설정**하는 가이드입니다.

## 이게 뭔가요?

클로드코드(Claude Code) 사용 시 화면 맨 아래에 현재 폴더, git 브랜치, 사용 모델, 대화 컨텍스트 및 5시간 사용량 한도 정보를 실시간으로 보여주는 상태바를 설정하는 방법입니다. 이 기능은 원래 `/status`, `/usage`, `/model` 명령어를 각각 입력해야만 알 수 있던 정보들을 한눈에 파악할 수 있게 해주어 작업 효율성을 크게 높여줍니다.

특히 코딩 경험이 없는 비개발자도 Claude Code의 활용도를 높일 수 있도록 돕는 기능입니다.

## 따라하기

### 1단계 · 시작하기 전에

**어디에 입력하나요?**

Claude Code 창에 직접 입력합니다. 터미널이 아닙니다.

*   **터미널:** `PS C:\Users\...>` 또는 `이름@맥북 ~ %` 와 같이 시작합니다.
*   **클로드코드:** `>` 만 보이며, `for agents` 와 같은 안내 메시지가 하단에 표시됩니다.

**클로드코드 켜는 법**

1.  터미널을 엽니다.
2.  작업할 폴더로 이동합니다.
3.  `claude` 를 입력하고 실행합니다.

`Welcome back` 메시지가 뜨면 성공입니다.

### 2단계 · 설정하기

**Windows 사용자**

Claude Code 창에 다음 명령어를 붙여넣으세요:

```
/statusline 현재 폴더명,
git 브랜치, 모델명,
컨텍스트 % 프로그레스바,
5시간 사용량 한도를 한 줄로 보여줘.
PowerShell로 만들어줘
```

`PowerShell로 만들어줘` 를 반드시 포함해야 합니다. 이 지시가 없으면 bash로 생성되는데, bash는 `jq` 라는 프로그램을 별도 설치해야만 데이터를 제대로 읽을 수 있습니다. PowerShell은 Windows에 기본 내장되어 있어 별도 설치 없이 바로 작동합니다.

**Mac 사용자**

Claude Code 창에 다음 명령어를 붙여넣으세요:

```
/statusline 현재 폴더명, git 브랜치, 모델명, 컨텍스트 % 프로그레스바, 5시간 사용량 한도를 한 줄로 보여줘.
Python으로 만들어줘
```

Mac에서도 `Python으로 만들어줘` 를 붙이는 것이 안전합니다. Mac에는 `jq`가 기본으로 없기 때문에 bash로 생성 시 상태줄이 비어 보일 수 있습니다. Python으로 생성하면 이 문제를 방지할 수 있습니다.

**그 다음**

1.  파일을 만들어도 되냐는 질문에 `승인` 합니다.
2.  설정이 완료되면, Claude Code에게 아무 말이나 건네보세요 (예: `안녕`).

그때부터 화면 아래에 상태줄이 나타나기 시작합니다.

## 뭐가 보이는 건가요?

| 항목     | 내용                                     | 예시                   |
| :------- | :--------------------------------------- | :--------------------- |
| **폴더명** | 현재 작업 중인 폴더                      | 뉴스 자동화            |
| **git 브랜치** | 현재 작업 중인 브랜치                    | master                 |
| **모델명**   | 현재 사용 중인 모델                      | Opus 5                 |
| **컨텍스트** | 대화가 얼마나 채워졌는지 (토큰 사용량)   | ■■□□□□□□□□ 7%       |
| **5시간 한도** | 최근 5시간 동안 사용량을 얼마나 썼는지 | 한도 12%               |

## 안 될 때

*   **설정했는데 아무것도 안 보여요:** Claude Code를 껐다 켜거나, 아무 말이나 한 번 더 걸어보세요.
*   **껐다 켜도 안 보여요:** 프롬프트를 다시 입력해야 할 수 있습니다. 설정 파일이 제대로 저장되지 않았을 수 있습니다.
*   **5시간 한도만 안 보여요:** `jq` 프로그램이 없거나 제대로 설치되지 않았을 수 있습니다 (Mac bash 사용자).
*   **git 브랜치만 안 보여요:** 해당 폴더가 git으로 관리되지 않거나, git 관련 정보 파싱에 문제가 있을 수 있습니다.
*   **한글 폴더인데 브랜치만 안 나와요:** 인코딩 문제일 수 있습니다. Claude Code의 터미널 환경 설정을 확인해보세요.
*   **상태줄은 있는데 값이 다 비어 있어요:** Claude Code가 백그라운드에서 정상적으로 실행되지 않거나, 정보 수집에 실패한 경우입니다. Claude Code를 재시작해보세요.
*   **글자가 네모나 물음표로 깨져요:** 폰트 문제이거나, Claude Code의 터미널 환경 설정이 한국어를 제대로 지원하지 못하는 경우입니다. Claude Code의 터미널 설정을 확인하거나, 다른 터미널 에뮬레이터를 사용해보세요.

## 마음에 안 들면

색상이나 표시되는 항목을 자유롭게 변경할 수 있습니다. Claude Code에게 직접 요청해보세요.

*   **색상 변경:** `상태줄 색이 너무 어두워. 5개 항목 전부 밝게 바꿔줘`
*   **프로그레스바 형식 변경:** `컨텍스트 바를 채운 칸은 ■, 빈 칸은 □ 로 바꿔줘`
*   **항목 이름 변경:** `5h 를 한도 로 바꿔줘`
*   **항목 제거:** `git 브랜치는 빼줘`
*   **줄바꿈:** `너무 길어. 두 줄로 나눠줘`

## 끄고 싶으면

상태바를 끄려면 다음 명령어를 사용하세요:

```
/statusline delete
```

이 명령어를 실행하면 설정 파일에서 상태줄 관련 항목이 삭제됩니다. 다시 켜려면 처음 안내된 프롬프트를 다시 입력하면 됩니다. 상태바에는 별도의 on/off 스위치가 없으며, 삭제 후 필요시 다시 생성하는 방식입니다.

## 알아두면 좋은 것

*   **설정 유지:** 한 번 설정하면 Claude Code를 껐다 켜거나 다른 폴더로 이동해도 설정이 계속 유지됩니다. 설정이 사용자별 설정 파일로 저장되기 때문입니다.
*   **기기별 설정:** 설정은 현재 사용 중인 컴퓨터에 저장됩니다. 따라서 다른 컴퓨터(예: PC에서 설정 후 노트북)에서는 별도로 다시 설정을 진행해야 합니다.
*   **토큰 미사용:** 상태줄 기능은 사용자의 컴퓨터에서 직접 실행되므로, Claude API의 토큰을 사용하지 않습니다. 따라서 사용량에 전혀 영향을 주지 않습니다.
