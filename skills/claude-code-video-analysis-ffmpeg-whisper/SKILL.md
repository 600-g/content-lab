# 클로드 코드 토큰 아끼며 영상 분석하기

💡 영상 분석 시 **FFMPEG, Remotion, Whisper** 등의 도구와 심층 분석 프롬프트를 활용하여 **클로드 코드 토큰 사용량을 절감**하는 스킬입니다.

## 이게 뭔가요?
본문은 사용자가 클로드(Claude) AI를 활용하여 영상 콘텐츠를 분석할 때 발생하는 토큰 사용량을 효율적으로 관리하고 절약하는 방법에 대한 안내입니다. 특히, 외부 도구들을 연동하고 특정 프롬프트 엔지니어링 기법을 적용하여 분석의 깊이를 더하는 동시에 비용 효율성을 높이는 데 초점을 맞추고 있습니다. 이를 통해 롱폼 영상 제작이나 복잡한 영상 편집 작업의 생산성을 향상시킬 수 있습니다. 

이 스킬은 주로 Claude Max와 같은 유료 AI 모델에서 활용 가치가 높으며, 영상 편집 및 분석 자동화에 관심 있는 사용자에게 유용합니다.

💰 유료 필요: Claude Max
✅ 무료 대안: 일부 기능은 ChatGPT, Gemini 등 무료 모델로도 실험 가능하나, Claude Code CLI 연동 및 고급 분석 기능은 제한적일 수 있습니다.

## 따라하기

**1단계: 필요한 외부 도구 설치**

클로드에게 전달하여 영상 분석 프로그램 및 관련 라이브러리를 설치합니다. 아래 링크들을 그대로 복사하여 클로드에게 전달하면 됩니다.

*   **FFMPEG**: 프로그램 설치
    ```
    https://ffmpeg.org/download.html
    ```
*   **Remotion**: 개발 프레임워크 설치
    ```
    https://www.remotion.dev/docs
    ```
*   **Whisper**: OpenAI의 음성 인식 모델 설치
    ```
    https://github.com/openai/whisper
    ```

**2단계: 심층 분석 프롬프트 추가**

설치된 도구들을 활용하여 영상을 분석하되, 토큰 사용량을 절감하면서도 상세한 정보를 얻기 위한 분석 심화 프롬프트를 클로드에게 전달합니다. 프롬프트는 다음과 같습니다.

```
지금 분석한 영상을 12fps로 정확히 다시 분석해줘. 요소들의 키프레임, 이징은 어떤 패턴인지도 정확하게 알아내줘. 각 컷별로 필요한 에셋들을 정리해서 나한테 알려줘. 마지막으로 이걸 그대로 재현한다면 어떤 순서로 만들어야 하는지 제작 순서표를 만들어줘.
```

**3단계: 롱폼 영상 제작 및 학습 (선택 사항)**

AI를 활용한 영상 편집 방법론을 배우고 롱폼 영상까지 제작해보고 싶다면, 제공된 추가 자료를 참고하여 관련 교육 과정이나 혜택을 확인할 수 있습니다. (예: 마이 페이지 → 쿠폰 사용 → '달비_작업실' 입력 → 4만원 쿠폰 사용)

```
https://abit.ly/hq9ylc
```

## 활용 예시

*   **영상 편집 효율화**: 특정 영상의 편집 스타일(키프레임, 이징 패턴)을 분석하여 동일한 스타일의 새로운 영상을 제작할 때 필요한 에셋 목록과 제작 순서를 파악하여 시간과 비용을 절약할 수 있습니다.
*   **콘텐츠 분석 자동화**: 긴 강의 영상이나 다큐멘터리를 12fps 기준으로 재분석하여 핵심 내용을 요약하고, 각 장면 전환에 필요한 시각적 요소와 제작 단계를 파악하여 콘텐츠 기획 및 제작에 활용할 수 있습니다.
*   **AI 기반 영상 제작 튜토리얼**: 제공된 프롬프트를 응용하여 다양한 영상 분석 요구사항에 맞춰 클로드에게 질문하고, 그 답변을 바탕으로 AI 영상 제작 학습 콘텐츠를 직접 만들어볼 수 있습니다.

## 💡 아이디어

*   **자동화된 영상 분석 리포트 생성**: 매주 또는 특정 주제의 영상들을 업로드하면 자동으로 분석 프롬프트를 적용하여 키프레임, 이징 패턴, 에셋 목록, 제작 순서 등을 포함한 상세 분석 리포트를 생성하는 서비스를 개발할 수 있습니다.
*   **AI 영상 편집 템플릿 라이브러리 구축**: 클로드의 분석 결과를 바탕으로 다양한 영상 스타일별 제작 순서와 에셋 가이드라인을 정리하여, 사용자들이 AI 기반 영상 편집 템플릿 라이브러리를 구축하고 공유하는 플랫폼을 만들 수 있습니다.
*   **교육 콘텐츠 제작**: 본 스킬을 활용하는 방법을 단계별로 설명하는 온라인 강의나 튜토리얼을 제작하여, AI 영상 편집 및 분석에 관심 있는 초보자들을 대상으로 제공할 수 있습니다.
