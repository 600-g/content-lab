# NVIDIA AI 100+ 모델 무료 API 활용

💡 NVIDIA가 제공하는 **100개 이상의 AI 모델**을 **무료 API**로 활용하여 콘텐츠 제작, 학습, 실험 등 다양한 작업을 수행할 수 있는 스킬입니다.

## 이게 뭔가요?
NVIDIA Build (build.nvidia.com)는 NVIDIA가 100개 이상의 AI 모델을 무료 API로 개방한 서비스입니다. ChatGPT와 유사한 수준의 AI 모델들을 코딩 없이도 활용하거나, 나만의 AI 도구를 만들어 자동화할 수 있습니다. 개인 학습, 콘텐츠 제작, 실험 등은 무료이며, 상업 서비스 운영 시에만 유료 라이선스가 필요합니다.

주요 특징은 다음과 같습니다:
*   **서비스**: NVIDIA Build (build.nvidia.com)
*   **제공**: AI 모델 100개 이상 무료 API 개방
*   **가격**: 개인 학습·콘텐츠 제작·실험 무료 / 상업 서비스 운영 시 유료
*   **가입**: 이메일 가입 (API 키 발급 시 휴대폰 인증 1회, 신용카드 불필요)
*   **속도**: 분당 약 40회 호출 (무료 기준)

다른 유료 API 서비스와 달리, NVIDIA Build는 무료 한도 내에서 토큰 요금이 발생하지 않으며, 한도를 초과하면 잠시 멈추는 방식입니다. 따라서 별도의 구독이나 종량제 과금 없이 고급 AI 모델들을 부담 없이 사용할 수 있습니다.

**⚠️ 주의**: 출처 불분명한 링크에서 API 키나 카드 정보를 요구하는 경우, 피싱 사기일 수 있으므로 주의해야 합니다.

## 따라하기
NVIDIA Build를 활용하는 방법은 크게 두 가지입니다.

### 방법 1: 사이트에서 바로 쓰기 (코딩 불필요)
1.  **가입**: build.nvidia.com에 접속하여 이메일로 가입합니다. 가입 과정에서 광고 수신 동의 여부를 선택할 수 있으며, 결제와는 무관합니다.
2.  **모델 선택**: 메인 페이지에서 원하는 용도의 모델을 선택합니다 (예: 글쓰기 - minimax, 이미지 생성 - qwen-image).
3.  **Playground 사용**: 선택한 모델 페이지의 오른쪽 입력칸에 한국어로 원하는 작업을 요청합니다. 예를 들어, "인스타 릴스 후킹 문구 5개만 만들어줘"와 같이 입력하면 바로 결과를 얻을 수 있습니다.
    *   `Pro Tip`: 화면에 "Get API Key" 버튼이 보여도 방법 1에서는 누르지 않아도 됩니다.

### 방법 2: 나만의 AI 도구 만들기 (활용성 증대)
매번 사이트에 접속하는 번거로움 없이 자동화된 도구를 만들고 싶을 때 사용합니다.

1.  **API 키 발급**: 모델 페이지에서 "Get API Key"를 누릅니다. `nvapi-`로 시작하는 API 키를 발급받아 안전하게 보관합니다. API 키 발급을 위해 휴대폰 인증이 필요하며, 이는 결제와 무관한 본인 확인 절차입니다.
2.  **클로드 또는 ChatGPT 준비**: 결과물을 바로 실행해 보여주는 클로드(Claude)나 ChatGPT를 준비합니다.
3.  **주문서 작성 및 입력**: 다음 템플릿을 참고하여 원하는 기능, 모델 ID, 답변 자유도 등을 지정한 후 클로드나 ChatGPT에 입력합니다.
    ```html
    역할: 너는 비개발자도 그대로 따라 할 수 있게 설명하는 친절한 개발 도우미야.
    목표: NVIDIA 무료 AI API로 [원하는 것 — 예: 유튜브 자막 요약기]를 만들어줘.
    연결 정보 (OpenAI 호환):
    - base_url: https://integrate.api.nvidia.com/v1
    - model: [모델 ID — build.nvidia.com 모델 페이지에서 복사, 예: minimaxai/minimax-m3]
    - temperature: [답변 자유도 0~1 — 번역·요약은 0.3, 아이디어·카피는 0.8 권장]
    - API 키는 'YOUR_API_KEY' 자리로 비워두고, 코드에 직접 박지 말고 화면 입력칸에서 받게 해줘
    요구사항:
    1) 복사 한 번이면 바로 돌아가는 HTML 파일 하나로 만들어줘
    2) 비개발자 기준으로, 어디에 붙여넣고 어떻게 여는지 1번부터 순서대로 알려줘
    3) 내 API 키를 정확히 어디에 넣는지 짚어줘
    4) 화면은 깔끔하게 — 입력칸, 실행 버튼, 결과 영역으로 보기 좋게 만들어줘
    5) 에러가 나면 무엇이 문제인지 한국어로 알려주게 해줘
    먼저 완성된 코드를 주고, 그다음에 실행 순서를 알려줘.
    ```
    *   **예시 (유튜브·긴 글 요약기)**:
        ```html
        역할: 너는 비개발자도 그대로 따라 할 수 있게 설명하는 친절한 개발 도우미야.
        목표: NVIDIA 무료 AI API로, 유튜브 자막이나 긴 글을 붙여넣으면 핵심 3줄과 한 줄 결론으로 요약해 주는 도구를 만들어줘.
        연결 정보 (OpenAI 호환):
        - base_url: https://integrate.api.nvidia.com/v1
        - model: minimaxai/minimax-m3
        - API 키는 'YOUR_API_KEY' 자리로 비워두고, 코드에 직접 박지 말고 화면 입력칸에서 받게 해줘
        요구사항:
        1) 복사 한 번이면 바로 돌아가는 HTML 파일 하나로 만들어줘
        2) 비개발자 기준으로, 어디에 붙여넣고 어떻게 여는지 1번부터 순서대로 알려줘
        3) 내 API 키를 정확히 어디에 넣는지 짚어줘
        4) 화면은 깔끔하게 — 글 붙여넣는 입력칸, 요약 버튼, 결과 영역으로 만들어줘
        5) 에러가 나면 무엇이 문제인지 한국어로 알려주게 해줘
        먼저 완성된 코드를 주고, 그다음에 실행 순서를 알려줘.
        ```
4.  **실행 및 API 키 입력**: AI가 생성한 코드와 실행 방법을 따라 HTML 파일을 만들고, `YOUR_API_KEY` 부분에 발급받은 NVIDIA API 키를 입력하여 도구를 실행합니다.

## 활용 예시

*   **직장인**: 회의 메모나 녹취 내용을 붙여넣고 "핵심 3줄 요약 + 결정사항 + 담당자별 할 일 정리 + 팀장 보고용 메일 초안 작성"을 요청하여 5분 만에 보고용 문서를 생성합니다.
*   **자영업자**: 상품 사진 1장을 기반으로 배경 교체, 상세페이지 카피 작성, 해외 판매용 영어 번역까지 일괄 처리하여 판매 페이지 세트를 만듭니다.
*   **콘텐츠 크리에이터**: 주제 한 줄을 입력하여 릴스 후킹 문구, 캐러셀 카드 문구, 표지 이미지, 내레이션 음성까지 릴스 소재 한 세트를 제작합니다.
*   **1인 사업자**: 고객 문의나 후기 텍스트를 입력하면 답변 초안을 뽑아주는 웹 도구를 만들어 CS 응대나 리뷰 답글 작성을 자동화합니다.

## 💡 아이디어

*   **다국어 콘텐츠 제작**: 블로그 글이나 상품 설명을 여러 언어로 동시에 번역하여 글로벌 시장을 공략합니다.
*   **AI 코딩 도구 연동**: Cursor, Cline 등 OpenAI 호환 코딩 도구의 API 설정을 NVIDIA Build로 변경하여 무료로 코딩 보조를 받습니다. (예: Mistral Nemotron, MiniMax 계열 모델 활용)
*   **노코드 자동화 툴 연동**: n8n과 같은 자동화 툴에 NVIDIA 모델을 연결하여 이메일 자동 분류 및 답변 초안 생성, 뉴스 요약, RAG 챗봇 등 반복 업무 파이프라인을 구축합니다.

## 주의사항

*   **속도 제한**: 무료 API는 분당 약 40회 호출이 기본이며, 필요시 사이트에서 무료로 상향 신청(약 200회/분)이 가능합니다. 대량 자동화 시 이 제한을 고려해야 합니다.
*   **데이터 보안**: 무료 엔드포인트는 입력 및 출력 내용이 기록 및 활용될 수 있습니다. 고객 개인정보, 회사 기밀 등 민감한 정보는 입력하지 않는 것이 좋습니다. 완전한 비공개가 필요하다면 자체 서버 설치(self-host) 방식을 고려해야 합니다.
*   **상업적 이용**: 개발, 테스트, 학습, 평가 용도는 무료이지만, 실제 비즈니스 운영(production)에는 NVIDIA AI Enterprise 라이선스(GPU당 연 약 4,500달러 또는 GPU 시간당 약 1달러부터)가 필요합니다.
