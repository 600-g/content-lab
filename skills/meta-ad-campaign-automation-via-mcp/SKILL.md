# 클로드 기반 메타 광고 자동 운영 (MCP 연동) (합병됨)

## 두근컴퍼니 적용

MCP 연동을 통해 광고 운영의 효율성을 극대화하는 핵심 자동화 스킬입니다. **사전 준비물(메타 개발자 앱 설정 및 토큰 확보)이 필수적**이며, 클로드가 광고 계정에 직접 접근하여 작업을 수행하므로, 데이터 보안 및 권한 관리에 특히 유의해야 합니다.
