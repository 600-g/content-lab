# Claude 인스타 콘텐츠 운영

💡 **계정 설정 → 소재 발굴 → 제작(릴스·카드뉴스·캡션) → 성과 분석** 을 Claude 프롬프트로 돌리고, 매일 반복되는 트렌드 수집은 **Claude 예약 작업 + MCP** 로 자동화해 사람은 **주제 선택과 최종 확인**만 합니다.

## 이게 뭔가요?

콘텐츠 제작이 부담스러운 인스타그램 운영자를 위해, 트렌드 조사부터 소재 발굴·릴스 대본·카드뉴스 구성·캡션·성과 분석까지 전 과정을 Claude 로 처리하는 **반복 사용 가능한 운영 시스템**입니다.

두 축으로 이루어집니다.

- **대화형 프롬프트 세트**: 각 단계를 Claude 대화창에서 실행하는 프롬프트 14종. 계정 정보를 한 번 알려준 같은 대화창에서 이어 쓰면 결과가 내 계정에 맞춰집니다.
- **트렌드 자동 수집 파이프라인**: Claude 의 **예약 작업** 기능에 PlayMCP(YouTubeData)·Zapier MCP(구글 시트)·Slack MCP 를 연결해, 매일 아침 유튜브 실시간 트렌드를 수집하고 **댓글 키워드**(사람들이 실제로 궁금해하는 것)와 **인스타 캐러셀 각도**까지 예측해 구글 시트에 쌓습니다. 아침에 슬랙 알림을 확인하면 이미 트렌드가 시트에 정리되어 있고, 고른 주제로 Claude 에 캐러셀을 요청하면 Higgsfield MCP 가 이미지까지 만듭니다.

### 어떤 방법을 언제 쓰나

| 상황 | 쓸 방법 | 필요한 것 |
|---|---|---|
| 처음 시작, 내 계정 방향부터 잡고 싶다 | 1단계 계정 기본 설정 | Claude |
| 가끔 소재가 필요하다 | 2단계-A 대화형 트렌드 리서치 | Claude (웹 검색) |
| 매일 소재를 받아보고 데이터로 누적하고 싶다 | 2단계-B 예약 작업 자동 수집 | Claude 예약 작업 + PlayMCP + Zapier MCP + 구글 시트 + Slack MCP |
| 릴스를 찍는다 | 4단계 오프닝 → 5단계 대본 → 대본 다듬기 | Claude |
| 카드뉴스 글 구성이 필요하다 | 6단계-A 카드뉴스 10장 구성 | Claude |
| 이미지까지 한 번에 뽑고 싶다 | 6단계-B 캐러셀 5장 자동 생성 | Claude + Higgsfield MCP(유료) |
| 꾸준히 발행하는 루틴을 만들고 싶다 | 8단계 체크리스트·캘린더·재활용 | Claude (+ Notion) |
| 반응이 낮았던 이유를 알고 싶다 | 9단계 성과 분석 → 10단계 자가 검수 | Claude |

💰 **유료 필요**: 프롬프트 세트는 Claude Max 같은 유료 도구 사용을 기준으로 합니다. 자동화 파이프라인에서는 Higgsfield MCP(캐러셀 이미지 생성)가 유료, Zapier MCP 는 연동하는 외부 앱·요금제에 따라 비용이 다릅니다.
✅ **무료 대안**: 프롬프트의 원리는 Gemini, ChatGPT 등 다른 AI 에도 그대로 적용됩니다. 자동화는 **PlayMCP 만으로 1·2단계(수집·정리)가 충분**하며, Apify 는 더 깊은 데이터 수집이 필요할 때만 추가합니다. 다만 캐러셀 이미지 생성 등 일부 기능은 유료 도구 의존도가 높습니다.

## 따라하기

### 1단계. 계정 기본 설정

AI 에게 계정·상품 정보를 충분히 알려줘야 이후 모든 기획이 맞춤형이 됩니다. 이 프롬프트를 먼저 넣고, **같은 대화창**에서 나머지 프롬프트를 이어서 씁니다.

```
지금부터 너는 내 인스타그램 콘텐츠 전략가이자 카피라이터야.
아래 내용을 바탕으로 앞으로 내 콘텐츠를 기획해줘.
1. 내가 다루는 주제:
[주제와 전문 분야]
2. 주요 타겟:
[나이, 직업, 현재 상황, 고민]
3. 타겟이 가장 자주 겪는 문제:
[타겟의 대표 고민 3~5가지]
4. 내가 제공하는 해결 방법:
[강의, 프로그램, 서비스, 상품]
5. 현재 판매하거나 운영하는 상품:
[상품명, 가격, 진행 방식, 기간]
6. 내가 보여주고 싶은 이미지:
[전문적, 친근한, 솔직한, 따뜻한, 유쾌한 등]
7. 내가 피하고 싶은 표현:
[과장된 표현, 어려운 전문용어, 공격적인 판매 문구 등]
8. 콘텐츠의 최종 목표:
[팔로우, 저장, 공유, 댓글, 프로필 방문, 강의 신청 등]
앞으로 콘텐츠를 제안할 때는 단순히 조회수가 잘 나올 만한 주제만 제시하지 말고,
내 전문성과 상품으로 자연스럽게 연결될 수 있는 방향을 우선으로 생각해줘.
내 타겟이 실제로 사용하는 쉬운 표현을 사용하고,
추상적인 설명보다는 바로 콘텐츠로 만들 수 있을 정도로 구체적으로 작성해줘.
위 내용을 이해했다면 내 계정의 핵심 포지셔닝을 한 문장으로 정리하고,
앞으로 콘텐츠를 기획할 때 지켜야 할 원칙 5가지를 알려줘.
```

결과로 나온 **포지셔닝 한 문장**과 **원칙 5가지**는 따로 저장해 두고, 2단계-B 자동화의 `[내 분야 키워드]` 와 캐러셀 각도 판단 기준으로도 씁니다.

### 2단계. 트렌드와 콘텐츠 소재 찾기

#### 2-A. 대화형 트렌드 리서치 (필요할 때마다)

내 분야에서 새로운 각도의 소재를 웹 검색으로 발굴합니다.

```
나는 [주제 설명]으로 콘텐츠를 운영하는 크리에이터야.
주요 타겟은 [타겟 설명]이고,
현재 [프로그램 또는 상품 설명]을 운영하고 있어.
이 분야에서 최근 화제가 되고 있는 콘텐츠 흐름을 웹 검색을 통해 조사해줘.
다음 내용을 포함해서 정리해줘.
1. 최근 사람들이 많이 관심을 갖는 주제 5개
2. 사람들이 반복해서 질문하거나 어려워하는 문제 5개
3. 이미 많이 다뤄져서 식상해진 콘텐츠
4. 아직 충분히 다뤄지지 않은 새로운 각도
5. 내가 지금 놓치고 있을 가능성이 높은 소재
6. 내가 운영하는 프로그램이나 상품과 자연스럽게 연결할 수 있는 콘텐츠 소재 5개
각 콘텐츠 소재는 아래 형식으로 작성해줘.
- 콘텐츠 제목
- 타겟이 이 콘텐츠를 봐야 하는 이유
- 첫 문장 또는 첫 장 후킹 문구
- 핵심 내용 3가지
- 추천 형식: 릴스 / 카드뉴스 / 스토리 / 라이브
- 내 프로그램과 연결하는 방법
- 추천 CTA
너무 일반적인 아이디어는 제외하고,
사람들이 저장하거나 공유할 만큼 실용적인 소재를 우선으로 제안해줘.
```

#### 2-B. 예약 작업으로 매일 유튜브 트렌드 자동 수집

**준비물 세팅** — Claude 에 외부 기능을 꽂는 '콘센트' 들입니다.

| 도구 | 역할 | 비용 |
|---|---|---|
| **Claude 예약 작업** | 매일 정해진 시각에 자동 실행 | 구독에 포함 |
| **PlayMCP (YouTubeData)** | 유튜브 검색·조회수·댓글 조회 | 무료 |
| **Apify MCP** | 유튜브 대량 수집 (선택) | 무료 크레딧 |
| **Google Sheets** | 결과 정리 — Zapier MCP 를 통해 연결 | 무료 |
| **Zapier MCP** | 구글 시트 등 외부 앱을 Claude 에 연결 | Zapier 요금제에 따름 |
| **Slack MCP** | 완료 알림 | 무료 |
| **Higgsfield MCP** | 캐러셀 이미지 생성 (6단계-B) | 유료 |

**① 시트 구조화 (가장 중요)**

이 단계를 건너뛰면 AI 가 매일 다른 형식으로 데이터를 채워 넣습니다. 구글 스프레드시트를 미리 만들고 **첫 행에 아래 컬럼을 정확히** 박아 둡니다.

```
수집일 | 제목 | 채널 | 조회수 | 좋아요 | 댓글수 | 업로드일 | 링크 | 댓글 키워드 | 캐러셀 각도
```

- **댓글 키워드**: 영상 댓글에서 사람들이 반복해서 묻는 핵심 질문을 요약합니다.
- **캐러셀 각도**: 이 주제를 내 계정의 인스타 캐러셀로 바꾼다면 어떤 각도(관점)가 좋을지 예측합니다.
- 이 두 필드가 시스템의 진짜 가치입니다. 조회수 데이터는 누구나 볼 수 있지만, "사람들이 묻는 것"과 "내 계정용 각도"는 바로 기획으로 이어집니다.

**② 예약 작업 만들기 (수집 + 정리 한 번에)**

Claude 예약 작업을 **매일 오전 9시**로 만들고 아래 프롬프트를 그대로 붙여넣습니다. 검색 → 댓글 읽기 → 시트 정리 → 슬랙 알림 4가지를 순서대로 수행합니다.

```
[내 분야 키워드]로 유튜브 트렌드를 조사해서 시트에 정리하고 슬랙으로 알려줘.
1) 검색
- YouTubeData의 search_videos 로 위 키워드를 검색 (order는 viewCount)
- get_video_details 로 각 영상의 업로드일·조회수·좋아요·댓글수를 확인
- 업로드일이 7일보다 오래된 것은 제외
- 남은 것 중 조회수 상위 10개만 남길 것
2) 댓글 읽기
- 상위 10개 각각 get_video_comments 로 댓글을 읽고
- 사람들이 반복해서 묻는 것을 한 줄로 요약
3) 시트 정리
- 구글 시트 "[시트 이름]" 의 "[탭 이름]" 맨 아래에 추가
- 컬럼 순서: 수집일 / 제목 / 채널 / 조회수 / 좋아요 / 댓글수 / 업로드일 / 링크 / 댓글 키워드 / 캐러셀 각도
- 수집일은 오늘 날짜
- 캐러셀 각도는 그 주제를 인스타 캐러셀로 바꿀 때의 각도를 한 줄로
- 기존 행은 절대 덮어쓰지 말 것
4) 슬랙 알림
- "[채널명]" 채널에 보낼 것
- 오늘 수집한 개수
- 조회수 1~3위의 제목과 조회수
- 시트 링크
```

**대괄호 안만 수정합니다.**

| 수정할 부분 | 예시 | 설명 |
|---|---|---|
| [내 분야 키워드] | AI 자동화, 노코드 창업, 인스타 마케팅 | 분석하고 싶은 핵심 키워드 쉼표로 구분 |
| [시트 이름] | 유튜브 트렌드 수집 | 실제 구글 시트의 이름 |
| [탭 이름] | 2026 | 시트 내의 특정 탭 이름 |
| [채널명] | #콘텐츠-트렌드 | 슬랙 채널 이름 |

🚨 **"기존 행은 절대 덮어쓰지 말 것"** 문구는 반드시 남겨 둡니다. 이 지시가 없으면 매일 데이터가 덮어쓰여 누적 분석이 불가능해집니다.

**③ 첫 실행 점검**: 예약 시각을 기다리지 말고 한 번 수동 실행해 시트 컬럼 순서·행 추가 위치·슬랙 알림 내용이 맞는지 확인한 뒤 매일 실행을 켭니다.

**④ 주제 고르기 (사람이 할 유일한 지점)**: 시트를 조회수 순으로 정렬하고, 내 브랜드 톤앤매너와 1단계의 포지셔닝에 가장 맞는 주제를 사람이 고릅니다. 고른 주제는 3단계(각도) → 4~6단계(제작)로 넘기거나, 바로 6단계-B 로 캐러셀을 만듭니다.

### 3단계. 남들과 다른 콘텐츠 각도 찾기

같은 주제라도 차별화된 관점으로 반응을 높입니다.

```
내가 만들 콘텐츠의 주제는 [주제]야.
이 주제와 관련해 인스타그램에서 흔히 볼 수 있는 뻔한 콘텐츠 방향을 먼저 정리해줘.
그다음 아래 관점으로 새로운 콘텐츠 각도 10개를 제안해줘.
- 사람들이 잘못 알고 있는 상식
- 초보자가 자주 하는 실수
- 직접 해본 사람만 알 수 있는 현실
- 시간이나 비용을 줄이는 방법
- 실패 경험에서 얻은 교훈
- 사람들이 말하지 않는 불편한 진실
- 기존 방법과 반대되는 접근
- 전과 후의 변화
- 숫자로 보여줄 수 있는 결과
- 내 프로그램이나 상품으로 연결할 수 있는 문제
각 아이디어에는 다음 내용을 포함해줘.
1. 콘텐츠 제목
2. 핵심 메시지
3. 타겟이 궁금해할 이유
4. 콘텐츠 형식
5. 내 경험이나 사례를 넣을 위치
6. 자연스러운 CTA
단순히 자극적인 제목만 제안하지 말고,
실제 내용까지 충분히 채울 수 있는 아이디어만 골라줘.
```

### 4단계. 시선을 잡는 오프닝 멘트 10개

릴스·카드뉴스의 첫인상을 결정하는 오프닝 멘트를 만듭니다.


## 활용 예시

### 1. 계정 설정 후 소재 발굴

1. 1단계 프롬프트에 계정 정보(주제, 타겟, 상품 등)를 넣어 Claude 에 제공합니다.
2. Claude 가 만든 포지셔닝 문장과 운영 원칙을 확인합니다.
3. 같은 대화창에 2-A 트렌드 리서치 프롬프트를 넣어, 계정 정보 기반의 최신 트렌드와 소재 5개를 받습니다. 각 소재에는 제목, 필요 이유, 후킹 문구, 핵심 내용, 형식, 상품 연결 방법, CTA 가 포함됩니다.

### 2. 릴스 대본 작성과 다듬기

1. 5-A 프롬프트에 주제, 타겟, 목표 행동을 넣어 20~30초 대본 초안을 만듭니다.
2. 자막, 화면 구성, 강조 단어, 썸네일 문구, 캡션 첫 문장, CTA 등 부가 요소를 확인합니다.
3. 5-B 프롬프트에 초안을 붙여넣어 말하듯 다듬고, 15초 버전·자막용 버전도 받습니다.

### 3. 카드뉴스 구성과 캡션

1. 6-A 프롬프트로 10장 구성(각 장의 역할, 메인/보조 문구, 이미지 요소, 연결 문장)을 받습니다.
2. 카드뉴스 내용을 7-A 캡션 프롬프트에 붙여넣고 타겟·목표를 명시해 캡션 초안을 만듭니다.
3. 캡션 첫 문장 5개, 댓글/저장/공유 유도 CTA 각 3개, 프로그램 연결 문장 3개를 함께 받습니다.

### 4. 트렌드 자동 수집 → 캐러셀 (인스타 마케팅 분야)

1. **오전 9시 자동 실행**: 예약 작업이 'AI 자동화' 키워드로 유튜브 트렌드를 수집하고 시트에 '댓글 키워드'와 '캐러셀 각도'를 채웁니다. 슬랙으로 '오늘 12개 수집 완료. 1위: [제목] (42만)' 같은 알림이 옵니다.
2. **분석 및 선택**: 시트를 열어 조회수 1위 주제를 확인하고, 채널 방향성과 맞는지 판단해 **행 번호 5** 를 고릅니다.
3. **콘텐츠 생성**: Claude 에 6-B 프롬프트의 `[행 번호]` 를 5 로 바꿔 넣으면 캐러셀 5장이 생성됩니다.
4. **마무리**: 7-A 로 캡션을 붙이고, 10단계 검수 후 업로드합니다.

## 주의사항

- **같은 대화창 유지**: 1단계 계정 설정을 넣은 대화에서 이어 써야 이후 프롬프트가 내 계정 맞춤으로 나옵니다. 새 대화를 열면 1단계를 다시 넣습니다.
- **시트 구조화를 건너뛰지 말 것**: 컬럼이 고정되지 않으면 AI 가 매일 다른 형식으로 채웁니다.
- **덮어쓰기 금지 문구 필수**: 예약 작업 프롬프트의 "기존 행은 절대 덮어쓰지 말 것" 이 빠지면 누적 데이터가 사라집니다.
- **수집 개수 표기**: 예약 작업 프롬프트는 조회수 상위 10개만 남기도록 지시하지만, 원문 예시 알림에는 '12개 수집' 으로 나옵니다. 실제 수집 개수는 알림의 '오늘 수집한 개수' 로 확인하고, 10개를 넘으면 프롬프트 조건이 지켜지는지 점검하세요.
- **주제 선택은 자동화하지 않는다**: 조회수가 높다고 내 톤앤매너에 맞는 것은 아닙니다. 사람이 고르는 단계가 브랜드를 지킵니다.
- **과장 금지**: 오프닝·CTA 프롬프트가 요구하듯, 본문에서 실제로 설명할 수 없는 문장이나 불안감을 유발하는 표현은 쓰지 않습니다.
