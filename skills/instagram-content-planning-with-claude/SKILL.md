# Claude로 인스타 콘텐츠 기획하기

💡 Claude를 활용하여 **인스타그램 콘텐츠 기획, 제작, 분석** 전 과정을 효율화하는 스킬입니다.

## 이게 뭔가요?
콘텐츠 제작에 부담을 느끼는 인스타그램 운영자들을 위해 Claude AI를 활용하여 트렌드 조사부터 소재 발굴, 릴스 대본 작성, 카드뉴스 구성, 캡션 작성, 성과 분석까지 전 과정을 효율적으로 진행할 수 있도록 돕는 프롬프트 모음입니다. 반복해서 사용할 수 있는 운영 시스템 구축을 목표로 합니다.

이 자료는 Claude Max와 같은 유료 AI 도구를 활용하는 것을 기반으로 하지만, 각 프롬프트의 핵심 원리를 이해하면 다른 AI 도구(예: Gemini, ChatGPT)에도 적용할 수 있는 무료 대안을 모색할 수 있습니다.

## 따라하기
### 0. 계정 기본 설정

AI에게 계정 및 상품 정보를 충분히 알려주어 맞춤형 콘텐츠 기획을 유도합니다.

```
지금부터 너는 내 인스타그램 콘텐츠 전략가이자 카피라이터야.
아래 내용을 바탕으로 앞으로 내 콘텐츠를 기획해줘.
1. 내가 다루는 주제:
[주제와 전문 분야]
2. 주요 타겟:
[나이, 직업, 현재 상황, 고민]
3. 타겟이 가장 자주 겪는 문제:
[타겟의 대표 고민 3~5가지]
4. 내가 제공하는 해결 방법:
[강의, 프로그램, 서비스, 상품]
5. 현재 판매하거나 운영하는 상품:
[상품명, 가격, 진행 방식, 기간]
6. 내가 보여주고 싶은 이미지:
[전문적, 친근한, 솔직한, 따뜻한, 유쾌한 등]
7. 내가 피하고 싶은 표현:
[과장된 표현, 어려운 전문용어, 공격적인 판매 문구 등]
8. 콘텐츠의 최종 목표:
[팔로우, 저장, 공유, 댓글, 프로필 방문, 강의 신청 등]
앞으로 콘텐츠를 제안할 때는 단순히 조회수가 잘 나올 만한 주제만 제시하지 말고,
내 전문성과 상품으로 자연스럽게 연결될 수 있는 방향을 우선으로 생각해줘.
내 타겟이 실제로 사용하는 쉬운 표현을 사용하고,
추상적인 설명보다는 바로 콘텐츠로 만들 수 있을 정도로 구체적으로 작성해줘.
위 내용을 이해했다면 내 계정의 핵심 포지셔닝을 한 문장으로 정리하고,
앞으로 콘텐츠를 기획할 때 지켜야 할 원칙 5가지를 알려줘.
```

### 1. 최근 트렌드와 콘텐츠 소재 찾기

내 분야에 맞는 새로운 각도의 콘텐츠 소재를 발굴합니다.

```
나는 [주제 설명]으로 콘텐츠를 운영하는 크리에이터야.
주요 타겟은 [타겟 설명]이고,
현재 [프로그램 또는 상품 설명]을 운영하고 있어.
이 분야에서 최근 화제가 되고 있는 콘텐츠 흐름을 웹 검색을 통해 조사해줘.
다음 내용을 포함해서 정리해줘.
1. 최근 사람들이 많이 관심을 갖는 주제 5개
2. 사람들이 반복해서 질문하거나 어려워하는 문제 5개
3. 이미 많이 다뤄져서 식상해진 콘텐츠
4. 아직 충분히 다뤄지지 않은 새로운 각도
5. 내가 지금 놓치고 있을 가능성이 높은 소재
6. 내가 운영하는 프로그램이나 상품과 자연스럽게 연결할 수 있는 콘텐츠 소재 5개
각 콘텐츠 소재는 아래 형식으로 작성해줘.
- 콘텐츠 제목
- 타겟이 이 콘텐츠를 봐야 하는 이유
- 첫 문장 또는 첫 장 후킹 문구
- 핵심 내용 3가지
- 추천 형식: 릴스 / 카드뉴스 / 스토리 / 라이브
- 내 프로그램과 연결하는 방법
- 추천 CTA
너무 일반적인 아이디어는 제외하고,
사람들이 저장하거나 공유할 만큼 실용적인 소재를 우선으로 제안해줘.
```

### 2. 남들과 다른 콘텐츠 각도 찾기

같은 주제라도 차별화된 관점으로 콘텐츠의 반응을 높입니다.

```
내가 만들 콘텐츠의 주제는 [주제]야.
이 주제와 관련해 인스타그램에서 흔히 볼 수 있는 뻔한 콘텐츠 방향을 먼저 정리해줘.
그다음 아래 관점으로 새로운 콘텐츠 각도 10개를 제안해줘.
- 사람들이 잘못 알고 있는 상식
- 초보자가 자주 하는 실수
- 직접 해본 사람만 알 수 있는 현실
- 시간이나 비용을 줄이는 방법
- 실패 경험에서 얻은 교훈
- 사람들이 말하지 않는 불편한 진실
- 기존 방법과 반대되는 접근
- 전과 후의 변화
- 숫자로 보여줄 수 있는 결과
- 내 프로그램이나 상품으로 연결할 수 있는 문제
각 아이디어에는 다음 내용을 포함해줘.
1. 콘텐츠 제목
2. 핵심 메시지
3. 타겟이 궁금해할 이유
4. 콘텐츠 형식
5. 내 경험이나 사례를 넣을 위치
6. 자연스러운 CTA
단순히 자극적인 제목만 제안하지 말고,
실제 내용까지 충분히 채울 수 있는 아이디어만 골라줘.
```

### 3. 시선을 잡는 오프닝 멘트 10개 만들기

릴스 및 카드뉴스의 첫인상을 결정하는 강력한 오프닝 멘트를 생성합니다.

```
내가 만들 콘텐츠의 주제는 [주제]야.
타겟은 [타겟]이고,
이 콘텐츠를 본 뒤 [원하는 행동: 저장, 공유, 댓글, 프로필 방문, 강의 신청 등]을 하게 만들고 싶어.
이 주제에 어울리는 오프닝 멘트 10개를 만들어줘.
각 문장은 처음 2초 안에 시선을 끌 수 있도록 짧고 강하게 작성해줘.
다음 감정 트리거를 각각 활용해줘.
1. 호기심
2. 공감
3. 반박
4. 실수 지적
5. 숫자 충격
6. 의외성
7. 손해 회피
8. 결과 제시
9. 비교
10. 질문
각 문장 옆에는 어떤 감정 트리거를 사용했는지 표시해줘.
과장되거나 사실이 아닌 표현은 사용하지 말고,
본문에서 실제로 설명할 수 있는 문장만 작성해줘.
마지막에는 가장 반응이 좋을 것으로 예상되는 문장 3개를 선정하고,
선정 이유도 알려줘.
```

### 4. 20~30초 릴스 대본 만들기

하나의 명확한 메시지를 전달하는 20-30초 분량의 릴스 대본을 작성합니다.

```
[주제]에 대한 인스타그램 릴스 대본을 작성해줘.
타겟은 [타겟 설명]이고,
이 콘텐츠를 본 뒤 [원하는 행동]을 하게 만들고 싶어.
영상 길이는 20~30초야.
대본은 다음 구조로 작성해줘.
1. 0~2초: 시선을 잡는 강한 첫 문장
2. 3~7초: 타겟이 겪는 문제 또는 공감 상황
3. 8~18초: 문제를 해결하는 핵심 정보
4. 19~24초: 내가 직접 경험한 사례 또는 결과
5. 25~30초: 부담스럽지 않은 CTA
말투는 실제로 카메라 앞에서 말하기 편하도록
짧고 자연스러운 구어체로 작성해줘.
한 문장이 너무 길지 않게 하고,
불필요한 인사말이나 서론은 빼줘.
대본이 완성되면 다음 내용도 함께 작성해줘.
- 화면에 넣을 자막
- 장면별 추천 화면
- 강조해야 할 단어
- 영상 제목
- 썸네일 문구 3개
- 캡션 첫 문장
- 추천 CTA 3개
마지막에는 사람들이 이탈할 가능성이 높은 부분을 스스로 점검하고,
더 빠르고 몰입감 있게 수정한 최종본도 보여줘.
```

### 5. 릴스 대본을 더 자연스럽게 다듬기

AI가 생성한 대본을 실제 사람이 말하는 것처럼 자연스럽고 간결하게 수정합니다.

```
아래 릴스 대본을 실제 사람이 카메라 앞에서 말하는 것처럼 자연스럽게 다듬어줘.
[작성한 대본 붙여넣기]
수정할 때 다음 기준을 지켜줘.
- 한 문장을 짧게 나눌 것
- 글말보다 말하듯이 작성할 것
- 어려운 단어를 쉬운 표현으로 바꿀 것
- 같은 의미가 반복되는 부분을 삭제할 것
- 첫 2초 안에 핵심을 보여줄 것
- 중간에 시청자가 이탈하지 않도록 궁금증을 남길 것
- 마지막 CTA가 갑작스럽지 않게 연결되도록 할 것
- 전체 길이는 20~30초 이내로 유지할 것
수정 후에는 다음 순서로 보여줘.
1. 수정 전 문제점
2. 수정된 최종 대본
3. 더 짧은 15초 버전
4. 자막용으로 문장을 짧게 나눈 버전
```

### 6. 카드뉴스 10장 구성 만들기

하나의 메시지를 담는 카드뉴스 10장 구성을 설계합니다.

```
[주제]에 대한 인스타그램 카드뉴스 10장 구성을 만들어줘.
타겟은 [타겟 설명]이고,
콘텐츠의 목표는 [저장, 공유, 댓글, 프로필 방문, 강의 신청 등]이야.
전체 흐름은 다음 구조를 따라줘.
1장: 결과나 문제를 보여주는 강한 표지
2장: 표지를 본 사람이 계속 읽어야 하는 이유
3장: 타겟이 겪는 구체적인 고민
4장: 사람들이 흔히 하는 실수
5장: 핵심 해결 방법 1
6장: 핵심 해결 방법 2
7장: 핵심 해결 방법 3
8장: 실제 사례, 결과 또는 변화
9장: 핵심 내용 요약
10장: 댓글, 저장, 공유 또는 프로그램 안내 CTA
각 장마다 아래 내용을 작성해줘.
- 페이지의 역할
- 메인 문구
- 보조 문구
- 강조할 단어
- 추천 이미지 또는 간단한 그림 요소
- 다음 장을 넘기게 만드는 연결 문장
한 장에 들어가는 문장은 최대 2~4문장으로 제한하고,
모바일 화면에서 읽기 쉽도록 짧게 작성해줘.
내용이 비슷한 페이지는 합치고,
중간에 흐름이 끊기거나 지루해질 만한 부분을 찾아 수정해줘.
마지막에는 카드뉴스 전체 제목 5개와
표지 문구 5개를 추가로 제안해줘.
```

### 7. 매주 콘텐츠를 만드는 체크리스트 만들기

콘텐츠 기획부터 발행, 분석까지 매주 반복 사용할 수 있는 체크리스트를 생성합니다.

```
내가 매주 릴스 3개와 카드뉴스 2개를 꾸준히 만들 수 있도록,
콘텐츠 하나를 기획부터 발행까지 완성하는 체크리스트를 만들어줘.
내 콘텐츠 주제는 [주제]이고,
타겟은 [타겟]이야.
체크리스트에는 다음 단계를 포함해줘.
1. 주제 선정
2. 타겟의 고민 확인
3. 콘텐츠의 목표 결정
4. 오프닝 문장 작성
5. 핵심 내용 정리
6. 대본 또는 카드뉴스 구성 작성
7. 이미지 프롬프트 작성
8. 촬영 또는 이미지 제작
9. 자막 작성
10. 캡션 작성
11. CTA 작성
12. 업로드 전 검수
13. 발행 후 댓글 관리
14. 성과 기록
15. 다음 콘텐츠 개선점 정리
각 항목을 실제로 체크할 수 있도록
Notion 체크박스 형태로 만들어줘.
추가로 아래 자료도 만들어줘.
- 월요일부터 금요일까지의 추천 작업 일정
- 하루 1시간만 사용할 때의 압축 일정
- 콘텐츠 한 편을 여러 콘텐츠로 재활용하는 방법
- 매주 기록해야 할 성과 지표
- 다음 주 콘텐츠에 반영할 회고 질문
내가 매주 복사해서 사용할 수 있는 템플릿 형태로 작성해줘.
```

### 8. 일주일 콘텐츠 캘린더 만들기

다양한 유형의 콘텐츠를 균형 있게 배치한 주간 콘텐츠 캘린더를 생성합니다.

```
나는 매주 릴스 3개와 카드뉴스 2개를 발행하고 싶어.
내 주제는 [주제]이고,
타겟은 [타겟 설명]이야.
현재 연결하고 싶은 상품이나 프로그램은 [상품 설명]이야.
월요일부터 금요일까지 콘텐츠 캘린더를 만들어줘.
콘텐츠가 모두 판매 이야기로 느껴지지 않도록 아래 비율을 적용해줘.
- 공감 콘텐츠 20%
- 정보 콘텐츠 40%
- 경험과 사례 콘텐츠 20%
- 상품 연결 콘텐츠 20%
각 콘텐츠는 아래 형식으로 정리해줘.
- 발행 요일
- 콘텐츠 형식
- 콘텐츠 주제
- 오프닝 문장
- 핵심 내용
- 내 경험이나 사례
- CTA
- 연결할 상품
- 촬영하거나 제작해야 할 자료
5개의 콘텐츠가 서로 비슷하지 않게 구성하고,
한 주 동안 하나의 큰 이야기처럼 자연스럽게 이어지게 만들어줘.
```

### 9. 캡션 작성하기

시선을 끄는 첫 문장부터 명확한 CTA까지 포함된 인스타그램 캡션을 작성합니다.

```
아래 콘텐츠를 바탕으로 인스타그램 캡션을 작성해줘.
콘텐츠 내용:
[릴스 대본 또는 카드뉴스 내용 붙여넣기]
타겟:
[타겟 설명]
캡션의 목표:
[저장, 공유, 댓글, 프로필 방문, 강의 신청 등]
캡션은 다음 구조로 작성해줘.
1. 첫 두 줄에 시선을 끄는 문장
2. 타겟이 겪는 문제에 대한 공감
3. 콘텐츠에서 꼭 기억해야 할 핵심 내용
4. 내 경험이나 생각
5. 독자가 바로 실행할 수 있는 작은 행동
6. 부담스럽지 않은 CTA
본문을 너무 길게 늘이지 말고,
한 문단을 1~3문장으로 나눠 모바일에서 읽기 쉽게 작성해줘.
추가로 다음 내용도 만들어줘.
- 캡션 첫 문장 5개
- 댓글을 유도하는 질문 3개
- 저장을 유도하는 CTA 3개
- 공유를 유도하는 CTA 3개
- 프로그램으로 자연스럽게 연결하는 문장 3개
```

### 10. 댓글 키워드 CTA 만들기

무료 자료 제공 등 특정 행동을 유도하는 구체적인 댓글 CTA 문구를 생성합니다.

```
내가 제공할 무료 자료는 [자료 설명]이야.
이 자료를 받고 싶은 사람들이 댓글에 [댓글 키워드]를 남기도록 유도하는 CTA 문구를 만들어줘.
다음 버전으로 각각 3개씩 작성해줘.
1. 친근한 버전
2. 전문적인 버전
3. 결과를 강조하는 버전
4. 궁금증을 만드는 버전
5. 부담 없이 참여하게 만드는 버전
문구에는 다음 내용이 자연스럽게 포함되어야 해.
- 어떤 자료를 받을 수 있는지
- 누구에게 필요한 자료인지
- 댓글에 남길 키워드
- 자료를 받으면 무엇이 쉬워지는지
과도하게 재촉하거나 불안감을 유발하는 표현은 빼줘.
```

### 11. 콘텐츠를 여러 개로 재활용하기

하나의 원본 콘텐츠를 다양한 형식의 인스타그램 콘텐츠로 재구성합니다.

```
아래 콘텐츠 하나를 여러 형태의 인스타그램 콘텐츠로 재구성해줘.
원본 콘텐츠:
[기존 게시물, 블로그 글, 강의 내용, 영상 대본 붙여넣기]
이 내용을 다음 형식으로 각각 변환해줘.
1. 20초 릴스 대본
2. 카드뉴스 10장
3. 인스타그램 캡션
4. 스토리 5장
5. 댓글을 유도하는 질문
6. 짧은 정보형 게시물
7. 경험담 중심 게시물
8. 상품으로 연결되는 게시물
단순히 문장을 짧게 자르지 말고,
각 콘텐츠 형식에 맞게 오프닝과 흐름을 새롭게 구성해줘.
모든 콘텐츠가 똑같아 보이지 않도록
각각 다른 관점과 감정 트리거를 사용해줘.
```

### 12. 성과가 낮았던 콘텐츠 분석하기

콘텐츠 성과 데이터를 기반으로 잘된 점과 개선점을 분석하고 다음 콘텐츠 기획에 반영합니다.

- 새로운 오프닝 문장 5개
- 더 구체적인 콘텐츠 각도 3개
- 수정된 콘텐츠 구성

### 13. AI가 준 답변을 스스로 검수하게 하는 마지막 프롬프트

AI의 답변을 전문가 관점에서 최종 검수하고, 개선점을 반영하여 완성도를 높입니다.

```
방금 작성한 콘텐츠를 인스타그램 전문 콘텐츠 디렉터의 관점에서 다시 검수해줘.
다음 항목을 각각 10점 만점으로 평가해줘.
- 첫 문장의 주목도
- 타겟과의 관련성
- 내용의 구체성
- 이해하기 쉬운 정도
- 저장하고 싶은 정도
- 공유하고 싶은 정도
- 끝까지 읽게 만드는 흐름
- CTA의 자연스러움
- 내 전문성이 드러나는 정도
- 내 상품과의 연결성
7점 이하인 항목은 문제점을 구체적으로 설명하고,
수정된 문장이나 구성을 제안해줘.
추상적이거나 어디서나 볼 수 있는 표현은 삭제하고,
내 경험, 사례, 숫자, 과정이 들어갈 수 있는 위치를 표시해줘.
마지막에는 수정사항을 모두 반영한 최종본을 다시 작성해줘.
```

## 활용 예시
### 1. 계정 정보 설정 후 콘텐츠 소재 발굴

1.  **계정 기본 설정 프롬프트**에 자신의 계정 정보(주제, 타겟, 상품 등)를 입력하여 Claude에게 제공합니다.
2.  Claude가 생성한 계정 포지셔닝 문장과 운영 원칙을 확인합니다.
3.  이후 **트렌드 리서치 프롬프트**를 같은 대화창에 입력하고, 계정 정보를 기반으로 최신 트렌드와 콘텐츠 소재 5개를 추천받습니다. 각 소재는 제목, 필요 이유, 후킹 문구, 핵심 내용, 형식, 상품 연결 방법, CTA를 포함합니다.

### 2. 릴스 대본 작성 및 자연스러운 수정

1.  **릴스 스크립트 프롬프트**에 콘텐츠 주제, 타겟, 목표 행동을 입력하여 20-30초 분량의 대본 초안을 생성합니다.
2.  생성된 대본과 함께 자막, 화면 구성, 강조 단어, 썸네일 문구, 캡션 첫 문장, CTA 등 부가 요소를 확인합니다.
3.  **대본 수정 프롬프트**에 초안 대본을 붙여넣고, 실제 말하는 것처럼 자연스럽게 다듬어 달라고 요청합니다. 15초 버전, 자막용 버전 등 추가 요청도 가능합니다.

### 3. 카드뉴스 구성 및 캡션 작성

1.  **카드뉴스 구성 프롬프트**에 주제, 타겟, 목표를 입력하여 10장 분량의 카드뉴스 구성을 받습니다. 각 장의 역할, 메인/보조 문구, 이미지 요소, 연결 문장 등을 확인합니다.
2.  카드뉴스 내용을 **인스타그램 캡션 프롬프트**에 붙여넣고, 타겟과 목표를 명시하여 캡션 초안을 생성합니다.
3.  캡션 초안과 함께 캡션 첫 문장 5개, 댓글/저장/공유 유도 CTA 3개씩, 프로그램 연결 문장 3개를 추가로 받습니다.
