# 클로드코드 한도 300% 활용법 (합병됨)

## 이게 뭔가요?

2026년 5월 13일부터 7월 13일까지(PDT 기준 7/13 18:00 만료) **클로드 코드(Claude Code)**의 주간 사용 한도가 50% 자동 인상되었습니다. Anthropic-SpaceX 컴퓨트 딜 체결과 사용자 이탈 방어가 배경으로 언급되며, 이번이 누적 세 번째 인상입니다: ① 5시간 한도 2배 → ② 피크 시간대 한도 제거 → ③ 주간 한도 50% 추가 인상.

적용 대상은 **Pro · Max · Team · Enterprise** 플랜이며 Free 플랜은 제외됩니다. 별도 신청 없이 자동 적용되고, `/usage` 명령어로 즉시 세션/주간 잔량을 확인할 수 있습니다.

이 스킬은 늘어난 한도를 그냥 1.5배 쓰는 데 그치지 않고, 토큰 절약 명령어·CLAUDE.md 룰북·서브에이전트 위임·autocompact 설정을 조합해 체감 작업량을 300%까지 끌어올리는 실전 패턴을 정리합니다. 특히 서브에이전트를 활용한 컨텍스트 보호와 병렬 작업 최적화는 한도 인상 기간이 끝난 뒤에도 그대로 유효한 상시 운영 패턴입니다.

## 따라하기

### 1. 한도 확인 및 토큰 절약 명령어 3종 습관화

작업 단계마다 아래 명령어를 사용하세요.

```
/usage
```
- 사용 시점: 작업 전후
- 효과: 세션/주간 사용량(%) 및 리셋 시간 한눈에 파악

```
/compact
```
- 사용 시점: 긴 작업 도중
- 효과: 채팅 요약 진행 → 오래된 데이터 드롭 (스레드 문맥은 유지)

```
/clear
```
- 사용 시점: 작업 전환 시
- 효과: 완전히 깨끗한 세션 시작 → 이전 디버깅 로그의 불필요한 토큰 낭비 차단

### 2. CLAUDE.md 룰북 템플릿 적용

프로젝트 루트 또는 `~/.claude/CLAUDE.md` 에 아래 내용을 그대로 저장하세요. 클로드가 매 요청마다 이 규칙을 먼저 읽어 불필요한 출력 토큰을 줄여줍니다.

```markdown
# Response Style
- 응답은 간결하게 작성하며, 불필요한 서문이나 요약은 금지합니다.
- 한 줄로 끝날 수 있는 답변은 한 줄로만 출력하세요.
- 코드만 요청한 경우, 코드에 대한 부연 설명은 생략하세요.

# Output Limits
- Bash output이 길 경우 `head`, `tail`, `jq` 등을 활용해 잘라서 보여주세요.
- 테스트 로그는 마지막 20줄만 분석하세요.

# Workflow
- 대규모 조사 및 분석 작업은 서브에이전트(Sub-agent)에 위임하세요.
- 메인 컨텍스트는 작업의 지휘 및 검토 역할만 수행하세요.
```

⚠️ 참고: 토큰 절감 효과는 진행 중인 프로젝트 규모와 작업 패턴에 따라 달라질 수 있습니다.

### 3. 서브에이전트 패턴 적용

메인 컨텍스트 오염을 막고 병렬 처리를 극대화하려면 아래 원칙을 따르세요.

**기본 원칙**
- 격리 작업: 서브에이전트는 격리된 컨텍스트에서 작업합니다.
- 결과만 반환: 작업 진행 과정은 숨기고 최종 결과만 메인으로 반환하여 메인 컨텍스트를 보호합니다.
- 병렬 저장: 3개 이상 병렬 작업 시, 각 결과를 파일로 개별 저장하고 메인은 '파일 경로 + 한 줄 요약'만 전달받도록 구성하세요.

**🚨 주의: Opus 비용 함정**
서브에이전트는 부모 모델의 설정을 상속받습니다. Opus 모델에서 서브에이전트를 5개 병렬로 돌리면 Opus 토큰 비용이 5배로 폭증합니다. 단순 정보 조사나 크롤링은 명시적으로 **Sonnet** 모델을 지정해 위임하세요.

**서브에이전트 위임 기준**
- ✅ 위임 추천: 다중 모듈 조사, 병렬 코드 리뷰
- ❌ 위임 비추천: 단일 검색, 짧은 Lookup, 순차적으로 의존성이 있는 작업

### 4. autocompact 임계값 낮추기

기본 임계값(약 95%)을 낮춰 컨텍스트가 꽉 차기 전에 미리 압축하도록 설정합니다. `~/.claude/settings.json` 파일에 아래 코드를 추가하세요.

```json
{
  "env": {
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "75"
  }
}
```

- 권장 설정: 일반적인 작업은 **60~75%**, 매우 큰 컨텍스트를 유지해야 하는 작업은 **85%** 수준이 적당합니다.

### 5. 7/13 만료 전 실행 체크리스트

- CLAUDE.md 템플릿 적용 완료
- autocompact 70~75% override 설정 완료 (`~/.claude/settings.json`)
- 토큰 소모가 큰 '대규모 리팩터링 및 마이그레이션' 작업을 이 기간으로 일정 재조정
- 서브에이전트 패턴 워크플로우 실무 정착
- 주 1회 `/usage` 명령어로 토큰 소모 패턴 점검 및 학습

## 활용 예시

- 긴 디버깅 세션 도중 컨텍스트가 늘어질 때 → `/compact` 실행 → 스레드 문맥은 유지한 채 오래된 로그만 드롭되어 이어서 작업 가능
- 새 기능 개발로 전환할 때 → `/clear` 로 세션을 초기화 → 이전 디버깅 로그가 남아 불필요한 토큰을 소모하는 것을 방지
- 여러 모듈을 동시에 조사해야 할 때 → Sonnet 모델을 지정한 서브에이전트 3개를 병렬로 실행하고 각 결과를 파일로 저장 → 메인 컨텍스트는 "파일 경로 + 한 줄 요약"만 받아 오염 없이 검토
- 두근컴퍼니 'company-hq' 아키텍처 구현 시: 단순 조사/크롤링 작업에는 Opus 대신 Sonnet 모델을 명시 지정해 서브에이전트 비용 폭증을 막고, `/compact` 등 토큰 관리 명령어를 팀 전체 습관으로 정착시켜 사용

- Free 플랜은 이번 인상 대상에서 제외됩니다.
