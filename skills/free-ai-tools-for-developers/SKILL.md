# 유료 AI 무료로 쓰는 방법 총정리

💡 유료 AI 를 0원으로 쓰는 길은 크게 **무료 API**(NVIDIA Build), **0원 체험 프로모션**(Kiro·힉스필드), **무료·로컬 도구**(로컬 모델·대체 도구·오픈소스) 세 갈래입니다. 내 목적에 맞는 갈래를 먼저 고르고, 프로모션은 **자동결제 해지**까지 한 번에 끝내는 것이 핵심입니다.

## 이게 뭔가요?

Claude Code·ChatGPT·이미지/영상 생성 AI 처럼 원래 돈을 내야 하는 AI 기능을 **무료로** 쓸 수 있는 경로를 한곳에 모은 정리입니다. 단순히 "무료다"라는 정보만 모은 게 아니라, 방법별로 **비용 조건, 준비물(API 키·카드 등록·그래픽카드 사양 등), 실제 절차, 함정**을 함께 적어 바로 시도해볼 수 있게 구성했습니다.

무료 경로는 성격이 전혀 다른 세 종류로 나뉩니다.

| 갈래 | 대표 방법 | 무료 조건 | 카드 등록 | 언제 끝나나 |
|---|---|---|---|---|
| **무료 API** | NVIDIA Build (build.nvidia.com) | 개인 학습·콘텐츠 제작·실험(PoC) 무료, 상업 운영은 유료 | 불필요 (휴대폰 인증 1회) | 상시. 한도 초과 시 과금 대신 잠시 멈춤 |
| **0원 체험 프로모션** | Kiro Pro/Pro+ 결제금액 0원, 힉스필드 Plus 24시간 무제한 | 프로모션 기간 한정 | **필요** | 기간 종료 후 자동결제 위험 → 미리 해지 |
| **무료·로컬 도구** | Claude 로컬 모델 토글, 270억 파라미터 로컬 실행, Claude Code 대체 도구, 오픈소스, 무료 강의 | 도구별로 상이 | 대부분 불필요 | 상시 (일부 기능만 유료 크레딧) |

| 여러 회사의 무료 할당량을 돌려 쓰고 싶다 | 무료 AI 통합 관리 서비스 | 방법 3-3 |
| 영상·웹사이트·논문·릴스 등 특정 작업용 무료 경로가 필요하다 | 작업별 무료 도구 | 방법 3-4 |

## 따라하기

### 방법 1. NVIDIA Build 무료 API

NVIDIA Build(build.nvidia.com)는 NVIDIA 가 100개 이상의 AI 모델을 무료 API 로 개방한 서비스입니다. ChatGPT 와 유사한 수준의 모델들을 코딩 없이 웹에서 바로 써보거나, 나만의 AI 도구로 만들어 자동화할 수 있습니다.

| 항목 | 내용 |
|---|---|
| 서비스 | NVIDIA Build (build.nvidia.com) |
| 제공 | AI 모델 100개 이상 무료 API 개방 (추론, 비전, 비주얼 디자인, 검색/RAG, 음성, 생물학, 시뮬레이션, 기후, 안전성·모더레이션 등 카테고리별 + 자동차·금융·게임·헬스케어·산업·로보틱스 등 산업별 탐색 가능) |
| 가격 | 개인 학습·콘텐츠 제작·실험 무료 / 상업 서비스 운영 시 유료 |
| 가입 | 이메일 가입 (API 키 발급 시 휴대폰 인증 1회, 신용카드 불필요) |
| 속도 | 분당 약 40회 호출 (무료 기준, 신청 시 약 200회/분까지 상향 가능) |

다른 유료 API 와 달리 무료 한도 안에서는 토큰 요금이 발생하지 않고, 한도를 넘으면 잠시 멈추는 방식입니다. 별도 구독이나 종량제 과금 없이 고급 모델을 부담 없이 쓸 수 있습니다.

**왜 NVIDIA 가 이걸 하나?** 모델 자체로 직접 수익을 내기보다, 커뮤니티가 만든 오픈 모델(Nemotron, DeepSeek, Kimi, GLM 등)을 NVIDIA 의 엔터프라이즈급 추론 런타임(NIM 컨테이너)으로 최적화·가속해 결국 NVIDIA GPU 위에서 실행되도록 유도하는 유입 퍼널 전략입니다. 무료 API 는 미끼이고, 엔터프라이즈 자체 호스팅(GPU 구매/DGX Cloud)이 실제 수익원입니다.

#### 1-1. 사이트에서 바로 쓰기 (코딩 불필요)

1. **가입**: build.nvidia.com 에 접속해 이메일로 가입합니다. 광고 수신 동의 여부는 선택 사항이며 결제와 무관합니다.
2. **모델 선택**: 메인 페이지에서 용도에 맞는 모델을 고릅니다 (예: 글쓰기 - minimax, 이미지 생성 - qwen-image).
3. **Playground 사용**: 모델 페이지 오른쪽 입력칸에 한국어로 요청합니다. 예를 들어 "인스타 릴스 후킹 문구 5개만 만들어줘"라고 입력하면 바로 결과가 나옵니다.
   - `Pro Tip`: 화면에 "Get API Key" 버튼이 보여도 이 방법에서는 누르지 않아도 됩니다.

#### 1-2. 나만의 AI 도구 만들기 (코딩 없이 자동화)

매번 사이트에 접속하지 않고 내 전용 도구를 쓰고 싶을 때의 방법입니다.

1. **API 키 발급**: 모델 페이지에서 "Get API Key"를 누릅니다. `nvapi-`로 시작하는 API 키를 받아 안전하게 보관합니다. 휴대폰 인증이 필요하지만 결제와는 무관한 본인 확인 절차입니다.
2. **Claude 또는 ChatGPT 준비**: 결과물을 바로 실행해 보여주는 Claude 나 ChatGPT 를 엽니다.
3. **주문서 작성·입력**: 아래 템플릿에서 원하는 기능, 모델 ID, 답변 자유도를 채워 Claude 나 ChatGPT 에 붙여넣습니다. 모델 ID 는 build.nvidia.com 모델 페이지에서 그대로 복사합니다.

```html
역할: 너는 비개발자도 그대로 따라 할 수 있게 설명하는 친절한 개발 도우미야.
목표: NVIDIA 무료 AI API로 [원하는 것 — 예: 유튜브 자막 요약기]를 만들어줘.
연결 정보 (OpenAI 호환):
- base_url: https://integrate.api.nvidia.com/v1
- model: [모델 ID — build.nvidia.com 모델 페이지에서 복사, 예: minimaxai/minimax-m3]
- temperature: [답변 자유도 0~1 — 번역·요약은 0.3, 아이디어·카피는 0.8 권장]
- API 키는 'YOUR_API_KEY' 자리로 비워두고, 코드에 직접 박지 말고 화면 입력칸에서 받게 해줘
요구사항:
1) 복사 한 번이면 바로 돌아가는 HTML 파일 하나로 만들어줘
2) 비개발자 기준으로, 어디에 붙여넣고 어떻게 여는지 1번부터 순서대로 알려줘
3) 내 API 키를 정확히 어디에 넣는지 짚어줘
4) 화면은 깔끔하게 — 입력칸, 실행 버튼, 결과 영역으로 보기 좋게 만들어줘
5) 에러가 나면 무엇이 문제인지 한국어로 알려주게 해줘
먼저 완성된 코드를 주고, 그다음에 실행 순서를 알려줘.
```

   빈칸을 채운 예시 (유튜브·긴 글 요약기):

```html
역할: 너는 비개발자도 그대로 따라 할 수 있게 설명하는 친절한 개발 도우미야.
목표: NVIDIA 무료 AI API로, 유튜브 자막이나 긴 글을 붙여넣으면 핵심 3줄과 한 줄 결론으로 요약해 주는 도구를 만들어줘.
연결 정보 (OpenAI 호환):
- base_url: https://integrate.api.nvidia.com/v1
- model: minimaxai/minimax-m3
- API 키는 'YOUR_API_KEY' 자리로 비워두고, 코드에 직접 박지 말고 화면 입력칸에서 받게 해줘
요구사항:
1) 복사 한 번이면 바로 돌아가는 HTML 파일 하나로 만들어줘

3) 내 API 키를 정확히 어디에 넣는지 짚어줘
4) 화면은 깔끔하게 — 글 붙여넣는 입력칸, 요약 버튼, 결과 영역으로 만들어줘
5) 에러가 나면 무엇이 문제인지 한국어로 알려주게 해줘
먼저 완성된 코드를 주고, 그다음에 실행 순서를 알려줘.
```

4. **실행·키 입력**: AI 가 준 코드와 실행 순서대로 HTML 파일을 만들고, `YOUR_API_KEY` 자리(화면 입력칸)에 발급받은 NVIDIA API 키를 넣어 실행합니다.

같은 `base_url` 과 키는 OpenAI 호환 설정을 받는 다른 도구(Cursor, Cline, n8n 등)에도 그대로 쓸 수 있습니다.

#### 1-3. Blueprints 로 실전 아키텍처 참고 (개발자·기획 단계)

1. **Blueprints 탐색**: build.nvidia.com 에서 AI 앱을 처음부터 만들 수 있는 워크플로와 코드 샘플을 확인합니다. 예: 기업 데이터를 연결·검색·추론하는 RAG 에이전트, 대량의 라이브·아카이브 영상을 수집해 요약하고 Q&A 까지 하는 영상 검색·요약 에이전트.
2. **PoC 비교**: 여러 오픈 모델(Nemotron, DeepSeek 등)을 무료로 테스트하며 Claude/GPT 같은 상용 모델과 성능·비용을 비교합니다.
3. **셀프 호스팅 고려(필요 시)**: 자체 GPU 인프라가 있다면 NIM 컨테이너로 모델을 직접 배포·운영하고, 보안 패치도 계속 받을 수 있습니다.

### 방법 2. 0원 체험 프로모션

프로모션은 공통적으로 **카드를 등록하고 0원(또는 무료 기간)으로 유료 플랜을 여는 방식**입니다. 그래서 순서는 언제나 같습니다: 신규 가입 → 유료 플랜 선택 → **결제 화면 최종 금액 확인** → 카드 등록 → **바로 해지 예약** → 남은 기간 동안 사용.

#### 2-1. Kiro Pro / Pro+ 결제금액 0원으로 Claude·GPT 쓰기

Kiro(app.kiro.dev)는 웹에서 가입해 쓰는 AI 코딩 도구로, 유료 플랜 **Kiro Pro** 와 **Kiro Pro+** 를 제공합니다. 블로그 작성자(여행 인플루언서 겸 AI·영상 크리에이터 솔랄라)에 따르면 프로모션 덕분에 이 유료 플랜을 **결제금액 0원**으로 신청할 수 있고, 그 안에서 Claude 와 ChatGPT(GPT) 계열 모델을 무료로 써볼 수 있습니다. 작성자는 약 2개월 전부터 "한 달 무료 이용" 프로모션이 계속 진행돼 왔다고 설명하며, 원문 기준 무료 이용 가능 기한은 **2026년 9월 30일까지**입니다. 조건은 언제든 바뀔 수 있으니 결제 화면의 최종 금액을 직접 확인하는 것이 가장 정확합니다.

- 사용 도구: Kiro (웹), 내부에서 Claude·GPT 계열 모델 사용
- 💰 유료 필요: 프로모션 종료 후 Kiro Pro / Pro+ 정식 구독료가 청구됨
- ✅ 무료 대안: 카드 등록이 부담되면 Gemini, ChatGPT 무료 플랜, Gemma4(Ollama 로컬)로 가능

1. **가입**: 아래 사이트에 접속해 가입합니다. (원문에 "광고X"로 명시)

```
https://app.kiro.dev/
```

2. 가입 후 화면에서 **Upgrade plan** 을 클릭합니다.
3. **플랜 선택**: Upgrade Plan 화면에서 **Kiro Pro** 또는 **Kiro Pro+** 를 고릅니다. 작성자는 **Kiro Pro+** 를 추천합니다.
4. **0원 확인**: 결제 화면에서 결제 금액이 **0원**으로 표시되는지 반드시 확인합니다. 0원이 아니면 진행하지 않습니다.
5. **카드 정보 입력 후 결제 버튼**을 누르면 바로 이용할 수 있습니다.
   - 카드 결제 알림이 오더라도, 작성자에 따르면 실제 결제가 완료되는 것이 아니라 곧바로 해외 결제 취소 처리됩니다.
6. **자동결제 해지 (가장 중요)**: 카드가 등록돼 있어 이용 기간이 끝나면 자동으로 유료 결제가 될 수 있습니다. 원치 않으면 가입 직후 아래 순서로 해지합니다.
   1. 프로필 아이콘 → **Account** → **Manage Plan** 클릭
   2. **구독 업데이트(Update Subscription)** 클릭
   3. **Kiro Free** 선택
   4. **Continue** → **Confirm** 순서로 진행
7. **해지 후 동작**: 중간에 해지해도 현재 유료 플랜은 해당 이용 기간이 끝날 때까지 그대로 쓸 수 있습니다. 다음 결제 주기부터 Kiro Free 로 전환되며 추가 월 구독료는 청구되지 않는다고 합니다.

#### 2-2. 힉스필드 이미지·영상·음성 모델 24시간 무제한

힉스필드에 신규 가입한 뒤 Plus 구독을 진행하면 **24시간 동안 완전 무료 + 무제한** 혜택을 받는 프로모션입니다. 대상은 Seedance 2.0, Kling 3.0, Gemini Omni Flash, GPT Image 2, Nano Banana Pro 등 주요 이미지·영상·음성 모델 **23개**입니다. 구독을 바로 취소해도 24시간 혜택은 유지되며, 24시간 이후에도 구독을 유지하면 **추가 7일 무료 + 무제한**이 이어집니다.

1. 힉스필드에 신규 가입합니다.
2. Plus 구독을 진행합니다.
3. 24시간 동안 완전 무료 + 무제한 혜택을 이용합니다. 24시간만 쓸 생각이면 구독을 바로 취소해도 혜택은 유지됩니다.
4. (선택) 최초 24시간 이후에도 Plus 구독을 유지하면 추가 7일 무료 혜택이 이어집니다. 이후 자동 갱신 조건은 가입·결제 화면에서 확인합니다.

24시간이 짧으므로, 만들 결과물(실사 이미지 캐릭터 시트, 3D 캐릭터 시트, 점토 캐릭터 시트, 프로덕트 시트 등)과 프롬프트를 **미리 준비해 두고** 가입하는 편이 효율적입니다.

### 방법 3. 무료·로컬 도구

설치형·로컬·오픈소스·무료 강의처럼 카드 없이 상시로 쓸 수 있는 경로입니다. 각 항목은 "무엇을 / 이점 / 비용·제약" 순으로 정리했습니다.

#### 3-1. Claude Code 대신 쓸 수 있는 무료 코딩 도구

- 중국 회사들이 Claude Code 와 비슷한 기능을 무료로 제공하는 도구들을 출시했습니다.
- 유료 결제 없이 코딩을 시켜볼 수 있으며, 대부분 설치는 명령 한 줄로 끝납니다.
- 회사마다 무료 제공량과 조건이 다르며, 일부는 신청 후에 쓸 수 있습니다.

#### 3-2. 내 컴퓨터에서 AI 돌리기

**Claude 로컬 모델 토글**
- Claude 설정에서 토글 하나를 켜면 인터넷 연결 없이 내 컴퓨터의 AI 모델로 답변을 받을 수 있습니다.
- 데이터가 인터넷으로 나가지 않고, 내 컴퓨터에서 실행되는 모델은 사용량이 차감되지 않습니다.
- 현재는 Mac 만 지원되며 Windows 는 준비 중입니다.

**270억 파라미터 AI 로컬 실행**
- 무료 앱을 설치하면 큰 AI 모델을 내려받아 내 컴퓨터에서 직접 구동할 수 있습니다.
- 인터넷 연결이나 결제가 필요 없고, 내 컴퓨터 사양에 맞는 크기의 모델을 고를 수 있습니다.
- 모델이 커서 저장 공간을 많이 차지할 수 있으며, 압축률이 높을수록 가볍지만 답변 품질은 떨어질 수 있습니다.

#### 3-3. 여러 회사의 무료 AI 를 한곳에서 쓰기

- 각 회사의 무료 사용량을 한곳에 모아 관리하고, 한쪽 사용량이 떨어지면 다른 쪽으로 자동 전환됩니다.
- 모델별로 따로 가입·결제하는 번거로움이 줄어듭니다.
- 개인 실험용으로 설계됐으며, 각 회사의 이용 약관이 그대로 적용됩니다.

#### 3-4. 작업별 무료 경로

| 작업 | 무엇을 할 수 있나 | 비용·제약 |

### 시작 전 체크리스트

- [ ] 목적이 "상시 무료 사용"인지 "짧은 기간 몰아 쓰기"인지 정했다 → 전자는 방법 1·3, 후자는 방법 2
- [ ] 프로모션이면 결제 화면 최종 금액(0원)을 눈으로 확인했다
- [ ] 프로모션 가입 **당일** 해지(Kiro Free 전환 / 구독 취소)까지 마쳤다
- [ ] API 키(`nvapi-` 등)를 코드·주소창·대화창에 직접 넣지 않고 화면 입력칸이나 별도 보관처에 두었다
- [ ] 민감한 개인정보·회사 기밀은 무료 엔드포인트에 넣지 않기로 했다
- [ ] 상업적으로 쓸 계획이면 해당 서비스의 라이선스·약관을 확인했다

### 이런 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| Kiro 결제 화면이 0원이 아님 | 프로모션이 끝났거나 조건이 바뀐 것. 진행하지 말고 다른 무료 경로(NVIDIA Build, 로컬 모델)로 전환 |
| 카드사에서 해외 결제 알림이 옴 | 작성자 설명대로 곧바로 취소 처리되는지 카드 내역에서 확인 |

| 영상 생성 모델이 목록에서 안 보이거나 막힘 | 훈위안처럼 대한민국이 사용 지역에서 제외된 모델일 수 있음. 다른 모델 선택 |

## 활용 예시

- **유료 결제 전 체험**: Claude Code 대체 도구나 Kiro 0원 프로모션으로 코딩 작업을 먼저 시켜본 뒤 유료 결제를 결정합니다.
- **Kiro 당일 체험·해지 루틴**: 오늘 가입 → Pro+ 선택 → 결제금액 0원 확인 → 카드 등록 → 그날 바로 Manage Plan 에서 Kiro Free 로 변경 → 이용 기간이 끝날 때까지 유료 플랜 기능을 그대로 쓰고, 다음 주기부터 자동으로 무료 전환.
- **Claude 비교 테스트**: 같은 코딩 과제를 Kiro 안의 Claude 모델과 기존 Claude Code CLI 에 각각 시켜 결과를 비교합니다.
- **직장인 보고서**: NVIDIA Build 모델에 회의 메모나 녹취를 붙여넣고 "핵심 3줄 요약 + 결정사항 + 담당자별 할 일 정리 + 팀장 보고용 메일 초안 작성"을 요청해 5분 만에 보고용 문서를 만듭니다.
- **자영업자 판매 페이지**: 상품 사진 1장으로 배경 교체, 상세페이지 카피, 해외 판매용 영어 번역까지 일괄 처리해 판매 페이지 세트를 만듭니다.
- **콘텐츠 크리에이터 소재 세트**: 주제 한 줄로 릴스 후킹 문구, 캐러셀 카드 문구, 표지 이미지, 내레이션 음성까지 한 세트를 만듭니다. 이미지·영상 비중이 크면 힉스필드 24시간 무제한 기간에 몰아서 생성합니다.
