# AI 요리 애니메이션 만들기

💡 해외에서 100만 뷰 이상 나오는 **AI 요리 애니메이션**을 여러 툴을 오가지 않고 **NEWTAKE** 하나에서 **대본 → 영상**까지 끝냅니다.

## 이게 뭔가요?

**NEWTAKE**는 대본만 입력하면 셰프 캐릭터, 재료, 소품, 샷 콘티까지 자동으로 만들어 주는 올인원 AI 영상 제작 플랫폼입니다. 감독처럼 카메라 앵글·조명·렌즈 같은 연출을 직접 지정할 수 있고, 여러 장면을 만들어도 캐릭터의 얼굴과 특징이 일관되게 유지됩니다. 효과음을 넣고 최대 20분 길이 영상까지 만들 수 있습니다.

### 주요 기능

| 단계 | 기능 |
|---|---|
| 기획 | 스크립트 작성, 스토리보드 생성 |
| 소재 | 캐릭터 생성, 상품·이미지 생성 |
| 연출 | 조명 효과 설정, 다각도 편집, 렌즈 수정(초점 거리, 조리개 등) |
| 완성 | 영상 제작, 효과음 추가, 최대 20분 길이 |

### 비용

가입만 해도 **50 크레딧**과 무료 플랜 **3GB 저장 공간**을 줍니다. 런칭 프로모션으로 런칭일 기준 2주간 연간 결제 최대 60% 할인, 주요 이미지 모델 최대 25% 할인, Minimax H3 40% 할인이 적용됩니다. 본격적으로 쓰려면 유료 플랜을 고려해야 합니다.

## 따라하기

### 1. 대본 준비

영상으로 만들 요리 과정이나 스토리를 대본으로 씁니다. 어떤 요리 과정을 보여줄지, 어떤 메시지를 전달할지 구체적으로 적을수록 자동 생성 결과가 좋아집니다.

### 2. NEWTAKE에 대본 입력

NEWTAKE에 가입·접속해 준비한 대본을 붙여넣습니다.

### 3. 자동 생성 결과 확인·수정

대본을 넣으면 셰프 캐릭터, 재료, 소품, 샷 콘티가 자동 생성됩니다. 셰프의 외모·의상과 배경을 확인하고 필요하면 수정합니다.

### 4. 감독 모드로 연출 설정(선택)

카메라 앵글, 조명, 렌즈, 움직임을 직접 지정해 음식의 질감과 분위기를 살립니다. ASMR 요리 애니메이션에서 효과가 큰 세 가지는 다음과 같습니다.

- 팬(pan)을 활용한 클로즈업 샷
- 따뜻한 조명 분위기
- 지글지글한 ASMR 기름 소리(6단계에서 추가)

### 5. 샷 생성과 타임라인 배치

생성한 샷들을 타임라인에 배치해 영상의 흐름을 구성합니다. 여러 장면을 만들 때는 캐릭터 일관성 기능으로 얼굴과 특징이 자연스럽게 이어지는지 확인합니다.

### 6. 효과음과 길이 조절

도마 소리, 기름 끓는 소리 같은 ASMR 효과음을 넣고 영상 총 길이를 정합니다(최대 20분).

### 7. 최종 점검과 내보내기

완성본을 재생해 전체 흐름과 퀄리티를 점검한 뒤, 원하는 형식으로 내보냅니다.

### 체크리스트

- [ ] 대본에 요리 과정·메시지가 구체적으로 들어 있다
- [ ] 자동 생성된 셰프·배경을 확인·수정했다
- [ ] 클로즈업·따뜻한 조명·기름 소리 세 요소를 챙겼다
- [ ] 여러 장면에서 캐릭터가 일관되게 보인다
- [ ] 크레딧 잔량과 런칭 할인 기간을 확인했다

## 활용 예시

| 콘텐츠 | 대본·연출 예시 |
|---|---|
| 간단한 레시피 소개 | "집에서 쉽게 만드는 김치볶음밥" 대본 → 1분 내외 영상. 따뜻한 조명 + 김치 볶는 ASMR 효과음 |
| AI 셰프 레시피 | "오늘 저녁은 근사한 스테이크!" 대본 → AI 셰프가 스테이크를 만드는 과정을 자동 생성하고 영상미를 더함 |
| 디저트 플레이팅 시연 | 섬세한 접시 위 플레이팅과 완성 비주얼을 강조하도록 카메라 앵글·조명을 세밀하게 조절해 고급스러운 영상 |
| 캐릭터 중심 요리 스토리 | 귀여운 셰프 캐릭터가 요리를 완성해 가는 짧은 스토리. 캐릭터 일관성 기능으로 얼굴·행동 유지 |
| 요리 챌린지 | "10분 안에 김치찌개 만들기" 같은 챌린지를 대본으로 넣어 역동적으로 연출 |
| 푸드트럭 홍보 | 여러 메뉴를 소개하는 짧은 홍보 영상으로 음식 비주얼과 분위기 강조 |

## 💡 아이디어

- **기존 레시피 콘텐츠 전환**: 푸드 블로거·요리 유튜버가 글·사진 레시피를 시각적으로 매력적인 AI 애니메이션으로 바꿉니다.
- **숏폼 대량 생산**: 틱톡 챌린지용 짧은 ASMR 요리 영상을 대본만 바꿔 연속 제작합니다.
- **수익화**: 유튜브·틱톡에 게시해 광고 수익을 얻거나, 요리 브랜드 홍보 영상 제작을 대행합니다.
- **블로그 연재**: 개인 블로그·웹사이트에 AI 요리 레시피 콘텐츠를 연재하고 주방용품 같은 관련 상품 링크를 붙입니다.
- **비용 효율**: 꾸준히 만들 계획이면 런칭 할인 기간 안에 연간 구독을 검토합니다.

## 주의사항

- **런칭 할인 기간**: 연간 결제 최대 60%, 주요 이미지 모델 최대 25%, Minimax H3 40% 할인은 런칭일 기준 2주간만 적용됩니다.
- **무료 자원 한도**: 가입 크레딧 50개와 무료 플랜 3GB 저장 공간은 금방 소진될 수 있으니 테스트 생성은 짧게 합니다.
- **무료 대안**: 초단편 영상이나 간단한 AI 영상은 CapCut, Canva 같은 무료 툴로도 부분적으로 구현할 수 있습니다.
