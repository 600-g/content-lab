# 구글 지도 동선 영상 만들기

💡 내 **구글 지도 이동 기록**을 **지도 위 경로 영상(MP4)**으로 만들어주는 **무료 AI 스킬**입니다.

## 이게 뭔가요?

구글 지도 타임라인에 저장된 사용자의 1년간 이동 기록을 지도 위에서 움직이는 경로 영상(MP4)으로 변환해주는 무료 도구입니다. 별도의 설치나 계정 연결 없이 아이폰, 컴퓨터에서는 웹 브라우저만 열면 바로 사용할 수 있습니다. 안드로이드 사용자는 깃허브에서 설치 파일을 받아 설치해야 합니다. 사용자의 위치 데이터는 어디에도 업로드되지 않으며, 계정 연결이나 위치 권한도 요구하지 않아 개인 정보 보호에 강점이 있습니다. 다양한 영상 형식(정사각형, 세로, 가로)과 해상도(480p, 720p, 1080p)를 지원합니다.

이 스킬은 다음과 같은 경우에 유용합니다:
- 지난 여행이나 일상의 동선을 시각적인 영상으로 기록하고 싶을 때
- 구글 지도 타임라인 데이터를 활용하여 특별한 콘텐츠를 만들고 싶을 때
- 개인의 이동 기록을 타인과 공유하거나 추억을 되새기고 싶을 때

💰 **유료 필요**: 없음
✅ **무료 대안**: 없음 (해당 기능을 제공하는 대체 무료 도구가 드뭅니다)

## 따라하기

**1단계. 타임라인 파일 꺼내기**

가장 중요한 단계로, 구글 지도에서 자신의 이동 기록 데이터를 `.json` 파일 형태로 내보냅니다.

*   **아이폰/아이패드/컴퓨터 (사파리 16.4 이상 권장)**:
    1.  구글 지도 앱 실행 → 오른쪽 위 프로필 사진 → 설정 → 개인 콘텐츠 → 타임라인 데이터 내보내기
    2.  `Timeline.json` 파일이 생성되면 '파일' 앱에 저장합니다.
*   **안드로이드**: (구글 지도 앱이 아닌 **폰 설정** 앱을 사용해야 합니다)
    1.  설정 앱 → 위치 → 위치 서비스 → 타임라인 → 타임라인 데이터 내보내기 → 계속
    2.  다운로드 폴더에 `Timeline.json` 파일이 저장됩니다.

    ⚠️ **주의**: 안드로이드에서 구글 지도 앱 내에서는 이 메뉴를 찾을 수 없습니다. 반드시 휴대폰 설정 앱을 통해 접근해야 합니다.

**2단계. 웹 앱에 파일 업로드 및 기본 설정**

1.  웹 앱 주소를 열고 **Timeline.json 선택** 버튼을 클릭하여 방금 저장한 파일을 업로드합니다.
2.  파일이 없다면 **가상 샘플 여행 체험하기** 버튼을 눌러 미리 앱의 작동 방식을 익힐 수 있습니다.
3.  파일을 업로드하면 배경 지도를 불러오기 위한 권한을 묻습니다. **확인**을 눌러 지도를 표시합니다.

**3단계. 기간 및 영상 설정 선택**

*   **기간**: 영상을 만들고 싶은 시작 월과 종료 월을 선택합니다. 한 해 전체를 담으려면 1월부터 12월까지 설정합니다.
*   **정확한 날짜 선택 (선택 사항)**: 특정 날짜 범위만 포함하고 싶을 때 이 옵션을 켭니다.
*   **재생 시간**: 영상의 길이를 선택합니다 (웹: 10~60초, 안드로이드 앱: 10~300초).
*   **카메라 움직임**: '고정 확대', '안정적 따라가기', '역동적 따라가기' 중 선택합니다. 좁은 지역 이동은 '고정 확대', 해외 이동 등 장거리는 '역동적 따라가기'가 적합합니다.
*   **GPS 이상치 필터링**: '보수적'으로 두면 불가능한 짧은 왕복 이동 등을 걸러 경로를 깔끔하게 만듭니다. 기본값으로 두는 것을 추천합니다.
*   **영상 제목**: `{year} {name}'s Timeline`과 같은 형식으로 자동으로 채워집니다. 원하는 대로 수정 가능합니다.

    💡 **팁**: 처음에는 기간만 설정하고 나머지 옵션은 기본값으로 두어 빠르게 결과를 확인한 후, 필요에 따라 세부 설정을 조절하는 것이 좋습니다.

**4단계. 미리보기 확인 및 영상 만들기**

1.  **미리보기** 버튼을 눌러 경로가 제대로 표시되는지 확인합니다. 경로가 이상하면 기간 설정을 조금 좁혀 다시 시도합니다.
2.  경로에 만족하면 **MP4 만들기** 버튼을 클릭합니다.
3.  영상 제작 진행률과 예상 시간이 표시됩니다. 제작 중 탭을 닫거나 앱을 종료하면 중단될 수 있으니, 완성될 때까지 열어두는 것이 좋습니다.
4.  영상이 완성되면 지정된 폴더(안드로이드 10 이상: `Movies/Timeline Visualizer`)에 자동으로 저장됩니다.

**릴스/스토리에 올릴 때**: 영상 형식을 '세로 1080×1920'으로 설정하면 최적화된 영상을 얻을 수 있습니다.

## 활용 예시

1.  **지난 휴가 동선 영상 제작**: 여름 휴가지로 다녀온 곳들의 이동 경로를 지도 영상으로 만들어 친구들과 공유합니다. 친구들과 함께 갔다면 각자의 타임라인 데이터를 합쳐서 하나의 영상으로 만들 수도 있습니다.
2.  **일년간의 생활 반경 시각화**: 1년 치 타임라인 데이터를 사용하여 집, 회사, 자주 가는 장소 등 일년간의 생활 반경을 한눈에 보여주는 영상을 만듭니다. 반복 경로를 '고정 확대' 카메라 움직임으로 설정하면 안정적인 영상을 얻을 수 있습니다.
3.  **교육용 콘텐츠 제작**: 지리 교육이나 여행 관련 콘텐츠 제작 시, 특정 지역의 이동 경로를 시각적으로 보여주는 자료로 활용할 수 있습니다.

## 💡 아이디어

*   **SNS 챌린지**: '나의 N년 동선 챌린지'와 같이 사용자들이 자신의 타임라인 영상을 공유하는 챌린지를 기획하여 확산시킬 수 있습니다.
*   **개인 아카이빙 서비스 연동**: 사용자가 자신의 타임라인 영상을 개인 아카이빙 서비스(예: Notion, Evernote)에 자동으로 저장하고 관리할 수 있도록 기능을 확장할 수 있습니다.

## 주의사항

*   **개인 정보 보호**: 업로드된 `Timeline.json` 파일과 생성된 영상은 브라우저 내에서만 처리되며, 개발자나 외부 서버로 전송되지 않습니다. 다만, 웹사이트 접속 시 GitHub Pages 및 Cloudflare, CARTO(지도 표시용)에는 일반 접속 정보가 전달될 수 있습니다. 개인정보 처리방침을 꼭 확인하세요.
*   **데이터 유실**: 구글 지도 타임라인 기록이 꺼져 있었다면 해당 기간의 데이터는 존재하지 않으므로 영상 생성이 불가능합니다. '원시 위치 데이터만 있음' 오류는 타임라인 기록이 제대로 저장되지 않았을 때 발생할 수 있습니다.
*   **호환성**: 아이폰에서 영상 생성 기능은 사파리 16.4 이상 버전에서 지원됩니다. 이전 버전 사용자는 iOS 업데이트 또는 안드로이드 기기 사용을 고려해야 합니다.
*   **처리 시간**: 영상 길이가 길거나 해상도가 높을수록 제작 시간이 오래 걸립니다. 급한 경우 낮은 해상도(480p)로 먼저 제작해보는 것이 좋습니다.
