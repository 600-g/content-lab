# AI 투자 분석 프롬프트 모음

💡 "지금 사도 될까?" 같은 투자 고민을 **목적별 복붙 프롬프트**로 풉니다. 매일 시장 읽기부터 **종목 비교·수급·주도 섹터**, 확증 편향 깨기, **백테스트**, **포트폴리오 에이전트**까지 한 문서에 정리했습니다.

## 이게 뭔가요?

"지금 사도 될까? 아니면 팔아야 하나? 너무 올랐는데 지금 들어가도 괜찮을까?" 같은 투자 고민을 대화형 AI로 풀어내는 프롬프트 모음입니다. 두 권의 책에서 실전에 쓸 만한 것만 골랐습니다.

- 머신러너 님의 도서 **"할 수 있다! AI 주식 투자"** 를 참고한 5가지 핵심 프롬프트 — 긍정·부정 AI 토론, 7개 황금지표 비교, 돈치안 채널 백테스트, 3가지 페르소나 관점, 에이전트 AI 6단계 오케스트레이션
- **《제미나이 주식투자》** (실전 200개 프롬프트 수록) 중 운영자 율리님이 직접 검증해 고른 5종 — 뉴스 속뜻 분석, 가치투자 종목 비교, 30초 미국 증시 리포트, 글로벌 수급 분석, 미래 주도 섹터

> Gemini 를 활용만 잘해도 투자 고민의 상당 부분이 해결됩니다.

공통 원리는 AI에 **전문가 페르소나**(냉철한 분석가, 가치투자 전문가, 헤지펀드 데이터 분석가, 20년 경력 수석 애널리스트 등)를 부여하고, 판단 기준(지표·기간·관점)을 명시해 막연한 의견 대신 구조화된 분석을 받는 것입니다. 여러 관점을 강제로 부딪치게 하면 투자자가 가진 **확증 편향**도 깰 수 있습니다.

💰 유료 필요: 대부분 없음 (Gemini 무료 / Claude·ChatGPT 무료 모두 동작). 에이전트 프롬프트(⑩)만 KIS MCP Server·dart-mcp 같은 외부 도구 연동이 필요합니다.
✅ 무료 대안: Gemini 무료 / Claude 무료 / ChatGPT 무료 모두 사용 가능

## 따라하기

프롬프트의 `[ ]` 부분을 정확히 채워 AI에 붙여넣습니다. 종목명·섹터·시점이 모호하면 답변도 모호해집니다. 최신 데이터가 필요한 ①③④⑤⑦은 웹 검색이 되는 환경(Gemini, 또는 웹 검색 기능을 켠 Claude·ChatGPT)에서 쓰는 것이 좋습니다.

### 매일 시장 읽기

#### ③ 아침을 여는 '30초 미국 증시 리포트'

전 세계 데이터를 실시간으로 훑어 오늘 내 주식에 줄 영향만 쏙쏙 골라주는 리포트입니다.

언제 쓰나:
- 바쁜 출근길 핵심 요약이 필요할 때 — 30초 브리핑
- 글로벌 이슈를 내 종목에 대입할 때 — 해외 대장주 뉴스가 내 한국 보유 종목에 미칠 변화 대비

```plain text
어제 미국 증시에서 [섹터] 지수가 얼마나 올랐어?
특히 엔비디아와 관련된 최신 뉴스 중에서
오늘 한국 [섹터] 주식인 [종목명]에 영향을 줄 만한
핵심 내용만 딱 정리해 줘.
```

#### ① 냉철한 분석가 모드 — 뉴스 속뜻 파헤치기

언제 쓰나:
- 따끈따끈한 뉴스가 내 주식에 약일지 독일지 궁금할 때
- 호재인지 악재인지 헷갈릴 때 — 주가 영향력 즉시 판별
- 단순 요약이 아니라 뉴스 이면의 시장 반응·전문가 시선 분석이 필요할 때

```plain text
너는 냉철한 주식 시장 분석가야.
방금 나온 [종목명]의 뉴스 [제목/내용]을 분석해 줘.
이 뉴스가 단기적으로 주가에 긍정적인지 부정적인지 판단하고,
그 이유를 세 가지로 요약해 줘.
마지막에는 주식 초보자가 주의해야 할 점도 알려줘.
```

### 종목 분석·비교

두 종목 사이에서 결정 장애가 왔을 때 씁니다. 빠르게 저평가 여부만 보려면 ②, 가치·성장·건전성을 모두 따지려면 ⑥를 씁니다.

#### ② 가치투자 전문가 모드 — 빠른 비교 (PER·PBR·ROE)

A 종목을 살까 B 종목을 살까 고민하며 밤잠을 설치는 분들을 위한 비교 공식입니다.

언제 쓰나:
- 비슷한 업종 중 어느 게 더 저평가인지 알고 싶을 때
- 막연한 설명 대신 PER·PBR·ROE 같은 핵심 지표를 표로 보고 싶을 때

```plain text
너는 가치투자 전문가야.
[종목 A]와 [종목 B]를 비교하려고 해.
두 회사의 최근 PER, PBR, ROE 수치를 표로 만들어서 비교해 줘.
현재 어떤 종목이 더 저평가되어 있는지,
그리고 수익성은 누가 더 좋은지
초보자도 이해하기 쉽게 설명해 줘.
```

#### ⑥ 7개 황금지표로 기업 비교하기

재무제표 출처를 지정하고, 지표를 세 묶음으로 나눠 표로 비교 평가받습니다.

- **가치 지표**: PER(주가이익배수), PBR(주가순자산배수)
- **성장 지표**: ROE(자기자본이익률), ROIC(투하자본이익률), 영업이익률
- **건전성 지표**: 부채비율, 배당수익률

```
삼성전자와 SK하이닉스에 대해서 비교해보자. 재무제표는 ‘에프앤가이드'에서 가져오자.
<가치 지표>
PER(주가이익배수)
PBR(주가순자산배수)
<성장 지표>
ROE(자기자본이익률)
ROIC(투하자본이익률)
영업이익률
<건전성 지표>
부채비율
배당수익률
이 7개 지표를 표로 정리하고, 이것으로부터 두 기업을 비교 평가해줘.
```

종목명만 바꿔서 같은 업종의 다른 경쟁사 쌍에도 그대로 씁니다.

### 수급 읽기

#### ④ 글로벌 수급 분석 모드 — 숫자에 숨은 의도

복잡한 수급 데이터를 전략의 언어로 번역합니다. '얼마나 샀는지'보다 '왜 샀는지'가 훨씬 중요합니다.

언제 쓰나:
- '큰 손'들의 진짜 속내 — 외국인·기관 매수가 단기 트레이딩인지 장기 매집인지
- 단단한 지지선을 찾고 싶을 때 — 세력 매수가 집중된 가격대 파악

```plain text
너는 글로벌 헤지펀드의 수석 데이터 분석가야.
최근 10거래일간 [종목명]에 대한 외국인과 기관의 수급 데이터를 분석해 줘.
순매수 강도와 환율과의 관계를 고려해 이 자금의 성격(단기/장기)을 판단하고,
향후 지지선 역할을 할 핵심 가격대를 평가해 줘.
```

### 관점 균형 잡기 (확증 편향 깨기)

이미 마음이 기운 종목일수록 반대 논리를 일부러 들어야 합니다. ⑦은 투자자 유형별 시각을 정리하고, ⑧은 찬반을 직접 싸우게 합니다.

#### ⑦ 3가지 페르소나 투자자 관점

같은 종목을 **가치투자자 / 성장주 투자자 / 단기 트레이더** 세 시각에서 긍정·부정 포인트로 나눠 봅니다. 증권사 리포트나 최근 뉴스를 근거로 삼게 합니다.

```
LG에너지솔루션 주가에 대한 시장의 다양한 관점을 분석해줘. 세 가지 페르소나를 부여할게.
가치투자자
성장주 투자자
단기 트레이더
각 페르소나 시각에서 어떤 점을 긍정적으로 보는지 부정적으로 보는지 정리 해줘증권사 리포트나 최근 뉴스를 참고해서 각 투자 주체의 입장을 정리해줘
```

#### ⑧ 긍정 AI vs 부정 AI 토론

AI 하나가 '긍정 AI'와 '부정 AI' 두 역할을 맡아, 직전 발언을 반박하거나 인정하면서 의견을 수렴시킵니다.

```
너는 지금부터 테슬라 투자에 관해 ‘긍정 AI’와 '부정 AI’가 각각 되어라. 대화 방식은 긍정 AI가 먼저 시작한다. 서로 직전 발언을 반박하거나 인정하면서, 대 화를 이어서 서로 논쟁해라. 치열하게 논쟁하면서 의견을 수렴시켜보자.
```

### 다음 주도 섹터 찾기

#### ⑤ 수석 애널리스트 모드 — 미래 주도 섹터 분석

20년 경력 전문가의 시선으로 거시 경제와 산업 변화를 꿰뚫어 봅니다. AI에 글로벌 자산운용사 수석 애널리스트 역할을 주고, 현재 시점의 금리 상황과 AI 산업 변화 같은 거시 트렌드를 넣어 향후 시장을 주도할 업종과 대장주를 받습니다.

언제 쓰나:
- 다음 시장의 주인공을 미리 선점하고 싶을 때 — 금리·AI 트렌드를 반영한 향후 6개월 핵심 업종
- 업종 내 진짜 '대장주'를 가려내고 싶을 때 — 기술력·수급이 가장 몰리는 1등 기업
- 투자뿐 아니라 신규 사업 아이템 발굴이나 사업 방향 설정에 필요한 거시 인사이트를 얻고 싶을 때

```plain text
너는 20년 경력의 글로벌 자산운용사 수석 애널리스트야.
현재 [시점: 2026년] 금리 상황과 AI 산업 변화를 반영해서,
향후 6개월간 시장을 주도할 핵심 업종 3가지를 분석하고
각 업종의 대장주를 추천해 줘.
```

진행 순서:
1. Gemini 또는 Claude에 접속합니다. 최신 데이터 반영을 위해 웹 검색이 되는 환경을 씁니다.
2. 위 프롬프트를 복사해 붙여넣습니다.
3. `[시점: 2026년]` 부분에 현재 시점 또는 목표하는 미래 시점을 넣고, 현재 금리 상황과 AI 산업 관련 최신 정보를 덧붙여 프롬프트를 완성합니다.
4. 실행해 분석 결과를 확인합니다.
5. 추천된 업종 중 관심 가는 대장주는 ②·⑥로 비교하고 ④로 수급을 확인한 뒤, 투자나 사업 전략 수립에 활용합니다.

### 전략 검증

#### ⑨ 돈치안 채널 백테스트

매매 규칙을 문장으로 정해 주고, 파이썬 백테스트 템플릿을 첨부해 투자 시뮬레이션을 시킵니다. 돈치안 채널(Donchian Channel)은 선물 거래 산업의 선구자인 리처드 돈치안(Richard Donchian)이 개발한 변동성 및 추세 추종 기술적 분석 지표입니다.

프롬프트:

```
투자 시뮬레이션(백테스트)를 하기 위한 파이썬 템플릿을 첨부했다 시각화는 일반 시각화와 plotly 시각화 두 개를 동시에 보여줘.성과 지표: CAGR, MDD, MAR, 누적 수익률, 승률, 손익비는 필히 포함시켜라.1~5번까지 규칙대로 투자 시뮬레이션을 진행하자.

전략 이름: 돈치안 20일 채널 전략
백테스트할 데이터: 코스피지수
매수(진입) 조건: 20일 돈치안 채널 상단 돌파 시 즉시 매수
매도(탈출) 조건: 20일 돈치안 채널 하락 이탈 시 즉시 매도
스탑로스(손절) 조건 유/무: 사용 안 함
```

함께 첨부할 파이썬 템플릿의 뼈대 예시입니다 (실제 템플릿은 원본 참조).

```python
# (실제 파이썬 코드 템플릿은 원본 참조)
# 예시: 백테스트 수행 및 결과 시각화 코드

import pandas as pd
```

### 포트폴리오 자동 관리

#### ⑩ 에이전트 AI 6단계 오케스트레이션

AI를 내 포트폴리오 관리 에이전트로 지정하고, 단계마다 쓸 도구를 지정해 계좌 조회부터 투자 일지 기록까지 한 번에 수행시킵니다. 각 단계의 도구(KIS MCP Server, dart-mcp, 웹 검색, Filesystem)가 미리 연결되어 있어야 합니다.

| 단계 | 할 일 | 도구 |
|---|---|---|
| 1 | 계좌 조회 | KIS.MCP Server |
| 2 | 재무제표 수집 — 보유 종목 최근 3년 실적(매출액·영업이익·순이익), 투자지표(PER·PBR·ROE·부채비율), 배당흐름(현금흐름 3가지) | dart-mcp |
| 3 | 뉴스 수집 — 개별 보유 종목의 최근 뉴스·보도 자료·산업 동향 | LLM 웹 검색 |
| 4 | 리밸런싱 계획 수립 | LLM |
| 5 | 매매 실행 | KIS_MCP_Server |
| 6 | 투자 일지 기록 | Filesystem |

```
너는 나의 주식 포트폴리오를 관리하는 주식 투자 에이전트야. 현재 상황에서 포트폴리오 점검을 하고 다음 6단계를 수행해라.
[1단계] 계좌 조회(도구: KIS.MCP Server)
[2단계] 재무제표 수집(도구: dart-mcp) 보유 종목들의 최근 3년간 재무제표로부터,
실적(매출액, 영업이익, 순이익)
투자지표(PER, PBR, ROE, 부채비율)
배당흐름(현금흐름 3가지),
세 가지를 수집해줘.
[3단계] 뉴스 수집(도구: LLM 웹 검색) 개별 보유 종목의 최근 뉴스와 보도 자료, 산 업 동향 등 투자에 필요한 자료를 수집해줘.
[4단계] 리밸런싱 계획 수립(도구: LLM)
[5단계] 매매 실행(도구: KIS_MCP_Server)
[6단계] 투자 일지 기록(도구: Filesystem)
```

5단계(매매 실행)는 실제 주문이 나가는 단계입니다. 처음에는 4단계 계획까지만 받아 직접 검토하고, 실행은 본인이 승인한 뒤 진행하는 것이 안전합니다.

### 조합 — 매일 30분 투자 루틴

```plain text
07:30 — ③ 30초 미국 증시 리포트 (어제 미국 → 오늘 한국 영향)
07:45 — ④ 글로벌 수급 분석 (내 보유 종목 외국인·기관 동향)
08:00 — ① 냉철한 분석가 (밤사이 나온 뉴스 호재/악재 판단)
주말   — ⑤ 수석 애널리스트 (다음 주·다음 분기 섹터 전망)
신규 종목 검토 시 — ② 가치투자 전문가 (A vs B 비교)
```

번호는 위 목차 번호와 같습니다. 확신이 강한 종목을 매수하기 전에는 ⑧ 토론을, 신규 종목은 ② 다음에 ⑥ 7개 지표로 한 번 더 깊게 보고, 분기마다 ⑨ 백테스트로 내 매매 규칙을 점검하는 것을 덧붙이면 좋습니다.

## 활용 예시

- **확증 편향 극복**: ⑧ 토론으로 특정 종목(예: 테슬라)에 대한 긍정·부정 시각을 AI가 각각 대변하게 해, 내가 가진 확증 편향을 인지하고 균형 잡힌 결정을 내립니다.
- **투자 대상 비교 분석**: ⑥로 경쟁사(예: 삼성전자 vs SK하이닉스)의 재무 상태·성장성·건전성을 지표 기반으로 비교해 투자 가치가 높은 기업을 고릅니다.
- **자율 포트폴리오 관리**: ⑩으로 계좌 조회부터 리밸런싱, 매매 실행, 일지 기록까지 AI가 수행하게 해 시간과 노력을 절약합니다.
- **개인 투자자 — 출근 전 30분 매매 의사결정**: ③+① 조합으로 매일 출근 전 매수·매도 결정. 데이트레이더 수준의 정보를 무료로 받습니다.
- **장기 투자자 — 가치주 발굴**: ②+④+⑤ 조합으로 매월 본인 종목 평가 + 새 종목 발굴. 외국인·기관을 따라가는 추세 확인.
- **재무 컨설턴트 — 클라이언트 보고서 자동화**: 클라이언트 N명 보유 종목 각각 ①+②+④ 자동 분석 → 주간 보고서. 1인이 50+ 클라이언트 처리.
- **재테크 유튜버**: ③+① 매일 아침 자동 분석 → 영상 스크립트 → 매일 영상 1개 업로드.
- **재테크 블로거**: 본인 보유 종목 5개에 매주 ②+④+⑤ 분석 → 블로그 글 → 광고 수익.
- **재테크 학습자**: 매일 30분 루틴으로 학습 + 모의 매매 → 6개월 후 실전 진입.
- **부동산·암호화폐 투자자**: 같은 프롬프트를 부동산·암호화폐 용어로 치환해 다른 자산군을 분석합니다.
- **사내 투자 동아리**: 동료 5-10명이 각자 종목 분석 후 ⑤ 결과를 공유 → 집단 지성.

## 💡 아이디어

- **맞춤형 투자 보고서 생성**: 프롬프트를 조합해 투자자 성향과 보유 자산에 맞는 보고서를 자동 생성합니다. 예를 들어 가치투자 성향이면 ⑥ 7개 지표 비교와 ⑦ 페르소나 분석을 강화합니다.
- **실시간 시장 모니터링 및 알림**: ⑨ 돈치안 채널 규칙에 실시간 시장 데이터를 연동해, 채널 돌파 시 매수 신호 알림을 자동으로 받는 시스템을 만듭니다.
- **자동 매일 보고서 SaaS**: 사용자 보유 종목 등록 → 매일 프롬프트 자동 실행 → 슬랙·텔레그램 푸시 → 월 $10-20 구독.
- **재테크 뉴스레터 자동화**: 매주 시장 분석 → 뉴스레터 자동 발송 → 광고·제휴 수익.
- **종목 분석 자동화 1인 사업**: 클라이언트 1명당 본인 종목 5개 + 5종 분석 = 월간 보고서 → $50-100/월/클라이언트.
- **AI 주식 강의 패키지**: 프롬프트 + 활용법 + 책 《제미나이 주식투자》 추천 강의 4시간 ($100-200).
- **종목 코드 자동 입력 봇**: 종목명만 말하면 프롬프트 5종을 자동 실행 + 결과 통합 → 카카오톡 봇.
- **프롬프트 정확도 검증**: 과거 시점의 ⑤ 결과 vs 실제 시장 결과를 비교해 본인 프롬프트의 정확도를 검증합니다.

## 주의사항

- **투자 결정은 본인 책임**: 모든 결과는 정보 제공·분석 보조용입니다. AI 판단으로 매매해 생긴 손실 위험은 전적으로 본인에게 있으며, 이 문서는 투자 권유가 아닙니다.
- **실시간 데이터 정확도**: Gemini·Claude·ChatGPT는 학습 데이터 시점 차가 있습니다. 최신 시점 데이터는 증권사 앱·HTS로 따로 검증하세요.
- **지표 환각 주의**: PER·PBR·ROE 등 수치는 AI가 환각(hallucination)을 일으킬 수 있습니다. DART·증권사 리포트·지정한 재무제표 출처로 재검증이 필수입니다.
- **거시 예측은 시나리오 중 하나**: ⑤ 수석 애널리스트 결과는 입력한 시점·금리 상황·산업 변화에 따라 달라지는 시나리오 하나일 뿐입니다. 최신 정보를 정확히 넣고, 다른 의견·반대 시나리오(⑧)도 같이 검토하세요.
- **`[ ]` 정보는 정확히**: 종목명·섹터·시점을 정확하게 입력해야 답변도 정확합니다.
- **유료 도구·API**: ⑩의 KIS.MCP Server, dart-mcp 등은 별도 서비스·API 연동이 필요할 수 있습니다. 무료 대안 여부와 비용을 확인하세요.
- **자동 매매는 단계적으로**: ⑩의 매매 실행 단계는 실제 주문입니다. 계획 검토 후 수동 승인하는 방식부터 시작하세요.
- **백테스트의 한계**: ⑨의 템플릿 예시 데이터는 난수입니다. 실데이터로 돌려야 의미가 있고, 과거 성과가 미래 수익을 보장하지 않습니다.
- **개인정보**: 보유 종목·평단·수익률·계좌 정보 같은 민감 정보는 외부 LLM에 신중히 입력하세요.
