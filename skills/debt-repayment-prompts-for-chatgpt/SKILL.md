# ChatGPT로 빚 청산하는 7가지 프롬프트

💡 이 스킬은 **ChatGPT를 활용하여 개인의 부채 현황을 분석하고, 구체적인 상환 계획을 수립하며, 지출을 최적화하고, 이자를 절감하는 7가지 프롬프트를 제공**하는 스킬입니다.

## 이게 뭔가요?
전문가 수준의 재무 컨설팅은 비싸지만, ChatGPT는 무료로 이용 가능합니다. 이 7가지 프롬프트는 실제로 부채 상환에 사용되었으며, 순서대로 사용하면 4개월 안에 구체적인 재정적 변화를 만들 수 있습니다. 은행 명세서, 대출 내역, 월급 명세서 등을 ChatGPT에 입력하면 어떤 빚을 먼저 갚아야 하는지, 어떻게 지출을 줄여야 하는지, 이자를 어떻게 낮출 수 있는지 등을 즉시 분석해 줍니다.

## 따라하기

### 1. 부채 현황 완전 분석
- **목표**: 현재 가지고 있는 모든 부채의 총액과 세부 내역을 정확히 파악합니다.
- **방법**: 모든 대출, 카드 빚, 마이너스 통장 등의 정보를 ChatGPT에 입력합니다.
```
내 모든 부채 정보를 입력할게. 은행 대출, 카드론, 현금서비스, 마이너스 통장 등 모든 금융 기관의 정보를 포함해서 알려줘. 정확한 총액과 각 부채별 상세 내역(금액, 금리, 상환일, 대출 기관)을 파악하고 싶어.
```

### 2. 상환 우선순위 설계
- **목표**: 이자 손실을 최소화하면서 수학적으로 최적화된 상환 순서를 결정합니다.
- **방법**: 눈덩이 전략(Snowball)과 눈사태 전략(Avalanche) 중 본인 상황에 맞는 방식을 ChatGPT가 계산하도록 요청합니다.
```
내가 가진 부채 목록이야. (앞 단계에서 분석한 부채 정보를 여기에 구체적으로 입력)
각 부채의 금리와 금액을 바탕으로, 총 이자를 최소화할 수 있는 수학적으로 최적화된 상환 순서를 알려줘. 눈덩이(Snowball) 방식과 눈사태(Avalanche) 방식 중 나에게 더 유리한 방식은 무엇이고, 그 이유는 무엇인지도 설명해줘.
```

### 3. 월별 상환 플랜
- **목표**: 실제 실행 가능한 구체적인 월별 상환 계획을 수립합니다.
- **방법**: 월 소득과 고정 지출을 알려주고, 현실적인 월별 상환표 생성을 요청합니다.
```
내 월 소득은 OOO원이고, 이번 달 고정 지출은 OOO원이야. (앞 단계에서 결정된 상환 우선순위에 따라) 이번 달에는 OO원, 다음 달에는 OO원을 상환할 수 있도록 구체적인 월별 상환 계획표를 만들어줘. 각 월별 상환 금액과 남은 총 부채 금액을 포함해서.
```

### 4. 지출 구조 재설계
- **목표**: 낭비되는 지출을 찾아내고, 삶의 질은 유지하면서 지출을 줄이는 방법을 찾습니다.
- **방법**: 카드 명세서를 ChatGPT에 붙여넣고 낭비 항목 분석 및 절감 방안 제안을 요청합니다.
```
내 이번 달 카드 사용 내역이야. (카드 명세서를 여기에 붙여넣기)
내가 어디에 얼마를 썼는지 분석해주고, "이걸 왜 결제했지?" 싶을 만한 낭비 항목을 찾아줘. 또한, 나의 삶의 질을 크게 해치지 않으면서 지출을 줄일 수 있는 현실적인 방법을 제안해줘.
```

### 5. 이자 절감 협상 스크립트
- **목표**: 은행에 금리 인하 요구권을 신청하는 데 사용할 협상 스크립트를 얻습니다.
- **방법**: ChatGPT에게 금리 인하 요구권 신청을 위한 협상 스크립트 작성을 요청합니다.
```
내가 OO은행에서 받은 대출의 금리를 낮추고 싶어. (나의 신용 점수 개선, 소득 변화 등 금리 인하 요구권 신청 사유를 간략히 언급)
은행 담당자와 통화할 때 사용할 수 있는, 금리 인하 요구권 신청을 위한 설득력 있는 협상 스크립트를 작성해줘. 내가 사용할 수 있는 구체적인 발언 내용을 포함해서.
```

### 6. 긴급 현금 마련 전략
- **목표**: 상환 속도를 높이기 위한 추가 수입 확보 방안을 찾습니다.
- **방법**: 본인의 상황을 설명하고, 즉시 실행 가능한 추가 수입 창출 방법을 제안받습니다.
```
내 현재 상황은 이래. (현재 수입, 지출, 상환 계획 등을 간략히 설명)
상환 계획을 더 빠르게 실행하기 위해 추가 수입을 만들고 싶어. 지금 당장 실행할 수 있는 현실적인 추가 수입 창출 방법 몇 가지를 제안해줘. (예: 부업, 중고 판매, 절약 등)
```

### 7. 빚 0원 이후 재무 설계
- **목표**: 빚을 모두 갚은 후, 다시 같은 상황에 빠지지 않기 위한 재무 로드맵을 설계합니다.
- **방법**: 빚 청산 이후의 재무 목표와 자산 축적 계획 수립을 ChatGPT에 요청합니다.
```
나는 곧 모든 빚을 청산할 예정이야. 앞으로 다시는 이런 재정적 어려움을 겪지 않기 위해, 빚을 갚는 데 썼던 에너지를 자산을 쌓는 데 사용하고 싶어. 빚 0원 달성 이후를 위한 재무 설계 로드맵을 만들어줘. (예: 비상 자금 마련, 투자 계획, 은퇴 준비 등)
```

## 활용 예시

1.  **시나리오**: 사회 초년생 A씨는 여러 카드론과 학자금 대출로 인해 매달 이자 부담이 큽니다.
    *   **입력**: 위 "부채 현황 완전 분석" 및 "상환 우선순위 설계" 프롬프트를 자신의 부채 정보와 함께 사용합니다.
    *   **결과**: A씨는 자신의 총 부채 규모를 명확히 파악하고, 어떤 대출부터 갚아야 이자를 가장 많이 절약할 수 있는지 구체적인 순서를 알게 됩니다.

2.  **시나리오**: B씨는 "최대한 빨리 빚을 갚겠다"는 막연한 생각만 하고 실제 실행이 어렵습니다.
    *   **입력**: "월별 상환 플랜" 프롬프트에 자신의 월 소득과 고정 지출을 입력합니다.
    *   **결과**: B씨는 이번 달 얼마를, 다음 달 얼마를 상환해야 하는지 구체적인 숫자가 포함된 달력상의 계획을 얻어 실행력을 높입니다.

3.  **시나리오**: C씨는 대출 금리가 높다고 생각하지만, 금리를 낮추는 방법을 모릅니다.
    *   **입력**: "이자 절감 협상 스크립트" 프롬프트에 자신의 상황을 넣어 은행과의 협상 스크립트를 받습니다.
    *   **결과**: C씨는 은행에 전화하여 자신의 신용도 개선을 근거로 금리 인하를 요구하는 구체적인 대화 내용을 얻어 실제 금리 인하를 시도할 수 있습니다.
