# Claude에게 뭐든 배우기

💡 **Claude**를 정답 검색창이 아니라 **AI 과외 선생님**으로 씁니다. 로드맵 → **단계별 비유 설명** → **이해도 확인** → 오답 분석까지, 상황별 프롬프트에서 대괄호만 채워 붙여넣으면 됩니다.

## 이게 뭔가요?

Claude는 답을 알려주는 데서 그치지 않고, 원리를 설명하고 질문을 던져 스스로 이해했는지 확인시켜 주는 **과외 선생님**으로 쓸 수 있습니다. 이 문서는 그렇게 쓰기 위한 상황별 복붙 프롬프트를 학습 흐름 순서로 모은 팩입니다. "제대로 된 프롬프트 하나가 수십만 원짜리 강의보다 더 깊은 배움을 만든다"는 것이 핵심 메시지입니다.

핵심 원리는 세 가지입니다.

- **점진적 깊이**: 하나의 개념을 기초 → 중급 → 심화 3단계로 나눠, 비유로 시작해 전문 용어로 끝나게 합니다.
- **능동적 확인**: 설명 끝에 반드시 이해도 확인 질문·퀴즈를 받아 직접 답해 봅니다.
- **원리 중심 피드백**: 틀렸을 때 정답만이 아니라 "왜 틀렸는지"와 원리를 설명받습니다.

💰 유료 필요: 없음 (Claude 무료 플랜으로도 충분히 사용 가능)
✅ 무료 대안: Gemini, ChatGPT 등 다른 대화형 AI에도 프롬프트 구조 그대로 적용 가능

### 어떤 프롬프트를 언제 쓰나

| 지금 상황 | 쓸 프롬프트 |
|---|---|
| 새 분야를 시작하는데 어디서부터 할지 막막하다 | 01 학습 로드맵 |
| 어려운 개념을 처음 접했다 / 남에게 설명해야 한다 | 02 단계별 비유 설명 |
| 배운 걸 제대로 이해했는지 확인하고 싶다 | 03 이해도 테스트 |
| 책·강의 내용을 빠르게 흡수해 오늘 적용하고 싶다 | 04 책 요약 |
| 틀린 문제·쓴 글·코드에서 원리를 배우고 싶다 | 05 내 실수에서 배우기 |
| 돈 없이 제대로 된 자료를 찾고 싶다 | 06 무료 자료 큐레이션 |
| 정답 대신 스스로 생각하는 힘을 키우고 싶다 | 07 소크라테스식 튜터 |
| 상황 구분이 귀찮다, 일단 시작하고 싶다 | 보너스 만능 버전 |

## 따라하기

필요한 상황의 프롬프트를 골라 대괄호 `[ ]` 부분만 채워서 Claude에 그대로 붙여넣으세요. 권장 흐름은 **01 로드맵 → 02 설명 → 03 테스트 → 05 오답 분석**의 반복이며, 04·06·07은 필요할 때 끼워 넣습니다.

### 01 — 학습 로드맵 만들기

💡 새로운 분야를 처음 시작할 때, 어디서부터 공부해야 할지 막막할 때 사용합니다.

```
나는 [목표]를 위해 [스킬]을 배우고 싶어.
주당 [시간] 투자 가능.
무료 자료만 써서 주차별 학습 계획 짜줘.
각 주마다 무엇을 공부하고, 무엇을 만들고,
이해했는지 확인하는 법까지.
```

사용 예시:
- [목표] → 유튜브 채널 운영
- [스킬] → 영상 편집
- [시간] → 주 5시간

로드맵의 각 주차에 나오는 개념은 바로 아래 02번으로 하나씩 깊게 파고들면 됩니다.

### 02 — 단계별 비유 설명 (12살도 이해하게)

💡 어려운 개념을 처음 접할 때, 새로운 기술·프레임워크를 학습할 때, 복잡한 시스템이나 아이디어를 팀원에게 설명해야 할 때 사용합니다.

Claude가 지정한 주제를 비유로 설명하되 기초·중급·심화의 세 단계로 나눠 점진적으로 깊이를 더하고, 마지막에 이해도를 점검하는 질문 3개를 내서 능동적인 학습을 유도합니다.

```
[복잡한 개념]을 비유로 설명해줘.
기초→중급→심화 3단계로.
마지막에 내가 이해했는지 확인할 질문 3개도.
```

한 줄로 쓰고 싶다면 아래 버전도 같은 결과를 냅니다.

```
[주제]를 비유로 설명해줘. 기초→중급→심화 3단계로. 마지막엔 내가 이해했는지 확인할 질문 3개도.
```

사용 예시: [복잡한 개념] → 양자컴퓨터 / 블록체인 / SEO 알고리즘 / RAG / Function Calling / Phaser 엔진

진행 순서:

1. 설명받고 싶은 **[주제]**를 명확히 정의합니다. (예: "RAG", "Function Calling", "Phaser 엔진")
2. 프롬프트의 **[주제]**를 채워 Claude에 입력합니다.
3. 단계별 설명을 읽으며 학습하고, 마지막 3개의 질문에 직접 답하며 이해도를 점검합니다. 답을 Claude에 보내면 채점과 보충 설명을 받을 수 있습니다.
4. 필요하면 "더 구체적으로", "다른 비유로 설명해줘" 등의 추가 지시로 설명을 심화합니다.

**입력 예:**
```
[주제]를 비유로 설명해줘. 기초→중급→심화 3단계로. 마지막엔 내가 이해했는지 확인할 질문 3개도.

주제: RAG (Retrieval Augmented Generation)
```

### 03 — 이해도 테스트

💡 배운 내용을 제대로 이해했는지 확인하고 싶을 때 사용합니다. 02번의 확인 질문 3개로 부족하다고 느껴지면 이어서 쓰세요.

```
방금 배운 [개념] 관련 퀴즈 5개 내줘.
틀리면 틀린 이유와 원리를 설명해줘.
단순 정답 말고.
```

- 팁: 퀴즈를 풀고 나서 틀린 문제만 다시 모아서 복습 세션 만들어달라고 요청하면 오답 노트처럼 활용할 수 있습니다.

### 04 — 책 한 권을 10분에 요약

💡 책/강의 내용을 빠르게 흡수하고 오늘 바로 적용하고 싶을 때 사용합니다.

```
[책/강의]의 핵심 인사이트 10가지를 3~4문장으로 요약해줘.
각 인사이트마다 오늘 바로 실천할 수 있는
한 가지 행동도.
```

사용 예시: [책/강의] → 아토믹 해빗 / 부의 추월차선 / 마케팅 불변의 법칙

### 05 — 내 실수에서 배우기

💡 틀린 문제나 잘못 작성한 내용에서 원리를 파악하고 싶을 때 사용합니다.

```
내가 [문제를 해결/작성]한 내용이야: [붙여넣기].
무엇을 틀렸고 왜 틀렸는지 분석해줘.
정답보다 원리를 알고 싶어.
연습 문제 3개도.
```

- 팁: 에세이, 코드, 수학 문제, 영어 작문 등 뭐든 붙여넣으면 됩니다.

### 06 — 무료 자료 큐레이션

💡 돈 없이 제대로 배우고 싶을 때 사용합니다.

```
[주제]를 배우고 싶어.
돈 없이 배울 수 있는 최고의 무료 자료를 순위별로 알려줘.
유튜브, 플랫폼 강의, 커뮤니티 포함.
```

사용 예시: [주제] → 파이썬 / 포토샵 / 영어회화 / AI 활용

### 07 — 소크라테스식 AI 튜터

💡 단순히 정답을 받는 게 아니라, 스스로 생각하는 힘을 키우고 싶을 때 사용합니다.

```
[과목] 전문 튜터 역할을 해줘.
소크라테스식으로 질문하며 내가 스스로 깨닫게 도와줘.
2번 막히면 직접 설명하고 다시 테스트해줘.
```

사용 예시: [과목] → 철학 / 경제학 / 마케팅 전략 / 글쓰기

### 보너스 — 오늘 당장 쓰는 만능 버전

상황을 구분하기 귀찮다면, 아래 통합 프롬프트 하나로 시작해도 됩니다.

```
나는 [목표]를 이루고 싶어.
[스킬]을 처음부터 가르쳐줘.
비유와 예시를 사용하고,
내가 이해했는지 확인해줘.
틀리면 원리부터 설명해줘.
```

## 활용 예시

- **유튜브 채널을 시작하려는 초보자**: 01번에 [목표]=유튜브 채널 운영, [스킬]=영상 편집, [시간]=주 5시간을 입력 → 주차별 무료 학습 로드맵(1주차: 컷 편집 기초 툴 익히기, 2주차: 자막·효과음 넣기... 식)을 받습니다.
- **새 AI 기술을 익히는 초보 개발자**: 02번에 RAG, Function Calling, 프롬프트 엔지니어링 같은 개념을 넣어 단계별 설명을 받고, 확인 질문 3개에 답한 뒤 03번 퀴즈로 넘어갑니다.
- **팀 교육 자료 제작**: 02번의 기초·중급·심화 출력을 그대로 사내 교육 슬라이드의 3단 구성(입문자용 비유 → 실무 설명 → 아키텍처)으로 옮겨 씁니다.
- **자격증 준비**: 시험 범위의 어려운 개념(예: 클라우드 AI 서비스 개념)을 02번으로 단계별 학습하고, 03번 퀴즈로 이해도를 점검합니다.
- **파이썬 독학자**: 06번에 [주제]=파이썬을 입력 → 무료 유튜브 강의, 무료 플랫폼 강좌, 커뮤니티(예: 인프런 무료 강의, 점프 투 파이썬, 파이썬 관련 디스코드/카페) 순위 목록을 받습니다.
- **영어 작문 연습**: 자신이 쓴 문장을 05번에 붙여넣기 → 어디서 어떤 문법 원리를 틀렸는지 분석받고, 같은 원리를 다시 테스트할 연습 문제 3개를 받습니다.

## 💡 아이디어

- 강의·클래스를 운영한다면 이 프롬프트 팩을 수강생용 "학습 온보딩 자료"로 배포해, 강의 전 자기주도 학습을 유도하는 무료 리드마그넷으로 쓸 수 있습니다.
- 01번(로드맵)과 03번(이해도 테스트)을 묶어 "N주 챌린지" 형태의 콘텐츠 시리즈로 재구성하면 인스타그램/블로그 연재 포맷으로 확장할 수 있습니다.
- 02번 출력의 3단계 구조는 그대로 "초보용 / 실무용 / 전문가용" 3단 설명 카드뉴스로 재가공하기 좋습니다.

## 주의사항

- Claude가 만든 학습 로드맵·요약·설명도 최신성이 떨어지거나 사실과 다를 수 있습니다. 특히 도구 사용법·가격 정보 등은 실제 서비스에서 한 번 더 확인하는 것이 안전합니다.
- 비유의 적절성은 모델에 따라 달라질 수 있습니다. 비유가 와닿지 않으면 "다른 비유로 설명해줘"로 보완하세요.
- 복잡성이 매우 높은 주제는 3단계로 부족할 수 있습니다. 단계를 더 세분화하거나 원하는 비유(예: "요리에 비유해서")를 직접 지정해 주세요.
