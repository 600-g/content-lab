# Claude에게 뭐든 배우기

💡 이 스킬은 **Claude**를 개인 과외 선생님처럼 활용해 학습 로드맵 설계·개념 설명·이해도 테스트·요약·오답 분석까지 처리하는 **7종 복붙 프롬프트 팩**입니다.

## 이게 뭔가요?

Claude는 단순히 정답을 알려주는 검색창이 아니라, 질문을 던지고 원리를 설명하며 스스로 이해했는지 확인시켜주는 **AI 과외 선생님**으로 쓸 수 있습니다. 이 스킬은 그렇게 쓰기 위한 7가지 상황별 복붙 프롬프트를 모아둔 프롬프트 팩입니다. 학습 로드맵 짜기, 어려운 개념 쉽게 설명받기, 이해도 테스트, 책 요약, 내 실수 분석, 무료 자료 큐레이션, 소크라테스식 튜터링까지 — "제대로 된 프롬프트 하나가 수십만 원짜리 강의보다 더 깊은 배움을 만든다"는 것이 핵심 메시지입니다.

💰 유료 필요: 없음 (Claude 무료 플랜으로도 충분히 사용 가능)
✅ 무료 대안: Gemini, ChatGPT 등 다른 대화형 AI에도 프롬프트 구조 그대로 적용 가능

## 따라하기

아래 7개 프롬프트 중 지금 필요한 상황에 맞는 것을 골라 대괄호 `[ ]` 부분만 채워서 Claude에 그대로 붙여넣으세요.

### 01 — 학습 로드맵 만들기

💡 새로운 분야를 처음 시작할 때, 어디서부터 공부해야 할지 막막할 때 사용합니다.

```
나는 [목표]를 위해 [스킬]을 배우고 싶어.
주당 [시간] 투자 가능.
무료 자료만 써서 주차별 학습 계획 짜줘.
각 주마다 무엇을 공부하고, 무엇을 만들고,
이해했는지 확인하는 법까지.
```

사용 예시:
- [목표] → 유튜브 채널 운영
- [스킬] → 영상 편집
- [시간] → 주 5시간

### 02 — 12살도 이해하게 설명해줘

💡 어려운 개념을 처음 접할 때, 쉽게 이해하고 싶을 때 사용합니다.

```
[복잡한 개념]을 비유로 설명해줘.
기초→중급→심화 3단계로.
마지막에 내가 이해했는지 확인할 질문 3개도.
```

사용 예시: [복잡한 개념] → 양자컴퓨터 / 블록체인 / SEO 알고리즘

### 03 — 이해도 테스트

💡 배운 내용을 제대로 이해했는지 확인하고 싶을 때 사용합니다.

```
방금 배운 [개념] 관련 퀴즈 5개 내줘.
틀리면 틀린 이유와 원리를 설명해줘.
단순 정답 말고.
```

- 팁: 퀴즈를 풀고 나서 틀린 문제만 다시 모아서 복습 세션 만들어달라고 요청하면 오답 노트처럼 활용할 수 있습니다.

### 04 — 책 한 권을 10분에 요약

💡 책/강의 내용을 빠르게 흡수하고 오늘 바로 적용하고 싶을 때 사용합니다.

```
[책/강의]의 핵심 인사이트 10가지를 3~4문장으로 요약해줘.
각 인사이트마다 오늘 바로 실천할 수 있는
한 가지 행동도.
```

사용 예시: [책/강의] → 아토믹 해빗 / 부의 추월차선 / 마케팅 불변의 법칙

### 05 — 내 실수에서 배우기

💡 틀린 문제나 잘못 작성한 내용에서 원리를 파악하고 싶을 때 사용합니다.

```
내가 [문제를 해결/작성]한 내용이야: [붙여넣기].
무엇을 틀렸고 왜 틀렸는지 분석해줘.
정답보다 원리를 알고 싶어.
연습 문제 3개도.
```

- 팁: 에세이, 코드, 수학 문제, 영어 작문 등 뭐든 붙여넣으면 됩니다.

### 06 — 무료 자료 큐레이션

💡 돈 없이 제대로 배우고 싶을 때 사용합니다.

```
[주제]를 배우고 싶어.
돈 없이 배울 수 있는 최고의 무료 자료를 순위별로 알려줘.
유튜브, 플랫폼 강의, 커뮤니티 포함.
```

사용 예시: [주제] → 파이썬 / 포토샵 / 영어회화 / AI 활용

### 07 — 소크라테스식 AI 튜터

💡 단순히 정답을 받는 게 아니라, 스스로 생각하는 힘을 키우고 싶을 때 사용합니다.

```
[과목] 전문 튜터 역할을 해줘.
소크라테스식으로 질문하며 내가 스스로 깨닫게 도와줘.
2번 막히면 직접 설명하고 다시 테스트해줘.
```

사용 예시: [과목] → 철학 / 경제학 / 마케팅 전략 / 글쓰기

### 보너스 — 오늘 당장 쓰는 만능 버전

7가지 상황을 구분하기 귀찮다면, 아래 통합 프롬프트 하나로 시작해도 됩니다.

```
나는 [목표]를 이루고 싶어.
[스킬]을 처음부터 가르쳐줘.
비유와 예시를 사용하고,
내가 이해했는지 확인해줘.
틀리면 원리부터 설명해줘.
```

## 활용 예시

- 유튜브 채널을 시작하려는 초보자가 01번 프롬프트에 [목표]=유튜브 채널 운영, [스킬]=영상 편집, [시간]=주 5시간을 입력 → Claude가 주차별 무료 학습 로드맵(1주차: 컷 편집 기초 툴 익히기, 2주차: 자막·효과음 넣기... 식)을 만들어줍니다.
- 파이썬을 독학하려는 사람이 06번 프롬프트에 [주제]=파이썬을 입력 → 무료 유튜브 강의, 무료 플랫폼 강좌, 커뮤니티(예: 인프런 무료 강의, 점프 투 파이썬, 파이썬 관련 디스코드/카페) 순위 목록을 받습니다.
- 영어 작문을 하고 05번 프롬프트에 자신이 쓴 문장을 붙여넣기 → 어디서 어떤 문법 원리를 틀렸는지 분석받고, 같은 원리를 다시 테스트할 연습 문제 3개를 받습니다.

## 💡 아이디어

- 두근컴퍼니의 AI 인스타툰/광고영상/그림책 클래스 준비생에게 이 프롬프트 팩을 "학습 온보딩 자료"로 배포하면, 강의 전 자기주도 학습을 유도하는 무료 리드마그넷으로 활용할 수 있습니다.
- 01번(로드맵)과 03번(이해도 테스트)을 묶어 "N주 챌린지" 형태의 콘텐츠 시리즈로 재구성하면 인스타그램/블로그 연재 포맷으로 확장 가능합니다.

## 주의사항

- Claude가 만든 학습 로드맵이나 요약도 최신성이 떨어지거나 사실과 다를 수 있으므로, 특히 도구 사용법·가격 정보 등은 실제 서비스에서 한 번 더 확인하는 것이 안전합니다.
- 소크라테스식 튜터(07번) 프롬프트는 대화가 길어질수록 맥락을 유지해야 하므로, 같은 채팅창 안에서 이어서 질문하는 것이 효과적입니다.
