# 3D 지구본 실시간 관제하기

💡 **God's Eye View**는 전 세계 실시간 공개 데이터를 사진 같은 3D 지구본 위에 겹쳐 보여주는 MIT 오픈소스 앱입니다. **cmd 복붙 몇 줄**이면 구글 키 없이 **0원**으로 돌아갑니다.

## 이게 뭔가요?

**God's Eye View**는 브라우저에서 실행되는 3D 지구본 애플리케이션입니다. 항공기(민항기+군용기), 선박, 위성·ISS, 도시 CCTV, 지진, 화재, 교통, 라디오 정보 같은 전 세계 실시간 공개 데이터를 사진처럼 사실적인 3D 지구 위에 그대로 오버레이합니다. 제작자 Bilawal Sidhu가 2026년에 코드를 전부 **MIT 라이선스**로 무료 공개했습니다(원본 저장소: github.com/bilawalsidhu/gods-eye-view · 데이터 출처 상세: DATA_SOURCES.md).

### 핵심 기능

- **비행기 추적** — 지금 하늘에 떠 있는 실제 항공기를 실시간 추적
- **조종석 모드** — 추적 중인 비행기에 카메라를 태워서 실제 지형 위를 함께 비행
- **위성·ISS** — 궤도 위 위성을 클릭하면 궤도를 따라 함께 이동
- **CCTV** — 공개된 도시 CCTV 영상이 3D 도시 공간에 실제로 투영됨
- **지진·화재·선박·교통·라디오** — 전부 공개 데이터 기반
- **센서 스타일 7종** — 키보드 숫자로 CRT / 야간투시경(NVG) / 열화상(FLIR) 등 전환
- **음성 조종** — "도쿄로 가줘" 같은 말로 지구본 조작(선택 기능, 유료 키 필요)

이 앱은 특정 개인을 검색하거나 얼굴을 인식하는 기능을 의도적으로 만들지 않았습니다. 공개된 사물·시설·이벤트(비행기, 배, 카메라, 지진 등)만 다룹니다.

## 따라하기

준비물: 윈도우 PC, 인터넷, 크롬(또는 다른 브라우저). 코딩 지식 불필요.

### 1. Node.js 설치

1. [nodejs.org](https://nodejs.org/)에서 Windows Installer(.msi)를 다운로드합니다. LTS 최신 버전을 권장합니다.
2. 설치는 "다음"만 계속 누르면 됩니다.
3. 설치 후 컴퓨터를 **반드시 재시작**합니다. 재시작하지 않으면 다음 단계에서 `'npm'은(는) 내부 또는 외부 명령이 아닙니다` 오류가 날 수 있습니다.

### 2. 명령 프롬프트(cmd) 열기

`PowerShell` 대신 **명령 프롬프트(cmd)**를 사용합니다. PowerShell은 보안 정책 때문에 `npm : 이 시스템에서 스크립트를 실행할 수 없으므로...` 오류가 자주 발생하는데, cmd에는 이 제한이 없습니다.

1. `⊞`(윈도우 키)를 누른 후 `cmd`를 입력하고 검색 결과의 "명령 프롬프트"를 클릭합니다.
2. 아래 두 줄을 각각 입력하고 엔터를 누릅니다.

```bash
node -v
npm -v
```

버전 번호(예: `v24.14.0`, `v26.8.1`)가 표시되면 성공입니다.

### 3. 코드 다운로드

아래 코드를 통째로 복사해 명령 프롬프트에 붙여넣고(마우스 오른쪽 클릭 = 붙여넣기) 엔터를 누릅니다.

```bash
mkdir C:\gev 2>nul & cd /d C:\gev
curl -L -o gev.zip https://github.com/bilawalsidhu/gods-eye-view/archive/refs/heads/main.zip
tar -xf gev.zip
move gods-eye-view-main gods-eye-view
cd gods-eye-view
```

### 4. 키 없이 실행할 `.env` 만들기

```bash
echo GOOGLE_MAPS_API_KEY=>.env
echo OPENSKY_AUTH_MODE=anon>>.env
```

구글 키 칸을 비워 두고 OpenSky는 익명 모드로 쓰는 설정입니다 — 이 상태가 0원 모드입니다.

### 5. 설치하고 실행하기

설치에는 3~8분 정도 걸립니다.

```bash
npm install
```

`npm warn` 메시지나 `X high severity vulnerabilities` 문구는 정상이며 무시해도 됩니다. **절대 `npm audit fix`를 실행하지 마세요.** 버전이 깨질 수 있습니다.

설치가 끝나면 실행합니다.

```bash
npm run dev -- --host localhost --port 4173
```

화면에 `Local: http://localhost:4173/` 줄이 보이고 커서가 멈춰 있으면 정상 작동 중입니다. **이 창은 앱을 쓰는 동안 계속 열어 둬야 합니다** — 닫으면 앱도 꺼집니다. 브라우저 주소창에 `http://localhost:4173`을 입력해 접속합니다.

다음에 다시 실행할 때는 두 줄만 칩니다.

```bash
cd /d C:\gev\gods-eye-view
npm run dev -- --host localhost --port 4173
```

앱을 끌 때는 실행 창을 클릭한 후 `Ctrl + C`를 누릅니다.

#### 한국어로 보기

앱 자체는 한글을 지원하지 않지만(개발자가 다국어 기능을 만들지 않음), 크롬 자동 번역을 켜면 됩니다. 접속 시 나타나는 "한국어로 번역" 배너를 그대로 쓰면 일부 버튼 이름이 어색하게 번역될 수 있지만 사용에는 무리가 없습니다. 아래 설명의 버튼 이름은 원문(영어) 기준입니다.

### 6. 처음 5분 — 뭐부터 눌러볼까

1. 첫 화면 팝업에서 **LIVE CONTACTS**를 클릭하면 실시간 비행기 정보가 표시됩니다. 아무 비행기나 클릭하면 카메라가 고정되고 정보 카드가 뜹니다.
2. `C` 키 또는 **COCKPIT** 버튼을 누르면 선택한 비행기의 조종석 시점으로 전환됩니다.
3. 숫자 `1`~`7` 키로 CRT, 야간 투시경(NVG), 열화상(FLIR) 등 화면 스타일을 바꿉니다.
4. `H` 키는 HUD 표시, `D` 키는 탐지 박스 표시, `Esc` 키는 시점에서 빠져나옵니다.
5. **Satellites**를 켜고 ISS(국제 우주 정거장)를 클릭하면 궤도를 따라 함께 이동합니다.
6. 탐색이 끝나면 **Reset Globe** 버튼으로 전체 지구본 화면으로 돌아옵니다.

| 키 | 동작 |
|---|---|
| `C` | 조종석(COCKPIT) 시점 |
| `1`~`7` | 센서 스타일(CRT / NVG / FLIR 등) |
| `H` | HUD 표시 |
| `D` | 탐지 박스 표시 |
| `Esc` | 시점 빠져나오기 |

### 7. CCTV 보기

1. 화면이 잘려 보이면 `Ctrl` + `-` 키로 브라우저 배율을 낮춥니다.
2. 오른쪽 패널에서 **CCTV**를 클릭해 펼칩니다.
3. `CCTV OFF` 버튼을 `CCTV ON`으로 바꾸면 카메라 로딩이 시작됩니다.
4. **NEAREST**는 가장 가까운 카메라를 찾고, **FOCUS**는 해당 카메라 시점으로 이동합니다. 영상이 3D 도시 위에 실제로 투영됩니다.
5. **COVERAGE**를 켜면 카메라 시야 범위가 입체적으로 표시됩니다.
6. `PREV` / `NEXT`로 카메라를 넘기거나, **AUTO HOP**을 켜면 카메라를 자동으로 순회합니다.

CCTV는 현재 오스틴(텍사스), 캘리포니아, 런던 지역에만 약 800대가 있습니다. 다른 도시나 한국에서는 CCTV를 켜도 영상이 안 보이는 것이 정상입니다. 검색창에 `Austin`, `London` 등을 입력해 해당 지역으로 이동한 뒤 다시 시도합니다.

### 8. 무료 키 2개 추가 — 화질·정확도 업그레이드(카드 등록 없음)

**Cesium ion — 위성사진 지구본**

1. [cesium.com/ion/signup](https://cesium.com/ion/signup)에서 무료 가입합니다.
2. 로그인 후 **Access Tokens** 탭으로 이동합니다.
3. **Default Token** 문자열을 복사합니다.

**TomTom — 실제 교통 정체**

1. [developer.tomtom.com](https://developer.tomtom.com/)에서 회원가입 후 로그인합니다.
2. **Dashboard** → **My Keys**로 이동합니다.
3. 기본 생성된 키 문자열을 복사합니다.

**앱에 적용하기**

1. 실행 창에서 `Ctrl` + `C`를 눌러 서버를 중지합니다(저장 여부를 물으면 `Y` 입력).
2. 같은 창에 `notepad .env`를 입력하고 엔터를 눌러 메모장을 엽니다.
3. 파일 맨 아래에 아래 두 줄을 추가하고 저장(`Ctrl`+`S`)합니다.

```
CESIUM_ION_TOKEN=복사한_Cesium_토큰
TOMTOM_API_KEY=복사한_TomTom_키
```

4. 서버를 다시 시작합니다.

```bash
npm run dev -- --host localhost --port 4173
```

5. 브라우저를 새로고침(`F5`)합니다.

확인: 지도 선택 칩에서 **Bing Aerial**이 활성화되면 성공입니다. **Traffic**을 켜고 도심으로 8km 이하까지 내려가면 흰 점 대신 실제 색깔로 표시되는 교통 정체를 볼 수 있습니다.

## 활용 예시

- **실시간 비행 추적 쇼츠**: 항공기 클릭 → **COCKPIT**으로 조종석 시점 진입 → 열화상(FLIR) 필터 전환 후 화면 녹화 → 몰입감 있는 쇼츠 소재.
- **라이브 도시 콘텐츠**: CCTV 패널에서 오스틴/런던으로 이동 → **AUTO HOP**을 켜 도시 곳곳을 자동 순회하는 화면을 녹화 → "지금 이 순간의 런던" 같은 영상.
- **우주·과학 오프닝**: Satellites 켜고 ISS 클릭 → 궤도를 따라가는 화면 캡처 → 정보성 콘텐츠의 오프닝 영상.
