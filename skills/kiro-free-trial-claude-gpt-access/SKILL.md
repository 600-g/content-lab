# Kiro 무료 프로모션으로 Claude 쓰기

💡 이 스킬은 AI 코딩 도구 **Kiro** 의 유료 플랜(Pro / Pro+) 프로모션을 **결제금액 0원**으로 신청해 Claude·GPT 계열 모델을 무료로 체험하고, **자동 결제를 미리 해지**하는 절차입니다.

## 이게 뭔가요?

Kiro(app.kiro.dev)는 웹에서 가입해 쓰는 AI 서비스로, 유료 플랜인 **Kiro Pro** 와 **Kiro Pro+** 를 제공합니다. 원문 작성자(여행 인플루언서 겸 AI·영상 크리에이터 솔랄라)에 따르면, 현재 프로모션 덕분에 이 유료 플랜을 **결제금액 0원**으로 신청할 수 있고, 이를 통해 Claude와 ChatGPT(GPT) 계열 모델을 무료로 써볼 수 있다고 합니다. 원문 기준 무료 이용 가능 기한은 **2026년 9월 30일까지**입니다.

핵심은 두 가지입니다. 첫째, 결제 화면에서 최종 금액이 0원으로 표시되는지 확인하고 진행한다. 둘째, 카드를 등록해야 하므로 무료 기간이 끝나면 자동으로 유료 결제가 될 수 있어, 원치 않으면 **미리 Kiro Free 로 해지**해 둔다. 원문 작성자도 이 해지 안내를 "가장 중요한 부분"이라고 강조합니다.

원문 작성자는 약 2개월 전부터 "한 달 무료 이용" 프로모션이 계속 진행되어 왔다고 설명합니다. 다만 프로모션 조건은 언제든 바뀔 수 있으므로, 결제 화면의 최종 금액을 직접 확인하는 것이 가장 정확합니다.

- 사용 도구: Kiro (웹), 내부에서 Claude·GPT 계열 모델 사용
- 💰 유료 필요: 프로모션 종료 후 Kiro Pro / Pro+ 정식 구독료가 청구됨
- ✅ 무료 대안: 카드 등록이 부담되면 Gemini, ChatGPT 무료 플랜, Gemma4(Ollama 로컬)로 가능

## 따라하기

1. **가입**: 아래 사이트에 접속해 가입합니다. (원문에 "광고X"로 명시)

```
https://app.kiro.dev/
```

2. 가입 후 화면에서 **Upgrade plan** 을 클릭합니다.

3. **플랜 선택**: Upgrade Plan 화면에서 **Kiro Pro** 또는 **Kiro Pro+** 를 선택합니다. 원문 작성자는 **Kiro Pro+** 를 추천합니다.

4. **0원 확인**: 결제 화면에서 결제 금액이 **0원**으로 표시되는지 반드시 확인합니다. 0원이 아니면 진행하지 않습니다.

5. **카드 정보 입력 후 결제 버튼**을 누르면 이용이 가능해집니다.
   - 카드 결제 알림이 오더라도, 원문에 따르면 실제 결제가 완료되는 것이 아니라 바로 해외 결제 취소 처리됩니다.

6. **자동결제 해지(가장 중요)**: 카드가 등록되어 있으므로 이용 기간이 끝나면 자동으로 유료 결제가 진행될 수 있습니다. 원치 않으면 미리 아래 순서로 해지합니다.
   1. 프로필 아이콘 → **Account** → **Manage Plan** 클릭
   2. **구독 업데이트(Update Subscription)** 클릭
   3. **Kiro Free** 선택
   4. **Continue** → **Confirm** 순서로 진행

7. **해지 후 동작**: 중간에 해지해도 현재 이용 중인 유료 플랜은 해당 이용 기간이 끝날 때까지 그대로 쓸 수 있습니다. 다음 결제 주기부터 Kiro Free 로 전환되며 추가 월 구독료는 청구되지 않는다고 합니다.

## 활용 예시

- **바로 체험하기**: 오늘 가입 → Pro+ 선택 → 결제금액 0원 확인 → 카드 등록 → 그날 바로 Manage Plan 에서 Kiro Free 로 변경 → 이용 기간이 끝날 때까지 유료 플랜 기능을 그대로 사용하고, 다음 주기부터는 자동으로 무료 플랜 전환
- **Claude Max 와 비교 테스트**: 같은 코딩 과제를 Kiro 안의 Claude 모델과 기존 Claude Code CLI 에 각각 시켜 결과를 비교해 본다
- **결제 알림 대응**: 카드사에서 해외 결제 알림이 오면 원문 설명대로 곧바로 취소 처리되는지 카드 내역에서 확인한다

## 💡 아이디어

- 프로모션 종료일(2026-09-30) 전후로 결제 화면이 여전히 0원인지 확인하는 체크리스트를 만들어 두면, 가입·해지 시점을 놓치지 않는다
- 여러 AI 도구를 무료로 비교 체험하는 콘텐츠(블로그·인스타 릴스)의 소재로 활용할 수 있다

## 주의사항

- **자동결제 위험**: 해지하지 않으면 무료 기간 종료 후 실제 구독료가 청구될 수 있습니다. 가입 직후 해지까지 마쳐 두는 것이 안전합니다.
- **0원 확인 필수**: 최종 결제 금액이 0원이 아니면 진행하지 않습니다. 원문 작성자는 안내를 확인하지 않아 생기는 문제에 책임지지 않는다고 밝히고 있습니다.
- **기한 임박**: 원문 기준 무료 기간은 2026년 9월 30일까지입니다. 이 문서 작성 시점(2026-09-21)에는 며칠 남지 않았습니다. 원문은 10월 초에도 무료 프로모션이 있는지 다시 확인해 보라고 권합니다.
- **다른 계정 재가입 제안은 신중히**: 원문은 10월 초에 다른 계정으로 신규 가입하면 프로모션이 적용되는지 확인해 보라고 하지만, 이는 이용약관에 어긋날 수 있습니다. 실행 전 Kiro 의 프로모션 약관을 직접 확인하세요.
- **원문 검증 한계**: 프로모션 내용과 "Claude·GPT 무료 이용" 범위는 블로그 작성자의 주장이며 공식 문서로 확인된 것이 아닙니다. 사용 가능한 모델과 한도는 Kiro 공식 페이지에서 확인하세요.
