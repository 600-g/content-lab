# 한국 생활정보 스킬 묶음 설치하기

💡 이 스킬은 GitHub 주소 하나를 붙여넣어 **k-skill**(한국 생활용 AI 스킬 125개)을 클로드에 연결하고, KTX 시간표·부동산 실거래가·판례·쇼핑 최저가를 **평소 말투로 조회**하는 스킬입니다.

## 이게 뭔가요?

k-skill은 NomaDamas 팀이 GitHub에 무료로 공개한 **한국 생활용 AI 스킬 125개 묶음**입니다. 교통, 부동산, 법률, 투자, 쇼핑, 날씨, 생활 정보까지 20개 분야로 나뉘어 있고, 분야별 스킬 목록은 GitHub README 표에서 확인할 수 있습니다.

클로드에 붙여 두면 "이번 주말 부산 가는 KTX 있어?"처럼 평소 말투로 물어도 해당 데이터를 조회해서 답해 줍니다. 대부분의 공공데이터 스킬은 운영자 서버(프록시)를 거치기 때문에, 사용자가 따로 API 키를 발급받지 않아도 됩니다.

- 라이선스: MIT (누구나 무료로 쓰고 고칠 수 있는 공개 라이선스). 프록시 관련 폴더는 AGPL-3.0입니다.
- 어떤 AI 도구에서 쓰나요: Claude(코워크 Cowork에 주소를 붙여넣는 방식), ChatGPT(워크 화면에 같은 방식으로 붙여넣는 방식)
- 두근 환경: Claude Max 구독 환경에서 Claude 기준으로 쓰는 흐름입니다.

💰 유료 필요: 스킬 자체는 무료이며, 클로드를 쓰려면 구독 플랜이 필요합니다. 두근 환경에서는 이미 Claude Max를 사용 중입니다.

## 따라하기

1. Claude를 열고 코워크(Cowork)를 실행합니다. ChatGPT를 쓴다면 워크 화면을 엽니다.
2. 아래 GitHub 주소를 붙여넣고, 하고 싶은 일을 평소 말투로 말합니다. 플러그인 설치나 설정 화면은 필요 없습니다.

```
https://github.com/NomaDamas/k-skill 이거 보고 이번 주말 부산 가는 KTX 시간표 알려줘
```

3. AI가 질문에 맞는 스킬을 고른 뒤 데이터를 조회해서 답합니다. 어떤 스킬을 쓸지는 AI가 정합니다.
4. 명령어로 설치했다면 주소 없이 질문만 해도 됩니다.
5. 일부 스킬은 인증 정보가 필요할 수 있습니다. 설치 뒤 클로드에 아래처럼 요청하면 필요한 설정을 확인해 줍니다.

```
k-skill-setup 실행해줘
```

6. 답이 마음에 들지 않으면 지역·기간·조건을 바꿔 다시 묻습니다. 질문 예시는 출발점일 뿐이므로, 내 상황에 맞게 계속 고쳐 가는 것이 가장 중요합니다.

### 부동산

곧 매매할 건데 어딜 사야 투자하기 좋을까?

```
곧 매매할건데 어딜 사야 투자하기 좋을까?
```

클로드가 아파트·빌라 실거래가와 전월세(real-estate-search), LH 분양·임대 공고(lh-notice-search), 법원 경매 매각공고(court-auction-notice-search)를 찾아 지역별로 모아 비교해 줍니다. 관심 지역과 예산을 같이 적으면 비교 범위가 좁혀집니다.

이 스킬은 어느 동네가 오를지 예측하지 않습니다. 실거래가·청약·경매 자료를 모아 보여 줄 뿐이며, 살지 말지는 그 자료를 보고 직접 판단해야 합니다.

```
마포구 공덕동 아파트 최근 실거래가 알려줘
```

```
지금 접수 중인 LH 청약 공고 있어? 마감일도 같이
```

```
이번 달 서울 법원 경매로 나온 아파트 찾아줘
```

### 법률

```
이거 환불 불가라는데 이거 맞는거야?
```

클로드가 korean-law-search로 관련 법령 조문과 판례, 유권해석을 찾아 줍니다. 판매처의 환불 안내 문구나 약관을 같이 붙여 넣으면 관련 조문과 나란히 놓고 볼 수 있습니다.

iros-registry-automation은 인터넷등기소에서 부동산·법인 등기부등본을 장바구니에 담고, 결제 후 열람·저장하는 과정을 도와줍니다. 결제는 직접 하셔야 합니다.

```
전세 보증금을 못 돌려받고 있어. 관련 법 조문이랑 판례 찾아줘
```

```
이 집 등기부등본 떼는 거 도와줘
```

### 쇼핑

```
이 제품 어디가 최저가인지 찾아와
```

"이 제품" 자리에는 제품명이나 모델명을 넣어 주세요. 클로드가 쿠팡(coupang-product-search), 네이버쇼핑(naver-shopping-search), 다나와(danawa-price-search)에서 같은 상품을 찾아 판매처별 가격을 비교합니다. 다나와 쪽은 배송비를 더한 실구매가와 카드 할인가까지 확인합니다.

```
에어팟 프로 쿠팡, 네이버쇼핑, 다나와 가격 비교해줘
```

### 그 밖의 분야

```
교통: 내일 아침 서울에서 부산 가는 KTX 시간표 알려줘
투자: 삼성전자 최근 시세랑 공시, 배당 내역 정리해줘
중고거래: 당근이랑 번개장터에 아이패드 미니 중고 매물 찾아줘
배송: 이 송장번호 배송 어디쯤인지 알려줘
날씨: 오늘 우리 동네 미세먼지 어때?
```

## 활용 예시

- 부동산 시세 비교: "마포구 공덕동 아파트 최근 실거래가 알려줘" → 최근 실거래가를 조회해 정리해서 답합니다. 여기에 "예산 10억, 출퇴근 기준 지하철역 근처로 좁혀줘"처럼 조건을 더하면 비교 범위가 줄어듭니다.
- 쇼핑 최저가 찾기: "에어팟 프로 쿠팡, 네이버쇼핑, 다나와 가격 비교해줘" → 판매처별 가격을 모아 보여 주고, 다나와 쪽은 배송비 포함 실구매가와 카드 할인가를 함께 확인합니다.
- 환불 조건 확인: 판매처 환불 안내 문구를 붙여넣고 "이거 환불 불가라는데 이거 맞는거야?"라고 물으면 → 관련 법 조문과 나란히 놓고 해석 근거를 함께 보여 줍니다.

## 주의사항

- 조회만 됩니다. KTX는 시간표 조회만 가능하고 예매·대기·결제·취소는 안 됩니다. 항공권도 검색과 가격 비교까지만 됩니다.
- 등기부등본은 떼는 흐름만 도와주며, 결제는 직접 해야 합니다.
- 부동산·법률·투자 답변은 참고용입니다. 매매·소송 판단은 원문 확인과 전문가 상담을 거쳐 직접 하세요.
- 공공데이터 조회는 개인 비영리 용도로만 사용해야 합니다. 대량 수집이나 접근 제한 우회는 금지입니다.
- 토스증권처럼 내 계좌를 보는 스킬은 사용자의 로그인·인증이 따로 필요합니다.
- 쿠팡, 네이버 같은 서비스 이름은 기능 설명용이며 공식 제휴가 아닙니다.
- 공공 API 프록시 개인정보 처리 안내: k-skill-proxy.nomadamas.org/privacy
