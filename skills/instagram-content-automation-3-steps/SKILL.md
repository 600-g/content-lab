# 인스타 콘텐츠 자동화 3단계

💡 클로드와 연동된 도구들을 활용하여 유튜브 트렌드를 수집하고, 인사이트를 기반으로 인스타 캐러셀 콘텐츠를 자동으로 생성하는 스킬입니다.

## 이게 뭔가요?
이 스킬은 **Claude**의 **예약 작업** 기능을 핵심으로 하여, **유튜브**의 실시간 트렌드를 자동으로 수집하고 분석하여 **콘텐츠 기획의 초기 단계**를 자동화하는 프로세스입니다. 단순히 데이터를 모으는 것을 넘어, 사람들이 실제로 궁금해하는 **댓글 키워드**와 **인스타 캐러셀 각도**까지 예측하여 **구글 시트**에 구조화하는 것이 핵심입니다. 

이 시스템은 **PlayMCP**와 같은 외부 도구(MCP)들을 **Claude**에 연결하여 마치 하나의 워크플로우처럼 작동하게 만듭니다. 아침에 일어나 슬랙 알림을 확인하면, 이미 12개의 트렌드가 수집되어 시트에 정리되어 있는 것을 볼 수 있습니다. 이 자동화된 데이터를 기반으로, 사용자는 **Claude**에게 직접 **인스타 캐러셀** 생성을 요청하여 콘텐츠 제작까지 이어갈 수 있습니다.

💰 유료 필요: Higgsfield MCP (캐러셀 이미지 생성), Zapier MCP (외부 앱 연동에 따라 요금제 상이)
✅ 무료 대안: PlayMCP만으로 1~2단계 자동화가 가능하며, Apify는 더 깊은 데이터 수집이 필요할 때 추가할 수 있습니다. 다만, 캐러셀 이미지 생성 등 일부 기능은 유료 도구 의존도가 높습니다.

## 따라하기
이 프로세스는 크게 3단계로 나뉘며, 각 단계별로 필요한 설정과 프롬프트를 정확히 이해하고 적용해야 합니다.

### 🛠️ 준비물 세팅
먼저 필요한 도구들을 준비하고 연결해야 합니다. 이 도구들은 **Claude**에 외부 기능을 추가하는 '콘센트'와 같습니다.

| 도구 | 역할 | 비용 | |
|---|---|---| |
| **Claude 예약 작업** | 매일 정해진 시각에 자동 실행 | 구독에 포함 |
| **PlayMCP (YouTubeData)** | 유튜브 검색·조회수·댓글 조회 | 무료 |
| **Apify MCP** | 유튜브 대량 수집 (선택) | 무료 크레딧 |
| **Google Sheets** | 결과 정리 — Zapier MCP를 통해 연결 | 무료 |
| **Zapier MCP** | 구글 시트 등 외부 앱을 Claude에 연결 | Zapier 요금제에 따름 |
| **Slack MCP** | 완료 알림 | 무료 |
| **Higgsfield MCP** | 캐러셀 이미지 생성 | 유료 |

**💡 중요:** **PlayMCP**만으로도 1, 2단계 자동화는 충분하며, **Apify**는 더 많이, 깊게 긁고 싶을 때만 추가하는 것이 효율적입니다.

### 🧱 0단계 · 시트 구조화 (가장 중요)
이 단계를 건너뛰면 AI가 매일 다른 형식으로 데이터를 채워 넣기 때문에, **구글 스프레드시트**를 미리 만들고 첫 행에 아래 컬럼을 정확하게 박아두는 것이 핵심입니다.

```
수집일 | 제목 | 채널 | 조회수 | 좋아요 | 댓글수 | 업로드일 | 링크 | 댓글 키워드 | 캐러셀 각도
```

*   **댓글 키워드**: 영상 댓글에서 사람들이 반복해서 묻는 핵심 질문을 요약합니다.
*   **캐러셀 각도**: 이 주제를 내 계정의 **인스타 캐러셀**로 바꾼다면 어떤 각도(관점)가 좋을지 예측하는 필드입니다. 이 두 필드가 이 시스템의 '진짜 가치'를 만듭니다.

### 🤖 1·2단계 · 예약 작업 프롬프트 설정 (자동화 핵심)
수집과 정리를 한 번에 처리하는 **Claude 예약 작업**을 만듭니다. 매일 오전 9시로 설정하고, 아래의 **프롬프트**를 그대로 붙여넣습니다. 이 프롬프트는 4가지 핵심 기능을 순차적으로 수행하도록 지시합니다.

```
[내 분야 키워드]로 유튜브 트렌드를 조사해서 시트에 정리하고 슬랙으로 알려줘.
1) 검색
- YouTubeData의 search_videos 로 위 키워드를 검색 (order는 viewCount)
- get_video_details 로 각 영상의 업로드일·조회수·좋아요·댓글수를 확인
- 업로드일이 7일보다 오래된 것은 제외
- 남은 것 중 조회수 상위 10개만 남길 것
2) 댓글 읽기
- 상위 10개 각각 get_video_comments 로 댓글을 읽고
- 사람들이 반복해서 묻는 것을 한 줄로 요약
3) 시트 정리
- 구글 시트 "[시트 이름]" 의 "[탭 이름]" 맨 아래에 추가
- 컬럼 순서: 수집일 / 제목 / 채널 / 조회수 / 좋아요 / 댓글수 / 업로드일 / 링크 / 댓글 키워드 / 캐러셀 각도
- 수집일은 오늘 날짜
- 캐러셀 각도는 그 주제를 인스타 캐러셀로 바꿀 때의 각도를 한 줄로
- 기존 행은 절대 덮어쓰지 말 것
4) 슬랙 알림
- "[채널명]" 채널에 보낼 것
- 오늘 수집한 개수
- 조회수 1~3위의 제목과 조회수
- 시트 링크
```

**⚠️ 반드시 수정해야 할 부분 (대괄호 안의 내용만 수정):**

| 수정할 부분 | 예시 | 설명 |
|---|---|---|
|[내 분야 키워드]| AI 자동화, 노코드 창업, 인스타 마케팅 | 분석하고 싶은 핵심 키워드 쉼표로 구분 |
|[시트 이름]| 유튜브 트렌드 수집 | 실제 구글 시트의 이름 |
|[탭 이름]| 2026 | 시트 내의 특정 탭 이름 |
|[채널명]| #콘텐츠-트렌드 | 슬랙 채널 이름 |

**🚨 필수 지시사항:** 프롬프트 내에 **"기존 행은 절대 덮어쓰지 말 것"** 이라는 문구를 포함하는 것이 매우 중요합니다. 이 지시가 없으면 매일 데이터가 덮어쓰여 누적 분석이 불가능해집니다.

### ✨ 3단계 · 사람의 개입 (최종 콘텐츠 생성)
이 단계는 **자동화할 수 없는 유일한 지점**입니다. 자동화된 시트를 열어 **조회수 순**으로 정렬된 주제 중, **내 브랜드 톤앤매너**에 가장 적합한 주제를 사람이 선택해야 합니다. 주제를 선택했다면, **Claude**에게 다음과 같이 요청합니다.

```
시트 [행 번호] 주제로 인스타 캐러셀 5장 만들어줘.
구성
1장 표지 — 이 주제로 얻는 결과를 한 줄로
2~4장 — 단계별 설명, 한 장에 메시지 하나
5장 — 팔로우와 댓글 유도
규칙
- 한 장에 텍스트 블록 4개 이하
- 제목 한 줄 14자 이하, 본문 한 줄 20자 이하
- 이미지는 Higgsfield nano_banana_pro 로 생성, 4:5 비율
- 글씨는 굵게, 작은 화면에서 읽히게
```

**하루 루틴 요약:**
*   **오전 9시**: 자동 (수집 → 시트 정리 → 슬랙 알림)
*   **일어난 뒤**: 수동 (슬랙 확인, 주제 1개 선택)
*   **그 직후**: 자동 (선택된 주제로 캐러셀 5장 생성)
*   **마지막**: 수동 (확인 및 업로드)
