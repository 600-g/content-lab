# AI 활용 만능 프롬프트 70개 모음집 (합병됨)

## 이게 뭔가요?
이 콘텐츠는 단순한 프롬프트 모음집을 넘어, 사용자가 AI의 성능을 최대한 끌어낼 수 있도록 **'무엇을, 어떤 형식으로, 무엇을 하지 말라'**까지 구체적으로 지정해 놓은 완성형 프롬프트 70가지의 집합체입니다. 회의록 정리부터 복잡한 데이터 분석, 마케팅 콘텐츠 생성까지, 하루의 업무 효율을 극대화하는 데 초점을 맞추고 있습니다. 

이 프롬프트들은 사용자가 복사하여 AI 채팅창에 붙여넣기만 하면 바로 사용할 수 있도록 설계되어 있으며, 결과물이 아쉬울 경우 '더 짧게', '표로'와 같은 **후속 요청(Follow-up Prompt)**까지 가이드하여 완성도를 높일 수 있게 돕습니다. 마치 AI 활용의 '만능 치트키'와 같습니다.

특히, 회의록이나 긴 메모를 AI에게 맡겨 핵심 내용을 빠르고 정확하게 파악할 수 있도록 돕는 프롬프트는 임원 비서처럼 중요한 정보만을 선별하여 정리해 주기 때문에, 회의 후 후속 조치를 신속하게 진행할 수 있습니다. 이 프롬프트는 **주요 결정 사항, 담당자별 액션 아이템(할 일, 기한 포함), 그리고 다음 회의까지 해결해야 할 미결 안건**으로 명확하게 구분하여 제시합니다. 추측 없이 원문에 기반한 정보만을 제공하며, 모호한 내용은 '확인 필요'로 표시하여 정확성을 높입니다.

💰 유료 필요: 해당 프롬프트 자체는 무료로 제공되나, 최적의 성능을 위해서는 **Claude Max**와 같은 고성능 모델 사용이 권장됩니다. ✅ 무료 대안: **Gemini**나 **ChatGPT** 등 최신 모델에서도 충분히 높은 성능을 경험할 수 있습니다.

## 따라하기
이 모음집은 크게 10가지 주제별로 분류되어 있으며, 각 주제별로 구체적인 프롬프트가 제공됩니다. 사용자는 원하는 기능을 선택하여 해당 프롬프트를 복사한 후, **[지시사항]** 부분에 자신의 내용을 붙여넣어 실행하면 됩니다. 프롬프트 사용의 일반적인 절차는 다음과 같습니다.

1.  원하는 프롬프트의 **[복사]** 버튼을 누릅니다.
2.  Fable 5 (또는 사용 중인 AI) 채팅창에 붙여넣습니다.
3.  맨 아래 **[여기에 붙여넣기]** 또는 **[회의 내용]** 자리에 여러분의 내용을 넣고 실행합니다.
4.  결과가 아쉬우면 **후속 요청(Follow-up Prompt)**을 활용합니다. (예: '더 짧게', '표로 정리해줘')

회의록/메모 요약 프롬프트의 경우:
```
너는 임원 비서다. 아래 회의 내용을 세 부분으로 정리해라. (1)핵심 결정사항 3~5개 (2)담당자별 액션 아이템(이름·할 일·기한 표) (3)다음 회의까지 미결 안건. 추측하지 말고 원문에 있는 것만 써라. 애매하면 '확인 필요'로 표시해라. [회의 내용] 여기에 붙여넣기
```

## 활용 예시
**예시 1: 신규 프로젝트 회의록 요약**

*   **입력:**
    ```
    [회의 내용]
    오늘 신규 프로젝트 A에 대한 논의가 있었습니다. 주요 안건은 다음과 같습니다. 첫째, 프로젝트 목표를 시장 점유율 5% 달성으로 설정하기로 했습니다. 둘째, 개발팀은 UX 개선에 집중하고, 마케팅팀은 사전 홍보 활동을 시작합니다. 각 팀별로 구체적인 실행 계획은 다음 주까지 제출하기로 했습니다. QA팀에서는 베타 테스트 일정을 다음 달 말로 확정했습니다. 다만, 예산 증액 건은 추가 검토가 필요합니다.
    ```

*   **결과:**
    ```
    (1) 핵심 결정사항:
    - 신규 프로젝트 A 목표: 시장 점유율 5% 달성
    - 개발팀: UX 개선 집중
    - 마케팅팀: 사전 홍보 활동 시작
    - QA팀: 베타 테스트 일정 확정 (다음 달 말)

    (2) 담당자별 액션 아이템:
    | 이름 | 할 일 | 기한 |
    |---|---|---|
    | 개발팀 | 구체적인 실행 계획 제출 | 다음 주까지 |
    | 마케팅팀 | 구체적인 실행 계획 제출 | 다음 주까지 |

    (3) 다음 회의까지 미결 안건:
    - 프로젝트 A 예산 증액 건 검토
    ```

**예시 2: 주간 팀 회의 메모 요약**

*   **입력:**
    ```
    [회의 내용]
    지난주 우리 팀 회의에서는 고객 피드백 분석 결과 공유와 다음 분기 마케팅 전략 수립이 논의되었습니다. 고객들은 UI가 복잡하다는 의견이 많아, 이 부분 개선이 시급합니다. 김대리는 다음 주까지 UI 개선 아이디어 3가지와 예상 소요 시간을 정리해오기로 했습니다. 박주임은 새로운 소셜 미디어 캠페인 컨셉 초안을 이번 주 금요일까지 마무리합니다. 다만, 캠페인 예산은 아직 확정되지 않았습니다. 다음 주 회의에서는 이 예산안을 논의해야 합니다.
    ```

*   **결과:**
    ```
    (1) 핵심 결정사항:
    - 고객 피드백 반영: UI 복잡성 개선 시급
    - 마케팅 전략: 새로운 소셜 미디어 캠페인 수립

    (2) 담당자별 액션 아이템:
    | 이름 | 할 일 | 기한 |
    |---|---|---|
    | 김대리 | UI 개선 아이디어 3가지 및 예상 소요 시간 정리 | 다음 주까지 |
    | 박주임 | 새로운 소셜 미디어 캠페인 컨셉 초안 마무리 | 이번 주 금요일까지 |

    (3) 다음 회의까지 미결 안건:
    - 캠페인 예산 확정 및 논의
    ```

## 💡 아이디어
이 프롬프트를 활용하여 팀별 주간 업무 보고, 고객 지원 티켓 요약, 또는 개인적인 회의 메모 정리 등 다양한 상황에서 정보의 효율성을 극대화할 수 있습니다. 특히, AI에게 단순히 요약을 넘어 구체적인 액션 아이템과 담당자, 기한까지 정리하도록 요청함으로써 업무 누락을 방지하고 생산성을 높이는 데 기여할 수 있습니다. 회의록 요약 기능을 업무 프로세스에 통합하면, 회의 내용을 간결하게 파악하고 즉각적인 실행 계획을 수립하는 데 큰 도움이 될 것입니다.
