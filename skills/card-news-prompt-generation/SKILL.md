# 카드뉴스 프롬프트 자동 생성 (합병됨)

## 이게 뭔가요?
Claude AI는 Anthropic에서 개발한 대화형 인공지능 모델로, 인간과 자연스럽게 대화하며 글쓰기, 분석, 아이디어 생성, 코딩 등 다양한 작업을 지원합니다. 특히 긴 문서를 이해하고 핵심만 깔끔하게 정리하는 능력이 뛰어나며, 사용자와의 대화를 통해 결과물을 개선할 수 있습니다.

이 가이드에서는 Claude AI를 사용하여 인스타그램 카드뉴스 콘텐츠를 제작하는 방법을 소개합니다. 다양한 디자인 템플릿을 활용하여 AI가 카드뉴스 레이아웃, 텍스트, 그리고 이미지까지 생성하도록 유도하는 프롬프트 작성법을 배울 수 있습니다. 별도의 디자인 툴 없이 AI만으로 퀄리티 높은 카드뉴스를 만들 수 있다는 장점이 있습니다.

## 디자인 템플릿 종류
총 6가지 디자인 템플릿을 제공합니다:
- 디자인1: 이미지, 텍스트 반반
- 디자인2: 전체 이미지 속 텍스트
- 디자인3: 이미지 중간, 아래 텍스트
- 디자인4: 숫자, 작은 이미지
- 디자인5: 왼쪽 텍스트, 오른쪽 이미지
- 디자인6: 왼쪽 이미지, 오른쪽 텍스트

각 디자인 템플릿은 고유한 레이아웃 규칙, 금지 요소, 그리고 Gemini 프롬프트 형식을 가지고 있어 사용자의 필요에 맞게 선택할 수 있습니다.

## 따라하기
Claude AI를 사용하여 카드뉴스를 제작하는 단계는 다음과 같습니다.

1.  **Claude AI 접속**: 제공된 링크를 통해 Claude AI 웹사이트에 접속합니다.
2.  **카드뉴스 프롬프트 복사 및 붙여넣기**: 원하는 디자인 템플릿의 카드뉴스 프롬프트를 복사하여 Claude AI의 입력창에 붙여넣습니다.
3.  **주제 및 계정 정보 입력**: 프롬프트 상단의 `[주제]`와 `[계정명]` 부분을 본인의 정보에 맞게 수정합니다.
4.  **컬러 추출**: 디자인 템플릿 설명에 따라, 첨부한 이미지나 컬러 조합에서 주조색, 보조색, 배경색을 추출하여 프롬프트에 적용합니다. 이는 카드뉴스의 전반적인 색감과 통일성을 결정하는 중요한 요소입니다.
5.  **Gemini 프롬프트 생성**: Claude AI는 입력된 주제와 컬러 정보를 바탕으로 Gemini에서 사용할 이미지 생성 프롬프트를 자동으로 만들어줍니다. 이 프롬프트는 카드뉴스 각 카드에 들어갈 이미지의 구체적인 묘사를 담고 있습니다.

### 디자인1 (이미지, 텍스트 반반) 카드뉴스 프롬프트 예시
```
[주제]에 대한 인스타그램 카드뉴스를 만들어줘.
계정명: @[계정명]
사이즈는 1080×1350px 기준이야.

── 컬러 추출 ──
첨부한 이미지(또는 아래 컬러 조합)에서
주조색 1개, 보조색 1개, 배경색 1개를 추출해줘.
추출한 컬러를 아래 역할에 적용해:

배경색 → 텍스트 블록 배경

주조색 → 포인트 강조 문구 컬러

보조색 → 본문 텍스트 컬러
모든 카드에 동일한 컬러 팔레트를 일관되게 유지해줘.

── 절대 금지 요소 (예외 없음) ──
① 카테고리 태그 / 필 뱃지 / 라벨

제목 위아래에 붙는 모든 작은 텍스트 요소

둥근 테두리나 배경이 있는 텍스트 박스
② 서브텍스트 / 소제목 / 부제

메인 텍스트 외 추가 설명 텍스트 일체
③ 모든 종류의 선(line) 요소

세로 포인트 바, 가로 구분선, 액센트 바

텍스트 위아래 장식용 선 전부
④ 페이지 번호
⑤ 이미지와 텍스트 블록 사이의 추가 장식 요소

── 카드 구성 ──
카드 수는 주제 분량에 맞게 자동으로 정해줘.

[ 1. 표지 카드 ]
들어가는 요소: 이미지 위(3/5) + 텍스트 블록 아래(2/5) + @계정명
그 외 다른 텍스트나 요소는 절대 추가하지 마.

상단 이미지 영역이 카드의 3/5를 차지

하단 텍스트 블록이 2/5를 차지

텍스트 블록 배경: 추출한 배경색 적용

텍스트 블록 안: 메인 제목 (상단) + @계정명 (하단 고정)

제목: 주제에 맞는 후킹 멘트로 자동 생성
(질문형 / 숫자형 / 반전형 / 공감형 중 가장 강한 스타일로 선택)

이미지 영역에 아래 형식으로 Gemini 프롬프트 삽입:

[GEMINI PROMPT]
"A [구체적 장면 묘사 — 주제와 직접 연관],
[감정/분위기], [구도/시점],
keep the lower area clear, main subject centered,
no text, no logos, 4:3 ratio, cinematic photo"

[ 2. 본문 카드 ]
들어가는 요소: 이미지 영역 + 포인트 강조 문구 + 본문 텍스트
그 외 다른 텍스트나 요소는 절대 추가하지 마.

레이아웃 자동 선택 규칙:
· 본문 텍스트 2줄 이하 → A / B / C 중 선택
· 본문 텍스트 3줄 이상 → A 또는 B만 선택
A: 이미지 위(3/5) + 텍스트 아래(2/5)
B: 텍스트 위(2/5) + 이미지 아래(3/5)
C: 이미지 좌(1/2) + 텍스트 우(1/2)

텍스트 블록 배경: 추출한 배경색 적용

포인트 강조 문구: 추출한 주조색 적용

본문 텍스트: 추출한 보조색 적용

이미지 영역에 아래 형식으로 Gemini 프롬프트 삽입:

[GEMINI PROMPT]
"A [카드 내용과 직접 연관된 구체적 장면],
[감정/분위기 묘사],
[구도 — close-up / wide / bird's eye 등],
[스타일 — cinematic photo / flat illustration /
3D render 중 내용에 맞게 선택],
no text, no logos, square format"

[ 3. 마무리 카드 ]
들어가는 요소: 이미지 영역 + CTA 문구 + @계정명
그 외 다른 텍스트나 요소는 절대 추가하지 마.

이미지 위(3/5) + 텍스트 블록 아래(2/5)

텍스트 블록 배경: 추출한 배경색 적용

CTA 문구: 주제에 맞게 자동 생성
(저장 유도 / 행동 유도 / 공유 유도 중 선택)

CTA 문구 컬러: 추출한 주조색 적용

텍스트 블록 안: CTA 문구 (상단) + @계정명 (하단 고정)

이미지 영역에 아래 형식으로 Gemini 프롬프트 삽입:

[GEMINI PROMPT]
"A [주제의 마무리/결론을 상징하는 구체적 장면],
[따뜻하거나 희망적인 분위기 묘사],
[구도], [스타일],
no text, no logos, square format"

── 공통 규칙 ──

모든 Gemini 프롬프트는 영어로 작성

언어: 한국어

이미지와 텍스트 블록 사이 선/구분선 절대 없음

스타일: 클린, 모던, 에디토리얼

과도한 장식 없이 정보 중심으로 구성

완성된 카드뉴스는 클릭하면 다음 카드로 넘어가는
토글 방식의 HTML로 출력해줘
```

*프롬프트 수정 시 고려사항*
- `[주제]`: 카드뉴스 내용을 가장 잘 나타내는 핵심 키워드 또는 문구로 변경하세요.
- `@[계정명]`: 본인의 소셜 미디어 계정명으로 변경하세요.
- 컬러 추출: 디자인의 통일성을 위해 제공된 컬러 팔레트 가이드라인을 따르는 것이 좋습니다.
- Gemini 프롬프트: 이미지의 구체적인 묘사를 추가하면 원하는 결과에 더 가까워질 수 있습니다.

## 활용 예시
**예시 1: 'AI 활용 팁' 카드뉴스 제작**
1.  **주제**: "AI 활용 꿀팁 5가지"
2.  **계정명**: "@aipioneer"
3.  **디자인 선택**: 디자인1 (이미지, 텍스트 반반)
4.  **컬러**: 레퍼런스 이미지에서 주조색(파란색), 보조색(회색), 배경색(흰색) 추출
5.  **Claude AI 입력**: 위 정보로 프롬프트 구성 후 입력
    → Claude AI가 카드 5개 분량의 텍스트와 각 카드에 맞는 Gemini 이미지 생성 프롬프트를 생성합니다.
    → Gemini 프롬프트 예시 (표지 카드): "A visually engaging flat illustration representing the concept of AI, with a sense of innovation and learning, centered subject with clear space at the bottom, no text, no logos, 4:3 ratio, cinematic photo"

**예시 2: '여행지 추천' 카드뉴스 제작**
1.  **주제**: "숨겨진 보석 같은 국내 여행지 3곳"
2.  **계정명**: "@travelholic_korea"
3.  **디자인 선택**: 디자인2 (전체 이미지 속 텍스트)
4.  **컬러**: 특정 여행지의 분위기를 나타내는 색상 조합(예: 주조색-하늘색, 보조색-베이지, 배경색-아이보리) 추출
5.  **Claude AI 입력**: 위 정보로 프롬프트 구성 후 입력
    → Claude AI가 각 여행지에 대한 설명과 함께 Gemini 프롬프트를 생성합니다.
    → Gemini 프롬프트 예시 (본문 카드): "A breathtaking wide shot of a hidden beach with crystal clear turquoise water and lush green cliffs, serene and inviting atmosphere, tranquil scenery, flat illustration, no text, no logos, square format"
