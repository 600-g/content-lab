# AI 카드뉴스 제작 가이드

💡 디자인 툴 없이 **Claude** 만으로 카드뉴스·캐러셀을 만듭니다. 한 장씩 공들일 땐 **디자인 템플릿 프롬프트 + Gemini 이미지**, 빨리 뽑을 땐 **힉스필드 MCP**, 대량·반복 제작은 **Claude Code 자동화 에이전트**로 갑니다.

## 이게 뭔가요?

Claude 는 Anthropic 이 만든 대화형 AI 로, 긴 자료를 이해해 핵심만 정리하고 대화로 결과물을 다듬는 데 강합니다. 이 능력을 카드뉴스 제작에 쓰면 **기획(후킹 제목·카드별 문구) → 레이아웃 → 이미지** 까지 AI 가 맡고, 사람은 주제·계정명·색만 정하면 됩니다. 결과는 **AI 티 안 나는**, 정보 중심의 클린한 카드뉴스가 목표입니다.

목적과 분량에 따라 방법이 셋으로 나뉩니다.

| 방법 | 언제 쓰나 | 입력 | 결과물 | 필요한 것 |
|---|---|---|---|---|
| A. 디자인 템플릿 프롬프트 | 브랜드 톤을 지키며 한 세트씩 공들여 만들 때 | 주제·계정명·(선택) 컬러 레퍼런스 | 클릭으로 넘기는 토글형 HTML 카드뉴스 + 카드별 Gemini 이미지 프롬프트 | Claude(무료/Pro) + Gemini(무료) |
| B. 힉스필드 MCP 자동 생성 | 프롬프트 없이 주제 한 줄로 빨리 뽑을 때, 프로필 사진도 같이 만들 때 | 주제 한 줄 또는 내 사진 | 생성된 이미지(카드뉴스·아바타·삽화) | Claude(Max 권장) + 힉스필드 커넥터 |
| C. 자동화 에이전트 | 시트·PDF 로 정리된 자료를 주기적으로 대량 변환할 때 | 엑셀 시트·구조화된 PDF | 레이아웃이 적용된 카드뉴스 PDF 또는 이미지 시퀀스 | Claude Code |

💰 **유료 필요**: Claude 는 무료 버전과 유료 버전(Claude Pro)이 있으며, 특정 기능이나 사용량 제한은 유료 버전에서 해제될 수 있습니다. 방법 B 는 클로드 Max 권장(무료 버전으로도 일부 기능 사용 가능)입니다.
✅ **무료 대안**: Gemini 는 무료로 사용할 수 있습니다. MCP 연동 없이도 Gemini, ChatGPT, Canva 등으로 수동 제작할 수 있습니다.

## 따라하기

### 방법 A. 디자인 템플릿 프롬프트로 한 세트씩 만들기

#### A-1. 디자인 템플릿 고르기

6가지 템플릿이 있고, 각각 레이아웃 규칙·금지 요소·Gemini 프롬프트 형식이 다릅니다.

| 템플릿 | 레이아웃 | 컬러 역할 (주조색 / 보조색 / 배경색) | 페이지 번호 |
|---|---|---|---|
| 디자인1 | 이미지, 텍스트 반반 | 포인트 강조 문구 / 본문 텍스트 / 텍스트 블록 배경 | 없음(금지) |
| 디자인2 | 전체 이미지 속 텍스트 | 강조 문구 / 본문 텍스트 / (배경색 없음 — 풀블리드 이미지) | 없음(금지) |
| 디자인3 | 이미지 중간, 아래 텍스트 | 소제목 라벨 / 본문 텍스트 / 전체 카드 배경 | 없음(금지) |
| 디자인4 | 숫자, 작은 이미지 | 메인 카피 / 서브 카피·페이지 번호 / 카드 전체 배경 | 모든 카드(01, 02, 03...) |
| 디자인5 | 왼쪽 텍스트, 오른쪽 이미지 | 메인 카피 / 서브 카피·페이지 번호 / 텍스트 컬럼 배경 | 모든 카드 |
| 디자인6 | 왼쪽 이미지, 오른쪽 텍스트 | 메인 카피 / 서브 카피·페이지 번호 / 텍스트 컬럼 배경 | 모든 카드 |

모든 템플릿은 **[주제]**, **계정명: @[계정명]**, **사이즈: 1080×1350px** 를 기준으로 하고, **표지 → 본문 → 마무리** 카드 3종으로 구성됩니다. 카드 수는 주제 분량에 맞게 자동으로 정해집니다.

**템플릿 공통 규칙**

- 모든 Gemini 프롬프트는 영어로 작성됩니다.
- 언어: 한국어 기준으로 작성됩니다.
- 스타일: 클린, 모던, 에디토리얼을 추구하며, 과도한 장식 없이 정보 중심으로 구성됩니다.
- 완성된 카드뉴스는 클릭하면 다음 카드로 넘어가는 토글 방식의 HTML 로 출력됩니다.

#### A-2. Claude 에 프롬프트 넣기

1. **Claude 접속**: Claude 웹사이트에 접속합니다.
2. **프롬프트 붙여넣기**: 고른 디자인 템플릿의 카드뉴스 프롬프트를 복사해 Claude 입력창에 붙여넣습니다.
3. **주제·계정 정보 수정**: 프롬프트 상단의 `[주제]` 와 `[계정명]` 을 본인 정보로 바꿉니다.
4. **(선택) 컬러 추출**: 레퍼런스 이미지를 첨부하거나 컬러 조합을 적어 주면, Claude 가 주조색·보조색·배경색을 뽑아 위 표의 역할대로 적용합니다. 카드뉴스 전체의 색감과 통일성을 결정하는 단계입니다.

#### A-3. 템플릿별 프롬프트

##### 디자인 1 (이미지, 텍스트 반반) — 전문

```
[주제]에 대한 인스타그램 카드뉴스를 만들어줘.
계정명: @[계정명]
사이즈는 1080×1350px 기준이야.

── 컬러 추출 ──
첨부한 이미지(또는 아래 컬러 조합)에서
주조색 1개, 보조색 1개, 배경색 1개를 추출해줘.
추출한 컬러를 아래 역할에 적용해:

배경색 → 텍스트 블록 배경

주조색 → 포인트 강조 문구 컬러

보조색 → 본문 텍스트 컬러
모든 카드에 동일한 컬러 팔레트를 일관되게 유지해줘.

── 절대 금지 요소 (예외 없음) ──
① 카테고리 태그 / 필 뱃지 / 라벨

제목 위아래에 붙는 모든 작은 텍스트 요소

둥근 테두리나 배경이 있는 텍스트 박스
② 서브텍스트 / 소제목 / 부제

메인 텍스트 외 추가 설명 텍스트 일체
③ 모든 종류의 선(line) 요소

세로 포인트 바, 가로 구분선, 액센트 바

텍스트 위아래 장식용 선 전부
④ 페이지 번호
⑤ 이미지와 텍스트 블록 사이의 추가 장식 요소

── 카드 구성 ──
카드 수는 주제 분량에 맞게 자동으로 정해줘.

[ 1. 표지 카드 ]
들어가는 요소: 이미지 위(3/5) + 텍스트 블록 아래(2/5) + @계정명
그 외 다른 텍스트나 요소는 절대 추가하지 마.

상단 이미지 영역이 카드의 3/5를 차지

하단 텍스트 블록이 2/5를 차지

텍스트 블록 배경: 추출한 배경색 적용

텍스트 블록 안: 메인 제목 (상단) + @계정명 (하단 고정)

제목: 주제에 맞는 후킹 멘트로 자동 생성
(질문형 / 숫자형 / 반전형 / 공감형 중 가장 강한 스타일로 선택)

이미지 영역에 아래 형식으로 Gemini 프롬프트 삽입:

[GEMINI PROMPT]
"A [구체적 장면 묘사 — 주제와 직접 연관],
[감정/분위기], [구도/시점],

A: 이미지 위(3/5) + 텍스트 아래(2/5)
B: 텍스트 위(2/5) + 이미지 아래(3/5)
C: 이미지 좌(1/2) + 텍스트 우(1/2)

텍스트 블록 배경: 추출한 배경색 적용

포인트 강조 문구: 추출한 주조색 적용

본문 텍스트: 추출한 보조색 적용

이미지 영역에 아래 형식으로 Gemini 프롬프트 삽입:

[GEMINI PROMPT]
"A [카드 내용과 직접 연관된 구체적 장면],

[구도 — close-up / wide / bird's eye 등],

3D render 중 내용에 맞게 선택],

텍스트 블록 안: CTA 문구 (상단) + @계정명 (하단 고정)

이미지 영역에 아래 형식으로 Gemini 프롬프트 삽입:

[GEMINI PROMPT]
"A [주제의 마무리/결론을 상징하는 구체적 장면],
[따뜻하거나 희망적인 분위기 묘사],
[구도], [스타일],

── 공통 규칙 ──

모든 Gemini 프롬프트는 영어로 작성

이미지와 텍스트 블록 사이 선/구분선 절대 없음

스타일: 클린, 모던, 에디토리얼

과도한 장식 없이 정보 중심으로 구성

완성된 카드뉴스는 클릭하면 다음 카드로 넘어가는
토글 방식의 HTML로 출력해줘
```

요점 정리
- **컬러 추출**: 주조색 → 강조 문구, 보조색 → 본문 텍스트, 배경색 → 텍스트 블록 배경
- **절대 금지 요소**: 카테고리 태그, 서브텍스트, 모든 종류의 선, 페이지 번호, 이미지/텍스트 분리 장식
- **표지 카드**: 이미지 위(3/5) + 텍스트 블록 아래(2/5) + @계정명. 제목은 후킹 멘트로 자동 생성
- **본문 카드**: 이미지 영역 + 포인트 강조 문구 + 본문 텍스트. 레이아웃은 텍스트 길이에 따라 자동 선택
- **마무리 카드**: 이미지 위(3/5) + 텍스트 블록 아래(2/5) + CTA 문구 + @계정명

##### 디자인 2~6 — 디자인 1 프롬프트를 바꿔 쓰기

디자인 2~6 은 디자인 1 프롬프트와 같은 틀(컬러 추출 → 절대 금지 요소 → 카드 구성 → 공통 규칙)에 아래 규격을 넣어 씁니다. 디자인 1 프롬프트를 복사한 뒤 `── 컬러 추출 ──` 의 역할 배정, `── 절대 금지 요소 ──`, `── 카드 구성 ──` 세 부분을 해당 디자인 내용으로 바꾸면 됩니다.

**디자인 2 (전체 이미지 속 텍스트)**
- **컬러 추출**: 주조색, 보조색 추출 (주조색: 강조 문구, 보조색: 본문 텍스트)
- **절대 금지 요소**: 카테고리 태그, 서브텍스트, 모든 종류의 선, 페이지 번호, 이미지/텍스트 구분 영역 (텍스트는 이미지 위에 직접 배치)
- **카드 구성**: 전체 이미지가 카드 전체를 덮는 풀블리드 구조
  - **표지 카드**: 풀블리드 이미지 + 그라디언트 오버레이 + 메인 제목 + @계정명. 제목은 이미지 위에 직접 배치
  - **본문 카드**: 풀블리드 이미지 + 그라디언트 오버레이 + 포인트 문구 + 본문 텍스트. 텍스트는 이미지 위에 직접 배치
  - **마무리 카드**: 풀블리드 이미지 + 그라디언트 오버레이 + CTA 문구 + @계정명

### 방법 B. 힉스필드 MCP 로 주제만 넣어 자동 생성

힉스필드(Higgsfield, 원문 표기 Hixfield)는 이미지 생성을 위한 **MCP & CLI** 기능을 제공합니다. Claude 에 커넥터로 붙이면 복잡한 프롬프트 없이 주제 한 줄이나 사진 한 장으로 이미지를 만들 수 있습니다.

1. **힉스필드에서 MCP 링크 복사**
   - 힉스필드에 접속합니다.
   - 상단 메뉴에서 `MCP & CLI` 를 클릭합니다.
   - `1번 MCP 링크` 를 복사합니다.
2. **Claude 에 커스텀 커넥터 추가**
   - Claude 에 접속해 `설정` 메뉴로 이동합니다.
   - `커스텀 커넥터 추가` 를 선택합니다.
   - 복사한 힉스필드 MCP 링크를 붙여넣습니다.
3. **모델 선택 후 요청**
   - Claude 모델에서 `sonnet5` 를 선택합니다.
   - **카드뉴스**: 만들고자 하는 카드뉴스의 주제만 넣고 생성을 요청합니다. 예: "AI 기술의 미래에 대한 카드 뉴스 3장 만들어줘."
   - **프로필 사진**: 내 사진을 첨부하고 간단한 단어로 명령합니다. 예: "이 사진을 AI 아바타 스타일로 만들어줘."
   - 두 경우 모두 힉스필드 MCP 에 자동으로 연결되어 결과물이 생성됩니다.

> 방법 A 의 템플릿 규칙(금지 요소·컬러 역할·1080×1350px)을 요청문에 덧붙이면 B 로 만든 결과물도 톤을 맞추기 쉽습니다.

### 방법 C. 시트·PDF 자료로 대량 자동화 (Claude Code 에이전트)

**원리**: Claude Code 환경에서 에이전트를 구축해, 입력된 구조화 데이터(예: 엑셀 시트)를 분석하고 카드뉴스 형식으로 자동 변환합니다. 핵심은 **데이터 입력 → 내용 추출/가공 → 시각적 레이아웃 구성** 의 자동화입니다.

1. **데이터 준비**: 카드뉴스에 들어갈 원본 데이터를 엑셀 시트나 구조화된 PDF 로 정리합니다. 주제별 핵심 키워드와 내용이 행·열로 나뉘어 있을수록 추출이 정확합니다.
2. **에이전트 설계**: Claude Code 에서 에이전트의 역할을 정의하고, 데이터 입력 및 콘텐츠 생성 로직을 설계합니다. 방법 A 의 템플릿 프롬프트(컬러 역할·금지 요소·카드 구성)를 에이전트의 디자인 규칙으로 넣으면 결과물 톤이 일정해집니다.
3. **자동화 구현**: 데이터가 입력되면 에이전트가 자동으로 내용을 추출하고, 카드뉴스에 적합한 텍스트와 레이아웃을 구성하도록 코드를 작성·테스트합니다.
4. **주기 실행(선택)**: Zapier/Make 같은 자동화 도구가 필요했던 반복 과정을 Claude Code + GitHub Actions 조합으로 대체해 정기 실행할 수 있습니다.
5. **사람 검수**: 생성된 이미지/PDF 의 최종 디자인은 반드시 사람이 확인합니다.

예시
- 입력: `[클로드 코드 마스터 시트 자료.xlsx]` (주제별 핵심 키워드 및 내용)
- 출력: `[카드뉴스 자동화 에이전트 실행 결과]` (시각적 레이아웃이 적용된 카드뉴스 PDF 또는 이미지 시퀀스)
